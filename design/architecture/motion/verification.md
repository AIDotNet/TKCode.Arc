# 动效验证

> 动效系统的数值对照、确定性测试与性能预算。测试的临时 / 常驻划分遵循 [测试规范](../../engineering/testing.md)。

## 1. 数值对照（Core.Tests，常驻）

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 预设换算 | `SpringSpec.FromVisual` 对 smooth / snappy / morph 的 k、c、ζ | 与 [弹簧引擎](spring-engine.md#3-与-motion-的换算) 表格一致（4 位有效数字） |
| 轨迹对照 | 用 Motion `spring()` 生成器离线导出参考采样（5 个预设 × 3 组初速度 × 60 个时间点），作为测试数据提交 | 位置误差 ≤ 1e-3（归一化位移） |
| 三种阻尼 | 欠阻尼、临界、过阻尼的解析解与高精度数值积分比较 | 误差 ≤ 1e-6 |
| 收敛判定 | 精细量与像素量两种阈值 | 收敛时刻与 Motion 参考相差 ≤ 1 帧（16.7ms） |
| 重定向连续性 | 在 t = 0.1s 改变目标 | 位置连续；速度误差 ≤ 1% |
| 大步长 | 一次推进 500ms | 结果与 16ms 子步推进一致 |

## 2. 确定性测试（Arc.Tests，常驻，关键路径）

使用 `ManualFrameClock` 与 Headless 平台：

| 测试 | 断言 |
|---|---|
| 首帧不动画 | 控件首次显示时属性直接为终值，没有活动的动效值 |
| 共享主题实例 | 两个 Switch 同时切换，各自的弹簧状态互不影响 |
| 快速反复切换 | 连续切换 5 次，速度连续，最终停在正确终值 |
| 等级 Off | 状态变化后同一帧即为终值 |
| 等级 Reduced | 空间运动直接到终值；进场有透明度淡入 |
| 分离 | 动画中途从可视树移除，值跳到终值，调度器不再请求帧 |
| 空闲 | 所有动画收敛后，调度器不再调用 `RequestAnimationFrame` |

## 3. 性能预算

| 指标 | 预算 | 测量方式 |
|---|---|---|
| 200 个变换弹簧同时运行 | UI 线程每帧推进 ≤ 2ms（Release，M 系列 Mac） | S0.6 基准；`ArcMotion.Diagnostics` |
| 空闲时 | 0 帧请求 | 调度器计数 |
| 每帧分配 | 推进路径零托管分配（复用 `MatrixTransform` 与 `BlurEffect`） | 基准中记录 GC 计数 |
| 宽高弹簧 | 单个组件的逐帧布局 ≤ 1ms | 在组件规格中按需测量 |
| 持续循环 | 不可见时 0 帧请求 | 隐藏窗口后检查 |

## 4. 视觉对照（验收用，不常驻）

- 在 Gallery 中录制关键动效（按压、开关、指示器滑动、高度展开、弹层进出），与 Arc 网站同一组件的录屏逐帧对比，确认曲线形状与时长一致。
- 每个组件进入"已实现"状态前完成一次对照，结论写入组件规格的"测试计划"。
