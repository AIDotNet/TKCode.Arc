## 何时使用

`FunnelChart` 展示一个群体在一系列有序步骤中如何缩小，以及在哪一步缩小得最多。色带逐步变窄，每一步都标出人数、留存率和离开的人数。

- **注册与新手引导**，用于产品分析页面，找出流失新用户最多的步骤。
- **结账流程**，用于店铺仪表盘，从购物车到付款，并用 `View` 比较不同流量来源。
- **销售管道**，用于 CRM，从线索到成交。
- **课程或教程完成情况**，每节课是一个步骤。
- **客服流程**，从打开聊天到解决问题。

## 何时不用

- **步骤没有固定顺序**，或者人们可以从任意步骤进入：用 `BarChart`。
- **某一时刻的占比**：用 `DonutChart`。漏斗的各步是嵌套关系，不是组成部分。
- **随时间的变化**：用 `LineChart`。一个漏斗表示一个时段，比较时段时每个时段用一个漏斗。
- **在多个步骤和分组之间精确查数**：用 `DataGrid`。
- **逐步上升的数值**，例如累计收入：漏斗会把每一步限制为不超过上一步，上升不会显示出来。用 `BarChart`。

## 用法

按顺序添加阶段。只有一个数字的阶段设置 `Value`。

```xml
<arc:FunnelChart xmlns:arc="https://github.com/AIDotNet/TKCode.Arc" Label="Checkout in May" Unit="carts">
    <arc:FunnelChart.Stages>
        <arc:FunnelStage Key="cart" Label="Filled a cart" Value="900" />
        <arc:FunnelStage Key="address" Label="Entered an address" Value="510" />
        <arc:FunnelStage Key="paid" Label="Paid" Value="330" />
    </arc:FunnelChart.Stages>
</arc:FunnelChart>
```

### 分组与视图

添加 `Segments`，并在每个阶段的 `Values` 中按分组顺序为每个分组给出一个数字。没有 `Values` 的阶段在每个分组中都计为零。

`View` 决定色带显示的内容：

| 视图 | 色带显示 |
|---|---|
| `total`（默认） | 所有分组合成一条色带，使用第一个系列色 |
| `split` | 每个分组一条色带，之间有间隙，使用各系列色 |
| 分组的键 | 只显示该分组，并重新缩放，让它的第一步占满色带。人数和比率也变为该分组的数值 |

其他名称显示总计。本页顶部的预览用 `SegmentedControl` 切换 `View`。系列色在四个分组之后会重复，所以分组请不要超过四个。

### 读取数字

每一步显示名称（最多两行）、人数、占上一步的比例，以及一个向下箭头和自上一步以来离开的人数。聚焦某一步时会增加一列高亮和一个提示框，其中有人数、相对上一步的留存率、相对第一步的留存率和流失人数。拆分视图还会列出每个分组。

某一步不可能大于上一步。较大的值会被限制为上一步的值（有分组时按分组分别限制），负数和非数字计为零，所以流失绝不会为负，留存率始终在 0 到 100% 之间。上一步为零时留存率为 0%。

当前视图的第一步为零或没有阶段时，图表显示 `EmptyLabel`，并且不能获得焦点。

### 格式

`ValueFormatter` 替换所有位置的数字格式：人数、流失、提示框和朗读内容。`Unit` 只由默认格式添加，以字母开头时前面加一个空格。百分比不受它影响。

```csharp
chart.ValueFormatter = value => value >= 1000 ? $"{value / 1000:0.#}k" : $"{value:0}";
```

### 方向与尺寸

`Orientation` 默认为 `Auto`：从左到右，图表窄于 420 px 时从上到下。`Horizontal` 和 `Vertical` 固定方向。`BandHeight` 设置从左到右时第一步的粗细。从上到下时，色带约占宽度的 42%，每一步高度固定。

### 在代码中读取当前步骤

`ActiveIndex` 是双向的，`ActiveIndexChanged` 会报告步骤及其数字。清除读数时，它们为 null 或零。

```csharp
chart.ActiveIndexChanged += (_, e) =>
{
    if (e.Index is not null)
    {
        status.Text = $"{e.Stage!.Label}: {e.RetentionFromPrevious:P0} of the previous step";
    }
};
```

### 更改数据

`FunnelStage` 和 `FunnelSegment` 是普通对象：图表不监听它们的属性。请给 `Stages` 赋一个新列表，或在可观察列表中添加和移除项。阶段和分组按 `Key` 匹配，保留下来的会形变到新的大小。

## 无障碍

- 图表是可获得焦点的分组。它的自动化名称是当前步骤的读数（步骤序号、名称、人数和两个留存率），没有当前步骤时是 `Label`。帮助文本包含读数或所有步骤的摘要，变化时以礼貌方式播报。
- 流失是箭头加数字，留存是百分比，所以没有任何信息只靠颜色传达。拆分视图还会在提示框中写出每个分组的名称。
- 焦点环跟随 `:focus-visible`。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` | 聚焦图表并读取第一步。图表为空时会被跳过 |
| `Right` / `Down` | 读取下一步 |
| `Left` / `Up` | 读取上一步 |
| `Home` / `End` | 读取第一步或最后一步 |
| `Escape` | 清除读数 |

## 动效

- 首次出现时，色带从中心线长出。
- 切换视图时，色带在同一个弹簧上形变，拆分视图的间隙随之张开和闭合。形变途中再次更改会保留每条边的速度。
- 发生变化的人数和比率会滚动：旧文字沿变化方向离开，新文字同时到来。
- 高亮和提示框在步骤之间沿各自的弹簧滑动。提示框始终留在图表内。
- 圆点只在图表位于屏幕内时运行，回到屏幕时保持原来的位置。

| 变化 | Full | Reduced | Off |
|---|---|---|---|
| 首次出现 | 色带从中心线长出 | 整个图表短暂淡入 | 立即绘制 |
| 视图或数据变化 | 色带沿弹簧形变，数字滚动 | 立即应用 | 立即应用 |
| 在步骤之间移动 | 高亮和提示框滑动 | 立即应用 | 立即应用 |
| 圆点 | 同时约 40 个，按真实流失离开 | 无 | 无 |

## 响应式行为

- `Orientation` 为 `Auto` 时，图表测量自身宽度，低于 420 px 时变为从上到下，所以在窄面板和手机上表现一致。此时阶段名称位于色带右侧。
- 提示框在该列旁边打开，靠近边缘时翻到另一侧。从上到下时，它在该步上方打开，靠近顶部时翻到下方。它始终保持在图表内。
- 触摸按下读取手指下的步骤，拖动会移动读数。图表既不处理也不捕获触摸，所以在 `ScrollViewer` 中纵向拖动仍会滚动页面，读数随之结束。
- 在狭窄空间使用 `Horizontal` 时，每列的文字会被裁剪到该列内；建议使用 `Auto`。

## 相关组件

- `BarChart` 用于没有顺序的分组。
- `DonutChart` 用于整体中的占比。
- `LineChart` 用于转化率随时间的变化。
- `Treemap` 用于按大小的细分。
- `DataGrid` 用于漏斗背后的精确数字。
