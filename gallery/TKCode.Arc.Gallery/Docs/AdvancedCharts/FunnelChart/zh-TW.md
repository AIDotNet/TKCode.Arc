## 何時使用

`FunnelChart` 呈現一個族群在一系列有序步驟中如何縮小，以及在哪一步縮小得最多。色帶逐步變窄，每一步都標出人數、留存率和離開的人數。

- **註冊與新手引導**，用於產品分析頁面，找出流失新使用者最多的步驟。
- **結帳流程**，用於商店儀表板，從購物車到付款，並用 `View` 比較不同流量來源。
- **銷售管道**，用於 CRM，從潛在客戶到成交。
- **課程或教學完成情形**，每堂課是一個步驟。
- **客服流程**，從開啟聊天到解決問題。

## 何時不用

- **步驟沒有固定順序**，或者使用者可以從任意步驟進入：用 `BarChart`。
- **某一時刻的占比**：用 `DonutChart`。漏斗的各步是巢狀關係，不是組成部分。
- **隨時間的變化**：用 `LineChart`。一個漏斗代表一個時段，比較時段時每個時段用一個漏斗。
- **在多個步驟和區隔之間精確查數**：用 `DataGrid`。
- **逐步上升的數值**，例如累計營收：漏斗會把每一步限制為不超過上一步，上升不會顯示出來。用 `BarChart`。

## 用法

依序加入階段。只有一個數字的階段設定 `Value`。

```xml
<arc:FunnelChart xmlns:arc="https://github.com/AIDotNet/TKCode.Arc" Label="Checkout in May" Unit="carts">
    <arc:FunnelChart.Stages>
        <arc:FunnelStage Key="cart" Label="Filled a cart" Value="900" />
        <arc:FunnelStage Key="address" Label="Entered an address" Value="510" />
        <arc:FunnelStage Key="paid" Label="Paid" Value="330" />
    </arc:FunnelChart.Stages>
</arc:FunnelChart>
```

### 區隔與檢視

加入 `Segments`，並在每個階段的 `Values` 中依區隔順序為每個區隔給一個數字。沒有 `Values` 的階段在每個區隔中都計為零。

`View` 決定色帶顯示的內容：

| 檢視 | 色帶顯示 |
|---|---|
| `total`（預設） | 所有區隔合成一條色帶，使用第一個系列色 |
| `split` | 每個區隔一條色帶，之間有間隙，使用各系列色 |
| 區隔的鍵 | 只顯示該區隔，並重新縮放，讓它的第一步占滿色帶。人數和比率也變為該區隔的數值 |

其他名稱顯示總計。本頁頂端的預覽用 `SegmentedControl` 切換 `View`。系列色在四個區隔之後會重複，所以區隔請不要超過四個。

### 讀取數字

每一步顯示名稱（最多兩行）、人數、占上一步的比例，以及一個向下箭頭和自上一步以來離開的人數。聚焦某一步時會增加一欄醒目提示和一個工具提示，其中有人數、相對上一步的留存率、相對第一步的留存率和流失人數。拆分檢視還會列出每個區隔。

某一步不可能大於上一步。較大的值會被限制為上一步的值（有區隔時依區隔分別限制），負數和非數字計為零，所以流失絕不會為負，留存率始終在 0 到 100% 之間。上一步為零時留存率為 0%。

目前檢視的第一步為零或沒有階段時，圖表顯示 `EmptyLabel`，並且不能取得焦點。

### 格式

`ValueFormatter` 取代所有位置的數字格式：人數、流失、工具提示和朗讀內容。`Unit` 只由預設格式加入，以字母開頭時前面加一個空格。百分比不受它影響。

```csharp
chart.ValueFormatter = value => value >= 1000 ? $"{value / 1000:0.#}k" : $"{value:0}";
```

### 方向與尺寸

`Orientation` 預設為 `Auto`：從左到右，圖表窄於 420 px 時從上到下。`Horizontal` 和 `Vertical` 固定方向。`BandHeight` 設定從左到右時第一步的粗細。從上到下時，色帶約占寬度的 42%，每一步高度固定。

### 在程式碼中讀取目前步驟

`ActiveIndex` 是雙向的，`ActiveIndexChanged` 會回報步驟及其數字。清除讀數時，它們為 null 或零。

```csharp
chart.ActiveIndexChanged += (_, e) =>
{
    if (e.Index is not null)
    {
        status.Text = $"{e.Stage!.Label}: {e.RetentionFromPrevious:P0} of the previous step";
    }
};
```

### 變更資料

`FunnelStage` 和 `FunnelSegment` 是一般物件：圖表不監看它們的屬性。請給 `Stages` 指派新清單，或在可觀察清單中新增和移除項目。階段和區隔依 `Key` 比對，保留下來的會變形到新的大小。

## 無障礙

- 圖表是可取得焦點的群組。它的自動化名稱是目前步驟的讀數（步驟序號、名稱、人數和兩個留存率），沒有目前步驟時是 `Label`。說明文字包含讀數或所有步驟的摘要，變化時以禮貌方式朗讀。
- 流失是箭頭加數字，留存是百分比，所以沒有任何資訊只靠顏色傳達。拆分檢視還會在工具提示中寫出每個區隔的名稱。
- 焦點環跟隨 `:focus-visible`。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` | 聚焦圖表並讀取第一步。圖表為空時會被略過 |
| `Right` / `Down` | 讀取下一步 |
| `Left` / `Up` | 讀取上一步 |
| `Home` / `End` | 讀取第一步或最後一步 |
| `Escape` | 清除讀數 |

## 動態效果

- 首次出現時，色帶從中心線長出。
- 切換檢視時，色帶在同一個彈簧上變形，拆分檢視的間隙隨之張開和閉合。變形途中再次變更會保留每條邊的速度。
- 發生變化的人數和比率會捲動：舊文字沿變化方向離開，新文字同時到來。
- 醒目提示和工具提示在步驟之間沿各自的彈簧滑動。工具提示始終留在圖表內。
- 圓點只在圖表位於螢幕內時執行，回到螢幕時保持原來的位置。

| 變化 | Full | Reduced | Off |
|---|---|---|---|
| 首次出現 | 色帶從中心線長出 | 整個圖表短暫淡入 | 立即繪製 |
| 檢視或資料變化 | 色帶沿彈簧變形，數字捲動 | 立即套用 | 立即套用 |
| 在步驟之間移動 | 醒目提示和工具提示滑動 | 立即套用 | 立即套用 |
| 圓點 | 同時約 40 個，依真實流失離開 | 無 | 無 |

## 回應式行為

- `Orientation` 為 `Auto` 時，圖表測量自身寬度，低於 420 px 時變為從上到下，所以在窄面板和手機上表現一致。此時階段名稱位於色帶右側。
- 工具提示在該欄旁邊開啟，靠近邊緣時翻到另一側。從上到下時，它在該步上方開啟，靠近頂端時翻到下方。它始終保持在圖表內。
- 觸控按下讀取手指下的步驟，拖曳會移動讀數。圖表既不處理也不擷取觸控，所以在 `ScrollViewer` 中縱向拖曳仍會捲動頁面，讀數隨之結束。
- 在狹窄空間使用 `Horizontal` 時，每欄的文字會被裁切到該欄內；建議使用 `Auto`。

## 相關元件

- `BarChart` 用於沒有順序的群組。
- `DonutChart` 用於整體中的占比。
- `LineChart` 用於轉換率隨時間的變化。
- `Treemap` 用於依大小的細分。
- `DataGrid` 用於漏斗背後的精確數字。
