## 何時使用

`RadarChart` 呈現幾個對象在同一組度量上的均衡情況。每個對象是一個封閉形狀，讀者一眼就能看出誰強、誰弱，再掃過各軸讀取準確數值。

- **技能評估**，例如幾位候選人的面試評分或團隊能力盤點。
- **產品比較**，三款產品依續航力、儲存空間、價格等各有刻度的度量評分。
- **前後對照**，例如服務在移轉前後的可靠性、成本與速度。
- **均衡檢查**，形狀本身就是結論：圓潤代表均衡，尖銳代表偏重某項。

圖表最適合不超過三個對象、五到八條軸。

## 何時不用

- **超過約四個對象**：形狀會互相遮擋。請使用分組的 `BarChart`，或為每個對象放一張小圖。
- **在單一度量上精確排名**：不同角度上的長度難以比較。請使用 `BarChart`。
- **隨時間的變化**：請使用橫軸為時間的 `LineChart`。
- **整體的組成部分**：請使用 `DonutChart`。雷達圖的各軸是彼此獨立的度量，不能相加。
- **有自然順序或可能為負的度量**：各軸圍成一圈，並從中心的零開始，序列或帶正負號的值會被誤讀。請使用 `SlopeChart` 或 `BarChart`。

## 用法

為圖表提供軸與系列，可以內嵌，也可以繫結。`Axes` 與 `Series` 初始是空清單，可在 XAML 中直接加入，也接受檢視模型提供的任意 `IList`。可觀察的清單會被追蹤。

### 結構

1. **網**：`Rings` 個環（圓形或多邊形，見 `GridShape`），每條軸一根輻條。
2. **軸標籤**：位於每根輻條的末端，依 `Axes` 的順序從頂端開始順時針排列。
3. **形狀**：每個系列一個帶填滿的封閉輪廓。顏色依系列順序取用，第一個來自強調色，每個系列還有自己的線條樣式。
4. **標記**：在目前的軸上，每個對象一個標記。
5. **提示**：位於軸標籤之外，並且始終在圖表之內，列出每個對象的線條樣式、名稱與數值。
6. **圖例**：在網的下方，顯示每個對象的線條樣式與名稱。

### 軸與系列

`RadarAxis` 有 `Key`、`Label` 與選用的 `Maximum`。`RadarSeries` 有 `Key`、`Label` 與 `Values`，每條軸一個 `RadarValue`，其 `Axis` 是軸的索引鍵。

| 型別 | 成員 | 說明 |
|---|---|---|
| `RadarAxis` | `Key` | 穩定的識別碼，供數值與 `ActiveAxis` 參照 |
| `RadarAxis` | `Label` | 軸末端的文字 |
| `RadarAxis` | `Maximum` | 這條軸外環處的值；為 null 時使用圖表的 `Maximum` |
| `RadarSeries` | `Key` | 穩定的識別碼，用於在更新之間比對形狀 |
| `RadarSeries` | `Label` | 圖例與提示中的名稱 |
| `RadarSeries` | `Values` | 各個 `RadarValue` |
| `RadarValue` | `Axis` | 軸的索引鍵 |
| `RadarValue` | `Value` | 數值；NaN 視為缺少 |

在程式碼中，系列可接受以軸為索引鍵的字典：

```csharp
chart.Axes = [new RadarAxis("speed", "Speed"), new RadarAxis("cost", "Cost", 500), new RadarAxis("reach", "Reach")];
chart.Series = [new RadarSeries("north", "North", new Dictionary<string, double> { ["speed"] = 70, ["cost"] = 320, ["reach"] = 55 })];
```

### 刻度、缺少的值與截斷

每條軸從中心的 0 延伸到外環的最大值：設定了 `RadarAxis.Maximum` 時用它，否則用圖表的 `Maximum`（預設 100）。超過最大值的數值畫在外環上，小於零的數值畫在中心；提示仍讀出原始數值。缺少的值或 NaN 畫在中心，在提示中顯示為破折號。

### 刻度各異的多個產品

為每條軸設定合適的 `Maximum`，再用 `ValueFormatter` 為每條軸加上對應的單位，它會收到數值及其軸。

### 替換對象

替換 `Series` 即可顯示另一個對象。保留 `Key` 的系列會變形到新數值。使用新索引鍵的系列會接管它在該位置替換掉的系列的形狀，因此替換比較中的第二個對象時它會變形。沒有來源的系列從中心長出。

```csharp
chart.Series = [maya, selectedCandidate];
```

### 格線形狀、環數與填滿

`GridShape` 繪製圓形（預設）或每條軸上有一個角的多邊形，後者適合軸較少的圖表。`Rings` 設定網的環數，`FillOpacity` 設定每個形狀的填滿強度。

```xml
<arc:RadarChart Label="Coverage" GridShape="Polygon" Rings="5" FillOpacity="0.3" Series="{Binding Regions}" Axes="{Binding Measures}" />
```

### 讀取一條軸

`ActiveAxis` 是正在讀取的軸的索引鍵，支援雙向繫結。`ActiveAxisChanged` 回報每次變化，帶有 `Key` 與 `Axis`，清除讀數時兩者都為 null。與任何軸都不相符的索引鍵不顯示讀數。

```csharp
chart.ActiveAxisChanged += (_, e) => readout.Text = e.Axis?.Label ?? "Sweep the axes to compare";
```

### 尺寸與圖例

`Size` 是網的最大直徑，預設 320。網會縮小以符合其方塊，圖表占據取得的寬度並讓網置中。如果頁面以其他方式標明了對象，可把 `IsLegendVisible` 設為 false。少於三條軸或沒有系列時，圖表顯示 `EmptyLabel`。

### 繫結到檢視模型

```xml
<arc:RadarChart Label="Team skills"
                Axes="{Binding Skills}"
                Series="{Binding Members}"
                ActiveAxis="{Binding SelectedSkill, Mode=TwoWay}" />
```

- `Skills` 與 `Members` 可以是 `RadarAxis`、`RadarSeries` 的陣列、清單或可觀察集合。
- 就地修改 `RadarValue` 不會被察覺；請替換系列或清單來更新圖表。

### 資料形狀與效能

軸與系列的索引鍵必須唯一，後出現的重複項會被忽略。圖表在一個控制項內自行繪製：變形期間幾何就地移動，不重新版面配置，因此在資料變化時讓圖表留在畫面上開銷很小。

### 內容指南

- **Label**：說明比較的內容，例如「Staff engineer panel scores」。
- **軸標籤**：一兩個短詞。較長的標籤會被截斷，寬度低於 360 時換成兩行。
- **系列標籤**：使用短名稱，它們與數值共用提示中的一行。

### 最佳實務

**建議**

- 控制在三個對象、五到八條軸以內。
- 把相關的度量放在相鄰位置，因為相鄰的軸決定輪廓。
- 刻度不明顯時，在標籤或格式化函式中寫明。

**避免**

- 比較面積：形狀的面積取決於軸的順序，請讀數值。
- 把越高越好的度量與越低越好的度量混在一起。

### 常見問題

**為什麼新對象沒有變形？** 只有當它替換的系列已不存在，且新系列占據其在 `Series` 中的位置時才會變形。如果插入到其他位置，它會從中心長出。

**數值可以為負嗎？** 讀數正確，但形狀停在中心，因為每條軸都從零開始。

## 無障礙

- 網是可聚焦的群組。它的自動化名稱是圖表的 `Label` 加上按鍵說明，讀取某條軸時會播報該軸及每個對象的數值，例如「Mentoring: Maya 64, Theo 83」。
- 沒有讀數時，說明文字會概括每個對象在每條軸上的數值。
- 除了顏色，還能透過名稱與線條樣式區分對象。每個圖例項目都是一個 Tab 停駐點，以對象及其線條樣式命名。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| `Tab` | 聚焦到網並讀取第一條軸，然後依序經過各圖例項目。取得焦點的圖例項目會把其形狀提到最前 |
| `Right` / `Down` | 讀取順時針方向的下一條軸 |
| `Left` / `Up` | 讀取上一條軸 |
| `Home` / `End` | 讀取第一條或最後一條軸 |
| `Escape` | 清除讀數 |

## 動態效果

- 替換對象時，其形狀在輕微回彈的彈簧上變形。
- 首次顯示時，網從中心展開。
- 標記與提示在各軸之間滑動，標記沿每個輪廓移動。
- 懸停或聚焦圖例項目時，其形狀提到最前，其他形狀變淡。
- 減少動態效果時，形狀立即切換，標記與提示立即移動，首次顯示為短暫淡入。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 替換對象 | 在回彈彈簧上變形 | 立即 | 立即 |
| 首次顯示 | 從中心展開 | 短暫淡入 | 立即 |
| 目前的軸變化 | 標記與提示滑動 | 立即 | 立即 |

## 響應式

- 網會縮小以符合取得的寬度與高度，且不會超過 `Size`。
- 寬度低於 360 時，標籤環收緊，軸標籤換成兩行。
- 提示在任何寬度下都留在圖表之內；標籤之外放不下時，移到標籤旁邊。
- 觸控螢幕按下時讀取手指所在的軸，拖曳時掃過其他軸。圖例會換到更多行。
