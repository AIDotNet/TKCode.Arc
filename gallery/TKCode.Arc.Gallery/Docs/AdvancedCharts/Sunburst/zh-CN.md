## 何时使用

`Sunburst` 同时展示总量如何在多个层级上分配。每一圈是树的一个层级，扇区的角度是它在中心节点中所占的比例，因此读者可以在同一个圆上既看到各部分，也看到部分中的部分，然后点击扇区，使其成为新的中心。

- **预算评审中的年度成本**：第一圈是部门，第二圈是成本类型，第三圈是供应商，点击即可查看某个部门的内部构成。
- **管理后台中的存储用量**：文件夹层层嵌套，中心显示当前文件夹的名称，并随读者在树中移动滚动显示总量。
- **按产品、领域和原因划分的客服工单**：三个不深的层级，占比比精确数值更重要。
- **按类别划分的家庭或项目支出**：顶层分组不多，图例在圆环旁给出精确金额。

## 何时不用

- **需要精确比较相近的数值**：人们判断角度不如判断长度准确。请用 `BarChart`。
- **只有一层**：单个圆环不需要缩放。请用 `DonutChart`。
- **大量小叶子节点都需要显示名称**：矩形比细长的圆弧更容易容纳标签。请用 `Treemap`。
- **随时间变化**：旭日图只展示某一时刻。请用 `LineChart` 或 `Streamgraph`。
- **逐项浏览大型树**：请用 `TreeView`；需要精确数值时用 `DataGrid`。

## 用法

把 `Root` 设为 `SunburstNode` 对象组成的树，或者直接内联写出顶层节点。节点包含 `Id`、`Label`、叶子节点的 `Value` 以及 `Children`。分支的值始终是其子节点之和。

```csharp
chart.Label = "Annual costs";
chart.ValueFormatter = v => $"${v:#,0}K";
chart.Root = new SunburstNode("all", "All costs", children:
[
    new SunburstNode("people", "People", children:
    [
        new SunburstNode("crew", "Crew", 2060),
        new SunburstNode("shore", "Shore staff", 430)
    ]),
    new SunburstNode("fleet", "Fleet", 2975)
]);
```

内联节点位于图表自动创建的根节点之下，根节点以 `Label` 命名。

### 结构

1. **面包屑**：从根节点到中心的路径。选择前面的层级即可缩小回到该层。
2. **圆环**：中心以下最多 `Depth` 层，厚度相同。顶层分支按数据顺序使用系列色相，下面每一层是其分支的更浅色调。
3. **中心**：当前节点的标签和总计，总计变化时数字滚动。点击中心缩小一层。
4. **弧上标签**：沿圆弧或横跨圆环显示，仅在文字放得下时才显示。其余标签保留在工具提示中。
5. **图例**（`IsLegendVisible`）：中心的子节点及其数值和在中心中的占比。
6. **工具提示**：扇区的路径、数值和在父节点中的占比。

### 受控焦点

`FocusedId` 是中心节点的 id，并且是双向的。`null` 表示根节点，因此缩小回根节点时会写入 `null`。设为叶子节点的 id 时，中心显示其父节点，因为叶子节点没有可展开的内容；不在树中的 id 会显示根节点。`FocusedIdChanged` 报告每一次移动，包含新节点及其原因。

<Demo name="ControlledFocus" />

```xml
<arc:Sunburst Label="Annual costs"
              Root="{Binding Costs}"
              FocusedId="{Binding CentreId, Mode=TwoWay}" />
```

```csharp
chart.FocusedIdChanged += (_, e) =>
    status.Text = $"{e.Node.Label} from {e.ChangeSource}";
```

事件参数中的 `Id` 始终是真实的 id，在根节点时是根节点自己的 id。`ChangeSource` 是 `Segment`、`Breadcrumb`、`Legend`、`Center` 或 `Code`。

### 深度与图例

`Depth` 设置同时显示的圈数。各圈平分中心孔到边缘之间的空间，因此当中心以下的层级少于 `Depth` 时，圆环会变厚以填满整个圆。`IsLegendVisible="False"` 把全部宽度留给圆环。`Size` 是最大直径，圆环会缩小以适应容器。

### 格式与空状态

`ValueFormatter` 用于中心、图例、工具提示和无障碍朗读。默认格式对数字分组，最多保留一位小数。格式化文本中第一个数字的各位会滚动，其余文字保持不动，所以 `$1,284K` 滚动的是 `1,284`。不含数字的格式化值以纯文本显示。

总计为零时，图表在空圆环中显示 `EmptyLabel`，并隐藏面包屑和图例。

### 数据形状与性能

每次数据变化只计算一次布局，每段圆弧由图表自行绘制，因此几百个节点也能保持流畅。请为每个节点提供稳定且唯一的 `Id`：替换 `Root` 时，保留 id 的节点会移动到新的角度。没有 id 的节点按其在树中的位置获得一个 id，重复的 id 会被跳过。要显示变化后的数值，请替换 `Root`，因为图表不会监听节点的子节点。负值和缺失值按零计算。扇区按数据顺序排列。

## 无障碍

- `Label` 为图表命名。各圈是一个可聚焦的分组，也是礼貌的实时区域，其名称给出当前中心和可用的按键。
- 扇区获得焦点时，自动化名称朗读其路径、数值和在父节点中的占比，例如“People, Crew, $2,060K, 82.7% of People”。
- 图例行是按钮，以标签、数值和占比命名，每一行都是一个 Tab 停靠点。
- 面包屑是导航地标，其最后一项公开为当前层级。
- 色相从来不是唯一的信号：标签、图例和朗读内容都提供相同的信息。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` | 聚焦圆环并高亮第一个扇区，然后依次到图例行 |
| `Left` / `Right` | 上一个或下一个同级节点，循环移动 |
| `Home` / `End` | 第一个或最后一个同级节点 |
| `Down` | 第一个子节点；如果它超出最后一圈，中心随之移动 |
| `Up` | 父节点；在第一圈时缩小一层 |
| `Enter` / `Space` | 放大到获得焦点的分支，并聚焦其第一个子节点 |
| `Escape` / `Backspace` | 缩小一层并聚焦刚离开的节点；在根节点时清除高亮 |

在叶子节点上按 Enter 没有作用，因为叶子节点没有可展开的子节点。

## 动效

- 每段圆弧在同一个共享弹簧上移动到新的角度和半径，因此一次缩放读起来是一个动作。打断缩放时，每段圆弧保留其速度。
- 层级出现或离开时圆环改变大小，离开的圆弧向中心或外缘收拢。
- 弧上标签在圆弧移动时淡出，稳定后淡入。
- 首次进入视图时，圆弧从 12 点钟方向顺时针展开，中心的数字向上滚动。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 放大或缩小 | 圆弧在约 0.62 s 的弹簧上移动 | 圆弧直接跳转；标签淡入 | 立即完成 |
| 数据变化 | 圆弧移动到新的角度；总计滚动 | 圆弧直接跳转；标签淡入 | 立即完成 |
| 首次进入视图 | 圆弧在约 0.9 s 的弹簧上展开 | 图表淡入 | 立即完成 |
| 工具提示 | 以灵敏的弹簧跟随指针 | 立即完成 | 立即完成 |

## 响应式

- 图表读取自身宽度，而不是窗口宽度。能同时容纳圆环和旁边 `LegendMinWidth`（200 px）时，图例位于右侧，否则移到圆环下方。
- 圆环直径不超过 `Size`，并会缩小以适应空间。位于圆环旁的图例行数超过圆环高度时可以滚动。
- 轻点与点击相同：在分支上放大，在叶子节点上显示工具提示。轻点中心或面包屑可以缩小。

## 相关组件

- `Treemap`：包含大量需要标签的叶子节点的层级结构。
- `DonutChart`：只有一层的组成部分。
- `Breadcrumb`：图表之外的导航路径。

| 组件 | 何时选择 |
|---|---|
| `Treemap` | 树有许多小叶子节点，面积比角度更易读 |
| `DonutChart` | 只有一层，占比就是要传达的信息 |
| `BarChart` | 数值相近且必须精确比较 |
| `TreeView` | 读者逐项浏览树 |
| `DataGrid` | 读者需要每个节点的精确数值 |
