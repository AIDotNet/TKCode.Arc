## 何時使用

`Sunburst` 同時呈現總量如何在多個層級上分配。每一圈是樹的一個層級，扇區的角度是它在中心節點中所佔的比例，因此讀者可以在同一個圓上既看到各部分，也看到部分中的部分，然後點擊扇區，使其成為新的中心。

- **預算審查中的年度成本**：第一圈是部門，第二圈是成本類型，第三圈是供應商，點擊即可查看某個部門的內部組成。
- **管理主控台中的儲存用量**：資料夾層層巢狀，中心顯示目前資料夾的名稱，並隨讀者在樹中移動捲動顯示總量。
- **依產品、領域和原因劃分的客服工單**：三個不深的層級，佔比比精確數值更重要。
- **依類別劃分的家庭或專案支出**：頂層群組不多，圖例在圓環旁提供精確金額。

## 何時不用

- **需要精確比較相近的數值**：人們判斷角度不如判斷長度準確。請用 `BarChart`。
- **只有一層**：單一圓環不需要縮放。請用 `DonutChart`。
- **大量小葉節點都需要顯示名稱**：矩形比細長的圓弧更容易容納標籤。請用 `Treemap`。
- **隨時間變化**：旭日圖只呈現某一時刻。請用 `LineChart` 或 `Streamgraph`。
- **逐項瀏覽大型樹狀結構**：請用 `TreeView`；需要精確數值時用 `DataGrid`。

## 用法

將 `Root` 設為 `SunburstNode` 物件組成的樹，或直接內嵌寫出頂層節點。節點包含 `Id`、`Label`、葉節點的 `Value` 以及 `Children`。分支的值始終是其子節點的總和。

```csharp
chart.Label = "Annual costs";
chart.ValueFormatter = v => $"${v:#,0}K";
chart.Root = new SunburstNode("all", "All costs", children:
[
    new SunburstNode("people", "People", children:
    [
        new SunburstNode("crew", "Crew", 2060),
        new SunburstNode("shore", "Shore staff", 430)
    ]),
    new SunburstNode("fleet", "Fleet", 2975)
]);
```

內嵌節點位於圖表自動建立的根節點之下，根節點以 `Label` 命名。

### 結構

1. **麵包屑**：從根節點到中心的路徑。選擇前面的層級即可縮小回到該層。
2. **圓環**：中心以下最多 `Depth` 層，厚度相同。頂層分支依資料順序使用系列色相，下面每一層是其分支的較淺色調。
3. **中心**：目前節點的標籤和總計，總計變化時數字捲動。點擊中心縮小一層。
4. **弧上標籤**：沿圓弧或橫跨圓環顯示，僅在文字放得下時才顯示。其餘標籤保留在工具提示中。
5. **圖例**（`IsLegendVisible`）：中心的子節點及其數值和在中心中的佔比。
6. **工具提示**：扇區的路徑、數值和在父節點中的佔比。

### 受控焦點

`FocusedId` 是中心節點的 id，並且是雙向的。`null` 表示根節點，因此縮小回根節點時會寫入 `null`。設為葉節點的 id 時，中心顯示其父節點，因為葉節點沒有可展開的內容；不在樹中的 id 會顯示根節點。`FocusedIdChanged` 回報每一次移動，包含新節點及其原因。

<Demo name="ControlledFocus" />

```xml
<arc:Sunburst Label="Annual costs"
              Root="{Binding Costs}"
              FocusedId="{Binding CentreId, Mode=TwoWay}" />
```

```csharp
chart.FocusedIdChanged += (_, e) =>
    status.Text = $"{e.Node.Label} from {e.ChangeSource}";
```

事件參數中的 `Id` 始終是真實的 id，在根節點時是根節點自己的 id。`ChangeSource` 是 `Segment`、`Breadcrumb`、`Legend`、`Center` 或 `Code`。

### 深度與圖例

`Depth` 設定同時顯示的圈數。各圈平分中心孔到邊緣之間的空間，因此當中心以下的層級少於 `Depth` 時，圓環會變厚以填滿整個圓。`IsLegendVisible="False"` 將全部寬度留給圓環。`Size` 是最大直徑，圓環會縮小以符合容器。

### 格式與空狀態

`ValueFormatter` 用於中心、圖例、工具提示和無障礙朗讀。預設格式對數字分組，最多保留一位小數。格式化文字中第一個數字的各位會捲動，其餘文字保持不動，所以 `$1,284K` 捲動的是 `1,284`。不含數字的格式化值以純文字顯示。

總計為零時，圖表在空圓環中顯示 `EmptyLabel`，並隱藏麵包屑和圖例。

### 資料形狀與效能

每次資料變化只計算一次版面配置，每段圓弧由圖表自行繪製，因此數百個節點也能保持流暢。請為每個節點提供穩定且唯一的 `Id`：取代 `Root` 時，保留 id 的節點會移動到新的角度。沒有 id 的節點依其在樹中的位置取得一個 id，重複的 id 會被略過。要顯示變化後的數值，請取代 `Root`，因為圖表不會監聽節點的子節點。負值和缺失值以零計算。扇區依資料順序排列。

## 無障礙

- `Label` 為圖表命名。各圈是一個可聚焦的群組，也是禮貌的即時區域，其名稱提供目前中心和可用的按鍵。
- 扇區取得焦點時，自動化名稱朗讀其路徑、數值和在父節點中的佔比，例如「People, Crew, $2,060K, 82.7% of People」。
- 圖例列是按鈕，以標籤、數值和佔比命名，每一列都是一個 Tab 停駐點。
- 麵包屑是導覽地標，其最後一項公開為目前層級。
- 色相從來不是唯一的訊號：標籤、圖例和朗讀內容都提供相同的資訊。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` | 聚焦圓環並醒目提示第一個扇區，接著依序到圖例列 |
| `Left` / `Right` | 上一個或下一個同層節點，循環移動 |
| `Home` / `End` | 第一個或最後一個同層節點 |
| `Down` | 第一個子節點；如果它超出最後一圈，中心隨之移動 |
| `Up` | 父節點；在第一圈時縮小一層 |
| `Enter` / `Space` | 放大到取得焦點的分支，並聚焦其第一個子節點 |
| `Escape` / `Backspace` | 縮小一層並聚焦剛離開的節點；在根節點時清除醒目提示 |

在葉節點上按 Enter 沒有作用，因為葉節點沒有可展開的子節點。

## 動態效果

- 每段圓弧在同一個共用彈簧上移動到新的角度和半徑，因此一次縮放讀起來是一個動作。中斷縮放時，每段圓弧保留其速度。
- 層級出現或離開時圓環改變大小，離開的圓弧向中心或外緣收攏。
- 弧上標籤在圓弧移動時淡出，穩定後淡入。
- 首次進入檢視時，圓弧從 12 點鐘方向順時針展開，中心的數字向上捲動。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 放大或縮小 | 圓弧在約 0.62 s 的彈簧上移動 | 圓弧直接跳轉；標籤淡入 | 立即完成 |
| 資料變化 | 圓弧移動到新的角度；總計捲動 | 圓弧直接跳轉；標籤淡入 | 立即完成 |
| 首次進入檢視 | 圓弧在約 0.9 s 的彈簧上展開 | 圖表淡入 | 立即完成 |
| 工具提示 | 以靈敏的彈簧跟隨指標 | 立即完成 | 立即完成 |

## 響應式

- 圖表讀取自身寬度，而不是視窗寬度。能同時容納圓環和旁邊 `LegendMinWidth`（200 px）時，圖例位於右側，否則移到圓環下方。
- 圓環直徑不超過 `Size`，並會縮小以符合空間。位於圓環旁的圖例列數超過圓環高度時可以捲動。
- 輕觸與點擊相同：在分支上放大，在葉節點上顯示工具提示。輕觸中心或麵包屑可以縮小。

## 相關元件

- `Treemap`：包含大量需要標籤的葉節點的階層結構。
- `DonutChart`：只有一層的組成部分。
- `Breadcrumb`：圖表之外的導覽路徑。

| 元件 | 何時選擇 |
|---|---|
| `Treemap` | 樹有許多小葉節點，面積比角度更易讀 |
| `DonutChart` | 只有一層，佔比就是要傳達的訊息 |
| `BarChart` | 數值相近且必須精確比較 |
| `TreeView` | 讀者逐項瀏覽樹狀結構 |
| `DataGrid` | 讀者需要每個節點的精確數值 |
