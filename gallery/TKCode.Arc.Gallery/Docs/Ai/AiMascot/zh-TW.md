## 何時使用

`AiMascot` 給助理一張臉，用來呈現它正在做什麼。它是一顆柔和的鵝卵石，有兩隻膠囊形的眼睛、右下方一道安靜的陰影和一個小小的伴隨圓點。六種狀態各是一段沒有循環接縫的連續動作，而且每種狀態都會改變表情，所以在 24px 下也看得懂。

- **回覆標題與輸入框**：在助理名稱旁放一個 24 到 32px 的吉祥物，等待第一個 token 時思考，回覆串流輸出時跟著讀。
- **側邊面板**：在助理面板的標題裡放一個 40 到 64px 的吉祥物。
- **空白狀態**：一個 96 到 160px 的吉祥物，呼吸、眨眼，並在整個視窗內注視指標。
- **圖像畫布與耗時工作**：模型運作時用一個友善、有生氣的角色取代載入圈。

## 何時不用

- **需要呈現執行的步驟、工具和經過時間**：使用 `AgentStatus`。吉祥物呈現的是情緒，不是進度。
- **資訊密集的介面**：一行帶微光的「Thinking」比一個角色更不干擾。
- **已知進度**：知道百分比時使用進度列。

## 用法

```xml
<arc:AiMascot Status="Thinking" Size="24" AssistantName="Atlas" FollowPointer="Never" />
```

`AiMascot` 是 Special 套件中的 `TemplatedControl`（用 `UseArcSpecial()` 註冊）。把助理的階段對應到 `Status`：麥克風開啟 → `Listening`，等待第一個 token → `Thinking`，串流輸出 → `Writing`，完成 → `Done`，失敗 → `Error`，其他情況 → `Idle`。思考階段盡量短，收到第一個 token 就切換到書寫，讓吉祥物讀它寫下的內容。

不設定 `Status` 時，吉祥物會循環播放所有狀態（閒置、聆聽、思考、書寫、完成、出錯），每切換一次就引發 `StatusChanged`。這只用於展示；在產品中請一律設定 `Status`。

### 結構

1. **身體**：一顆柔和的鵝卵石，以底部中心為錨點。它繞著這個點呼吸、浮動、前傾和側傾。
2. **形體陰影**：右下邊緣一道安靜的月牙形陰影，讓身體有立體感。
3. **眼睛**：兩個膠囊形狀，會眨眼、張望、睜大、往上或往下看、閉成一條線，再變成開心的瞇眼。
4. **眉毛**：只在出錯狀態出現，內側端抬起。
5. **伴隨圓點**：在頭旁漂浮，像音量一樣跳動，繞頭旋轉，書寫，下垂，並變成完成時的閃光。
6. **地面**：柔和的接觸陰影和圓點寫下的線，只在 56px 以上繪製。

### 狀態

| Status | 表情 | 身體 | 圓點 |
|---|---|---|---|
| `Idle` | 每 2.4 到 5.2 秒眨一次眼，四處張望 | 呼吸並浮動 | 在頭旁漂移 |
| `Listening` | 眼睛睜大 | 往前靠近 | 像音量一樣跳動 |
| `Thinking` | 往上看並追隨圓點 | 歪頭 | 繞頭旋轉，從後方和前方經過 |
| `Writing` | 往下看並跟著讀 | 朝筆尖傾斜 | 寫下一行，然後提筆返回 |
| `Done` | 開心地瞇眼 | 稍微抬起 | 縮小，同時在原處長出一個閃光 |
| `Error` | 擔憂的眉毛，眼睛變小 | 搖晃一次 | 下垂並變暗 |

### 尺寸

`Size` 是以 px 為單位的寬和高，從 24（行內）到 160（空白狀態），預設 96。小於 56 時改用精簡畫法：取景更緊，眼睛、圓點和閃光更大，不畫地面。吉祥物是固定大小的正方形，從不跟隨容器尺寸，圖形在任何縮放下都保持清晰。

<Demo name="Sizes" />

### 色調與顏色

`Tone` 從主題中選擇身體顏色：`Accent`（強調色，眼睛用強調前景色）、`Ink`（前景色，眼睛用背景色）或 `Soft`（柔和的表面色加一條細框線，眼睛用前景色）。`BodyColor` 會覆寫色調；此時眼睛變成它的深色混合，除非設定了 `EyeColor`。`DotColor` 改變伴隨圓點和閃光的顏色。

<Demo name="Tones" />

### 跟隨指標

指標在吉祥物上方時眼睛會跟隨它（`FollowPointer="Hover"`，預設），或在整個視窗內跟隨（`Page`，適合空白狀態），或從不跟隨（`Never`）。觸控會被忽略。思考和書寫保持自己的視線。

<Demo name="EmptyState" />

### 伴隨圓點與地面

`ShowCompanion="False"` 隱藏圓點和閃光。`ShowGround="False"` 隱藏接觸陰影和寫下的線；小於 56px 時它們從不繪製。

### 暫停

`IsPaused` 讓吉祥物停在螢幕上的目前影格。它被捲出可視範圍、被隱藏或被移出視覺樹時也會自行暫停，恢復時從同一影格繼續，不會跳動。

### 減少動態效果

<Demo name="ReducedMotion" />

減少動態效果時，每個狀態都是一個靜止、具代表性的姿勢（眼睛往上、圓點在頭頂，寫了一半的線，瞇眼和閃光，眉毛），切換在原地完成，沒有循環、張望、眨眼或搖晃。指標跟隨關閉。沒有設定 `Status` 的吉祥物仍會在狀態之間輪替。

### 常見問題

**為什麼截圖測試裡吉祥物不動？** 測試和截圖通常在關閉動態效果的情況下執行；每個狀態此時顯示它的靜止姿勢。

**一個頁面能放多個吉祥物嗎？** 可以。每個都有自己的時鐘，離開螢幕時暫停，並有自己的眨眼和張望節奏。最多為其中一個開啟 `Announce`。

## 無障礙

- 圖形是一張圖像，它的名稱由助理名稱和狀態組成，例如「Atlas, thinking」，並隨每次狀態變化更新。`Label` 取代整個名稱；`AccessibleLabel` 讀取目前使用的名稱。
- 開啟 `Announce` 後，狀態變化會透過圖像之外的禮貌型即時區域朗讀。每個畫面只在一個吉祥物上使用，避免螢幕閱讀器重複朗讀。
- 狀態從不只靠動作表達：每個狀態都會改變表情（睜大的眼睛、往上看、往下看、開心的瞇眼、擔憂的眉毛）和名稱。狀態重要時，請在旁邊顯示文字狀態。
- 指標跟隨會忽略觸控，並在減少動態效果時關閉。

## 動態效果

- 每個狀態都是時間的連續函數（緩慢正弦波之和、一個軌道角度、一個起點和終點長度都為零的書寫週期），因此循環從不重新開始，也沒有接縫。
- 狀態切換在約 420ms 內把舊姿勢混合到新姿勢，沒有回彈。每個狀態的權重由一個臨界阻尼彈簧驅動，所以混合進行中再次切換時，會從螢幕上的目前影格開始並保持速度。首次繪製是靜止姿勢，循環在同樣的 420ms 內從它緩出。
- 眼睛由自己的臨界阻尼彈簧驅動：閒置時快速掃視，思考時柔和跟隨，書寫時緊密追蹤。沒有任何回彈。
- 完成時眼睛先閉成一條線再變成開心的瞇眼，同時圓點縮小、閃光在原處長出。出錯時搖晃一次，約 0.7 秒內平息。
- 圓點在身體後方和前方各畫一次，只在軌道兩端、離開身體的位置切換圖層。它從前方經過頭頂時會漸變為眼睛的顏色，以便在身體上保持可見。
- 每 2.4 到 5.2 秒眨一次眼，有時連眨兩次，每次 160ms。
- 時鐘只在吉祥物顯示時執行；離開螢幕時停止，並從同一影格恢復。減少動態效果時每個狀態顯示靜止姿勢，不做任何循環。
