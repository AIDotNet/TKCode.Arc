## 何时使用

`AiSpark` 是一个品牌级的标记，用来表示 AI 正在工作：四条渐细的主光线和四条较浅的斜向光线围绕着柔和的核心。每种状态都有自己的动效，每次切换都从标记当前所处的姿态过渡过去，状态之间从不生硬切换。

- **流式回复的上方**，表示助手正在思考或书写。
- **发送或生成按钮内部**，在输入框中变成工作指示。
- **图像或画布工具之上**，渲染进行时需要一个安静、带品牌感的工作标记。
- **空状态与新手引导**，用 64 到 96px 的大号标记给 AI 功能一个形象。

## 何时不用

- **确定的进度**，已知百分比时：使用进度条。
- **多步骤的智能体运行**，每一步都需要自己的状态与细节时：使用 `AgentStatus` 或 `AgentPlan`。
- **没有标记的纯文字加载行**：改用闪烁的文字标签。

## 用法

把流的生命周期对应到 `Status`：请求已发送或工具运行中为 `Thinking`，从第一个词元到最后一个为 `Generating`，完成为 `Done`，失败或中止为 `Error`。输入框再次就绪时回到 `Idle`。

```xml
<arc:AiSpark Variant="Pill" Status="{Binding Phase}" />
```

```csharp
spark.Status = AiSparkStatus.Thinking;   // request sent
spark.Status = AiSparkStatus.Generating; // first token
spark.Status = AiSparkStatus.Done;       // last token
```

不设置 `Status` 时，火花会自行依次播放空闲、思考、书写和完成。这只用于演示和营销页面；`EffectiveStatus` 报告它正在显示的那一步。

### 结构

1. **主光线**：位于四个轴向的渐细光线，使用标记的颜色。
2. **斜线**：主光线之间四条较短、较浅的光线；小于 18px 时变成圆点。
3. **核心**：较浅色调的柔和圆形。
4. **粒子**：书写时在光线外侧环绕的两个小点，40px 及以上才显示。
5. **标签**（仅胶囊）与**底块**（仅头像）。

### 状态

| 状态 | 动效 | 静止姿态（减少动效） |
|---|---|---|
| `Idle` | 整个标记以 6.4s 为周期呼吸，斜线轮流向外伸展 | 静止 |
| `Thinking` | 一道波峰每 1.9s 绕环一周；标记以每秒 26 度旋转 | 波峰停在顶部 |
| `Generating` | 每 1.04s 一次"扑通"心跳，两条轴依次搏动；每秒 46 度 | 更饱满的光线与核心 |
| `Done` | 光线向中心收拢后回到静止；旋转滑回原位 | 静止 |
| `Error` | 一次逐渐减弱的轻微摇晃；光线变短、斜线变暗、转为柔和的危险色 | 短光线，危险色 |

### 胶囊

<Demo name="Pill" />

`Variant="Pill"` 在一个 28px 高、带细边框的安静胶囊里加上状态标签（Ready、Thinking、Writing、Done、Couldn't finish）。标签交叉淡化，胶囊平滑过渡到新宽度；思考或书写时标签带有闪光。`Label` 用具体进度替换内置文字，例如 "Searching 4 sources"；保持一两个词。

### 头像

<Demo name="Avatar" />

`Variant="Avatar"` 把标记放在一个圆形、浅色着色的底块中，用于消息头像和图标按钮。`Size` 设置底块大小（默认 32），标记占其 56%。

### 嵌入文字

<Demo name="Inline" />

把 `Size` 设为文字大小，并设置 `Tone="Inherit"`，标记就会采用周围文字或按钮的颜色。

### 尺寸

<Demo name="Sizes" />

标记从 12px 到 120px 乃至更大都清晰锐利。光线粗细按渲染尺寸在对数刻度上做光学修正：小标记的光线更粗，小于 18px 时斜线变成圆点。标记在任何状态下占位都固定，绝不会挤动周围布局。

### 颜色

<Demo name="Tones" />

`Tone` 选择语义颜色：`Accent`（默认）、`Foreground`、`Muted` 或 `Inherit`。`MarkBrush` 可以用任意颜色覆盖它。斜线和核心始终使用同一颜色的较浅色调，出错时无论原本是什么颜色，都会过渡到柔和的危险色。

### 大号标记

<Demo name="Hero" />

64 到 96px 的空闲标记能给空状态一个形象。`Twinkle="False"` 让空闲标记完全静止。

### 速度与暂停

<Demo name="Playback" />

`Speed` 让所有循环与旋转速度成倍变化。`IsPaused` 让标记原地定格；恢复后从同一相位继续。

### 内容指南

- 胶囊标签用一两个词说明正在发生什么（"Searching 4 sources"、"Drawing"）。
- 每个进行中的生成只用一个动画火花。列表有很多行时，显示静止标记（`Status="Idle"`、`Twinkle="False"`），只让活动的那一行动起来。

### 最佳实践

- 把"停止"等控件放在火花旁边；火花本身不接受输入。
- 在装饰性的副本上设置 `Announce="False"`，让读屏软件只听到一个声音。

### 常见问题

**能传入 1em 这样的 CSS 长度吗？** 改为把 `Size` 设成周围文字的字号。

**不在屏幕上的火花有开销吗？** 没有。循环只在标记运动且位于屏幕内时运行，静止状态稳定后完全停止。

## 无障碍

- `Announce` 开启且设置了状态时，火花是一个礼貌型（polite）实时区域：状态变化只播报一次，标记读作 "AI is thinking"，胶囊读作标签文字。
- 设置 `Announce="False"` 时，以及自行播放期间，它以带可访问名称的图像呈现，装饰性副本因此保持安静。
- `AccessibleName` 替换名称；所有文字都在 `AiSparkLabels` 中。
- 状态从不只靠颜色区分：每种状态都有自己的形状与动效，出错时光线变短、斜线变暗，胶囊还有文字标签。

### 键盘

| 按键 | 操作 |
|---|---|
| 无 | 火花是状态指示，不获取焦点。把"停止"等控件放在它旁边。 |

## 动效

| 变化 | 完整 | 减少 | 关闭 |
|---|---|---|---|
| 空闲 | 6.4s 呼吸，斜线轮流向外伸展 | 静止 | 静止 |
| 思考 | 波峰每 1.9s 绕环一周，每秒 26 度旋转 | 静止姿态 | 静止姿态 |
| 书写 | 每 1.04s 一次心跳，每秒 46 度旋转，两个环绕粒子（40px 及以上） | 静止姿态 | 静止姿态 |
| 完成 | 光线 170ms 内收拢，510ms 内无回弹地回到静止；旋转以只减不增的缓出速度滑回原位 | 静止姿态 | 静止姿态 |
| 出错 | 460ms 内一次逐渐减弱的摇晃；色调在 320ms 内过渡到柔和的危险色 | 静止姿态，色调 200ms | 立即 |
| 状态切换 | 从当前姿态与速度出发约 480ms 过渡；被打断的过渡成为下一次的起点 | 200ms 过渡 | 立即 |
| 胶囊标签 | 旧标签 100ms 淡出，新标签 160ms 淡入并上升 2px，同时宽度平滑变化 | 短暂交叉淡化 | 立即 |

每个火花只有一个帧循环，原地更新八条光线路径、核心与变换，不产生任何分配。火花不在屏幕上或被隐藏时循环暂停，静止状态稳定后完全停止。收拢与摇晃即使状态再次改变也总会平滑地完成。
