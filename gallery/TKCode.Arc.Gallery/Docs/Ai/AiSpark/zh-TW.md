## 何時使用

`AiSpark` 是一個品牌級的標記，用來表示 AI 正在工作：四道漸細的主光線和四道較淺的斜向光線圍繞著柔和的核心。每種狀態都有自己的動態效果，每次切換都從標記目前所處的姿態過渡過去，狀態之間從不生硬切換。

- **串流回覆的上方**，表示助理正在思考或書寫。
- **傳送或產生按鈕內部**，在輸入框中變成工作指示。
- **影像或畫布工具之上**，算圖進行時需要一個安靜、具品牌感的工作標記。
- **空白狀態與新手導覽**，用 64 到 96px 的大型標記給 AI 功能一個形象。

## 何時不用

- **確定的進度**，已知百分比時：使用進度列。
- **多步驟的代理程式執行**，每一步都需要自己的狀態與細節時：使用 `AgentStatus` 或 `AgentPlan`。
- **沒有標記的純文字載入列**：改用閃爍的文字標籤。

## 用法

把串流的生命週期對應到 `Status`：請求已送出或工具執行中為 `Thinking`，從第一個詞元到最後一個為 `Generating`，完成為 `Done`，失敗或中止為 `Error`。輸入框再次就緒時回到 `Idle`。

```xml
<arc:AiSpark Variant="Pill" Status="{Binding Phase}" />
```

```csharp
spark.Status = AiSparkStatus.Thinking;   // request sent
spark.Status = AiSparkStatus.Generating; // first token
spark.Status = AiSparkStatus.Done;       // last token
```

不設定 `Status` 時，火花會自行依序播放閒置、思考、書寫和完成。這只用於示範和行銷頁面；`EffectiveStatus` 回報它正在顯示的那一步。

### 結構

1. **主光線**：位於四個軸向的漸細光線，使用標記的顏色。
2. **斜線**：主光線之間四道較短、較淺的光線；小於 18px 時變成圓點。
3. **核心**：較淺色調的柔和圓形。
4. **粒子**：書寫時在光線外側環繞的兩個小點，40px 以上才顯示。
5. **標籤**（僅膠囊）與**底塊**（僅頭像）。

### 狀態

| 狀態 | 動態效果 | 靜止姿態（減少動態效果） |
|---|---|---|
| `Idle` | 整個標記以 6.4s 為週期呼吸，斜線輪流向外伸展 | 靜止 |
| `Thinking` | 一道波峰每 1.9s 繞環一圈；標記以每秒 26 度旋轉 | 波峰停在頂部 |
| `Generating` | 每 1.04s 一次「撲通」心跳，兩條軸依序搏動；每秒 46 度 | 更飽滿的光線與核心 |
| `Done` | 光線向中心收攏後回到靜止；旋轉滑回原位 | 靜止 |
| `Error` | 一次逐漸減弱的輕微搖晃；光線變短、斜線變暗、轉為柔和的危險色 | 短光線，危險色 |

### 膠囊

<Demo name="Pill" />

`Variant="Pill"` 在一個 28px 高、帶細邊框的安靜膠囊裡加上狀態標籤（Ready、Thinking、Writing、Done、Couldn't finish）。標籤交叉淡化，膠囊平滑過渡到新寬度；思考或書寫時標籤帶有閃光。`Label` 用具體進度取代內建文字，例如 "Searching 4 sources"；保持一兩個詞。

### 頭像

<Demo name="Avatar" />

`Variant="Avatar"` 把標記放在一個圓形、淺色著色的底塊中，用於訊息頭像和圖示按鈕。`Size` 設定底塊大小（預設 32），標記佔其 56%。

### 嵌入文字

<Demo name="Inline" />

把 `Size` 設為文字大小，並設定 `Tone="Inherit"`，標記就會採用周圍文字或按鈕的顏色。

### 尺寸

<Demo name="Sizes" />

標記從 12px 到 120px 乃至更大都清晰銳利。光線粗細依算繪尺寸在對數刻度上做光學修正：小標記的光線更粗，小於 18px 時斜線變成圓點。標記在任何狀態下佔位都固定，絕不會擠動周圍版面。

### 顏色

<Demo name="Tones" />

`Tone` 選擇語意顏色：`Accent`（預設）、`Foreground`、`Muted` 或 `Inherit`。`MarkBrush` 可以用任意顏色覆寫它。斜線和核心一律使用同一顏色的較淺色調，出錯時無論原本是什麼顏色，都會過渡到柔和的危險色。

### 大型標記

<Demo name="Hero" />

64 到 96px 的閒置標記能給空白狀態一個形象。`Twinkle="False"` 讓閒置標記完全靜止。

### 速度與暫停

<Demo name="Playback" />

`Speed` 讓所有循環與旋轉速度成倍變化。`IsPaused` 讓標記原地定格；恢復後從同一相位繼續。

### 內容指南

- 膠囊標籤用一兩個詞說明正在發生什麼（"Searching 4 sources"、"Drawing"）。
- 每個進行中的產生只用一個動畫火花。清單有很多列時，顯示靜止標記（`Status="Idle"`、`Twinkle="False"`），只讓作用中的那一列動起來。

### 最佳做法

- 把「停止」等控制項放在火花旁邊；火花本身不接受輸入。
- 在裝飾性的副本上設定 `Announce="False"`，讓螢幕報讀器只聽到一個聲音。

### 常見問題

**能傳入 1em 這樣的 CSS 長度嗎？** 改為把 `Size` 設成周圍文字的字級。

**不在畫面上的火花有負擔嗎？** 沒有。循環只在標記運動且位於畫面內時執行，靜止狀態穩定後完全停止。

## 無障礙

- `Announce` 開啟且設定了狀態時，火花是一個禮貌型（polite）即時區域：狀態變化只播報一次，標記讀作 "AI is thinking"，膠囊讀作標籤文字。
- 設定 `Announce="False"` 時，以及自行播放期間，它以帶無障礙名稱的影像呈現，裝飾性副本因此保持安靜。
- `AccessibleName` 取代名稱；所有文字都在 `AiSparkLabels` 中。
- 狀態從不只靠顏色區分：每種狀態都有自己的形狀與動態效果，出錯時光線變短、斜線變暗，膠囊還有文字標籤。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| 無 | 火花是狀態指示，不取得焦點。把「停止」等控制項放在它旁邊。 |

## 動態效果

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 閒置 | 6.4s 呼吸，斜線輪流向外伸展 | 靜止 | 靜止 |
| 思考 | 波峰每 1.9s 繞環一圈，每秒 26 度旋轉 | 靜止姿態 | 靜止姿態 |
| 書寫 | 每 1.04s 一次心跳，每秒 46 度旋轉，兩個環繞粒子（40px 以上） | 靜止姿態 | 靜止姿態 |
| 完成 | 光線 170ms 內收攏，510ms 內無回彈地回到靜止；旋轉以只減不增的緩出速度滑回原位 | 靜止姿態 | 靜止姿態 |
| 出錯 | 460ms 內一次逐漸減弱的搖晃；色調在 320ms 內過渡到柔和的危險色 | 靜止姿態，色調 200ms | 立即 |
| 狀態切換 | 從目前姿態與速度出發約 480ms 過渡；被打斷的過渡成為下一次的起點 | 200ms 過渡 | 立即 |
| 膠囊標籤 | 舊標籤 100ms 淡出，新標籤 160ms 淡入並上升 2px，同時寬度平滑變化 | 短暫交叉淡化 | 立即 |

每個火花只有一個影格循環，原地更新八道光線路徑、核心與變換，不產生任何配置。火花不在畫面上或被隱藏時循環暫停，靜止狀態穩定後完全停止。收攏與搖晃即使狀態再次改變也總會平滑地完成。
