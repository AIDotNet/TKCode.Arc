## 何时使用

`CubeMascot` 是一个用真实三维数学绘制的助手角色：一个轮廓圆润的立方体，三个面按朝向光线的程度着色，正面画着一张脸。每种状态都会同时改变它的动效和表情。

- **表示助手正在生成**，用一个辨识度高、像产品一样的角色：放在回复标题、输入框、图像画布或空状态中。
- **几何感、技术感强的品牌**，柔软的团状角色会显得不协调时。

## 何时不用

- **需要更柔和圆润的角色**，或需要“聆听”状态时：改用卵石或幽灵风格的吉祥物。
- **需要展示一次运行的步骤、工具和耗时**：使用 `AgentStatus`。
- **已知百分比的进度**：使用进度条；立方体表示的是活动，不是进度。

## 用法

把助手的真实阶段映射到 `Status`：等待第一个 token 是 `Thinking`，流式输出是 `Writing`，结束是 `Done`，失败是 `Error`，其余为 `Idle`。实际使用时让思考阶段尽量短，收到第一个 token 就切换到书写。

```xml
<arc:CubeMascot Size="24" Status="{Binding Phase}" AssistantName="Atlas" />
```

```csharp
mascot.Status = CubeMascotStatus.Thinking; // request sent
mascot.Status = CubeMascotStatus.Writing;  // first token
mascot.Status = CubeMascotStatus.Done;     // last token
```

不设置 `Status` 时，立方体会循环播放空闲、思考、书写、完成和出错。这用于展示场景；`EffectiveStatus` 给出当前显示的状态，每一步都会触发 `StatusChanged`。

### 结构

1. **主体**：一个立方体，转到画着脸的一面略朝左，从上方 32 度俯视。它的轮廓是八个投影顶点的凸包，转角做了圆角。
2. **各个面**：顶面、脸所在的面和背光的侧面，各自按法线与左上方光源的夹角着色，所以一个面转开时会连续地变暗。
3. **表情**：眼睛、眉毛和嘴巴通过脸所在面的投影平面绘制，随该面一起透视缩短。
4. **地面**（56px 及以上）：接触阴影，以及书写时印在脸前方地面上的线条。
5. **闪光**：一颗四角星，完成时长大并旋转到位。

### 状态

| 状态 | 动效 | 表情 |
|---|---|---|
| `Idle` | 缓慢地倾斜、摇摆、浮动和张望，正弦组合永不重复；每 2.6 到 4.9 秒眨一次眼 | 睁眼，浅浅的微笑 |
| `Thinking` | 停 0.5 秒，然后在 0.8 秒内转四分之一圈，转动时微微升起并向转动方向倾斜 | 眼睛向上；脸在转到正面的那一面上淡入 |
| `Writing` | 脸向下低；每 360ms 一条线沿地面滑出；每四条线点一次头 | 眼睛向下，缓慢地左右扫视 |
| `Done` | 下沉一次后安顿下来；闪光长大、旋转到位，然后闪烁 | 眼睛合拢成开心的眯眼 |
| `Error` | 在 560ms 内摇晃 3.5 次后停稳 | 担忧的眉毛和皱眉的嘴 |

### 在回复标题中

<Demo name="ReplyHeader" />

在消息标题或输入框中内联使用 24 到 32px，在面板标题中用 40 到 64px，在空状态或正在生成的画布上用 96 到 160px。把 `AssistantName` 设为助手的名字，它会用在无障碍标签中。

### 尺寸

<Demo name="Sizes" />

`Size` 设置这个正方形的宽和高（默认 96）。小于 56px 时改用紧凑画法：立方体在画框中占得更多，眼睛更粗，没有嘴巴、阴影和印出的线条，所以在 24px 也能看清。这个正方形在各状态间大小不变，因此不会挤动周围的布局。

### 颜色

<Demo name="Colors" />

主体默认是强调色，表情默认是强调色上的前景色，所以立方体会在亮色和暗色下跟随主题与强调色。`BodyBrush` 和 `FaceBrush` 可以改变它们；顶面和背光侧面由主体颜色混合得到。`TopBrush`、`FrontBrush` 和 `SideBrush` 直接设置三个着色锚点，`LineBrush`、`ShadowBrush` 和 `SparkleBrush` 分别为印出的线条、接触阴影和闪光着色。`ShowsGround="False"` 去掉阴影和线条。

### 在画布上与暂停

<Demo name="EmptyState" />

`IsPaused` 把立方体冻结在当前帧。立方体在屏幕外或被隐藏时也会自动暂停，并从同一帧继续。

### 最佳实践

- 只为承载状态的那个吉祥物打开 `Announce`，装饰性的副本不要打开。
- 在状态重要的地方，在立方体旁边显示文字状态；立方体不接受输入，所以把“停止”等控件放在它旁边。
- 只在展示场景中不设置 `Status`。

## 无障碍

- 立方体呈现为一张图像，名称由助手的名字和状态组成，例如“Atlas, writing”，并随每个状态更新。`AccessibleName` 替换整个标签；所用的词都在 `CubeMascotLabels` 中。
- 打开 `Announce` 后，状态变化会在礼貌（polite）实时区域中朗读。每个视图只对一个吉祥物使用。
- 状态从不只靠动效表达：每种状态都会改变表情（眼睛向上、眼睛向下、开心的眯眼、担忧的眉毛和皱眉）以及标签。
- 在减弱动效下，每种状态都是一个静止的姿态，原地切换。

### 键盘

| 按键 | 操作 |
|---|---|
| 无 | 吉祥物是状态图像，不获取焦点。当用户需要对它显示的内容采取行动时，搭配一个真正的控件。 |

## 动效

| 变化 | 完整 | 减弱与关闭 |
|---|---|---|
| 空闲 | 倾斜、摇摆、浮动和张望由周期互不相称的慢速正弦叠加而成；每 2.6 到 4.9 秒眨一次 170ms 的眼，偶尔连眨两次 | 静止姿态 |
| 思考 | 停 0.5 秒，以三次缓入缓出在 0.8 秒内转 90 度，微微升起并向转动方向倾斜；离开的脸转到侧向时淡出，到来的脸淡入并睁开眼睛 | 静止，眼睛向上 |
| 书写 | 每 360ms 一条线从脸下沿地面滑出，持续 1.44 秒，只做淡入淡出；线条长度在不可见时改变；眼睛扫视，每四条线点一次头 | 静止，三条印出的线 |
| 完成 | 下沉一次后无过冲地停稳；眼睛经过一条闭合的线变成眯眼；闪光在 550ms 内长大、旋转到位，然后缓慢闪烁 | 静止的眯眼和闪光 |
| 出错 | 在平方包络下于 560ms 内摇晃 3.5 次，停下时速度为零 | 静止的眉毛和皱眉 |
| 状态切换 | 每个姿态值都从屏幕上的当前帧以缓入缓出在 420ms 内过渡（进入出错为 240ms）；转到一半时切换会继续向前转完 | 原地切换 |

立方体是真正的三维：每一帧都把八个顶点依次旋转（偏航、横滚、俯仰，然后是固定 32 度的相机）并投影。每个立方体一个帧循环，原地移动路径、重新着色画刷，所以每帧不分配内存。循环只在立方体位于屏幕内且可见时运行，时钟也只在此时前进，所以会从同一帧继续。停稳后的出错状态完全不循环，减弱动效下也没有任何循环。
