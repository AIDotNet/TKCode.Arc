## 何時使用

`CubeMascot` 是一個用真實三維數學繪製的助理角色：一個輪廓圓潤的立方體，三個面依朝向光線的程度著色，正面畫著一張臉。每種狀態都會同時改變它的動態效果和表情。

- **表示助理正在生成**，用一個辨識度高、像產品一樣的角色：放在回覆標題、輸入框、影像畫布或空狀態中。
- **幾何感、技術感強的品牌**，柔軟的團狀角色會顯得不協調時。

## 何時不用

- **需要更柔和圓潤的角色**，或需要「聆聽」狀態時：改用卵石或幽靈風格的吉祥物。
- **需要呈現一次執行的步驟、工具和耗時**：使用 `AgentStatus`。
- **已知百分比的進度**：使用進度列；立方體表示的是活動，不是進度。

## 用法

把助理的真實階段對應到 `Status`：等待第一個 token 是 `Thinking`，串流輸出是 `Writing`，結束是 `Done`，失敗是 `Error`，其餘為 `Idle`。實際使用時讓思考階段盡量短，收到第一個 token 就切換到書寫。

```xml
<arc:CubeMascot Size="24" Status="{Binding Phase}" AssistantName="Atlas" />
```

```csharp
mascot.Status = CubeMascotStatus.Thinking; // request sent
mascot.Status = CubeMascotStatus.Writing;  // first token
mascot.Status = CubeMascotStatus.Done;     // last token
```

不設定 `Status` 時，立方體會循環播放閒置、思考、書寫、完成和出錯。這用於展示情境；`EffectiveStatus` 提供目前顯示的狀態，每一步都會觸發 `StatusChanged`。

### 結構

1. **主體**：一個立方體，轉到畫著臉的一面略朝左，從上方 32 度俯視。它的輪廓是八個投影頂點的凸包，轉角做了圓角。
2. **各個面**：頂面、臉所在的面和背光的側面，各自依法線與左上方光源的夾角著色，所以一個面轉開時會連續地變暗。
3. **表情**：眼睛、眉毛和嘴巴透過臉所在面的投影平面繪製，隨該面一起透視縮短。
4. **地面**（56px 以上）：接觸陰影，以及書寫時印在臉前方地面上的線條。
5. **閃光**：一顆四角星，完成時長大並旋轉到位。

### 狀態

| 狀態 | 動態效果 | 表情 |
|---|---|---|
| `Idle` | 緩慢地傾斜、搖擺、浮動和張望，正弦組合永不重複；每 2.6 到 4.9 秒眨一次眼 | 睜眼，淺淺的微笑 |
| `Thinking` | 停 0.5 秒，然後在 0.8 秒內轉四分之一圈，轉動時微微升起並向轉動方向傾斜 | 眼睛向上；臉在轉到正面的那一面上淡入 |
| `Writing` | 臉向下低；每 360ms 一條線沿地面滑出；每四條線點一次頭 | 眼睛向下，緩慢地左右掃視 |
| `Done` | 下沉一次後安頓下來；閃光長大、旋轉到位，然後閃爍 | 眼睛闔成開心的瞇眼 |
| `Error` | 在 560ms 內搖晃 3.5 次後停穩 | 擔憂的眉毛和皺眉的嘴 |

### 在回覆標題中

<Demo name="ReplyHeader" />

在訊息標題或輸入框中內嵌使用 24 到 32px，在面板標題中用 40 到 64px，在空狀態或正在生成的畫布上用 96 到 160px。把 `AssistantName` 設為助理的名字，它會用在無障礙標籤中。

### 尺寸

<Demo name="Sizes" />

`Size` 設定這個正方形的寬和高（預設 96）。小於 56px 時改用精簡畫法：立方體在畫框中佔得更多，眼睛更粗，沒有嘴巴、陰影和印出的線條，所以在 24px 也能看清。這個正方形在各狀態間大小不變，因此不會擠動周圍的版面配置。

### 顏色

<Demo name="Colors" />

主體預設是強調色，表情預設是強調色上的前景色，所以立方體會在淺色和深色下跟隨主題與強調色。`BodyBrush` 和 `FaceBrush` 可以改變它們；頂面和背光側面由主體顏色混合而成。`TopBrush`、`FrontBrush` 和 `SideBrush` 直接設定三個著色錨點，`LineBrush`、`ShadowBrush` 和 `SparkleBrush` 分別為印出的線條、接觸陰影和閃光著色。`ShowsGround="False"` 去掉陰影和線條。

### 在畫布上與暫停

<Demo name="EmptyState" />

`IsPaused` 把立方體凍結在目前的影格。立方體在螢幕外或被隱藏時也會自動暫停，並從同一影格繼續。

### 最佳實務

- 只為承載狀態的那個吉祥物開啟 `Announce`，裝飾性的副本不要開啟。
- 在狀態重要的地方，在立方體旁邊顯示文字狀態；立方體不接受輸入，所以把「停止」等控制項放在它旁邊。
- 只在展示情境中不設定 `Status`。

## 無障礙

- 立方體呈現為一張影像，名稱由助理的名字和狀態組成，例如「Atlas, writing」，並隨每個狀態更新。`AccessibleName` 取代整個標籤；所用的詞都在 `CubeMascotLabels` 中。
- 開啟 `Announce` 後，狀態變化會在禮貌（polite）即時區域中朗讀。每個檢視只對一個吉祥物使用。
- 狀態從不只靠動態效果表達：每種狀態都會改變表情（眼睛向上、眼睛向下、開心的瞇眼、擔憂的眉毛和皺眉）以及標籤。
- 在減少動態效果下，每種狀態都是一個靜止的姿態，原地切換。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| 無 | 吉祥物是狀態影像，不取得焦點。當使用者需要對它顯示的內容採取行動時，搭配一個真正的控制項。 |

## 動效

| 變化 | 完整 | 減少與關閉 |
|---|---|---|
| 閒置 | 傾斜、搖擺、浮動和張望由週期互不相稱的慢速正弦疊加而成；每 2.6 到 4.9 秒眨一次 170ms 的眼，偶爾連眨兩次 | 靜止姿態 |
| 思考 | 停 0.5 秒，以三次緩入緩出在 0.8 秒內轉 90 度，微微升起並向轉動方向傾斜；離開的臉轉到側向時淡出，到來的臉淡入並睜開眼睛 | 靜止，眼睛向上 |
| 書寫 | 每 360ms 一條線從臉下沿地面滑出，持續 1.44 秒，只做淡入淡出；線條長度在不可見時改變；眼睛掃視，每四條線點一次頭 | 靜止，三條印出的線 |
| 完成 | 下沉一次後無過衝地停穩；眼睛經過一條閉合的線變成瞇眼；閃光在 550ms 內長大、旋轉到位，然後緩慢閃爍 | 靜止的瞇眼和閃光 |
| 出錯 | 在平方包絡下於 560ms 內搖晃 3.5 次，停下時速度為零 | 靜止的眉毛和皺眉 |
| 狀態切換 | 每個姿態值都從螢幕上的目前影格以緩入緩出在 420ms 內過渡（進入出錯為 240ms）；轉到一半時切換會繼續向前轉完 | 原地切換 |

立方體是真正的三維：每一影格都把八個頂點依序旋轉（偏航、橫滾、俯仰，然後是固定 32 度的相機）並投影。每個立方體一個影格迴圈，原地移動路徑、重新著色筆刷，所以每影格不配置記憶體。迴圈只在立方體位於螢幕內且可見時執行，時鐘也只在此時前進，所以會從同一影格繼續。停穩後的出錯狀態完全不循環，減少動態效果下也沒有任何迴圈。
