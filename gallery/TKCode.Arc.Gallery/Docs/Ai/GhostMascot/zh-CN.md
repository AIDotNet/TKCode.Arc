## 何时使用

`GhostMascot` 给助手一张轻松友好的脸，表明它正在做什么。一张柔软的布单带着起伏的下摆漂浮着，配有低调的形体阴影和两只简单的眼睛；每种状态都会改变脸和它的标记，所以在 24px 下依然清晰可辨。

- **在回复标题或输入框中**，放在助手名字旁边，表示它正在思考和书写。
- **在图像画布之上**，表示图片正在生成。
- **在空状态中**，用 96 到 160px 的幽灵给 AI 功能一个形象。
- **代替加载圈**，让生成过程显得生动。

## 何时不用

- **一次运行的步骤、工具与耗时**：使用 `AgentStatus`，而不只是一种情绪。
- **信息密集的界面**，角色会分散注意力时：一行闪烁的“Thinking”文字就够了。
- **已知进度**，有百分比时：使用进度条。

## 用法

把助手的真实阶段对应到 `Status`：麦克风打开为 `Listening`，等待第一个词元为 `Thinking`，流式输出为 `Writing`，完成为 `Done`，失败为 `Error`，其余为 `Idle`。实际使用中思考要短，收到第一个词元就切换到书写。

```xml
<arc:GhostMascot Size="24" Status="{Binding Phase}" AssistantName="Atlas" Announce="True" />
```

```csharp
ghost.Status = GhostMascotStatus.Thinking; // request sent
ghost.Status = GhostMascotStatus.Writing;  // first token
ghost.Status = GhostMascotStatus.Done;     // last token
```

不设置 `Status` 时，幽灵会循环演示每一种状态。这用于展示；`EffectiveStatus` 报告它正在显示的状态，每一步都会引发 `StatusChanged`，说明文字或控件可以随之更新。

### 结构

1. **布单**：圆顶的头部、略微外展的两侧，以及由两道行进波组成、带圆角的下摆。
2. **形体阴影**：布单右下方一块更深、半透明的同色调，裁剪在布单之内。
3. **眼睛**：两个椭圆，会张望、眨眼、睁大、向上看、跟随笔尖，变成开心的弧线或耷拉下来。
4. **标记**：思考的旋涡、书写的笔和它写出的线、完成时的闪光（以及一个小小的微笑）。
5. **地面**：柔和的漂浮阴影，56px 及以上才显示。

### 状态

<Demo name="States" />

| 状态 | 姿态与表情 | 标记 |
|---|---|---|
| `Idle` | 漂浮，每隔几秒眨一次眼，四处张望 | 无 |
| `Listening` | 向前靠近，睁大眼睛看着你，头微微歪向一侧 | 无 |
| `Thinking` | 向上飘起并变得半透明，眼睛慢慢向上看 | 一个旋涡，从外端画入，并在身后擦去 |
| `Writing` | 倾向那条线，眼睛盯着笔尖 | 小笔逐词写出一行，然后在擦除时滑回 |
| `Done` | 升起，眼睛变成开心的弧线，带一个小微笑 | 闪光旋转四分之一圈长出，然后轻轻闪烁 |
| `Error` | 摇晃一次，下沉，眼睛耷拉 | 无 |

### 在回复标题中

<Demo name="ReplyHeader" />

在回复标题或输入框中内联使用 24 到 32px。小于 56px 时改用紧凑画法：幽灵取景更紧，眼睛更大，旋涡、笔和线更粗，并且没有阴影，因此每种状态依然清晰可辨。

### 尺寸

<Demo name="Sizes" />

`Size` 设置宽度和高度（默认 96）：内联用 24 到 32，面板或图像画布上用 40 到 64，空状态用 96 到 160。幽灵是固定的正方形，从不让父级重新排版；它是矢量图形，在任何缩放下都保持清晰。

### 颜色

<Demo name="Tones" />

`Tone` 从主题中选取布单颜色：`Accent`（默认）配强调前景色的眼睛，并跟随主题强调色，包括 Arc 近乎中性的灰色；`Sheet` 是经典的浅色幽灵，凸起的表面加一条细线和前景色的眼睛，标记保持强调色；`Ink` 使用前景色，眼睛为背景色。`SheetBrush` 可设置任意颜色，除非设置了 `EyeBrush`，眼睛会变成它的深色混合。`MarkBrush`、`ShadeBrush` 和 `GroundBrush` 用于重设标记、形体阴影和地面阴影的颜色。

### 空状态

<Demo name="EmptyState" />

一只 `Sheet` 色调的大号空闲幽灵，给空屏幕一张平静友好的脸。

### 在图像画布上

<Demo name="Canvas" />

画布角落里一只 64px 的幽灵表示图片正在生成。幽灵不是立在某个表面上时，关闭 `ShowGround`。`IsPaused` 把它冻结在当前帧；恢复后从同一帧继续。

### 内容准则

- 把 `AssistantName` 设为助手的名字，让标签读起来自然（“Atlas, thinking”）。
- 在状态重要的地方，于幽灵旁边显示文字状态；幽灵增添个性，文字传达含义。

### 最佳实践

- 只为承载状态的那一只幽灵打开 `Announce`，装饰用的副本不要打开。
- 当用户要根据它显示的内容采取行动时，把幽灵和真正的控件（例如 Stop）放在一起；幽灵本身不接受输入。
- 只在展示时不设置 `Status`。

### 常见问题

**屏幕外的幽灵有开销吗？** 没有。它的帧循环在屏幕外或隐藏时暂停，时钟只在可见时运行，所以恢复时从同一帧继续，而不会跳变。

**可以重设样式吗？** 可以：`SheetBrush`、`EyeBrush`、`MarkBrush`、`ShadeBrush` 和 `GroundBrush` 接受任意纯色。

## 无障碍

- 幽灵呈现为一张图像，其标签由 `AssistantName` 和状态组成，例如“Atlas, thinking”，并随每种状态更新。`AccessibleName` 替换整个标签；所有文字都在 `GhostMascotLabels` 中。
- 打开 `Announce` 时，幽灵同时也是一个礼貌的实时区域，状态变化只朗读一次。每个视图只在一只幽灵上使用它，以免屏幕阅读器重复朗读。
- 状态从不只靠颜色或动效传达：每种状态都会改变表情和标记（睁大的眼睛、向上看的眼睛配旋涡、笔和线、开心的眼睛配闪光、耷拉的眼睛）以及标签。

## 动效

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 漂浮与下摆 | 缓慢漂浮；两道行进波让下摆起伏，下摆跟随漂浮滞后：上升时布单被拉长，下降时下摆抬起并张开 | 静止 | 静止 |
| 空闲 | 每 2.4 到 5.2 秒眨一次眼（160ms），以快速的扫视四处张望 | 静止，眼睛居中 | 静止 |
| 思考 | 旋涡从外端画入并在身后擦去，循环衔接处为空；眼睛慢慢向上看 | 画了一半的旋涡 | 画了一半的旋涡 |
| 书写 | 笔逐词写出这一行，词与词之间抬笔，然后在线条擦除时滑回；眼睛跟随笔尖 | 写了一半的线 | 写了一半的线 |
| 完成 | 闪光在 320ms 内以缓出旋转四分之一圈长出，然后缓慢闪烁 | 闪光 | 闪光 |
| 出错 | 摇晃一次，约 1.2 秒内衰减到静止，开头经过柔化，从不突然一抖 | 耷拉的姿态 | 耷拉的姿态 |
| 状态切换 | 每个姿态值从屏幕上的当前帧开始，以缓入缓出在 400ms 内过渡（保留其速度）；眼睛跟随一个临界阻尼弹簧 | 原地切换 | 原地切换 |

每个循环都是一个只增不减的相位的函数：漂浮、两道下摆波、旋涡和书写循环。速率通过积分进入这些相位来过渡，所以速度变化从不跳变，也没有任何东西重新开始。每只幽灵一个帧循环，用缓存的画刷和画笔就地移动布单路径的各点；它在屏幕外或隐藏时暂停。在减弱动效下，幽灵只在状态变化时重绘。
