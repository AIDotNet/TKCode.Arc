## 何時使用

`GhostMascot` 給助理一張輕鬆友善的臉，表明它正在做什麼。一張柔軟的布單帶著起伏的下襬漂浮著，搭配低調的形體陰影和兩隻簡單的眼睛；每種狀態都會改變臉和它的標記，所以在 24px 下依然清楚可辨。

- **在回覆標頭或輸入框中**，放在助理名字旁邊，表示它正在思考和書寫。
- **在影像畫布之上**，表示圖片正在產生。
- **在空狀態中**，用 96 到 160px 的幽靈給 AI 功能一個形象。
- **取代載入圈**，讓產生過程顯得生動。

## 何時不用

- **一次執行的步驟、工具與耗時**：使用 `AgentStatus`，而不只是一種情緒。
- **資訊密集的介面**，角色會分散注意力時：一行閃爍的「Thinking」文字就夠了。
- **已知進度**，有百分比時：使用進度條。

## 用法

把助理的實際階段對應到 `Status`：麥克風開啟為 `Listening`，等待第一個詞元為 `Thinking`，串流輸出為 `Writing`，完成為 `Done`，失敗為 `Error`，其餘為 `Idle`。實際使用時思考要短，收到第一個詞元就切換到書寫。

```xml
<arc:GhostMascot Size="24" Status="{Binding Phase}" AssistantName="Atlas" Announce="True" />
```

```csharp
ghost.Status = GhostMascotStatus.Thinking; // request sent
ghost.Status = GhostMascotStatus.Writing;  // first token
ghost.Status = GhostMascotStatus.Done;     // last token
```

不設定 `Status` 時，幽靈會循環示範每一種狀態。這用於展示；`EffectiveStatus` 回報它正在顯示的狀態，每一步都會引發 `StatusChanged`，說明文字或控制項可以隨之更新。

### 結構

1. **布單**：圓頂的頭部、略微外展的兩側，以及由兩道行進波組成、帶圓角的下襬。
2. **形體陰影**：布單右下方一塊更深、半透明的同色調，裁切在布單之內。
3. **眼睛**：兩個橢圓，會張望、眨眼、睜大、向上看、跟隨筆尖，變成開心的弧線或垂下來。
4. **標記**：思考的漩渦、書寫的筆和它寫出的線、完成時的閃光（以及一個小小的微笑）。
5. **地面**：柔和的漂浮陰影，56px 以上才顯示。

### 狀態

<Demo name="States" />

| 狀態 | 姿態與表情 | 標記 |
|---|---|---|
| `Idle` | 漂浮，每隔幾秒眨一次眼，四處張望 | 無 |
| `Listening` | 向前靠近，睜大眼睛看著你，頭微微歪向一側 | 無 |
| `Thinking` | 向上飄起並變得半透明，眼睛慢慢向上看 | 一個漩渦，從外端畫入，並在身後擦去 |
| `Writing` | 傾向那條線，眼睛盯著筆尖 | 小筆逐詞寫出一行，然後在擦除時滑回 |
| `Done` | 升起，眼睛變成開心的弧線，帶一個小微笑 | 閃光旋轉四分之一圈長出，然後輕輕閃爍 |
| `Error` | 搖晃一次，下沉，眼睛垂下 | 無 |

### 在回覆標頭中

<Demo name="ReplyHeader" />

在回覆標頭或輸入框中內嵌使用 24 到 32px。小於 56px 時改用精簡畫法：幽靈取景更緊，眼睛更大，漩渦、筆和線更粗，而且沒有陰影，因此每種狀態依然清楚可辨。

### 尺寸

<Demo name="Sizes" />

`Size` 設定寬度和高度（預設 96）：內嵌用 24 到 32，面板或影像畫布上用 40 到 64，空狀態用 96 到 160。幽靈是固定的正方形，從不讓父層重新排版；它是向量圖形，在任何縮放下都保持清晰。

### 顏色

<Demo name="Tones" />

`Tone` 從主題中選取布單顏色：`Accent`（預設）搭配強調前景色的眼睛，並跟隨主題強調色，包括 Arc 近乎中性的灰色；`Sheet` 是經典的淺色幽靈，凸起的表面加一條細線和前景色的眼睛，標記保持強調色；`Ink` 使用前景色，眼睛為背景色。`SheetBrush` 可設定任意顏色，除非設定了 `EyeBrush`，眼睛會變成它的深色混合。`MarkBrush`、`ShadeBrush` 和 `GroundBrush` 用於重設標記、形體陰影和地面陰影的顏色。

### 空狀態

<Demo name="EmptyState" />

一隻 `Sheet` 色調的大型閒置幽靈，給空白畫面一張平靜友善的臉。

### 在影像畫布上

<Demo name="Canvas" />

畫布角落裡一隻 64px 的幽靈表示圖片正在產生。幽靈不是立在某個表面上時，關閉 `ShowGround`。`IsPaused` 把它凍結在目前影格；恢復後從同一影格繼續。

### 內容準則

- 把 `AssistantName` 設為助理的名字，讓標籤讀起來自然（「Atlas, thinking」）。
- 在狀態重要的地方，於幽靈旁邊顯示文字狀態；幽靈增添個性，文字傳達含義。

### 最佳實務

- 只為承載狀態的那一隻幽靈開啟 `Announce`，裝飾用的副本不要開啟。
- 當使用者要根據它顯示的內容採取行動時，把幽靈和真正的控制項（例如 Stop）放在一起；幽靈本身不接受輸入。
- 只在展示時不設定 `Status`。

### 常見問題

**畫面外的幽靈有負擔嗎？** 沒有。它的影格迴圈在畫面外或隱藏時暫停，時鐘只在可見時執行，所以恢復時從同一影格繼續，而不會跳動。

**可以重設樣式嗎？** 可以：`SheetBrush`、`EyeBrush`、`MarkBrush`、`ShadeBrush` 和 `GroundBrush` 接受任意純色。

## 無障礙

- 幽靈呈現為一張影像，其標籤由 `AssistantName` 和狀態組成，例如「Atlas, thinking」，並隨每種狀態更新。`AccessibleName` 取代整個標籤；所有文字都在 `GhostMascotLabels` 中。
- 開啟 `Announce` 時，幽靈同時也是一個禮貌的即時區域，狀態變化只朗讀一次。每個檢視只在一隻幽靈上使用它，以免螢幕閱讀器重複朗讀。
- 狀態從不只靠顏色或動態效果傳達：每種狀態都會改變表情和標記（睜大的眼睛、向上看的眼睛搭配漩渦、筆和線、開心的眼睛搭配閃光、垂下的眼睛）以及標籤。

### 鍵盤

| 按鍵 | 操作 |
|---|---|

## 動態效果

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 漂浮與下襬 | 緩慢漂浮；兩道行進波讓下襬起伏，下襬跟隨漂浮延遲：上升時布單被拉長，下降時下襬抬起並張開 | 靜止 | 靜止 |
| 閒置 | 每 2.4 到 5.2 秒眨一次眼（160ms），以快速的掃視四處張望 | 靜止，眼睛置中 | 靜止 |
| 思考 | 漩渦從外端畫入並在身後擦去，循環銜接處為空；眼睛慢慢向上看 | 畫了一半的漩渦 | 畫了一半的漩渦 |
| 書寫 | 筆逐詞寫出這一行，詞與詞之間提筆，然後在線條擦除時滑回；眼睛跟隨筆尖 | 寫了一半的線 | 寫了一半的線 |
| 完成 | 閃光在 320ms 內以緩出旋轉四分之一圈長出，然後緩慢閃爍 | 閃光 | 閃光 |
| 出錯 | 搖晃一次，約 1.2 秒內衰減到靜止，開頭經過柔化，從不突然一抖 | 垂下的姿態 | 垂下的姿態 |
| 狀態切換 | 每個姿態值從畫面上的目前影格開始，以緩入緩出在 400ms 內過渡（保留其速度）；眼睛跟隨一個臨界阻尼彈簧 | 原地切換 | 原地切換 |

每個循環都是一個只增不減的相位的函數：漂浮、兩道下襬波、漩渦和書寫循環。速率透過積分進入這些相位來過渡，所以速度變化從不跳動，也沒有任何東西重新開始。每隻幽靈一個影格迴圈，用快取的筆刷和畫筆就地移動布單路徑的各點；它在畫面外或隱藏時暫停。在減弱動態效果下，幽靈只在狀態變化時重繪。
