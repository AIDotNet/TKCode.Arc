## 何时使用

`SketchToImage` 是图像生成的等待状态，展示画面逐渐成形，而不是一个加载圈。铅笔线条一笔一笔勾出场景，笔尖在笔画之间抬起并移动；圆头画笔从后到前逐个区域来回扫过，铺上平涂色块；柔和的细节层、胶片颗粒与暖光加以润色，最后呈现完成的画面。画布下方，带图标的阶段标签位于提示词上方，旁边是一条细进度线、百分比和"重播"按钮。

- **图像画布**：第一张结果渲染期间。
- **返回图像的聊天回复**：在图像就绪前代替它显示。
- **落地页或引导页的介绍区块**：说明文生图或草图生图。

## 何时不用

- **文本或代码生成**：使用流式回复或闪烁的标签。
- **包含大量图像的长批处理任务**：使用带缩略图的进度列表。
- **模型提供真实的中间帧**：直接展示这些帧，而不是模拟的绘画过程。
- **精确的进度**：绘画按 `Duration` 推进，而不是按你的后端，所以不要用在百分比必须真实的地方。

## 用法

给卡片一个 `Scene`（它要画的内容，见下文）和一个 `Prompt`。不设置 `Status` 时，卡片自行播放完整一遍，在完成的画面上停留约两秒，淡回空白画纸后再画一遍。这里并不生成任何东西：它是在你提供的场景上播放的模拟预览。没有 `Scene` 也没有 `Image` 时，卡片显示空状态：空白画纸、0% 的 Waiting 标签、没有提示词，也不会循环（上方的 Empty 选项卡）。本页的高山场景是 Gallery 用代码绘制的演示数据，不属于组件库。

```xml
<arc:SketchToImage Scene="{Binding Scene}"
                   Prompt="Layered alpine ridges at golden hour, warm haze" />
```

### 跟随一次请求

<Demo name="FollowRequest" />

设置 `Status` 以跟随真实的生成。每个阶段播放到结尾并停在那里，标签保持闪烁，直到下一个阶段到来；后面的阶段会依次经过中间的阶段，而往回走（例如为新请求回到 `Idle`）时会先把画布淡回空白画纸。以 `Done` 显示卡片时会直接展示画面。按如下方式映射后端的进度：

| 后端 | `Status` |
|---|---|
| 排队中 | `Idle` 或 `Sketching` |
| 前期步骤 | `Sketching` |
| 中期步骤 | `Blocking` |
| 后期步骤 | `Refining` |
| 图像就绪 | `Done` |

```csharp
card.Status = SketchToImageStatus.Blocking;
card.StageChanged += (_, e) => Log($"Now {e.Stage}");
card.Completed += (_, _) => ShowResult();
card.ReplayRequested += (_, _) => Regenerate();
```

如果你更想传一个比例，可以用 `Progress`（0 到 1）代替各阶段的终点：勾线在 0.38 结束，铺色在 0.62，润色在 0.88。绘画仍按自己的节奏前往那里。

### 结构

1. **画布**：3:2 的空白画纸，带圆角。铅笔笔画、画笔色块、两层柔和的画面、颗粒、暖光与清晰的画面叠在上面。
2. **进度线**：画布下方一条 2px 的线，使用色调颜色。
3. **阶段标签**：图标（钢笔、画笔、星光、对勾）加一个词，阶段进行中时闪烁。
4. **提示词**：标签下方一行弱化文字；过长的提示词以省略号结尾，完整文字显示在提示框中。
5. **百分比与重播**：百分比宽度固定；"重播"淡回空白画纸后重新作画。

### 阶段

| 阶段 | 占 `Duration` 的比例 | 发生什么 |
|---|---|---|
| `Sketching` | 38% | 铅笔笔画按顺序绘出，每一笔的时长与其长度相称；笔尖在笔画之间抬起并移动 |
| `Blocking` | 24% | 圆头画笔从后到前在每个区域来回扫过；铅笔线淡为参考线 |
| `Refining` | 26% | 两层预先模糊的画面、胶片颗粒与暖光淡入；铅笔线淡出 |
| `Done` | 12% | 清晰的画面交叉淡入 |

### 尺寸

<Demo name="Sizes" />

`Size` 设置卡片的最大宽度（340、520 或 720px）与铅笔的粗细，让线条在每种尺寸下都保持清晰。卡片在该宽度内填满容器。`Small` 以及窄于 400px 的卡片只显示"重播"的图标。在输入框里做小型指示时，使用 `Size="Small"` 并设 `ShowsReplay="False"`。

### 色调

<Demo name="Neutral" />

`Tone="Neutral"` 用前景色而不是强调色绘制铅笔、笔尖、阶段图标与进度线。

### 自定义场景

<Demo name="OwnScene" />

`Scene` 设置在 600 × 400 画布上绘制的内容：`Lines` 是按顺序绘制的 SVG 路径字符串；`Regions` 从后到前上色，每个区域是一组形状（带平涂的 `Fill` 与完成后的 `Finish` 画刷）加一个供圆头画笔扫过的 `Brush` 矩形；`Light` 是暖光的来源位置。没有 `Fill` 的形状只出现在完成的画面里（雾气、高光）。按你的画面描出线条与区域，让草图与之吻合。

设置 `Image` 可让绘画呈现为你真实的结果：它会在柔和层与最后的交叉淡入中填满画布。可以用你自己的场景作为示意占位，也可以根据你的图像描一个场景。

```csharp
card.Image = new Bitmap(resultStream);
card.Status = SketchToImageStatus.Done;
```

### 自定义文案

`Labels` 包含卡片显示或朗读的所有文字。替换整个对象即可本地化或改写：

```csharp
card.Labels = new SketchToImageLabels
{
    Sketching = "Esquisse",
    Blocking = "Aplats de couleur",
    Refining = "Finitions",
    Done = "Terminé",
    Replay = "Rejouer",
};
```

### 减少动态效果

减少动态效果时，卡片显示当前阶段的终态；自行播放时显示完成的画面。状态变化或重播变为终态之间的短暂淡入淡出，没有绘制或移动。关闭动效时一切立即变化。

### 最佳实践

- 每个视图只放一个。
- `Done` 之后展示真实图像，或把它作为 `Image` 传入，让绘画呈现为它。
- 写一个人们认得出的提示词；它说明正在画的是什么。

## 无障碍

- 画布是一张图像，其名称由阶段与场景组成（"Sketching: Layered mountain ridges under a warm evening sky"），完成后变为场景的描述；没有场景时只有阶段名称（"Waiting"）。各绘制层对辅助技术隐藏。
- 设置了 `Status` 时，一个礼貌的状态区域会朗读每个阶段，并说明这是模拟预览。卡片自行循环时，它只说明一次这是循环的模拟预览，之后保持安静。
- 进度线是一个从 0 到 100 的只读进度条。
- 阶段从不只靠颜色表示：每个阶段都由图标加文字组成。
- 所有文字都在 `SketchToImageLabels` 中。

### 键盘

| 按键 | 操作 |
|---|---|
| Tab | 移到"重播"按钮 |
| Enter、Space | 在"重播"上时，把画布淡回空白画纸并重新作画 |

## 动效

| 变化 | 完整 | 减少 | 关闭 |
|---|---|---|---|
| 铅笔笔画 | 每一笔沿缓入缓出曲线绘出，时长与长度相称；笔尖跟随笔头，移到下一笔时抬起（缩小、变淡） | 终态 | 终态 |
| 画笔色块 | 宽大的圆头画笔从后到前在每个区域来回扫过，笔尖为区域的颜色；铅笔线淡为参考线 | 终态 | 终态 |
| 润色 | 两层预先模糊的画面、静态颗粒与暖光淡入（只有不透明度在变），然后清晰的画面交叉淡入 | 终态 | 终态 |
| 循环 | 在画面上停留 2s，用 520ms 淡回空白画纸，同时进度线回落，在不可见时重置并重新作画 | 停在画面上 | 停在画面上 |
| 状态变化、重播 | 向前播放；往回走时先淡回画纸 | 终态之间 160ms 淡出再淡入 | 立即 |
| 阶段标签 | 旧标签 100ms 淡出，新标签用 160ms 淡入并上升 2px；进行中时闪烁 | 120ms 交叉淡化，不闪烁 | 立即 |

一个时钟驱动唯一一条 0 到 1 的时间线。每一帧从缓存的几何重绘墨迹层并设置各层的不透明度，不分配任何内存。卡片不在屏幕上或没有任何东西在动时，时钟停止；标签只随阶段变化，百分比只在取整后的值变化时更新。
