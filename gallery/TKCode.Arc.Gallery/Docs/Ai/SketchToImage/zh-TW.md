## 何時使用

`SketchToImage` 是影像生成的等待狀態，呈現畫面逐漸成形，而不是一個載入圈。鉛筆線條一筆一筆勾出場景，筆尖在筆畫之間抬起並移動；圓頭畫筆由後往前逐個區域來回掃過，鋪上平塗色塊；柔和的細節層、底片顆粒與暖光加以潤飾，最後呈現完成的畫面。畫布下方，帶圖示的階段標籤位於提示詞上方，旁邊是一條細進度線、百分比和「重播」按鈕。

- **影像畫布**：第一張結果算繪期間。
- **回傳影像的聊天回覆**：在影像就緒前代替它顯示。
- **登陸頁或導覽頁的介紹區塊**：說明文生圖或草圖生圖。

## 何時不用

- **文字或程式碼生成**：使用串流回覆或閃爍的標籤。
- **包含大量影像的長批次作業**：使用帶縮圖的進度清單。
- **模型提供真實的中間影格**：直接顯示這些影格，而不是模擬的繪畫過程。
- **精確的進度**：繪畫依 `Duration` 推進，而不是依你的後端，所以不要用在百分比必須真實的地方。

## 用法

給卡片一個 `Scene`（它要畫的內容，見下文）和一個 `Prompt`。不設定 `Status` 時，卡片自行播放完整一遍，在完成的畫面上停留約兩秒，淡回空白畫紙後再畫一遍。這裡並不生成任何東西：它是在你提供的場景上播放的模擬預覽。沒有 `Scene` 也沒有 `Image` 時，卡片顯示空白狀態：空白畫紙、0% 的 Waiting 標籤、沒有提示詞，也不會循環（上方的 Empty 分頁）。本頁的高山場景是 Gallery 以程式碼繪製的展示資料，不屬於元件庫。

```xml
<arc:SketchToImage Scene="{Binding Scene}"
                   Prompt="Layered alpine ridges at golden hour, warm haze" />
```

### 跟隨一次請求

<Demo name="FollowRequest" />

設定 `Status` 以跟隨真實的生成。每個階段播放到結尾並停在那裡，標籤保持閃爍，直到下一個階段到來；後面的階段會依序經過中間的階段，而往回走（例如為新請求回到 `Idle`）時會先把畫布淡回空白畫紙。以 `Done` 顯示卡片時會直接呈現畫面。依下列方式對應後端的進度：

| 後端 | `Status` |
|---|---|
| 排隊中 | `Idle` 或 `Sketching` |
| 前期步驟 | `Sketching` |
| 中期步驟 | `Blocking` |
| 後期步驟 | `Refining` |
| 影像就緒 | `Done` |

```csharp
card.Status = SketchToImageStatus.Blocking;
card.StageChanged += (_, e) => Log($"Now {e.Stage}");
card.Completed += (_, _) => ShowResult();
card.ReplayRequested += (_, _) => Regenerate();
```

如果你比較想傳一個比例，可以用 `Progress`（0 到 1）取代各階段的終點：勾線在 0.38 結束，鋪色在 0.62，潤飾在 0.88。繪畫仍依自己的節奏前往那裡。

### 結構

1. **畫布**：3:2 的空白畫紙，帶圓角。鉛筆筆畫、畫筆色塊、兩層柔和的畫面、顆粒、暖光與清晰的畫面疊在上面。
2. **進度線**：畫布下方一條 2px 的線，使用色調顏色。
3. **階段標籤**：圖示（鋼筆、畫筆、星光、勾號）加一個詞，階段進行中時閃爍。
4. **提示詞**：標籤下方一行淡化文字；過長的提示詞以刪節號結尾，完整文字顯示在提示框中。
5. **百分比與重播**：百分比寬度固定；「重播」淡回空白畫紙後重新作畫。

### 階段

| 階段 | 占 `Duration` 的比例 | 發生什麼 |
|---|---|---|
| `Sketching` | 38% | 鉛筆筆畫依序繪出，每一筆的時長與其長度相稱；筆尖在筆畫之間抬起並移動 |
| `Blocking` | 24% | 圓頭畫筆由後往前在每個區域來回掃過；鉛筆線淡為參考線 |
| `Refining` | 26% | 兩層預先模糊的畫面、底片顆粒與暖光淡入；鉛筆線淡出 |
| `Done` | 12% | 清晰的畫面交叉淡入 |

### 尺寸

<Demo name="Sizes" />

`Size` 設定卡片的最大寬度（340、520 或 720px）與鉛筆的粗細，讓線條在每種尺寸下都保持清晰。卡片在該寬度內填滿容器。`Small` 以及窄於 400px 的卡片只顯示「重播」的圖示。在輸入框裡做小型指示時，使用 `Size="Small"` 並設 `ShowsReplay="False"`。

### 色調

<Demo name="Neutral" />

`Tone="Neutral"` 以前景色而不是強調色繪製鉛筆、筆尖、階段圖示與進度線。

### 自訂場景

<Demo name="OwnScene" />

`Scene` 設定在 600 × 400 畫布上繪製的內容：`Lines` 是依序繪製的 SVG 路徑字串；`Regions` 由後往前上色，每個區域是一組形狀（帶平塗的 `Fill` 與完成後的 `Finish` 筆刷）加一個供圓頭畫筆掃過的 `Brush` 矩形；`Light` 是暖光的來源位置。沒有 `Fill` 的形狀只出現在完成的畫面裡（霧氣、亮部）。依你的畫面描出線條與區域，讓草圖與之吻合。

設定 `Image` 可讓繪畫呈現為你真實的結果：它會在柔和層與最後的交叉淡入中填滿畫布。可以用你自己的場景作為示意佔位，也可以依你的影像描一個場景。

```csharp
card.Image = new Bitmap(resultStream);
card.Status = SketchToImageStatus.Done;
```

### 自訂文案

`Labels` 包含卡片顯示或朗讀的所有文字。替換整個物件即可在地化或改寫：

```csharp
card.Labels = new SketchToImageLabels
{
    Sketching = "Esquisse",
    Blocking = "Aplats de couleur",
    Refining = "Finitions",
    Done = "Terminé",
    Replay = "Rejouer",
};
```

### 減少動態效果

減少動態效果時，卡片顯示目前階段的終態；自行播放時顯示完成的畫面。狀態變化或重播變為終態之間的短暫淡入淡出，沒有繪製或移動。關閉動態效果時一切立即變化。

### 最佳做法

- 每個檢視只放一個。
- `Done` 之後顯示真實影像，或把它作為 `Image` 傳入，讓繪畫呈現為它。
- 寫一個大家認得出的提示詞；它說明正在畫的是什麼。

## 無障礙

- 畫布是一張影像，其名稱由階段與場景組成（"Sketching: Layered mountain ridges under a warm evening sky"），完成後變為場景的描述；沒有場景時只有階段名稱（"Waiting"）。各繪製層對輔助技術隱藏。
- 設定了 `Status` 時，一個禮貌的狀態區域會朗讀每個階段，並說明這是模擬預覽。卡片自行循環時，它只說明一次這是循環的模擬預覽，之後保持安靜。
- 進度線是一個從 0 到 100 的唯讀進度列。
- 階段從不只靠顏色表示：每個階段都由圖示加文字組成。
- 所有文字都在 `SketchToImageLabels` 中。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| Tab | 移到「重播」按鈕 |
| Enter、Space | 在「重播」上時，把畫布淡回空白畫紙並重新作畫 |

## 動態效果

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 鉛筆筆畫 | 每一筆沿緩入緩出曲線繪出，時長與長度相稱；筆尖跟隨筆頭，移到下一筆時抬起（縮小、變淡） | 終態 | 終態 |
| 畫筆色塊 | 寬大的圓頭畫筆由後往前在每個區域來回掃過，筆尖為區域的顏色；鉛筆線淡為參考線 | 終態 | 終態 |
| 潤飾 | 兩層預先模糊的畫面、靜態顆粒與暖光淡入（只有不透明度在變），然後清晰的畫面交叉淡入 | 終態 | 終態 |
| 循環 | 在畫面上停留 2s，用 520ms 淡回空白畫紙，同時進度線回落，在不可見時重設並重新作畫 | 停在畫面上 | 停在畫面上 |
| 狀態變化、重播 | 向前播放；往回走時先淡回畫紙 | 終態之間 160ms 淡出再淡入 | 立即 |
| 階段標籤 | 舊標籤 100ms 淡出，新標籤以 160ms 淡入並上升 2px；進行中時閃爍 | 120ms 交叉淡化，不閃爍 | 立即 |

一個時鐘驅動唯一一條 0 到 1 的時間軸。每一影格從快取的幾何重繪墨跡層並設定各層的不透明度，不配置任何記憶體。卡片不在螢幕上或沒有任何東西在動時，時鐘停止；標籤只隨階段變化，百分比只在取整後的值變化時更新。
