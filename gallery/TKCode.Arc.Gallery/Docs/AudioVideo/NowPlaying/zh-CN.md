## 何时使用

`NowPlaying` 是一个在人们做其他事情时始终留在原处的播放器。平时它是一个 64 px 高的迷你条：缩略封面、标题与艺术家、三根小小的电平条，以及播放和下一首按钮。按一下，同一个条会原地、以一次连续的动作生长为完整播放器：大尺寸封面、显示字体的标题、可拖动定位的波形、已播放与剩余时间，以及上一首、播放和下一首。封面与两个按钮会飞到各自的新位置，外壳的高度与圆角则跟随同一个弹簧变化；没有任何跳动。

- **在浏览其他内容时持续播放的音频**：音乐、播客、音频课程或录制的会议，放在侧边栏、页脚或窗口的角落。
- **有时需要更多功能的小型播放器**：大多数时候迷你条已经足够；完整播放器用于拖动定位和切换曲目，之后会再次折叠起来。
- **队列**：上一首与下一首会在曲目列表中移动，并在两端回绕；封面从你切换的那一侧滑入。
- **适合触摸的布局**：在手机上，下拉封面时完整播放器会折叠回去。

## 何时不用

- **不是播放器的一次性面板**：请使用 `Dialog` 或底部抽屉。
- **录制与回放简短的语音备忘**：请使用 `VoiceRecorder`。
- **单独的拖动条，周围没有播放器**：请使用 `Slider`。
- **视频**：请使用视频组件；这个播放器显示的是静态封面。
- **需要浏览的长播放列表**：请自行显示列表，并把队列交给播放器；它一次只显示一首曲目。

## 用法

为播放器提供它的队列。其他一切都有默认值：第一首曲目、暂停状态、迷你条。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:NowPlaying x:Name="Player" />
</UserControl>
```

```csharp
Player.Tracks = new AvaloniaList<NowPlayingTrack>
{
    new("ep-41", "Ep. 41 · Quiet machines", "Field Notes Radio", TimeSpan.FromSeconds(2292))
    {
        Artwork = cover,                       // any IImage: a bitmap, a DrawingImage
        ArtworkAlt = "A ring of warm light in the dark"
    }
};
```

`NowPlaying` 派生自 Avalonia 的 `TemplatedControl`，位于 Special 包中：请在 `UseArcControls()` 旁调用 `UseArcSpecial()` 进行注册。预览会播放来自 `NowPlayingSamples` 的一个虚构队列：五首虚构的曲目，每首三到四分钟，封面由代码绘制（渐变与简单图形）。

### 完整播放器

`IsExpanded` 是双向的。迷你条、在它上面按下 Enter 或 Space、封面上的箭头、Escape 以及下拉封面，都会改变它；你也可以自己设置它，或调用 `Expand()`、`Collapse()` 与 `ToggleExpanded()`，来展开或折叠播放器。`ExpandedChanged` 会报告每一次变化。设置 `IsExpanded="True"` 即可以完整播放器启动。

<Demo name="FullPlayer" />

在波形上任意位置按下，播放头会跳到那里；拖动时它会精确跟随指针，同时整个波形会稍微拉高一些，以表示它正被按住。时钟在你松开之前保持不动，松开后播放从该处继续。波形获得焦点时，方向键每次前进或后退 5 秒，Page Up 和 Page Down 每次 30 秒，Home 跳到开头，End 跳到结束前一秒。

已播放超过 3 秒时，上一首会让曲目从头开始（`RestartThreshold`）：播放头滑回起点。在前 3 秒内，它会回到上一首曲目。曲目结束时，下一首会开始并继续播放。

### 播放与真实音频

播放器运行自己的时钟：当 `IsPlaying` 为 true 时，每过一秒它就前进一秒，因此在没有任何音频的情况下也能工作（用于演示、原型或测试）。要播放真实音频，请跟随播放器的状态并把结果反馈给它：

- `IsPlaying` 与 `Index` 都是双向的。你可以绑定它们，也可以处理 `PlayingChanged`（播放或暂停你的音频）和 `IndexChanged`（加载新曲目；`Reason` 说明这是切歌还是曲目结束，`Direction` 说明方向）。
- 根据你的音频时间更新设置 `CurrentTime`。每个值都会校正时钟，从而让波形在两次更新之间保持平滑移动。当有人拖动波形时，该值会被忽略。
- 处理 `SeekRequested` 并设置你的音频位置。它会在拖动结束时、每次键盘定位时、上一首重新开始曲目时（参数为零），以及调用 `SeekTo` 时引发。

<Demo name="HostDriven" />

```csharp
player.PlayingChanged += (_, e) => { if (e.IsPlaying) { audio.Play(); } else { audio.Pause(); } };
player.IndexChanged += (_, e) => audio.Load(queue[e.NewIndex]);
player.SeekRequested += (_, e) => audio.Position = e.Position;
audio.PositionChanged += (_, _) => player.CurrentTime = audio.Position;
```

`Position` 表示播放头所在的位置（每整秒更新一次，并在每次定位和切换曲目时更新）。`Next()`、`Previous()`、`Play()`、`Pause()`、`TogglePlay()` 与 `SeekTo()` 可以通过代码完成按钮所做的操作。对于切歌和曲目结束，会引发 `IndexChanged`；而你的代码设置 `Index` 时则不会引发。

### 结构

1. **外壳**：最宽 336 px（窄于此的容器则为其全部宽度），迷你条时 64 px 高、圆角 22 px，完整播放器时约 411 px 高、圆角 30 px；是一个带 1 px 边框和浮动阴影的凸起表面。
2. **封面**：迷你条中为 44 px，完整播放器中与播放器等宽、高 192 px。图像始终以一个与封面等宽的正方形显示，居中并裁剪，因此放大时不会变形。其圆角为外壳圆角减去 10 px。没有图像时显示柔和的底色表面。
3. **迷你文字**：标题（14 px，中等字重）在艺术家（12 px，次要颜色）之上，每行一行并以省略号结尾。整个区域就是打开播放器的按钮。
4. **电平条**：`NowPlayingLevels`，三根 3 × 14 的条，播放时会跳动。
5. **播放**：迷你条中是一个 40 px 的柔和圆形；完整播放器中是一个 52 px 的圆形，颜色为文本色，图标为背景色。
6. **下一首与上一首**：迷你条中为 40 px，完整播放器中为 44 px 的圆形按钮，悬停前无填充。
7. **折叠**：封面右上角一个 34 px 的深色玻璃圆形，内有一个箭头，两种主题下相同。
8. **信息**：标题使用显示字体（18 px），艺术家在其下（14 px）。
9. **波形**：54 根条，间距 2 px。已播放的条使用文本色，其余的为该颜色的 16%；分界线连续移动，并可能落在某根条之内。
10. **时间**：左侧为已播放时间（"1:02"），右侧为带减号的剩余时间（"−2:24"），12 px，使用等宽数字。

### 单独使用电平条

`NowPlayingLevels` 是公开的：把它放在你自己列表中正在播放的那一行旁边，并绑定 `IsPlaying`。

### 手势

- **在完整播放器中下拉封面**：外壳以指针移动距离的 60% 跟随。松手时若超过 70 px（指针移动约 117 px），或以每秒 600 px 或更快的速度快速下甩，播放器就会折叠；否则它会带着小幅过冲弹回。
- **上拉**：外壳的阻力越来越大（橡皮筋回弹），然后弹回。
- **在波形上按下或拖动**：拖动定位，如上文所述。在迷你条中按下封面不会有任何反应；文字区域会打开播放器。

### 窄容器

外壳的宽度与其容器相同，最宽为 336 px。在更窄的列中，封面保持 192 px 的高度，波形的条会变细，过长的标题以省略号结尾。在宽 360 px 或更窄的窗口中，迷你条会去掉下一首按钮，为标题让出空间；完整播放器则保留它。

### 减弱动效

在减弱动效下，没有任何东西会飞动：封面和按钮立即位于最终位置，外壳以 160 ms 的短暂补间展开，露出它们。封面以淡入淡出代替滑动，文字淡入但不移动或模糊，电平条在播放时保持静止。每个状态、名称、焦点移动和播报都保持不变。

### 内容准则

标题和艺术家名称应保持人们所熟悉的写法；播放器会用省略号截断它们，而不是换行。`ArtworkAlt` 应描述图片本身的简短说明，而不是音乐本身（"Teal currents swirling in deep water"）；如果封面纯属装饰，则可以省略。

| Instead of | Write |
|---|---|
| Album art | Layered dunes under a pale sky |
| Track 3 | Paper, lanterns |
| Unknown | (the real artist, or leave the line short) |

### 最佳实践

**建议**

- 为每首曲目提供其真实时长：剩余时间与曲目的结束时刻都来自它。
- 播放真实音频时，通过 `CurrentTime` 报告真实位置，并在 `SeekRequested` 中设置你的音频位置。
- 为播放器留出可以生长的位置：展开时它需要约 411 px 的高度（预览会将其居中，因此它向上下两个方向生长）。
- 每个页面使用一个播放器；它本就应该留在那里。

**避免**

- 每次时间更新都重建 `Tracks`。只有在队列变化时才替换列表。
- 在曲目显示期间修改其对象的属性；应当在列表中替换该项。
- 把播放器放进会将其裁剪的滚动容器中：展开的播放器很高。

### 常见问题

**它会播放声音吗？** 不会。它负责显示和控制播放；由你的代码播放音频并报告位置。没有音频时，它的时钟依然运行，因此作为演示时它完全可用。

**如何从队列中间的曲目开始？** 设置 `Index`，然后设置 `CurrentTime`（或调用 `SeekTo`）。

**队列末尾会发生什么？** 下一首以及最后一首曲目结束后，都会转到第一首；在第一首曲目的 3 秒内点击上一首，会转到最后一首。

**能否更改波形？** 为每首曲目提供其自己的 `Peaks`（取值从 0 到 1，数量不限：它们会被重采样为 `PeakCount` 根条）。没有 peaks 时，会根据曲目的 `Id` 生成一个固定形状，因此同一首曲目总是呈现相同的样子。

**为什么 Escape 没有折叠播放器？** 当焦点位于播放器内部或没有特定焦点时，Escape 才会将其折叠，因此播放器永远不会抢走另一个已获得焦点的控件的 Escape。

## 无障碍

- 播放器是一个分组，名称由 `Label` 指定（"Now playing"）。
- 迷你条的文字区域是一个按钮，名称为 "Expand player, {title} by {artist}"，并报告自己处于折叠状态；箭头为 "Collapse player"，并报告自己处于展开状态。
- 播放按钮的名称为 "Play {title}" 或 "Pause {title}"；下一首与上一首分别为 "Next track" 和 "Previous track"。
- 波形是一个名为 "Position" 的滑块，范围从 0 到曲目长度，朗读的值如 "1:07 of 3:51"。
- 一个礼貌级别的实时区域会在每次切换曲目、播放和暂停时朗读曲目及其状态（"Low Orbit by Mara Quell, playing"）。
- 封面由 `ArtworkAlt` 描述；没有它时，封面被视为装饰，并对辅助技术隐藏。电平条、时间和进度线同样是装饰性的。
- 键盘焦点会在控件外侧显示一个向外偏移 2 px、宽 2 px 的环：按钮上为圆形，迷你文字区域与波形上为方形。指针焦点不绘制任何环。
- 播放器打开时，焦点移到折叠按钮；折叠时，焦点返回迷你条。

| `Left` / `Down`、`Right` / `Up` | 在波形上，后退或前进 5 秒 |
| `Page Down` / `Page Up` | 在波形上，后退或前进 30 秒 |
| `Home` / `End` | 在波形上，跳到开头，或跳到结束前一秒 |
| `Escape` | 折叠完整播放器（当焦点位于播放器内或没有特定焦点时） |

## 动效

- 展开：外壳的高度与圆角以弹簧从迷你条变化到播放器（视觉时长 0.46 s，带一丝回弹）；封面、播放与下一首沿同一弹簧飞行，封面从其左上角开始放大。迷你条的文字、电平条与进度线在 100 ms 内淡出，并带有轻微模糊；信息、波形、上一首与折叠按钮则在 80、120、140 和 160 ms 之后，经 240 ms 淡入，分别上升 12、14 和 10 px，并从 2 px 的模糊中浮现。
- 折叠：沿同一路径返回，弹簧不带回弹；迷你条的各部分分别在 100、140 和 160 ms 后回来。中途反向时会保留运动的速度，因此外壳会短暂地继续前进，然后才转向。
- 切歌：旧封面朝其离开的一侧滑动其宽度的 24%，同时略微缩小并模糊，新封面从另一侧滑入（平滑弹簧）；二者在 240 ms 内交叉淡化。标题与艺术家向上离开，新的标题与艺术家从下方 6 px 处升起。波形立即改变。
- 播放与暂停图标互换：旧图标在 120 ms 内淡出并缩小，新图标以坚定的弹簧放大出现。
- 按住波形时，波形会拉伸至其高度的 1.18 倍。电平条在播放时跳动，并在 240 ms 内归位。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 展开与折叠 | 外壳弹簧，封面与按钮飞行 | 外壳在 160 ms 内补间，各部分原位显示 | 立即 |
| 迷你条与播放器各部分 | 错落淡入、上升并模糊 | 仅淡入 | 立即 |
| 切歌 | 封面滑动并模糊，文字上升 | 交叉淡化 | 立即 |
| 播放与暂停图标 | 缩小、模糊并弹起 | 交叉淡化 | 立即 |
| 电平条 | 跳动 | 静止 | 静止 |
| 下拉松手 | 弹回或折叠 | 立即 | 立即 |
| 时钟、时间与波形切换 | 每一帧 | 每一帧 | 每一帧 |

## 响应式

- 外壳与其容器等宽，最宽为 336 px；高度、字体与按钮尺寸不会改变。
- 在宽 360 px 或更窄的窗口中（最近的移动预览框架也算作窗口），迷你条会去掉下一首按钮。
- 在窄播放器中，封面保持 192 px 的高度；波形的条会变细。
