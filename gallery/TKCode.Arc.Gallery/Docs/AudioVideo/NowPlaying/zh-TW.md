## 何時使用

`NowPlaying` 是一個在人們做其他事情時會留在原處的播放器。靜止時它是一個 64px 的列：封面縮圖、曲名與演出者、三條小音量列，以及播放與下一首按鈕。按一下後，同一個列會在原位、以一次連續的動作展開成完整播放器：大張封面、以顯示字體呈現的曲名、可拖曳定位的波形、已播放與剩餘時間，以及上一首、播放與下一首。封面和兩個按鈕會飛到各自的新位置，外殼的高度與圓角則跟隨同一個彈簧效果變化；沒有任何東西會跳動。

- **人們瀏覽時仍持續播放的音訊**：音樂、Podcast、語音課程或錄製的會議，放在側邊欄、頁尾或視窗角落。
- **有時需要更多空間的小型播放器**：多數時候迷你列已經足夠；完整播放器用來拖曳定位與切換曲目，之後會再次收合。
- **佇列**：下一首與上一首會在曲目清單中移動，並在兩端循環；封面會從你切換的那一側滑入。
- **適合觸控的版面**：按下封面向下拉時，完整播放器會像在手機上一樣收合。

## 何時不用

- **不是播放器的單次面板**：請使用 `Dialog` 或底部面板。
- **錄製與播放簡短語音備忘**：請使用 `VoiceRecorder`。
- **沒有播放器包覆、單獨存在的拖曳定位列**：請使用 `Slider`。
- **影片**：請使用影片相關元件；這個播放器顯示的是靜態封面。
- **需要瀏覽的長播放清單**：請自行顯示清單，並把佇列交給播放器；播放器一次只顯示一首曲目。

## 用法

為播放器提供它的佇列。其餘所有內容都有預設值：第一首曲目、暫停，以及迷你列。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:NowPlaying x:Name="Player" />
</UserControl>
```

```csharp
Player.Tracks = new AvaloniaList<NowPlayingTrack>
{
    new("ep-41", "Ep. 41 · Quiet machines", "Field Notes Radio", TimeSpan.FromSeconds(2292))
    {
        Artwork = cover,                       // any IImage: a bitmap, a DrawingImage
        ArtworkAlt = "A ring of warm light in the dark"
    }
};
```

`NowPlaying` 衍生自 Avalonia 的 `TemplatedControl`，位於 Special 套件中：請在 `UseArcControls()` 旁呼叫 `UseArcSpecial()` 來註冊。預覽會播放 `NowPlayingSamples` 提供的虛構佇列：五首虛構曲目，每首三到四分鐘，封面以程式碼繪製（漸層與簡單的圖形）。

### 完整播放器

`IsExpanded` 是雙向的。迷你列、在它上面按下 Enter 或空白鍵、封面上的收合箭頭、Escape，以及在封面上下拉，都會改變它；你也可以自行設定它，或呼叫 `Expand()`、`Collapse()` 與 `ToggleExpanded()` 來展開或收合播放器。`ExpandedChanged` 會回報每一次變更。設定 `IsExpanded="True"` 可讓播放器一開始就是完整播放器。

<Demo name="FullPlayer" />

在波形上任何位置按下，播放頭就會跳到那裡；拖曳時，播放頭會精確地跟隨指標，同時整個波形會稍微拉高，表示它正被按住。放開之前時鐘保持不動，放開後播放會從該處繼續。波形取得焦點時，方向鍵每次移動 5 秒，Page Up 與 Page Down 每次移動 30 秒，Home 跳到開頭，End 跳到結尾前一秒。

已播放超過 3 秒時，上一首會重新播放目前曲目（`RestartThreshold`）：播放頭會平滑地滑回開頭。在前 3 秒內，上一首會跳到前一首曲目。曲目結束時，下一首會開始並繼續播放。

### 播放與實際音訊

播放器有自己的時鐘：`IsPlaying` 為 true 時每秒前進一秒，因此即使沒有任何音訊也能運作（示範、原型或測試）。要播放實際音訊，請讓播放器跟隨你的音訊，並把狀態回報給它：

- `IsPlaying` 與 `Index` 是雙向的。你可以繫結它們，或處理 `PlayingChanged`（播放或暫停你的音訊）與 `IndexChanged`（載入新曲目；`Reason` 說明是切換還是曲目結束，`Direction` 說明方向）。
- 根據你音訊的時間更新來設定 `CurrentTime`。每個值都會校正時鐘，讓波形在兩次更新之間保持流暢移動。有人拖曳波形時，此值會被忽略。
- 處理 `SeekRequested` 並設定你音訊的位置。它會在拖曳結束時、每次鍵盤定位時、上一首重新播放曲目時（值為零），以及呼叫 `SeekTo` 時引發。

<Demo name="HostDriven" />

```csharp
player.PlayingChanged += (_, e) => { if (e.IsPlaying) { audio.Play(); } else { audio.Pause(); } };
player.IndexChanged += (_, e) => audio.Load(queue[e.NewIndex]);
player.SeekRequested += (_, e) => audio.Position = e.Position;
audio.PositionChanged += (_, _) => player.CurrentTime = audio.Position;
```

`Position` 會讀取播放頭目前的位置（每整秒、每次定位以及切換曲目時更新）。`Next()`、`Previous()`、`Play()`、`Pause()`、`TogglePlay()` 與 `SeekTo()` 會以程式碼執行按鈕所做的操作。切換與曲目結束時會引發 `IndexChanged`，但你的程式碼設定 `Index` 時不會引發。

### 結構

1. **外殼**：最寬 336px（若容器較窄則為容器的完整寬度），作為列時 64px 高、圓角 22px；作為播放器時約 411px 高、圓角 30px；是一個帶有 1px 邊框與浮起陰影的凸起表面。
2. **封面**：列中為 44px，完整播放器中與播放器同寬、高 192px。影像一律以正方形顯示，寬度等於封面，置中並裁切，因此放大時不會變形。其圓角比外殼少 10px。沒有影像時會顯示靜音的表面。
3. **迷你文字**：曲名（14px，中等字重）在演出者（12px，次要色）之上，各佔一行並以省略號結尾。整個區域就是開啟播放器的按鈕。
4. **音量列**：`NowPlayingLevels`，三條 3 × 14 的長條，播放時會跳動。
5. **播放**：列中是 40px 的靜音圓形；完整播放器中是 52px 的圓形，使用文字顏色，圖示使用背景色。
6. **下一首與上一首**：40px（列）與 44px（播放器）的圓形按鈕，滑鼠懸停前沒有填色。
7. **收合**：封面右上角 34px 的深色玻璃圓形，內含收合箭頭，兩種主題下相同。
8. **資訊**：曲名以顯示字體（18px）呈現，在演出者（14px）之上。
9. **波形**：54 條長條，間距 2px。已播放的長條使用文字顏色，其餘為其 16% 的色度；分界會連續移動，且可以落在長條之內。
10. **時間**：左側為已播放時間（"1:02"），右側為帶減號的剩餘時間（"−2:24"），12px，使用等寬數字。

### 手勢

- **在完整播放器中向下拉封面**：外殼會以指標移動距離的 60% 跟隨。放開時若超過 70px（約為指標移動 117px），或以每秒 600px 或更快的速度快速下滑，播放器就會收合；否則會以些微過衝的方式彈回。
- **向上拉**：外殼的阻力會越來越大（橡皮筋回彈），然後彈回。
- **在波形上按下或拖曳**：拖曳定位，如上所述。在列中按下封面不會有任何反應；文字區域才會開啟播放器。

### 窄容器

外殼最寬為 336px，並與容器同寬。在較窄的欄位中，封面仍保持 192px 的高度，波形的長條會變細，過長的曲名會以省略號結尾。在 360px 或更窄的視窗中，列會移除下一首按鈕以騰出空間放曲名；完整播放器則保留該按鈕。

### 減少動態效果

在減少動態效果下，沒有任何東西會飛行：封面與按鈕會立即位於最終位置，外殼則以 160ms 的短補間展開，並露出它們。封面以交叉淡化取代滑動，文字只淡入而不移動或模糊，播放時音量列保持靜止。每一種狀態、名稱、焦點移動與播報都保持不變。

### 內容指引

曲名與演出者請保留人們所熟知的寫法；播放器會以省略號截斷，而不會換行。撰寫 `ArtworkAlt` 時，請描述圖片的內容，而不是音樂的內容（"深水中盤旋的青綠色水流"）；若封面純粹是裝飾，則可省略。

| 不要寫 | 改為寫 |
|---|---|
| 專輯圖 | 淡天空下層疊的沙丘 |
| 第 3 首 | 紙張、燈籠 |
| 未知 | （真實的演出者，或讓該行保持簡短） |

### 最佳做法

**建議**

- 為每首曲目提供真實長度：剩餘時間與曲目結尾都由它計算。
- 播放實際音訊時，透過 `CurrentTime` 回報真實位置，並在 `SeekRequested` 中設定你音訊的位置。
- 為播放器預留可以展開的空間：展開時它需要約 411px 的高度（預覽會將它置中，因此向上與向下都能展開）。
- 每個頁面只使用一個播放器；它的設計本意就是持續存在。

**避免**

- 在每次時間更新時重建 `Tracks`。只有在佇列改變時才替換清單。
- 在曲目顯示期間變更曲目物件的屬性；請改為替換清單中的項目。
- 把播放器放在會裁切它的捲動器中：展開的播放器很高。

### 常見問題

**它會播放聲音嗎？** 不會。它負責顯示與控制播放；你的程式碼負責播放音訊並回報位置。沒有音訊時，它的時鐘仍會運作，因此播放器作為示範時完全可用。

**如何從佇列中間的曲目開始？** 設定 `Index`，然後設定 `CurrentTime`（或呼叫 `SeekTo`）。

**佇列結尾會發生什麼事？** 下一首以及最後一首曲目結束時，都會回到第一首；在第一首曲目上按上一首（3 秒內），則會跳到最後一首。

**可以更改波形嗎？** 為每首曲目提供自己的 `Peaks`（0 到 1 之間的數值，數量不限：它們會重新取樣為 `PeakCount` 條長條）。沒有 peaks 時，會根據曲目的 `Id` 產生固定的形狀，因此同一首曲目永遠看起來相同。

**為什麼按下 Escape 沒有收合播放器？** 當焦點在播放器內，或沒有特定焦點位置時，Escape 才會收合它；因此播放器不會把 Escape 從其他有焦點的控制項上搶走。

## 無障礙

- 播放器是一個群組，名稱由 `Label` 提供（"Now playing"）。
- 迷你列的文字區域是一個按鈕，名稱為 "Expand player, {title} by {artist}"，並回報自己處於收合狀態；收合箭頭的名稱為 "Collapse player"，並回報自己處於展開狀態。
- 播放按鈕的名稱為 "Play {title}" 或 "Pause {title}"；下一首與上一首分別為 "Next track" 與 "Previous track"。
- 波形是一個名為 "Position" 的滑桿，範圍從 0 到曲目長度，並有類似 "1:07 of 3:51" 的語音數值。
- 禮貌的即時區域會在每次切換曲目、播放與暫停時，播報曲目與狀態（"Low Orbit by Mara Quell, playing"）。
- 封面由 `ArtworkAlt` 描述；沒有它時，封面為裝飾性，並會對輔助技術隱藏。音量列、時間與進度線同樣是裝飾性的。
- 鍵盤焦點會在控制項外側顯示 2px 的焦點環，並內縮 2px：按鈕為圓形，迷你文字區域與波形為方形。滑鼠焦點則不顯示焦點環。
- 播放器展開時，焦點會移到收合按鈕；收合時，焦點會回到迷你列。

| 按鍵 | 操作 |
|---|---|

| `Page Down` / `Page Up` | 在波形上，向後或向前 30 秒 |

## 動態效果

- 展開：外殼的高度與圓角以彈簧效果從列伸展到播放器（視覺持續時間 0.46 s，帶有一絲回彈）；封面、播放與下一首沿同一彈簧一同飛行，封面從其左上角放大。列中的文字、音量列與進度線會在 100ms 內以輕微模糊淡出；曲目資訊、波形、上一首與收合按鈕會在 80、120、140 與 160ms 後，於 240ms 內淡入，並分別自 12、14 與 10px 的下方升起，同時從 2px 的模糊中清晰化。
- 收合：沿同一路徑以無回彈的彈簧效果返回；列的各部分會在 100、140 與 160ms 後回來。動作進行到一半時反向，會保留移動的速度，因此外殼會稍微繼續前進，然後才轉向。
- 切換曲目：舊封面會朝它離開的那一側滑動其寬度的 24%，同時稍微縮小並模糊，而新封面則從另一側滑入（平滑彈簧）；兩者會在 240ms 內交叉淡化。曲名與演出者向上離開，新的曲名與演出者則從下方 6px 處升起。波形會立即改變。
- 播放與暫停切換圖示：舊圖示在 120ms 內淡出並縮小，新圖示則以穩定的彈簧效果放大進入。
- 波形在被按住時會拉伸至其高度的 1.18 倍。播放時音量列會跳動，並在 240ms 內靜止。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 展開與收合 | 外殼以彈簧伸展，封面與按鈕飛行 | 外殼以 160ms 補間展開，各部分就地呈現 | 立即 |
| 列與播放器的各部分 | 交錯的淡入淡出、升起與模糊 | 僅淡入淡出 | 立即 |
| 切換曲目 | 封面滑動並模糊，文字升起 | 交叉淡化 | 立即 |
| 播放與暫停圖示 | 縮小、模糊並以彈簧變化 | 交叉淡化 | 立即 |
| 音量列 | 跳動 | 靜止 | 靜止 |
| 下拉放開 | 彈回或收合 | 立即 | 立即 |
| 時鐘、時間與波形切換 | 每一影格 | 每一影格 | 每一影格 |

## 響應式

- 外殼與其容器同寬，最寬至 336px；高度、字體與按鈕尺寸都不會改變。
- 在 360px 或更窄的視窗中（最近的行動預覽框架也算作視窗），列會移除下一首按鈕。
- 在窄播放器中，封面仍保持 192px 的高度；波形的長條會變細。
