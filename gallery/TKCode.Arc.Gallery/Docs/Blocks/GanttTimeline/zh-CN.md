## 何时使用

`GanttTimeline` 用于排期跨越数周或数月、任务之间互相依赖的计划。任务归入各个阶段；阶段行显示一条汇总条，可以折叠以隐藏其任务，并显示任务数。条形显示进度，箭头连接任务与它依赖的任务，今天线标出计划进行到哪里。

- **需要经常改期的路线图。** 拖动条形可整体移动，拖动两端可改日期；改动吸附到整天，并可撤销。
- **带依赖的计划。** 任务早于其依赖任务结束开始时，箭头变红。
- **分阶段的计划。** 把已完成的阶段折叠成汇总条，让其余部分留在视野内。

## 何时不用

- **没有日期的状态。** 请用项目看板。
- **一天之内的时间段。** 请用周日历。
- **只读的带日期事件列表。** 普通时间线更轻。
- **数百个任务。** 有物体移动时每帧都会重画箭头；请把计划控制在几十个任务以内。

## 用法

设置 `Groups`（按顺序的阶段）和 `Tasks`。`GanttTask` 有 `Id`、`Name`、所属阶段的 `GroupId`、`Start` 与 `End`（最后一天，含当天）、取值 0 到 1 的 `Progress`、可选的 `Assignee`、所依赖任务的 `DependsOn`，以及表示单日标记的 `IsMilestone`。`Today` 决定今天线和首次滚动位置。

时间线保存自己的任务副本，并通过 `TasksChanged` 报告每次编辑；页脚的 `Undo` 与 `Reset` 沿这些编辑回退。`Zoom` 在 `Day`、`Week`、`Month` 之间切换，并保持视图中心不动。`CollapsedGroups` 保存已折叠阶段的 id。

### 键盘

| 按键 | 作用 |
|---|---|
| Tab | 进入图表；同一时刻只有一个条形是 Tab 停靠点 |
| 下 / 上方向键 | 移到下一个或上一个可见条形 |
| Alt + 左 / 右方向键 | 把当前任务移动一天 |
| Alt + Shift + 左 / 右方向键 | 把当前任务的结束日期改一天 |
| Enter / 空格 | 选中条形并高亮它的箭头 |
| Escape | 清除选中 |

## 无障碍

条形是名为 "Task bar" 或 "Milestone" 的按钮，带有表示选中的按下状态，标签给出名称、日期、完成百分比，以及依赖被破坏时的警告。折叠的行对辅助技术隐藏。页脚状态行是礼貌型实时区域，会播报每次移动、撤销和冲突。日历表头、网格线、箭头和汇总条仅作装饰。

## 动效

拖动后，条形从松手的位置弹回吸附的那一天。把条形缩短到不足一天时会有柔和的橡皮筋阻力。缩放以弹簧围绕视图中心滑动，Today 按钮把今天线滑入视图。折叠阶段时，它的行向上滑入阶段行。减少动效时一切直接跳到目标。

## 响应式

- 图表按自身宽度而不是窗口宽度调整。宽度低于 560 px 时，任务列从 248 px（`TaskColumnWidth`）收窄为 132 px（`NarrowTaskColumnWidth`），日历占用其余宽度。
- 日历在图表内部横向与纵向滚动，放不下的方向会显示滚动条。按住 Shift 再滚动滚轮时，日历横向滚动。
- 标题与缩放切换按钮位于同一行。手机宽度下标题在它们旁边会被截断，因此为时间线设置简短的 `Title`。
- 触屏：任务行高 40 px（`GanttModel.RowHeight`），缩放切换按钮高 32 px（`SwitchButtonHeight`），低于舒适的触控目标。让时间线占满宽度并设置固定高度；只有父级没有给出高度时才使用 `DefaultChartHeight`。
