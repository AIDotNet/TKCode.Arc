## 何時使用

`GanttTimeline` 用於排程橫跨數週或數月、任務之間互相相依的計畫。任務歸入各個階段；階段列顯示一條彙總條，可以摺疊以隱藏其任務，並顯示任務數。長條顯示進度，箭頭連接任務與它所相依的任務，今天線標出計畫進行到哪裡。

- **需要經常改期的路線圖。** 拖曳長條可整體移動，拖曳兩端可調整日期；變更會吸附到整天，並可復原。
- **有相依關係的計畫。** 任務早於其相依任務結束就開始時，箭頭會變紅。
- **分階段的計畫。** 把已完成的階段摺疊成彙總條，讓其餘部分留在視野內。

## 何時不用

- **沒有日期的狀態。** 請用專案看板。
- **一天之內的時段。** 請用週曆。
- **唯讀的帶日期事件清單。** 一般時間軸更輕。
- **數百個任務。** 有物件移動時每個影格都會重畫箭頭；請把計畫控制在幾十個任務以內。

## 用法

設定 `Groups`（依序的階段）與 `Tasks`。`GanttTask` 有 `Id`、`Name`、所屬階段的 `GroupId`、`Start` 與 `End`（最後一天，含當天）、介於 0 到 1 的 `Progress`、選用的 `Assignee`、所相依任務的 `DependsOn`，以及表示單日標記的 `IsMilestone`。`Today` 決定今天線與首次捲動位置。

時間軸保存自己的任務副本，並透過 `TasksChanged` 回報每次編輯；頁尾的 `Undo` 與 `Reset` 會沿這些編輯回退。`Zoom` 在 `Day`、`Week`、`Month` 之間切換，並保持視圖中心不動。`CollapsedGroups` 保存已摺疊階段的 id。

### 鍵盤

| 按鍵 | 作用 |
|---|---|
| Tab | 進入圖表；同一時間只有一個長條是 Tab 停靠點 |
| 下 / 上方向鍵 | 移到下一個或上一個可見長條 |
| Alt + 左 / 右方向鍵 | 把目前任務移動一天 |
| Alt + Shift + 左 / 右方向鍵 | 把目前任務的結束日期改一天 |
| Enter / 空白鍵 | 選取長條並醒目提示它的箭頭 |
| Escape | 清除選取 |

## 無障礙

長條是名為 "Task bar" 或 "Milestone" 的按鈕，具有表示選取的按下狀態，標籤會給出名稱、日期、完成百分比，以及相依關係被破壞時的警告。摺疊的列對輔助技術隱藏。頁尾狀態列是禮貌型即時區域，會播報每次移動、復原與衝突。日曆表頭、格線、箭頭與彙總條僅作裝飾。

## 動態效果

拖曳後，長條會從放開的位置彈回吸附的那一天。把長條縮短到不足一天時會有柔和的橡皮筋阻力。縮放以彈簧圍繞視圖中心滑動，Today 按鈕把今天線滑入視圖。摺疊階段時，它的列會向上滑入階段列。減少動態時一切直接跳到目標。

## 響應式

- 圖表依自身寬度而不是視窗寬度調整。寬度低於 560 px 時，任務欄從 248 px（`TaskColumnWidth`）收窄為 132 px（`NarrowTaskColumnWidth`），日曆佔用其餘寬度。
- 日曆在圖表內部水平與垂直捲動，放不下的方向會顯示捲軸。按住 Shift 再捲動滾輪時，日曆水平捲動。
- 標題與縮放切換按鈕位於同一列。手機寬度下標題在它們旁邊會被截斷，因此為時間軸設定簡短的 `Title`。
- 觸控螢幕：任務列高 40 px（`GanttModel.RowHeight`），縮放切換按鈕高 32 px（`SwitchButtonHeight`），低於舒適的觸控目標。讓時間軸佔滿寬度並設定固定高度；只有父層沒有給出高度時才使用 `DefaultChartHeight`。
