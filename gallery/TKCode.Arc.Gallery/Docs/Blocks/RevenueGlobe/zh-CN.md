## 何时使用

`RevenueGlobe` 把一天的支付变成可以观看的画面。每笔支付都以一条弧线从它来自的城市飞向你的总部，弧线落地时，地球旁边的数字随之递增；地球下方的时间轴展示整天的情况：每个十五分钟时段有多繁忙、当前时刻在哪里，以及一个可以拖动到任意时刻的播放头。它适合放在运营或营收总览的顶部、办公室墙上的屏幕，或小型企业工具的首页。

- **面向全球销售团队的营收总览。** 各地区显示今日营收与预测的对比，因此“是否按计划进行？”可以按地区一眼看出；热门城市则说明当天的业务发生在哪里。
- **用于发布与活动的墙面展示。** 地球会自行缓慢漂移，弧线持续飞行，“重播今日”可在不到一分钟内播放完整的一天，便于在晨会上展示早上的高峰。
- **来自支付服务商的实时数据。** 将 `ClockMode` 设为 `External`，每当 webhook 到达时追加支付，并推进 `Now`；每笔新支付会在到期时立即飞出它的弧线。
- **事故复盘。** 将播放头拖到错误开始出现的那一分钟，读取当时的总计：每个数字、列表和条形都跟随播放头变化，而不只是跟随时钟。

## 何时不用

- **精确分析。** 地球展示的是活动的概况。按小时、按产品或按客户的总计应放在图表或表格（`DataGrid`、折线图）中，以便直接比较数值。
- **数以千计的地点。** 本区块为每个城市绘制一个点及其弧线。几十个城市读起来清晰；若有数百个，请把它们归并为人们熟悉的城市。
- **不以一天为周期的支付。** 时间轴始终跨越 24 小时。周或月的总计需要另一种视图。
- **页面上还有其他动画。** 漂移的地球和飞行的弧线会吸引视线。请把它放在唯一会动的位置，或使用 `DriftSpeed="0"` 关闭漂移。

## 用法

### 结构

从上到下（宽度超过 880 像素时，面板移到地球右侧）：

1. **头部**：`Title`、`Description` 和 `DateText`（日期由你自行格式化）。
2. **地球**：陆地与海洋以按深度着色的点绘制，城市的点大小取决于今日营收，总部及其名称，以及支付弧线。悬停在某个城市上会显示一张卡片，包含其营收、支付笔数、占总额的比例和当地时间。
3. **时间轴控件**：重播今日、暂停 / 播放、播放头处的时钟（默认为 UTC），以及“实时”药丸按钮。
4. **时间轴**：每 15 分钟的支付笔数以条形显示，播放头之前的部分颜色较深，到当前时刻之间的部分较浅，其余时段以虚线表示，播放头可以拖动。
5. **面板**：今日营收、支付笔数与最近一小时；各地区与其预测的对比；前五名热门城市。

### 数据

提供城市、它们所归属的地区、总部和支付。城市和地区是普通对象，因此可以写在 XAML 中；支付通常在代码中加载。

```xml
<arc:RevenueGlobe x:Name="Globe"
                  Title="Ebook orders"
                  Description="Cities buying from Dublin today."
                  DateText="Thursday, 22 October"
                  CurrencySymbol="€">
    <arc:RevenueGlobe.Regions>
        <arc:RevenueRegion Key="eu" Name="Europe" Forecast="61000" />
        <arc:RevenueRegion Key="am" Name="Americas" Forecast="38000" />
    </arc:RevenueGlobe.Regions>
    <arc:RevenueCity Key="dub" Name="Dublin" CountryCode="IE" RegionKey="eu" Latitude="53.35" Longitude="-6.26" />
    <arc:RevenueCity Key="ams" Name="Amsterdam" CountryCode="NL" RegionKey="eu" Latitude="52.37" Longitude="4.90" UtcOffsetHours="1" />
    <arc:RevenueCity Key="tor" Name="Toronto" CountryCode="CA" RegionKey="am" Latitude="43.65" Longitude="-79.38" UtcOffsetHours="-4" />
</arc:RevenueGlobe>
```

```csharp
Globe.Headquarters = Globe.Cities[0];
Globe.DayStart = new DateTimeOffset(2026, 10, 22, 0, 0, 0, TimeSpan.Zero);
Globe.Payments = orders.Select(o => new RevenuePayment(o.PaidAt, o.CityKey, o.Total)).ToList();
```

- 支付通过 `RevenueCity.Key` 指明其所在城市。总部的支付计入所有总计，但不绘制弧线。城市未知的支付只计入总计。
- 支付应按时间顺序提供；其他顺序会被排序一次。任意时刻的总计都是前缀和，因此包含几十万笔支付的一整天可以回放，而无需重新遍历它们。
- `RevenueRegion.Forecast` 是该地区全天预计的营收；它所在的行显示今日营收占预测的比例。地区会将镜头飞到 `CenterLatitude` / `CenterLongitude`；若未设置，则飞到其城市中按营收加权的中心。
- 地球的陆地数据来自 Natural Earth 1:110m（公共领域），一次性在 12,800 个点的网格上采样（点之间相距 1.7°）。`Land` 可以设置更粗或更细的采样（`RevenueGlobeLand.Sample(7000, 1200)`），或提供你自己的点（`RevenueGlobeLand.FromPoints(...)`）。

### 时钟

`Now` 表示当前时刻：之后的支付会等待，时间轴上的浅色条形在此结束。在默认的 `ClockMode="Internal"` 下，地球会从你设置的值开始按真实时间推进 `Now`，因此提前准备好的一天会实时播放出来，上方的预览正是从 14:30 开始这样运行的。当本区块滚出视口时，它停止绘制，并在回到视口时追上真实时间。

在 `ClockMode="External"` 下，由你的应用推进 `Now`。使用 `AddPayment` 追加支付（或将它们添加到会引发变更事件的集合中），然后把 `Now` 移动到你的服务器报告的时间：

### 重播、暂停与播放头

重播今日会回到 00:00，并以 `ReplaySpeed`（1500 倍速：一小时用 2.4 秒）播放这一天；播放开始时加速，接近时减速，使其恰好停在当前时刻，然后回到实时。暂停会冻结播放头（仍在飞行中的弧线会继续落地）；播放则从该处继续重播。回到实时，或在时间轴上按 End，会在至多两秒内快进到当前时刻。在时间轴上拖动会跳到指针处并跟随它；松开后，会以拖动的速度继续重播。

这些功能也可用于你自己的控件：`ReplayCommand`、`TogglePauseCommand` 和 `GoLiveCommand`，方法 `Replay()`、`Pause()`、`Play()`、`GoLive()` 和 `SeekTo(time)`，双向绑定的 `Time` 和 `IsPaused`，以及在播放头移动时每帧都会触发的 `TimeChanged`：

### 城市与地区

在地球上或热门城市列表中点击一个城市，镜头会沿大圆飞到该城市，放大到 `CityZoom` 并保持该视图；卡片始终停留在该城市上。点击一个地区，镜头会以 `RegionZoom` 飞到该地区，其他城市淡出，该地区三个最大的城市会显示名称。城市与地区不会同时被选中。再次点击已选中的行、点击地球上的空白处，或按 Escape 即可取消选择：缩放会以弹簧回弹，地球回到原位，并恢复漂移。

`SelectedCity` 和 `SelectedRegion` 为双向绑定，`FlyTo(city)` 和 `FlyTo(region)` 可以从代码中选择，`ResetView()` 会清除选择并让地球回到原位，`SelectionChanged` 会报告每一次变化：

### 窄版布局

本区块跟随它自身的宽度，而不是窗口的宽度。宽度从 880 像素起，面板位于地球旁边；宽度在 600 到 880 之间时，面板位于地球下方，分为两列；宽度低于 600 时为单列，营收数字较小；宽度低于 400 时，时钟独占一行。地球的高度随宽度变化（最大 580 像素），其半径始终为较短一边的 41%。

### 减少动效

当动效被减弱时，地球保持静止：它显示最新的弧线（已完整绘制），没有漂移，没有“重播”和“暂停”按钮，药丸上显示“现在”。拖动、选择以及时间轴的按键仍然有效；每次变化都会立即生效。

### 文字

本区块显示或朗读的每一个词都在 `Labels` 中，它是一个带有英文默认值的 `RevenueGlobeLabels`。若要翻译本区块或更改其措辞，请整体替换它；包含数字或名称的格式则是函数。

```csharp
Globe.Labels = new RevenueGlobeLabels
{
    Replay = "Tag wiederholen",
    Live = "Live",
    GoLive = "Zur Gegenwart",
    OfForecast = percent => $"{percent:0} % der Prognose",
};
Globe.Culture = CultureInfo.GetCultureInfo("de-DE");
```

### 性能

- 每一帧绘制 2,500 到 3,300 个点（陆地、海洋和城市）、飞行中的弧线及其光环：在桌面的软件渲染下约 3 毫秒，回放时略多（约 30 条弧线），每条弧线占用几千字节内存。浏览器中会更慢；在手机上，使用更粗的 `Land`（`RevenueGlobeLand.Sample(7000, 1200)`）可将点数减半。
- 地球只在有东西移动时请求帧：漂移、弧线、滑动或飞行。减少动效时，静止的地球不绘制任何内容。
- 回放时，每秒最多开始 14 条弧线；总计仍会统计每一笔支付。

## 无障碍

- 地球是一个可获得焦点的区域，名称为“Revenue globe”，并附有操作说明（“Arrow keys turn the globe, Escape clears the selection.”）。其描述是当前时刻的摘要：营收、支付笔数、时间、各地区以及领先的城市。描述会在每分钟变化时刷新，而不是每帧刷新。
- 屏幕阅读器还能找到一张隐藏表格，列出每个城市及其地区、营收和支付笔数，并随播放头更新。
- 城市的点本身不可获得焦点。键盘用户从热门城市列表中选择城市，从地区列表中选择地区；两者都是切换按钮，按下状态即为选中。地区的行会描述其占今日营收的比例及其预测。
- 数字会向屏幕上的值递增，但屏幕阅读器会直接朗读最终值。
- 时间轴是一个滑块，覆盖到当前为止的这一天（以午夜起算的秒数表示），名称为“Time of day, UTC”。
- 一条礼貌式实时区域会播报“Paused”、“Replaying today”、“Back to live”、“Camera on …”和“Selection cleared”。
- 重播、暂停 / 播放以及“实时”药丸都是按钮；暂停按钮的名称会说明它将执行什么操作。

### 键盘

| 按键 | 位置 | 操作 |
|---|---|---|
| `ArrowLeft` / `ArrowRight` | 地球 | 将地球向西或向东轻推一下；它会滑行出去 |
| `ArrowUp` / `ArrowDown` | 地球 | 短暂倾斜；它会弹回原来的倾斜角度 |
| `Escape` | 地球 | 清除所选的城市或地区 |
| `ArrowLeft` / `ArrowRight` | 时间轴 | 将播放头移动 5 分钟（按住 `Shift`：一小时）；若在过去，则从该处继续重播 |
| `PageUp` / `PageDown` | 时间轴 | 将播放头移动一小时 |
| `Home` | 时间轴 | 回到 00:00 |
| `End` | 时间轴 | 回到实时 |
| `Enter` 或 `Space` | 按钮与行 | 按下按钮；选择或取消选择地区或城市 |
| 拖动 | 地球 | 转动地球；快速松开会继续滑行，倾斜则弹回原位 |
| 拖动 | 时间轴 | 将播放头移动到指针下；松开后从该处继续重播 |

## 动效

- 空闲时，地球以每秒 4° 的速度围绕总部在 86° 经度范围内来回漂移，在两端平滑转向；倾斜角始终以慢速弹簧回到 22°。
- 拖动会使表面跟随指针移动。松开后会滑行（每帧速度降低 1.3%），直到漂移接管；将倾斜拉过 65° 时会像橡皮筋一样伸展，然后弹回。
- 飞向城市或地区时沿大圆运动，采用临界阻尼弹簧；飞行距离较远时，途中会稍微拉远视角。
- 弧线的头部约一秒钟到达（远距离城市需要更长时间），弧线保持完整三分之一秒，然后尾部跟随它进入总部，同时逐渐淡出。支付开始时，城市处会展开一个小光环；支付到达时，总部处会展开一个较大的光环；数字也在此刻递增。
- 数字在约四分之一秒内缓动到每个新值。提示卡淡入并放大，以弹簧跟随其城市，然后淡出。
- 减少动效时，上述动作都不会移动；参见[减少动效](#reduced-motion)。
