## 何時使用

`RevenueGlobe` 把一天的付款呈現為值得觀看的畫面。每一筆付款都會以一道弧線，從它來自的城市飛向你的總部；地球儀旁的數字會隨著弧線抵達而計數上升；地球儀下方的時間軸則呈現整天的樣貌：每十五分鐘有多繁忙、現在位於何處，以及一個可以拖回任一時刻的播放頭。它適合放在營運或營收總覽的頂端、辦公室牆面的螢幕，或小型商業工具的首頁。

- **面向全球銷售團隊的營收總覽。** 各區域顯示今日營收與其預測，因此「是否達標？」可以逐區一眼看出；排名前幾的城市則說明今天的交易集中在哪裡。
- **用於發表與活動的牆面顯示。** 地球儀會自行緩緩漂移，弧線持續飛行，「重播今日」可在不到一分鐘內播完整天，讓早上的高峰在站立會議中容易說明。
- **來自付款服務商的即時動態。** 將 `ClockMode` 設為 `External`，隨 webhook 抵達附加付款，並推進 `Now`；每筆新付款會在到期時立即飛出它的弧線。
- **事件的事後檢討。** 把播放頭拖到錯誤開始出現的那一分鐘，讀取當時的總計：每個數字、清單與長條都會跟著播放頭變動，而不只是跟著時鐘。

## 何時不用

- **精確的分析。** 地球儀是活動的示意圖。依小時、產品或客戶的總計，應放在圖表或表格（`DataGrid`、折線圖）中，讓數字可以直接比較。
- **數以千計的地點。** 此區塊把每座城市畫成一個點，並各自帶著一條弧線。幾十座城市能清楚呈現；數百座時，請把它們歸併為人們熟悉的城市。
- **不在一天之內發生的付款。** 時間軸永遠涵蓋 24 小時。每週或每月的總計需要另一種檢視。
- **頁面上還有其他動畫。** 漂移的地球儀與弧線會吸引目光。請把它放在唯一會移動的位置，或以 `DriftSpeed="0"` 關閉漂移。

## 用法

### 結構

由上到下（寬度超過 880 像素時，面板會移到地球儀的右側）：

1. **標題區**：`Title`、`Description` 與 `DateText`（日期的格式由你決定）。
2. **地球儀**：陸地與海洋以依深度著色的點呈現，城市的點依今日營收決定大小，總部與其名稱，以及付款弧線。將指標懸停在城市上，會顯示一張卡片，列出它的營收、付款筆數、占總額的比例與當地時間。
3. **時間軸控制**：重播今日、暫停／播放、播放頭處的時鐘（預設為 UTC），以及 Live 膠囊。
4. **時間軸**：每十五分鐘的付款數以長條呈現，播放頭之前的顏色較深，之後到現在之間的顏色較淡，其餘的一天以虛線表示，播放頭可以拖曳。
5. **面板**：今日營收、付款筆數與最近一小時；各區域與其預測的對照；前五名城市。

### 資料

提供城市、它們所屬的區域、總部與付款。城市與區域都是一般物件，因此可以直接寫在 XAML 中；付款通常在程式碼中載入。

```xml
<arc:RevenueGlobe x:Name="Globe"
                  Title="Ebook orders"
                  Description="Cities buying from Dublin today."
                  DateText="Thursday, 22 October"
                  CurrencySymbol="€">
    <arc:RevenueGlobe.Regions>
        <arc:RevenueRegion Key="eu" Name="Europe" Forecast="61000" />
        <arc:RevenueRegion Key="am" Name="Americas" Forecast="38000" />
    </arc:RevenueGlobe.Regions>
    <arc:RevenueCity Key="dub" Name="Dublin" CountryCode="IE" RegionKey="eu" Latitude="53.35" Longitude="-6.26" />
    <arc:RevenueCity Key="ams" Name="Amsterdam" CountryCode="NL" RegionKey="eu" Latitude="52.37" Longitude="4.90" UtcOffsetHours="1" />
    <arc:RevenueCity Key="tor" Name="Toronto" CountryCode="CA" RegionKey="am" Latitude="43.65" Longitude="-79.38" UtcOffsetHours="-4" />
</arc:RevenueGlobe>
```

```csharp
Globe.Headquarters = Globe.Cities[0];
Globe.DayStart = new DateTimeOffset(2026, 10, 22, 0, 0, 0, TimeSpan.Zero);
Globe.Payments = orders.Select(o => new RevenuePayment(o.PaidAt, o.CityKey, o.Total)).ToList();
```

- 付款以 `RevenueCity.Key` 指明它的城市。總部的付款會計入每個總計，但不繪製弧線；城市未知的付款只計入總計。
- 付款應依時間順序提供；其他情況會排序一次。任一時刻的總計都是前綴和，因此一整天數十萬筆的付款可以直接重播，而不必重新逐筆計算。
- `RevenueRegion.Forecast` 是該區域整天預期的營收；它那一列顯示今日營收占預測的比例。區域會讓相機飛到 `CenterLatitude` / `CenterLongitude`；未設定時，則飛到其城市依營收加權的中心位置。
- 地球儀的陸地取自 Natural Earth 1:110m（公共領域），以 12,800 個格點取樣一次（點與點相距 1.7°）。`Land` 可以採用較粗或較細的取樣（`RevenueGlobeLand.Sample(7000, 1200)`），或你自己的點（`RevenueGlobeLand.FromPoints(...)`）。

### 時鐘

`Now` 是現在：之後的付款會等待，時間軸的亮色長條也到此為止。預設的 `ClockMode="Internal"` 下，地球儀會從你設定的值開始，依真實時間推進 `Now`，因此事先準備好的一天會即時播放，上方的預覽就是從 14:30 開始這樣運作。當此區塊捲動到可視範圍之外時，它會停止繪製，並在回到畫面時追上真實時間。

使用 `ClockMode="External"` 時，由你的應用程式推進 `Now`。以 `AddPayment` 附加付款（或加入會引發變更事件的集合），再把 `Now` 移到伺服器回報的時間：

### 重播、暫停與播放頭

「重播今日」會回到 00:00，並以 `ReplaySpeed`（1500 倍速：一小時在 2.4 秒內播完）播放這一天，開始時加速、結束前減速，使它正好停在現在，之後再回到即時。暫停會凍結播放頭（飛行中的弧線仍會抵達）；播放則從該處繼續重播。切換到即時，或在時間軸上按 End，會在至多兩秒內快轉到現在。拖曳時間軸會跳到指標所在處並跟隨它；放開後會以拖曳的速度繼續重播。

這些功能也可供你自己的控制項使用：`ReplayCommand`、`TogglePauseCommand` 與 `GoLiveCommand`，方法 `Replay()`、`Pause()`、`Play()`、`GoLive()` 與 `SeekTo(time)`，雙向繫結的 `Time` 與 `IsPaused`，以及 `TimeChanged`（播放頭移動時每一影格都會觸發）：

### 城市與區域

在地球儀上或前幾名城市清單中點選一座城市，相機會沿大圓飛到那裡，放大至 `CityZoom` 並停留在該視角；卡片會留在該城市上。點選一個區域，相機會以 `RegionZoom` 飛到該區域，其他城市淡出，該區域三座最大的城市會顯示名稱。城市與區域不會同時被選取。再次點選已選取的列、點選地球儀上的空白處，或按下 Escape 即可放開：縮放會以彈簧回彈，傾斜回到原位，漂移也會繼續。

`SelectedCity` 與 `SelectedRegion` 是雙向的；`FlyTo(city)` 與 `FlyTo(region)` 可從程式碼選取；`ResetView()` 會清除選取並讓地球儀回到原位；`SelectionChanged` 會回報每一次變更：

### 窄版容器

此區塊依自己的寬度變化，而不是視窗的寬度。寬度從 880 像素起，面板位於地球儀旁邊；介於 600 與 880 之間時，面板位於地球儀下方、分為兩欄；低於 600 時為單欄，營收數字較小；低於 400 時，時鐘會單獨佔一列。地球儀的高度隨寬度變化（最高 580 像素），其半徑永遠是短邊的 41%。

### 減少動態效果

減少動態效果時，地球儀保持靜止：它顯示最近的弧線完整繪出，沒有漂移，也沒有「重播」與「暫停」按鈕，而 Live 膠囊會顯示「Now」。拖曳、選取與時間軸的按鍵仍然可用；每個變更都會立即生效。

### 文字

此區塊顯示或朗讀的每一個字，都在 `Labels` 中，它是一個預設為英文的 `RevenueGlobeLabels`。若要翻譯此區塊或變更用字，請整個替換它；需要帶入數字或名稱的格式則是函式。

```csharp
Globe.Labels = new RevenueGlobeLabels
{
    Replay = "Tag wiederholen",
    Live = "Live",
    GoLive = "Zur Gegenwart",
    OfForecast = percent => $"{percent:0} % der Prognose",
};
Globe.Culture = CultureInfo.GetCultureInfo("de-DE");
```

### 效能

- 一個影格會繪製 2,500 至 3,300 個點（陸地、海洋與城市）、飛行中的弧線與它們的光環：在桌機的軟體繪製下約 3 毫秒，重播時會稍多（約 30 條弧線），每條弧線約需數 KB 的記憶體。瀏覽器較慢；在手機上，改用較粗的 `Land`（`RevenueGlobeLand.Sample(7000, 1200)`）可使點數減半。
- 地球儀只在有東西在移動時才要求影格：漂移、弧線、滑行或飛行。減少動態效果下，靜止的地球儀不繪製任何東西。
- 重播時，每秒最多開始 14 條弧線；總計仍會計入每一筆付款。

## 無障礙

- 地球儀是一個可取得焦點的區域，名稱為「Revenue globe」，並說明如何操作（「Arrow keys turn the globe, Escape clears the selection.」）。其描述是當下狀況的摘要：營收、付款筆數、時間、各區域與領先的城市。它會在分鐘改變時更新，而不是每一影格都更新。
- 螢幕閱讀器也能找到一張隱藏的表格，列出每座城市與其區域、營收和付款筆數，並隨播放頭更新。
- 城市的點本身不能取得焦點。鍵盤使用者從前幾名城市清單中選擇城市，從區域清單中選擇區域；兩者都是切換按鈕，按下狀態即代表已選取。區域的列會描述其占今日營收的比例與預測。
- 數字會計數到畫面上的值，但螢幕閱讀器會一次讀出最終的值。
- 時間軸是一個以當日已過秒數（自午夜起算）為範圍的滑桿，名稱為「Time of day, UTC」。
- 禮貌模式的即時區域會播報「Paused」、「Replaying today」、「Back to live」、「Camera on …」與「Selection cleared」。
- 重播、暫停／播放與 Live 膠囊都是按鈕；暫停按鈕的名稱會說明它將執行的動作。

### 鍵盤

| 按鍵 | 位置 | 操作 |
|---|---|---|
| `ArrowLeft` / `ArrowRight` | 地球儀 | 讓地球儀向西或向東推一下；它會滑行出去 |
| `ArrowUp` / `ArrowDown` | 地球儀 | 短暫傾斜；它會以彈簧彈回原本的傾斜角度 |
| `Escape` | 地球儀 | 清除選取的城市或區域 |
| `ArrowLeft` / `ArrowRight` | 時間軸 | 移動播放頭 5 分鐘（`Shift`：一小時）；若在過去，會從該處繼續重播 |
| `PageUp` / `PageDown` | 時間軸 | 移動播放頭一小時 |
| `Home` | 時間軸 | 前往 00:00 |
| `End` | 時間軸 | 切換到即時 |
| `Enter` 或 `Space` | 按鈕與列 | 按下按鈕；選取或清除區域或城市 |
| 拖曳 | 地球儀 | 旋轉地球儀；快速放開會繼續滑行，傾斜會彈回原位 |
| 拖曳 | 時間軸 | 移動指標下的播放頭；放開即從該處重播 |

## 動態效果

- 閒置時，地球儀會以每秒 4° 在總部周圍、86° 經度的範圍內來回漂移，並在兩端平滑轉向；傾斜角度始終以緩慢的彈簧回到 22°。
- 拖曳會讓指標下的表面跟著移動。放開後會滑行（每影格速度減少 1.3%），直到漂移接手；把傾斜拉過 65° 時會像橡皮筋一樣拉伸，然後彈回。
- 飛向城市或區域時，沿大圓移動，並以臨界阻尼彈簧運行；距離較遠時，途中會稍微拉遠。
- 弧線的頭部約在一秒內移動完成（遠距離的城市更久），弧線完整停留三分之一秒，之後尾部跟上並在飛入總部的同時淡出。付款開始時，城市處會打開一個小光環；抵達總部時，總部處會出現較大的光環，數字也會在那一刻計數上升。
- 數字約在四分之一秒內緩和地過渡到每個新值。提示卡會淡入並放大，以彈簧跟隨它的城市，最後淡出。
- 減少動態效果下，以上都不會移動；請見[減少動態效果](#減少動態效果)。
