## 何时使用

`BarChart` 在一段连续的日、周或月之间比较同一个指标，并允许读者逐根查看任一柱子的精确数值。标题区在静止时显示平均值，因此读者首先看到的是该指标的总体水平，柱子则显示每个时段与平均值相比的情况。它适用于分析页或运维仪表板中的面板，关注的问题是“哪几天不寻常”，而不是“趋势将如何延续”。

- **产品分析页中的每日活跃分钟数**：产品团队把一周内每天的活跃分钟数与日均值比较，并逐根查看周四的柱子，读出确切的总量。
- **工程控制台中的每周部署或发布次数**：每根柱子都是一个独立的周，团队能看出哪个迭代发布最多，而不会出现暗示连续趋势的折线。
- **帮助台仪表板中的每日工单数**：队列负责人看到周一的峰值，并读出背后的数量，平均线则显示正常一天的水平。
- **财务复盘中按月的收入或订单量**：月均参考线让高于和低于它的月份一目了然，数值轴可以固定，使两个时段按相同的刻度绘制。
- **计量服务控制台中按计费周期统计的用量**：每日的 API 调用量或存储用量，读者逐根查看时，标题中显示该周期的合计。

## 何时不用

- **包含多个数据点或多个数据系列的连续趋势**：使用 `LineChart`，它会穿过各数据点画线，并可通过图例显示多个系列。
- **与单个数值并列的紧凑趋势**：使用 `Sparkline`，它可以放进表格单元格或指标卡片。
- **以网格呈现一整年的每日活动**：使用 `ActivityHeatmap`，每一天是一个方块，周与周之间的节奏才是重点。
- **一个整体的组成部分，例如流量来源或支出类别**：使用 `DonutChart`，各部分加起来就是总量。
- **单个数值与目标或上限的对比**：使用 `Gauge` 或 `UsageMeter`，它们显示某个指标的满载程度。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AtomUICommunity/TKCode.Arc">
    <arc:BarChart Label="活跃分钟数"
                  Period="2026 年 9 月 24–30 日"
                  Unit="分钟"
                  CategoryLabel="日"
                  ItemsSource="{Binding Week}" />
</UserControl>
```

`BarChart` 派生自 `ChartBase`，它是 Arc 自绘图表的基类。基类负责数据管线、调色板、首次显示时的揭示效果、读数的键盘操作模型、无障碍摘要以及隐藏的数据表，因此每个 Arc 图表的读取与逐点查看方式都一致。柱状图在此基础上加入标题、平均线和柱子的几何布局。整个绘图区一次绘制完成，因此更新一周或一个月的柱子依然开销很小。

### 结构

1. **标题类别**（`AverageLabel`、`ValueLabel`）：数字上方的小标签。静止时显示“每日平均”，逐根查看时显示“合计”。使用次要文字颜色和小号字体。
2. **标题数值**：静止时为平均值，逐根查看时为该柱子的数值，使用显示字体、3XL 字号和中等字重。数字会滚动到新值。`Unit` 跟在数字之后，与数字基线对齐，使用次要颜色。
3. **时间范围与读数**（`Period`）：位于标题下方，静止时显示当前范围（“2026 年 9 月 24–30 日”），逐根查看时显示该柱子的完整标签（“星期二，9 月 22 日”）。该行保持固定高度，切换时绘图区不会移动。
4. **绘图区**：每个数据点对应一根柱子。柱子占其槽位的 58%，最宽 28 px。容器较宽时，柱子之间增加间距，而不是把柱子变粗。
5. **平均线**（`ShowAverage`）：位于平均值处的虚线参考线，横跨整个绘图区。
6. **数值轴槽**：右侧 52 px，放置数值刻度，以及表示平均值的简短“平均”标签。
7. **类别轴行**：柱子下方 26 px，放置简短的轴标签（`AxisLabel`，或日期的简短形式）。
8. **网格线**（`ShowGrid`）：位于数值刻度处的水平参考线，绘制在柱子之后。

标题与绘图区之间相隔 20 px。绘图区高度默认为 176 px，使用 `PlotHeight` 设置；宽度随容器变化。

### 时间范围

时间范围变化时，同时替换 `ItemsSource` 与 `Period`。键相同的柱子在变化后会保留其身份，因此仍在范围内的某一天会变形到新的高度与位置，新增的柱子则在旁边生长出来。键默认为类别值，因此日期会保留其键；当类别不唯一或不稳定时，请自行设置 `ChartPoint.Key`。

```csharp
void ShowWeek()
{
    var culture = CultureInfo.GetCultureInfo("en-US");
    var start = new DateOnly(2026, 9, 24);
    int[] minutes = [46, 30, 52, 61, 38, 27, 44];
    chart.Period = "2026 年 9 月 24–30 日";
    chart.ItemsSource = Enumerable.Range(0, minutes.Length).Select(i =>
    {
        var day = start.AddDays(i);
        return new ChartPoint(day, minutes[i])
        {
            Label = day.ToString("dddd, MMM d", culture),
            AxisLabel = day.ToString("ddd", culture)
        };
    }).ToArray();
}
```

`ChartPoint` 是一个记录类型，包含类别、数值以及可选的文字。`ChartPoint.Label` 是提供给辅助技术朗读、并显示在读数中的完整名称。`ChartPoint.AxisLabel` 是柱子下方的简短文字；设为 null 可让该柱子下方的坐标轴保持简洁。读数与朗读使用相同的完整名称，因此范围变化时，读者会同时听到新的时间段与新的平均值。

获取下一个范围期间，设置 `IsLoading`。在新数据到达之前，现有图形保持在屏幕上，并以淡化、呼吸式闪烁的方式显示，因此页面不会在两个范围之间闪成空白。

### 标题标签

`AverageLabel` 为静止时标题的名称，`ValueLabel` 为逐根查看时柱子数值的名称。默认值分别为“每日平均”和“合计”。把它们改为该指标自己的用语，例如每周柱子使用“每周平均”；当参考线对读者没有帮助时，使用 `ShowAverage` 隐藏平均线。

```xml
<arc:BarChart Label="部署次数"
              Period="最近 12 周"
              AverageLabel="每周平均"
              ValueLabel="部署次数"
              CategoryLabel="周"
              ShowAverage="False"
              PlotHeight="140"
              ItemsSource="{Binding Weeks}" />
```

`Average` 是所有数值的平均值，为只读属性，因此标题注或状态行可以显示同样的数字。平均线本身是从数据中绘制的参考线，而不是目标值。

### 数值格式与坐标轴

`ValueFormat` 接受 en-US 的 .NET 格式字符串，例如用于分组整数的 `N0`、用于货币的 `C0`，或用于一位小数百分比的 `0.0'%'`。`ValueFormatter` 会接收数值及其索引和系列，两者都设置时以 `ValueFormatter` 为准；当标签取决于具体柱子时应使用它，例如“3 起事件，其中 1 起严重”。`Unit` 文字会附加在“50 分钟”这样的读数以及数据表中。

`ShowGrid`、`ShowXAxis` 与 `ShowYAxis` 控制参考线与标签。`YMinimum` 固定数值轴的下限，`YMaximum` 固定其上限。默认情况下，数值轴从零开始；若数据有低于零的值，则从最低值开始；并在最大值之上的下一个整齐刻度处结束。当同一页面上的两个图表需要共用刻度时，固定 `YMaximum`；当刻度标签需要与数值不同的格式时，使用 `TickFormatter` 格式化刻度标签。

```xml
<arc:BarChart Label="工单" YMaximum="100" ShowGrid="False" ItemsSource="{Binding Tickets}" />
```

### 读取数值

`ActiveIndex` 是指针或键盘所在的柱子，静止时为 null，并且是双向的。`ActiveIndexChanged` 会报告每一次移动，包括该时刻的索引、数据项、标签与数值。可用它在图表之外的状态行中显示数值。

```csharp
chart.ActiveIndexChanged += (_, e) => status.Text = e.Index is null
    ? $"平均 {chart.Average:N0}"
    : e.Label;
```

`Summary` 是提供给辅助技术的一段描述，例如“活跃分钟数，9 月 15–21 日。每日平均 40 分钟。最高为周四，60 分钟。最低为周三，20 分钟。”`DataTableText` 则是同样的数据，以制表符分隔的表格形式给出：一行表头，加上每根柱子一行，例如“日\t活跃分钟数”后接“周一\t10 分钟”。该表格对视觉隐藏，但对辅助技术可用，因此即使看不到柱子，也能读取图表。

### 数据结构与性能

图表只在 `ItemsSource` 变化时读取一次数据，而不是每次重绘都读取。对于已经在内存中的数据，使用 `ChartPoint`：`new ChartPoint(category, value)` 的类别参数接受对象，因此 `DateOnly`、`DateTime`、字符串或数字都可以使用；默认的坐标轴标签会把日期格式化为“Sep 15”，完整标签格式化为“Tue, Sep 15”。当数据以行的形式到达时，用 `XSelector` 与 `YSelector`，或 `XBinding` 与 `YBinding` 读取。编译绑定形式（例如 `YBinding="{CompiledBinding Visits, DataType=local:Day}"`）是 AOT 安全的路径。

一周或一个月的柱子完全在图表能够流畅处理的范围之内。对于较长的序列，优先使用 `LineChart`，或将数据按周聚合，因为柱子会变细，类别标签也会变得稀疏。隐藏的数据表会随柱子数量增长，因此请把范围控制在读者能够快速浏览的程度。

### 示例：产品团队的每周活跃分钟数

某产品分析页面，展示 2026 年 9 月 24 日至 30 日这一周。标题显示每日平均值，时间范围位于其下方，坐标轴上的柱子使用简短的星期标签。团队从中读出周四为峰值、周三为谷值，摘要行中也是这样描述的。此处不展示截图，因为柱子与标题数字来自代码提供的数据（实时示例见上方的 Demo）；XAML 需要与代码示例使用相同的 `ItemsSource`。


### 文案规范

- **标签**：用句子式大小写的指标名称，例如“活跃分钟数”或“支持工单”。它为图表、摘要和数据表命名，因此必须能独立理解。
- **时间范围**：可读的范围，并带年份，例如“2026 年 9 月 24–30 日”或“最近 12 周”。时间范围变化时会被朗读，因此必须具体。
- **单位**：数值后的简短单位，例如“分钟”“毫秒”或“次”。单位较长时，把完整的词写在标签中。
- **平均与数值标签**：使用该指标自己的用语：每周柱子用“每周平均”，计数用“部署次数”。
- **类别标签**：单根柱子的单数名词，例如“日”“周”或“月”，在数据表中用作列名。

| 不要写 | 改为 |
|---|---|
| 数据 | 活跃分钟数 |
| 平均 | 每日平均 |
| 9 月 24 - 30 日 | 2026 年 9 月 24–30 日 |
| 条目（计数） | 支持工单 |
| 数值 | 合计 |

### 最佳实践

**推荐**

- 每个图表都设置 `Label` 与 `Period`。标签为屏幕阅读器命名图表，时间范围变化时会被朗读，因此读者总能知道柱子统计的是什么、覆盖哪些日期。
- 每个图表保持一个范围和一个单位。在同一图表中混用分钟与调用次数，会让平均值失去意义。
- 当两个图表需要并排比较时设置 `YMaximum`，使相同的高度在两个图表中代表相同的数值。
- 当类别不是稳定的标识符时，在 `ChartPoint` 上设置 `Key`，使柱子在范围变化时平滑变形，而不是被重新绘制。
- 当标题不足以说明问题时，用 `ActiveIndexChanged` 在图表之外显示被逐根查看的数值。

**避免**

- 把折线画过互不相关的类别。每个类别一根柱子，能避免读者在互不相关的日期之间读出趋势。
- 平均值正是重点时隐藏平均线。当读者想知道某天是高于还是低于正常水平时，保持 `ShowAverage` 开启。
- 对很长的柱子序列使用柱状图。柱子会细到无法逐根查看，此时折线或聚合视图更易读。
- 每秒多次修改 `ItemsSource`。每次修改都会使柱子和平均线变形，频繁修改会让图表不断移动，却没有向读者传达任何信息。
- 只依赖柱子的颜色。标题、读数和数据表承载了数值，因此即使读者看不清柱子高度，图表依然可用。

### 常见问题

**为什么标题显示的是平均值，而不是最新的柱子？** 静止时标题显示平均值，它是整个范围的参考。指针或键盘停在某根柱子上时，标题会变为该柱子的数值；按 Escape 释放读数，或焦点离开绘图区时，标题返回平均值。

**如何从代码设置被逐根查看的柱子？** `ActiveIndex` 是双向的：设置它会把标题和读数移动到该柱子，设为 null 则让标题返回平均值。可用它恢复选择，或把图表与读者选择的列表关联起来。

**为什么调整页面大小时柱子宽度不一致？** 柱子宽度上限为 28 px，并占其槽位的 58%。在较宽的绘图区中，多出的宽度变成柱子之间的间距，因此柱子粗细保持不变，只是间隙变大。

**为什么首次显示有动画，之后的变化没有？** 图表第一次被看到时，柱子会从左到右依次生长一次。之后的变化会让柱子从当前高度变形到新高度，因此读者看到的是变化本身，而不是再次出现初始的生长动画。

**如何让读数中的数值与坐标轴使用不同格式？** 为数值设置 `ValueFormat` 或 `ValueFormatter`，为数值轴设置 `TickFormatter`。两者相互独立，因此“1,284 分钟”这样的值可以完整显示，而坐标轴可以使用“1.3K”这样的紧凑格式。

## 无障碍

- `Label` 为图表命名。摘要会说明平均值、最高与最低的柱子。
- 方向键在柱子之间移动，PageUp 与 PageDown 每次移动最多七根柱子，Home 与 End 分别跳到第一根与最后一根柱子，Escape 停止逐根查看并返回平均值。
- 隐藏的数据表列出每一个数值，因此即使看不到柱子，也能读取图表。
- 时间范围变化时会以礼貌的方式播报。
- 柱子对辅助技术隐藏。逐根查看的位置由光标指示，而不是焦点框。
- 绘图区是一个可获得焦点的元素，辅助技术将其读作滑块，因此随着读数移动，每根柱子的完整标签和数值都会被朗读。

### 键盘

绘图区作为一个 Tab 停靠点获得焦点。键盘焦点从最新的一根柱子开始，因此最新的数值会被优先读出。

| 按键 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 将焦点移入绘图区并定位到最新的柱子，或移出绘图区 |
| `Left` / `Right`、`Down` / `Up` | 移到上一根或下一根柱子；从静止状态首次按下时，从最新的柱子开始 |
| `PageUp` / `PageDown` | 向前或向后移动最多七根柱子 |
| `Home` / `End` | 移到第一根或最后一根柱子 |
| `Escape` | 停止逐根查看，并将标题返回为平均值 |

失去焦点会清除读数，因此读者离开图表时，标题会返回平均值。

## 动效

- 首次显示时，柱子从左到右依次生长。
- 时间范围变化时，保留的柱子、坐标轴刻度与平均线会变形到新的数值，离开的柱子沉入基线。
- 查看光标在柱子之间平滑滑动，标题数值滚动到新的数字。
- 标题标签在平均值与数值标签之间切换，并伴随短暂的模糊。
- 减弱动效时，柱子直接显示为最终高度，数字原地替换。关闭动效时直接到达最终状态。

动效在这里跟随数据。键相同的柱子会变形，因此读者可以在两个范围之间追踪同一天。首次显示的波浪效果只留给真正需要它的图表；在经常刷新的仪表板上，每次刷新都会变形，效果会不断累积，因此请让数据刷新的频率与数值变化的频率相匹配。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 首次显示 | 柱子以从左到右的波浪依次生长 | 柱子以最终高度显示 | 立即完成 |
| 新的时间范围 | 保留的柱子变形，新柱子在旁边生长，离开的柱子下沉 | 柱子以最终高度显示 | 立即完成 |
| 逐根查看柱子 | 光标滑向柱子，标题数值滚动 | 标题数值原地替换 | 立即完成 |
| 标题标签 | 在平均值与数值标签之间切换，并伴随短暂的模糊 | 原地替换 | 立即完成 |

## 相关组件

- `LineChart`：多数据点的连续趋势。
- `Sparkline`：表格或卡片中的紧凑趋势。
- `ActivityHeatmap`：一整年的每日活动。
- `DonutChart`：柱子需要表示整体的各个组成部分时使用。

| 组件 | 适用场景 |
|---|---|
| `LineChart` | 多数据点的趋势，或多个系列，比单个时段更重要 |
| `Sparkline` | 紧凑趋势与表格或卡片中的一个数字并列显示 |
| `ActivityHeatmap` | 一整年的每日活动以方块网格呈现 |
| `DonutChart` | 数值是加起来等于总量的整体组成部分 |
| `AnimatedCounter` | 单个变化的数字就是全部信息，不需要图表 |
