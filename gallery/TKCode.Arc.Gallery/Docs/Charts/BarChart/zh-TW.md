## 何時使用

`BarChart` 在一段連續的日、週或月之間比較同一個指標，並允許讀者逐一查看任一長條的精確數值。標題區在靜止時顯示平均值，因此讀者首先看到的是該指標的整體水準，長條則顯示每個時段與平均值相比的情況。它適用於分析頁或維運儀表板中的面板，關注的問題是「哪幾天不尋常」，而不是「趨勢將如何延續」。

- **產品分析頁中的每日活躍分鐘數**：產品團隊把一週內每天的活躍分鐘數與日平均值比較，並逐一查看週四的長條，讀出確切的總量。
- **工程主控台中的每週部署或發佈次數**：每根長條都是一個獨立的週，團隊能看出哪個迭代發佈最多，而不會出現暗示連續趨勢的折線。
- **客服中心儀表板中的每日工單數**：佇列負責人看到週一的高峰，並讀出背後的數量，平均線則顯示正常一天的水準。
- **財務檢討中按月的營收或訂單量**：月均參考線讓高於和低於它的月份一目了然，數值軸可以固定，使兩個時段按相同的刻度繪製。
- **計量服務主控台中按計費週期統計的用量**：每日的 API 呼叫量或儲存用量，讀者逐一查看時，標題中顯示該週期的合計。

## 何時不用

- **包含多個資料點或多個資料系列的連續趨勢**：使用 `LineChart`，它會穿過各資料點畫線，並可透過圖例顯示多個系列。
- **與單一數值並列的精簡趨勢**：使用 `Sparkline`，它可以放進表格儲存格或指標卡片。
- **以網格呈現一整年的每日活動**：使用 `ActivityHeatmap`，每一天是一個方塊，週與週之間的節奏才是重點。
- **一個整體的組成部分，例如流量來源或支出類別**：使用 `DonutChart`，各部分加總就是總量。
- **單一數值與目標或上限的對比**：使用 `Gauge` 或 `UsageMeter`，它們顯示某個指標的滿載程度。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:BarChart Label="活躍分鐘數"
                  Period="2026 年 9 月 24–30 日"
                  Unit="分鐘"
                  CategoryLabel="日"
                  ItemsSource="{Binding Week}" />
</UserControl>
```

`BarChart` 衍生自 `ChartBase`，它是 Arc 自繪圖表的基底類別。基底類別負責資料管線、調色盤、首次顯示時的揭示效果、讀數的鍵盤操作模型、無障礙摘要以及隱藏的資料表，因此每個 Arc 圖表的讀取與逐點查看方式都一致。長條圖在此基礎上加入標題、平均線和長條的幾何配置。整個繪圖區一次繪製完成，因此更新一週或一個月的長條依然開銷很小。

### 結構

1. **標題類別**（`AverageLabel`、`ValueLabel`）：數字上方的小標籤。靜止時顯示「每日平均」，逐一查看時顯示「總計」。使用次要文字顏色與小號字型。
2. **標題數值**：靜止時為平均值，逐一查看時為該長條的數值，使用顯示字型、3XL 字級與中等字重。數字會捲動到新值。`Unit` 跟在數字之後，與數字基線對齊，使用次要顏色。
3. **時間範圍與讀數**（`Period`）：位於標題下方，靜止時顯示目前範圍（「2026 年 9 月 24–30 日」），逐一查看時顯示該長條的完整標籤（「星期二，9 月 22 日」）。該列保持固定高度，切換時繪圖區不會移動。
4. **繪圖區**：每個資料點對應一根長條。長條佔其槽位的 58%，最寬 28 px。容器較寬時，長條之間增加間距，而不是把長條加粗。
5. **平均線**（`ShowAverage`）：位於平均值處的虛線參考線，橫跨整個繪圖區。
6. **數值軸槽**：右側 52 px，放置數值刻度，以及表示平均值的簡短「平均」標籤。
7. **類別軸列**：長條下方 26 px，放置簡短的軸標籤（`AxisLabel`，或日期的簡短形式）。
8. **格線**（`ShowGrid`）：位於數值刻度處的水平參考線，繪製在長條之後。

標題與繪圖區之間相隔 20 px。繪圖區高度預設為 176 px，使用 `PlotHeight` 設定；寬度隨容器變化。

### 時間範圍

時間範圍變化時，同時取代 `ItemsSource` 與 `Period`。鍵相同的長條在變化後會保留其身分，因此仍在範圍內的某一天會變形到新的高度與位置，新增的長條則在旁邊長出來。鍵預設為類別值，因此日期會保留其鍵；當類別不唯一或不穩定時，請自行設定 `ChartPoint.Key`。

```csharp
void ShowWeek()
{
    var culture = CultureInfo.GetCultureInfo("en-US");
    var start = new DateOnly(2026, 9, 24);
    int[] minutes = [46, 30, 52, 61, 38, 27, 44];
    chart.Period = "2026 年 9 月 24–30 日";
    chart.ItemsSource = Enumerable.Range(0, minutes.Length).Select(i =>
    {
        var day = start.AddDays(i);
        return new ChartPoint(day, minutes[i])
        {
            Label = day.ToString("dddd, MMM d", culture),
            AxisLabel = day.ToString("ddd", culture)
        };
    }).ToArray();
}
```

`ChartPoint` 是一個記錄型別，包含類別、數值以及選用的文字。`ChartPoint.Label` 是提供給輔助技術朗讀、並顯示在讀數中的完整名稱。`ChartPoint.AxisLabel` 是長條下方的簡短文字；設為 null 可讓該長條下方的座標軸保持簡潔。讀數與朗讀使用相同的完整名稱，因此範圍變化時，讀者會同時聽到新的時間段與新的平均值。

取得下一個範圍期間，設定 `IsLoading`。在新資料到達之前，現有圖形保持在畫面上，並以淡化、呼吸式閃爍的方式顯示，因此頁面不會在兩個範圍之間閃成空白。

### 標題標籤

`AverageLabel` 為靜止時標題的名稱，`ValueLabel` 為逐一查看時長條數值的名稱。預設值分別為「每日平均」和「總計」。把它們改成該指標自己的用語，例如每週長條使用「每週平均」；當參考線對讀者沒有幫助時，使用 `ShowAverage` 隱藏平均線。

```xml
<arc:BarChart Label="部署次數"
              Period="最近 12 週"
              AverageLabel="每週平均"
              ValueLabel="部署次數"
              CategoryLabel="週"
              ShowAverage="False"
              PlotHeight="140"
              ItemsSource="{Binding Weeks}" />
```

`Average` 是所有數值的平均值，為唯讀屬性，因此標題註解或狀態列可以顯示同樣的數字。平均線本身是從資料中繪製的參考線，而不是目標值。

### 數值格式與座標軸

`ValueFormat` 接受 en-US 的 .NET 格式字串，例如用於分組整數的 `N0`、用於貨幣的 `C0`，或用於一位小數百分比的 `0.0'%'`。`ValueFormatter` 會接收數值及其索引和系列，兩者都設定時以 `ValueFormatter` 為準；當標籤取決於具體長條時應使用它，例如「3 起事件，其中 1 起嚴重」。`Unit` 文字會附加在「50 分鐘」這樣的讀數以及資料表中。

`ShowGrid`、`ShowXAxis` 與 `ShowYAxis` 控制參考線與標籤。`YMinimum` 固定數值軸的下限，`YMaximum` 固定其上限。預設情況下，數值軸從零開始；若資料有低於零的值，則從最低值開始；並在最大值之上的下一個整齊刻度處結束。當同一頁面上的兩個圖表需要共用刻度時，固定 `YMaximum`；當刻度標籤需要與數值不同的格式時，使用 `TickFormatter` 格式化刻度標籤。

```xml
<arc:BarChart Label="工單" YMaximum="100" ShowGrid="False" ItemsSource="{Binding Tickets}" />
```

### 讀取數值

`ActiveIndex` 是指標或鍵盤所在的長條，靜止時為 null，並且是雙向的。`ActiveIndexChanged` 會回報每一次移動，包括該時刻的索引、資料項目、標籤與數值。可用它在圖表之外的狀態列中顯示數值。

```csharp
chart.ActiveIndexChanged += (_, e) => status.Text = e.Index is null
    ? $"平均 {chart.Average:N0}"
    : e.Label;
```

`Summary` 是提供給輔助技術的一段描述，例如「活躍分鐘數，9 月 15–21 日。每日平均 40 分鐘。最高為週四，60 分鐘。最低為週三，20 分鐘。」`DataTableText` 則是同樣的資料，以定位字元分隔的表格形式給出：一列表頭，加上每根長條一列，例如「日\t活躍分鐘數」後接「週一\t10 分鐘」。該表格對視覺隱藏，但對輔助技術可用，因此即使看不到長條，也能讀取圖表。

### 資料結構與效能

圖表只在 `ItemsSource` 變化時讀取一次資料，而不是每次重繪都讀取。對於已經在記憶體中的資料，使用 `ChartPoint`：`new ChartPoint(category, value)` 的類別參數接受物件，因此 `DateOnly`、`DateTime`、字串或數字都可以使用；預設的座標軸標籤會把日期格式化為「Sep 15」，完整標籤格式化為「Tue, Sep 15」。當資料以列的形式到達時，用 `XSelector` 與 `YSelector`，或 `XBinding` 與 `YBinding` 讀取。編譯繫結形式（例如 `YBinding="{CompiledBinding Visits, DataType=local:Day}"`）是 AOT 安全的路徑。

一週或一個月的長條完全在圖表能夠流暢處理的範圍之內。對於較長的序列，優先使用 `LineChart`，或將資料依週彙總，因為長條會變細，類別標籤也會變得稀疏。隱藏的資料表會隨長條數量增長，因此請把範圍控制在讀者能夠快速瀏覽的程度。

### 範例：產品團隊的每週活躍分鐘數

某產品分析頁面，展示 2026 年 9 月 24 日至 30 日這一週。標題顯示每日平均值，時間範圍位於其下方，座標軸上的長條使用簡短的星期標籤。團隊從中讀出週四為高峰、週三為谷底，摘要列中也是這樣描述的。此處不展示截圖，因為長條與標題數字來自程式碼提供的資料（即時範例見上方的 Demo）；XAML 需要與程式碼範例使用相同的 `ItemsSource`。

```xml
<arc:BarChart Label="活躍分鐘數"
              Period="2026 年 9 月 24–30 日"
              Unit="分鐘"
              CategoryLabel="日"
              ItemsSource="{Binding ActiveMinutesThisWeek}" />
```

### 文案規範

- **標籤**：用句首大寫的指標名稱，例如「活躍分鐘數」或「支援工單」。它為圖表、摘要和資料表命名，因此必須能獨立理解。
- **時間範圍**：可讀的範圍，並帶年份，例如「2026 年 9 月 24–30 日」或「最近 12 週」。時間範圍變化時會被朗讀，因此必須具體。
- **單位**：數值後的簡短單位，例如「分鐘」「毫秒」或「次」。單位較長時，把完整的詞寫在標籤中。
- **平均與數值標籤**：使用該指標自己的用語：每週長條用「每週平均」，計數用「部署次數」。
- **類別標籤**：單一長條的單數名詞，例如「日」「週」或「月」，在資料表中用作欄名。

| 不要寫 | 改為 |
|---|---|
| 資料 | 活躍分鐘數 |
| 平均 | 每日平均 |
| 9 月 24 - 30 日 | 2026 年 9 月 24–30 日 |
| 項目（計數） | 支援工單 |
| 數值 | 總計 |

### 最佳做法

**建議**

- 每個圖表都設定 `Label` 與 `Period`。標籤為螢幕閱讀器命名圖表，時間範圍變化時會被朗讀，因此讀者總能知道長條統計的是什麼、涵蓋哪些日期。
- 每個圖表維持一個範圍和一個單位。在同一圖表中混用分鐘與呼叫次數，會讓平均值失去意義。
- 當兩個圖表需要並排比較時設定 `YMaximum`，使相同的高度在兩個圖表中代表相同的數值。
- 當類別不是穩定的識別碼時，在 `ChartPoint` 上設定 `Key`，使長條在範圍變化時平順變形，而不是被重新繪製。
- 當標題不足以說明問題時，用 `ActiveIndexChanged` 在圖表之外顯示被逐一查看的數值。

**避免**

- 把折線畫過互不相關的類別。每個類別一根長條，能避免讀者在互不相關的日期之間讀出趨勢。
- 平均值正是重點時隱藏平均線。當讀者想知道某天是高於還是低於正常水準時，保持 `ShowAverage` 開啟。
- 對很長的長條序列使用長條圖。長條會細到無法逐一查看，此時折線或彙總視圖更易讀。
- 每秒多次修改 `ItemsSource`。每次修改都會使長條和平均線變形，頻繁修改會讓圖表不斷移動，卻沒有向讀者傳達任何資訊。
- 只依賴長條的顏色。標題、讀數和資料表承載了數值，因此即使讀者看不清長條高度，圖表依然可用。

### 常見問題

**為什麼標題顯示的是平均值，而不是最新的長條？** 靜止時標題顯示平均值，它是整個範圍的參考。指標或鍵盤停在某根長條上時，標題會變為該長條的數值；按 Escape 釋放讀數，或焦點離開繪圖區時，標題返回平均值。

**如何從程式碼設定被逐一查看的長條？** `ActiveIndex` 是雙向的：設定它會把標題和讀數移動到該長條，設為 null 則讓標題返回平均值。可用它還原選取，或把圖表與讀者選擇的清單連結起來。

**為什麼調整頁面大小時長條寬度不一致？** 長條寬度上限為 28 px，並佔其槽位的 58%。在較寬的繪圖區中，多出的寬度變成長條之間的間距，因此長條粗細維持不變，只是間隙變大。

**為什麼首次顯示有動畫，之後的變化沒有？** 圖表第一次被看到時，長條會從左到右依序長出一次。之後的變化會讓長條從目前高度變形到新高度，因此讀者看到的是變化本身，而不是再次出現初始的長出動畫。

**如何讓讀數中的數值與座標軸使用不同格式？** 為數值設定 `ValueFormat` 或 `ValueFormatter`，為數值軸設定 `TickFormatter`。兩者互不影響，因此「1,284 分鐘」這樣的數值可以完整顯示，而座標軸可以使用「1.3K」這樣的精簡格式。

## 無障礙

- `Label` 為圖表命名。摘要會說明平均值、最高與最低的長條。
- 方向鍵在長條之間移動，PageUp 與 PageDown 每次移動最多七根長條，Home 與 End 分別跳到第一根與最後一根長條，Escape 停止逐一查看並返回平均值。
- 隱藏的資料表列出每一個數值，因此即使看不到長條，也能讀取圖表。
- 時間範圍變化時會以禮貌的方式播報。
- 長條對輔助技術隱藏。逐一查看的位置由游標指示，而不是焦點框。
- 繪圖區是一個可取得焦點的元素，輔助技術將其讀作滑桿，因此隨著讀數移動，每根長條的完整標籤和數值都會被朗讀。

### 鍵盤

繪圖區作為一個 Tab 停駐點取得焦點。鍵盤焦點從最新的一根長條開始，因此最新的數值會被優先讀出。

| 按鍵 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 將焦點移入繪圖區並定位到最新的長條，或移出繪圖區 |
| `Left` / `Right`、`Down` / `Up` | 移到上一根或下一根長條；從靜止狀態首次按下時，從最新的長條開始 |
| `PageUp` / `PageDown` | 向前或向後移動最多七根長條 |
| `Home` / `End` | 移到第一根或最後一根長條 |
| `Escape` | 停止逐一查看，並將標題返回為平均值 |

失去焦點會清除讀數，因此讀者離開圖表時，標題會返回平均值。

## 動態效果

- 首次顯示時，長條從左到右依序長出。
- 時間範圍變化時，保留的長條、座標軸刻度與平均線會變形到新的數值，離開的長條沉入基線。
- 查看游標在長條之間平順滑動，標題數值捲動到新的數字。
- 標題標籤在平均值與數值標籤之間切換，並伴隨短暫的模糊。
- 減少動態效果時，長條直接顯示為最終高度，數字原地替換。關閉動態效果時直接到達最終狀態。

動態效果在這裡跟隨資料。鍵相同的長條會變形，因此讀者可以在兩個範圍之間追蹤同一天。首次顯示的波浪效果只留給真正需要它的圖表；在經常更新的儀表板上，每次更新都會變形，效果會不斷累積，因此請讓資料更新的頻率與數值變化的頻率相符。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 首次顯示 | 長條以從左到右的波浪依序長出 | 長條以最終高度顯示 | 立即完成 |
| 新的時間範圍 | 保留的長條變形，新長條在旁邊長出，離開的長條下沉 | 長條以最終高度顯示 | 立即完成 |
| 逐一查看長條 | 游標滑向長條，標題數值捲動 | 標題數值原地替換 | 立即完成 |
| 標題標籤 | 在平均值與數值標籤之間切換，並伴隨短暫的模糊 | 原地替換 | 立即完成 |

## 相關元件

- `LineChart`：多資料點的連續趨勢。
- `Sparkline`：表格或卡片中的精簡趨勢。
- `ActivityHeatmap`：一整年的每日活動。
- `DonutChart`：長條需要表示整體各個組成部分時使用。

| 元件 | 適用情境 |
|---|---|
| `LineChart` | 多資料點的趨勢，或多個系列，比單一時段更重要 |
| `Sparkline` | 精簡趨勢與表格或卡片中的一個數字並列顯示 |
| `ActivityHeatmap` | 一整年的每日活動以方塊網格呈現 |
| `DonutChart` | 數值是加總等於總量的整體組成部分 |
| `AnimatedCounter` | 單一變化的數字就是全部訊息，不需要圖表 |
