## 何时使用

`GravityWell` 把它的项目排成一格格正方形图块，并让网格围绕指针弯曲，就像下面压着一个重物。指针附近的图块向内倾斜、缩小、变暗，并滑到相邻图块下方；点击会发出一道冲击波，从网格中滚过，经过每个图块时让它的描边环闪一下。

- **团队、客户和合作伙伴墙**：一次展示许多面孔或标志，重点就是好玩。
- **落地页上的灵感板和图库**：用一个有趣的区块展示一整套作品的广度。
- **小型装饰集合**：图标、贴纸或色块，让人推来推去。

## 何时不用

- **需要人们仔细浏览或精确点击的网格**，例如文件选择器：图块会在指针下移动。请用普通网格。
- **大型集合**：每个图块都有动画。控制在几十个以内；更多时请用照片网格或虚拟化列表。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:GravityWell Label="Team" Columns="6">
        <Border Background="#d9c2a5" />
        <Border Background="#b8c7a3" />
        <Border Background="#a9bcd6" />
    </arc:GravityWell>
</UserControl>
```

`GravityWell` 是 Special 包中的 `ItemsControl`。在 `UseArcControls()` 旁边调用 `UseArcSpecial()` 注册该包。每个项目成为一个正方形图块，可以直接写在里面，也可以由 `ItemsSource` 和 `ItemTemplate` 生成。图块把内容裁剪到 `TileCornerRadius`（默认 12px），并在内容后面显示一层弱化表面，让仍在加载的照片保持占位。图片用 `Stretch="UniformToFill"` 铺满正方形。

### 列数

`Columns` 固定列数。保持为 0 时，网格在保证每个图块至少 `MinTileSize` 宽（默认 56px）的前提下放下尽可能多的列，剩余宽度由图块平分。`Gap` 是图块之间的间距（8px）。

### 作用范围与强度

`Radius` 是引力井的作用范围，单位 px（150）；`Strength` 是吸力强弱，从 0 到约 1.5（1）。范围越大，同时弯曲的网格越多；吸力越强，最近的图块被拉得越近、缩得越小。

### 响应冲击波

每次冲击波（来自点击、轻触、Space 或 Enter）都会触发 `Pulsed`，`GravityWellPulseEventArgs.Origin` 给出它的起点，单位是距网格左上角的 px。`Pulse(point)` 用代码发出一道冲击波。可以把它和有意义的操作关联起来，例如打乱顺序或挑选一个项目，也可以只当作一点小惊喜。

<Demo name="Shuffle" />

```csharp
well.Pulsed += (_, e) => Shuffle(people);
```

### 最佳实践

**建议**

- 使用一套统一的正方形图片，大约 30 到 60 张。
- 给网格一个说明内容的 `Label`，例如 "Team" 或 "Customers"。
- 当人物或标志很重要时，给每个图片图块加上提示或无障碍名称。

**避免**

- 混用竖图和横图而不裁剪；图块始终是正方形。
- 在图块里放按钮或链接。图块会在指针下移动，很难点中。

### 常见问题

**图块互相滑到下方时，阅读顺序会变吗？** 不会。图块保持在网格中的位置，只通过渲染变换、透明度和层叠顺序移动。

**为什么网格不动？** 减弱动效时每个图块都保持原位；冲击波只会让描边环闪一下。

## 无障碍

- 网格是一个可聚焦的分组，名称取自 `Label`（默认 "Gravity well"），类型描述为 "gravity well"。图块的内容保留自己的名称和角色。
- 动效只是装饰。图块从不离开自己的位置，所以屏幕阅读器读到的顺序与网格一致。
- 键盘聚焦时网格周围显示 2px 焦点环，指针聚焦时不显示。网格获得键盘焦点期间，引力井本身指示当前图块。
- 减弱动效时图块保持原位，冲击波只会让描边环闪一下。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` | 聚焦网格，并把引力井放在当前图块上 |
| `Left` / `Right` | 把引力井移到上一个或下一个图块 |
| `Up` / `Down` | 把引力井上移或下移一行 |
| `Home` / `End` | 把引力井移到第一个或最后一个图块 |
| `Space` / `Enter` | 从当前图块发出一道冲击波 |

## 动效

- 引力井沿临界阻尼弹簧跟随指针：快速移动时落在后面，到达时不会冲过头。
- 每个图块沿自己的轻阻尼弹簧跟随引力井的吸力，所以快速扫过会留下晃动的尾迹。图块陷得越深，就越向引力井倾斜、缩得越小（最深处约 0.56）、越暗，并沉到相邻图块下方。
- 冲击波以每秒 900px 的速度向外传播。波前到达某个图块时，把它从起点方向推开、让它的缩放下沉一下，并闪亮它的 2px 强调色描边环，离起点越近越强；之后描边环淡出。
- 触屏上轻触会发出冲击波，拖动会拉动引力井；纵向滚动照常可用。
- 每帧只为每个图块写入变换、透明度和层叠顺序，不触发布局。所有弹簧静止后停止请求帧，网格离开视图时暂停。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 引力井 | 弯曲网格 | 无 | 无 |
| 冲击波 | 推开图块并闪亮描边环 | 闪亮描边环 | 无 |

## 相关组件

- `DotGrid` 弯曲的是一片点阵，而不是内容。
- `CardStack` 和 `Carousel` 一次展示少量图片中的一张。

| 组件 | 适用场景 |
|---|---|
| `GravityWell` | 许多小图片放在一起应该显得好玩 |
| `DotGrid` | 想在标题背后放一个会反应的背景 |
