## 何時使用

`GravityWell` 把它的項目排成一格格正方形圖塊，並讓網格圍繞指標彎曲，就像下面壓著一個重物。指標附近的圖塊向內傾斜、縮小、變暗，並滑到相鄰圖塊下方；點擊會發出一道衝擊波，從網格中滾過，經過每個圖塊時讓它的外框環閃一下。

- **團隊、客戶與合作夥伴牆**：一次展示許多面孔或標誌，重點就是好玩。
- **登陸頁上的靈感板與圖庫**：用一個有趣的區塊展示整套作品的廣度。
- **小型裝飾集合**：圖示、貼紙或色塊，讓人推來推去。

## 何時不用

- **需要使用者仔細瀏覽或精確點擊的網格**，例如檔案選擇器：圖塊會在指標下移動。請用一般網格。
- **大型集合**：每個圖塊都有動畫。控制在幾十個以內；更多時請用照片網格或虛擬化清單。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:GravityWell Label="Team" Columns="6">
        <Border Background="#d9c2a5" />
        <Border Background="#b8c7a3" />
        <Border Background="#a9bcd6" />
    </arc:GravityWell>
</UserControl>
```

`GravityWell` 是 Special 套件中的 `ItemsControl`。在 `UseArc()` 旁呼叫 `UseArcSpecial()` 註冊此套件。每個項目成為一個正方形圖塊，可以直接寫在裡面，也可以由 `ItemsSource` 與 `ItemTemplate` 產生。圖塊把內容裁切到 `TileCornerRadius`（預設 12px），並在內容後方顯示一層柔和表面，讓仍在載入的照片保持位置。圖片用 `Stretch="UniformToFill"` 填滿正方形。

### 欄數

`Columns` 固定欄數。保持為 0 時，網格在確保每個圖塊至少 `MinTileSize` 寬（預設 56px）的前提下放入盡可能多的欄，剩下的寬度由圖塊平分。`Gap` 是圖塊之間的間距（8px）。

### 作用範圍與強度

`Radius` 是重力井的作用範圍，單位 px（150）；`Strength` 是吸力強弱，從 0 到約 1.5（1）。範圍越大，同時彎曲的網格越多；吸力越強，最近的圖塊被拉得越近、縮得越小。

### 回應衝擊波

每次衝擊波（來自點擊、輕觸、Space 或 Enter）都會觸發 `Pulsed`，`GravityWellPulseEventArgs.Origin` 提供它的起點，單位是距網格左上角的 px。`Pulse(point)` 以程式碼發出一道衝擊波。可以把它與有意義的操作連結，例如打亂順序或挑選一個項目，也可以只當作一點小驚喜。

<Demo name="Shuffle" />

```csharp
well.Pulsed += (_, e) => Shuffle(people);
```

### 最佳做法

**建議**

- 使用一套一致的正方形圖片，大約 30 到 60 張。
- 給網格一個說明內容的 `Label`，例如 "Team" 或 "Customers"。
- 當人物或標誌很重要時，為每個圖片圖塊加上提示或無障礙名稱。

**避免**

- 混用直式與橫式圖片而不裁切；圖塊永遠是正方形。
- 在圖塊裡放按鈕或連結。圖塊會在指標下移動，很難點中。

### 常見問題

**圖塊互相滑到下方時，閱讀順序會改變嗎？** 不會。圖塊保持在網格中的位置，只透過轉譯變換、不透明度與堆疊順序移動。

**為什麼網格不動？** 減少動態效果時每個圖塊都保持原位；衝擊波只會讓外框環閃一下。

## 無障礙

- 網格是一個可取得焦點的群組，名稱取自 `Label`（預設 "Gravity well"），類型描述為 "gravity well"。圖塊的內容保留自己的名稱與角色。
- 動態效果只是裝飾。圖塊從不離開自己的位置，所以螢幕閱讀器讀到的順序與網格一致。
- 以鍵盤取得焦點時網格周圍顯示 2px 焦點環，以指標取得焦點時不顯示。網格擁有鍵盤焦點期間，重力井本身指出目前的圖塊。
- 減少動態效果時圖塊保持原位，衝擊波只會讓外框環閃一下。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| `Tab` | 讓網格取得焦點，並把重力井放在目前的圖塊上 |
| `Left` / `Right` | 把重力井移到上一個或下一個圖塊 |
| `Up` / `Down` | 把重力井上移或下移一列 |
| `Home` / `End` | 把重力井移到第一個或最後一個圖塊 |
| `Space` / `Enter` | 從目前的圖塊發出一道衝擊波 |

## 動態效果

- 重力井沿臨界阻尼彈簧跟隨指標：快速移動時落在後面，抵達時不會衝過頭。
- 每個圖塊沿自己的輕阻尼彈簧跟隨重力井的吸力，所以快速掃過會留下晃動的尾跡。圖塊陷得越深，就越向重力井傾斜、縮得越小（最深處約 0.56）、越暗，並沉到相鄰圖塊下方。
- 衝擊波以每秒 900px 的速度向外傳播。波前到達某個圖塊時，把它從起點方向推開、讓它的縮放下沉一下，並閃亮它的 2px 強調色外框環，離起點越近越強；之後外框環淡出。
- 觸控螢幕上輕觸會發出衝擊波，拖曳會拉動重力井；垂直捲動照常可用。
- 每個影格只為每個圖塊寫入變換、不透明度與堆疊順序，不觸發版面配置。所有彈簧靜止後停止請求影格，網格離開畫面時暫停。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 重力井 | 彎曲網格 | 無 | 無 |
| 衝擊波 | 推開圖塊並閃亮外框環 | 閃亮外框環 | 無 |

## 相關元件

- `DotGrid` 彎曲的是一片點陣，而不是內容。
- `CardStack` 與 `Carousel` 一次展示少量圖片中的一張。

| 元件 | 適用情境 |
|---|---|
| `GravityWell` | 許多小圖片放在一起應該顯得好玩 |
| `DotGrid` | 想在標題背後放一個會反應的背景 |
| `Carousel` | 每張圖片都值得細看 |
