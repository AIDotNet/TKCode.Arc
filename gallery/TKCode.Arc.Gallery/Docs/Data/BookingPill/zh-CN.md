## 何时使用

`BookingPill` 把整个预订搜索放进一条圆角栏：去哪里、什么时候、几个人，最后是搜索按钮。每一段都会在栏下方打开自己的选择器：一个可以筛选的地点列表，一个用色带标出从入住到离开的月份，以及成人、儿童和婴儿的加减按钮。选择器打开时，整条栏围绕这一段改变形状：这一段变宽，一块浮起的底板滑到它下面，搜索按钮变长并显示文字。选好地点后会接着选日期，选好离开日期后会接着选人数。

- **住宿与租房**：房间、小屋、公寓。
- **餐位与活动**：一个地点、一天和一组人数。
- **任何由三个简短条件组成**、人们会依次填写的搜索。

## 何时不用

- **很多筛选条件**：价格、类型和设施应该放在筛选面板或底部面板中。
- **自由文本搜索**：一个搜索框更简单。
- **很窄的屏幕**：小于约 480 px 时各段会很挤；手机上更适合用全屏流程。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:BookingPill>
        <arc:BookingPlace Name="Lisbon" Detail="Old town by the river" />
        <arc:BookingPlace Name="Kyoto" Detail="Temples and quiet lanes" />
    </arc:BookingPill>
</UserControl>
```

`BookingPill` 在 Special 包中；请在 `UseArcControls()` 旁边用 `UseArcSpecial()` 注册。把它提供的地点作为 `BookingPlace` 放在里面。`Place`、`CheckIn`、`CheckOut`、`Adults`、`Children` 和 `Infants` 保存所选内容，可以双向绑定；`OpenPart` 表示哪个选择器打开着，`Open()` 和 `Close()` 在代码里做同样的事。搜索按钮触发 `SearchRequested`，带有栏里的全部内容。

### 预先填好，用你自己的文字

每个值都可以预先设置，每段文字都可以替换：各段的标签、空值（“Anywhere”“Add dates”“Add guests”）、人数和晚数的格式，以及选择器里的文字。`MinDate`（默认今天）让更早的日子变淡，`MaxGuests` 和 `MaxInfants` 限制加减按钮，`CultureName` 决定日期和月份名称。

### 最佳实践

**建议**

- 提供一份简短的可能地点列表；上方的输入框会在输入时筛选它。
- 每段标签只用一个词，比如“Where”“When”“Who”。
- 处理 `SearchRequested` 来执行搜索；这些值也在属性里。

**避免**

- 页面加载时就打开选择器：让人们从自己想要的地方开始。
- 超过三段；这条栏是为三段设计的。

## 无障碍

- 每一段都是一个按钮，读作标签加值，例如“Where, Lisbon”。搜索按钮的名称来自 `SearchText`。
- 用键盘打开一段时，焦点会移进它的选择器：地点输入框、月份，或第一个加号按钮。Escape 关闭选择器，并把焦点放回这一段。
- 一条礼貌的状态信息会读出打开的段、选中的日子（“Saturday, March 14, 2026, check-in”）和人数。
- 指针获得焦点时不显示焦点环；键盘获得焦点时在段、搜索按钮或日子周围显示焦点环。

### 键盘交互

| 按键 | 作用 |
|---|---|
| Tab | 在各段、搜索按钮和打开的选择器之间移动。 |
| Enter 或 Space | 打开或关闭一段的选择器；选中地点或日子。 |
| 下 / 上 | 在地点选择器中，在输入框和地点之间移动。 |
| 方向键 | 在月份中移动日期光标；Page Up 和 Page Down 切换月份。 |
| Home / End | 在月份中到这一周的开头或结尾。 |
| Escape | 关闭选择器。 |

## 动效

- 打开一段时，三段的宽度和打开那段下方的底板一起随弹簧变化，整条栏在一个动作中改变形状；切换段时底板滑过去。
- 选择器打开时，栏的背景加深一级，搜索按钮的宽度随弹簧变化以放下文字。
- 选择器从栏下方进入，切换到另一段时内容交叉淡化。
- 人数会滚动。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 打开一段 | 宽度和底板随弹簧变化 | 直接跳到 | 直接跳到 |
| 切换段 | 底板滑过，选择器交叉淡化 | 直接跳到 | 直接跳到 |
| 搜索按钮 | 宽度随弹簧变化以放下文字 | 直接跳到 | 直接跳到 |
| 人数 | 滚动 | 直接跳到 | 直接跳到 |

## 响应式

- 栏占满给它的宽度；三段平分宽度，空间不够时值以省略号结束。
- 选择器宽 340 px，浮在页面上、位于栏下方：地点选择器靠左，日期居中，人数靠右；下方空间不够时翻到栏上方。
- 在栏和选择器以外的任何地方按下都会关闭选择器。

## 相关组件

- `DateRangePicker` 在自己的字段中选择日期范围。
- `SearchField` 是普通的搜索框。

| 组件 | 适用场景 |
|---|---|
| `BookingPill` | 在一个紧凑的搜索中选择地点、日期和人数 |
| `DateRangePicker` | 只需要日期范围 |
| `SearchField` | 单一的文本搜索 |
