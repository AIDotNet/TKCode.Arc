## 何時使用

`DateReel` 用並排的三個滾輪選擇日期，就像手機上那樣：一個選日，一個選月，一個選年。拖動時滾輪跟著手指轉；帶著速度放手，它會繼續滑行、慢慢減速，停在最近的一列，選中的那一列位於中間的橫條裡。日和月的滾輪首尾相接；年的滾輪到兩端會停下，並帶一點彈性。

- **離今天較遠的日期**：生日和紀念日，一個月一個月地翻日曆太慢。
- **觸控螢幕和窄版面**：每列很大，容易撥動。
- **不在意星期幾的表單**。

## 何時不用

- **今天附近的日期或日期範圍**：月檢視能看出星期和空檔；請用 `Calendar` 或 `DateRangePicker`。
- **在桌面上憑記憶輸入**：可以輸入的日期欄位更快。
- **可預訂狀態**：滾輪無法顯示哪些日子有空。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:DateReel SelectedDate="2026-03-14" />
</UserControl>
```

`DateReel` 在 Special 套件中；請在 `UseArcControls()` 旁邊用 `UseArcSpecial()` 註冊。`SelectedDate` 預設是今天，可以雙向繫結；`SelectedDateChanged` 帶有舊日期和新日期。日的滾輪總是和當月天數一致，所以在 31 日轉到 2 月時，日會變成 28 日或 29 日。

### 順序、名稱與範圍

`Order` 把滾輪排成月日年、日月年或年月日。`CultureName` 和 `UsesFullMonthNames` 決定月份名稱。`MinDate` 和 `MaxDate` 限定日期：年的滾輪從第一年到最後一年，會超出範圍的列顯示為淡色，滾輪停在那裡時會轉回來。`VisibleItemCount` 顯示 3、5、7 或 9 列。

### 最佳實踐

**建議**

- 從可能的答案附近開始：生日選擇器可以從 1990 年代開始，而不是今天。
- 設定 `MinDate` 和 `MaxDate`，讓不可能的日期選不到。
- 日期有明確用途時，用 `DayLabel`、`MonthLabel` 和 `YearLabel` 給滾輪命名，比如「Birth year」。

**避免**

- 很長的年份範圍卻沒有合適的起點：撥過兩百年很累。
- 用它選時間；請用 `TimeDial` 或 `TimePicker`。

## 無障礙

- 每個滾輪是一個微調器，名稱來自它的標籤（「Day」、「Month」、「Year」），值是目前的列，說明文字是該列的文字。
- 每個滾輪都是一個 Tab 停駐點。指標取得焦點時不顯示焦點環；鍵盤取得焦點時在該滾輪中間一列周圍顯示焦點環。

### 鍵盤互動

| 按鍵 | 作用 |
|---|---|
| Tab | 在滾輪之間移動。 |
| 上 / 下 | 把滾輪往回或往前轉一列。 |
| Page Up / Page Down | 轉五列。 |
| Home / End | 到第一列或最後一列。 |
| 左 / 右 | 移到左邊或右邊的滾輪。 |

## 動效

- 拖動時滾輪與手指一比一跟隨。放手時按當時的速度推算它會停在哪一列，再由彈簧從這個速度開始把它帶過去，所以撥動和停下是同一個動作。
- 年的滾輪拉過兩端時會有阻力地伸長，然後彈回。
- 各列排在一個圓筒上：越靠近邊緣越密、越扁、越淡。
- 每個滾輪用快取的文字自己繪製各列，轉動時不配置記憶體。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 撥動 | 滑行後隨彈簧停下 | 直接跳到該列 | 直接跳到該列 |
| 按鍵、滾輪、點按 | 隨彈簧到該列 | 直接跳到 | 直接跳到 |
| 超出範圍 | 隨彈簧轉回 | 直接跳回 | 直接跳回 |

## 響應式

- 滾輪平分寬度，月的滾輪稍寬一些。每列高 36 px，所以五列佔 180 px。
- 在滾輪上的觸控拖動會轉動它；橫向滑動仍然交給頁面。
- 滑鼠滾輪每一格轉一列；觸控板捲動時會累積成列。

## 相關元件

- `Calendar` 和 `DatePicker` 一次顯示一個月。
- `TimeDial` 用轉動選擇時間。

| 元件 | 適用場景 |
|---|---|
| `DateReel` | 離今天較遠的日期，在觸控螢幕或窄空間中 |
| `DatePicker` | 今天附近、星期有意義的日期 |
| `DateRangePicker` | 有開始和結束的住宿或時段 |
