## 何时使用

`DnsResolution` 说明从输入域名到连上服务器之间发生了什么。浏览器向它的递归解析器询问某个域名的地址。解析器的缓存是空的，所以它从顶层开始：
根服务器不知道地址，但会把它引向顶级域（".dev"）的服务器，这些服务器再把它引向该域名自己的名称服务器，最后权威服务器给出地址以及这个答案可以保留多久。
解析器保存答案，交给浏览器；当同样的问题再次出现时，它直接从缓存回答，不再询问任何人。数据包在各部分之间传递，日志写出每条消息，两个读数统计往返次数和
所用时间。其中的时间和地址都是示意性的。

- **文档与课程**：网络课程，或主机产品中“域名如何工作”的页面。
- **产品页面**：放在介绍解析器、CDN 或域名注册商的文字旁边的示意图。
- **故障排查指南**：为什么修改后的记录可能要过一段时间才生效（答案会在它的存活时间内被缓存）。

## 何时不用

- **真实的查询或监控**：卡片不会解析任何东西。真实的查询日志请用 `Table` 显示。
- **地址以外的记录类型**：它讲的是一次地址查询的故事，不涉及邮件、文本或别名记录。
- **同一页面上有多张卡片**：每张卡片在播放时都会做动画。每个页面只保留一张，或用 `IsPlaying` 暂停其他卡片。

## 用法

卡片无需数据：它查询一个虚构的域名 `docs.lumen-garden.dev`，并以 `203.0.113.42` 作答，这是专门留给文档使用的地址。卡片第一次大部分可见时开始播放。

```xml
<arc:DnsResolution />
```

`DnsResolution` 派生自 `Explainer`，它是 Special 包中动画讲解插图的基类。基类提供故事时钟（`IsPlaying`、`Speed`、`IsLooping`、`Play()`、`Pause()`、
`StepForward()`、`Restart()`）、进入可视区域即开始播放的行为、播放、单步和重新开始按钮，以及礼貌的实时区域；本控件添加速度控件和示意图。

### 故事

| 章节 | 发生了什么 |
|---|---|
| `Query` | 浏览器发出询问；解析器的缓存里没有这个域名 |
| `Root` | 根服务器把解析器引向顶级域的服务器 |
| `Tld` | 顶级域服务器把它引向该域名的名称服务器（`ns1.` 加上域名的最后两段） |
| `Authoritative` | 权威服务器给出地址及其存活时间 |
| `Answer` | 解析器缓存答案并交给浏览器 |
| `Cached` | 再次提出同样的问题，从缓存中一次往返就得到回答 |

每个章节都在一个停顿处结束，因此 "Next step" 每次前进一个章节。`Step` 报告当前章节，每个章节开始时都会引发 `StepChanged`。

### 你自己的域名

`Domain`、`Address` 和 `TimeToLive` 改变故事的内容；`IsRepeatLookupShown="False"` 让故事在第一次查询后结束。请使用至少有两段的域名。

<Demo name="OwnDomain" />

```xml
<arc:DnsResolution Domain="status.paper-kite.io" Address="198.51.100.7" TimeToLive="60" IsRepeatLookupShown="False" />
```

## 无障碍

- 卡片是一个以 `Title` 命名的分组（"DNS resolution"）。状态行用图标和文字说明 Ready、Resolving、Paused 或 Resolved。
- 示意图的无障碍名称跟随故事：最后一条消息（"Root server to Resolver: Ask the .dev servers"）以及两个读数。
- 只有读者主动推进故事（单步、暂停、重新开始）时，实时区域才会播报：它读出当前章节的说明文字。故事自动播放时它保持安静。
- 播放、Next step 和重新开始都是带名称和工具提示的按钮；速度控件是一个名为 "Speed" 的分段控件。Tab 键在它们之间移动。
- 颜色不是唯一的信号：日志写出了每条消息的发送方、接收方和内容。

## 动效

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 数据包 | 一个带短尾迹的圆点在 0.9 s 内沿每条曲线移动 | 不显示 | 不显示 |
| 故事当前所在的部分 | 强调色光环淡入 | 立即显示 | 立即显示 |
| 日志行 | 上移 6 px 并在 240 ms 内淡入 | 直接出现 | 直接出现 |
| 查询时间 | 在 0.5 s 内向上计数 | 立即改变 | 立即改变 |
| 缓存检查 | 方框边框闪一下后淡出 | 立即显示 | 立即显示 |
| 说明文字 | 交叉淡入淡出 | 原位更换 | 原位更换 |

所有动画都跟随故事时钟，因此会随之暂停、单步，并按 `Speed` 缩放。卡片不在屏幕上时，时钟停止。

## 响应式

- 宽度达到 520 px 时，各服务器在解析器右侧排成一列；更窄时，它们在解析器下方排成一行，名称缩小以适应宽度。
- 卡片最宽 760 px；窄于 560 px 时内边距收紧，窄于 420 px 时隐藏 "Speed" 文字（控件保留其名称）。
- 每个控件都是按钮，因此触摸与指针操作效果相同。
