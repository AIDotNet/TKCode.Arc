## 何時使用

`DnsResolution` 說明從輸入網域名稱到連上伺服器之間發生了什麼事。瀏覽器向它的遞迴解析器詢問某個名稱的位址。解析器的快取是空的，所以它從最上層開始：
根伺服器不知道位址，但會把它轉介給頂級網域（".dev"）的伺服器，這些伺服器再把它轉介給該網域自己的名稱伺服器，最後由權威伺服器回覆位址，以及這個答案可以保留多久。
解析器儲存答案並交給瀏覽器；當同樣的問題再次出現時，它直接從快取回答，不必再問任何人。封包在各部分之間傳遞，記錄寫出每則訊息，兩個讀數計算往返次數與
所花時間。其中的時間與位址都是示意用的。

- **說明文件與課程**：網路課程，或主機產品中「網域如何運作」的頁面。
- **產品頁面**：放在介紹解析器、CDN 或網域註冊商的文字旁的視覺圖。
- **疑難排解指南**：為什麼修改後的紀錄可能要過一段時間才會生效（答案會在它的存活時間內被快取）。

## 何時不用

- **真實的查詢或監控**：卡片不會解析任何東西。真實的查詢記錄請用 `Table` 顯示。
- **位址以外的紀錄類型**：它講的是一次位址查詢的故事，不涉及郵件、文字或別名紀錄。
- **同一個頁面上有多張卡片**：每張卡片在播放時都會產生動畫。每頁只放一張，或使用 `IsPlaying` 暫停其他卡片。

## 用法

卡片不需要資料：它查詢一個虛構的名稱 `docs.lumen-garden.dev`，並以 `203.0.113.42` 回覆，這是保留給說明文件使用的位址。它第一次大部分進入畫面時開始播放。

```xml
<arc:DnsResolution />
```

`DnsResolution` 衍生自 `Explainer`，這是 Special 套件中動畫講解工具的基底類別。此基底提供故事時鐘（`IsPlaying`、`Speed`、`IsLooping`、`Play()`、`Pause()`、
`StepForward()`、`Restart()`）、進入畫面時開始播放的行為、播放、單步與重新開始按鈕，以及禮貌的即時區域；此控制項則加上速度控制項與圖表。

### 故事

| 章節 | 發生什麼事 |
|---|---|
| `Query` | 瀏覽器提出詢問；解析器的快取中沒有這個名稱 |
| `Root` | 根伺服器把解析器轉介給頂級網域的伺服器 |
| `Tld` | 頂級網域伺服器把它轉介給該網域的名稱伺服器（`ns1.` 加上網域的最後兩段） |
| `Authoritative` | 權威伺服器回覆位址及其存活時間 |
| `Answer` | 解析器快取答案並交給瀏覽器 |
| `Cached` | 再次提出同樣的問題，從快取中一次往返就得到回覆 |

每個章節都在一個停頓處結束，因此 "Next step" 每次前進一個章節。`Step` 回報目前的章節，每個章節開始時都會引發 `StepChanged`。

### 你自己的網域

`Domain`、`Address` 與 `TimeToLive` 會改變故事的內容；`IsRepeatLookupShown="False"` 會讓故事在第一次查詢後結束。請使用至少有兩段的名稱。

<Demo name="OwnDomain" />

```xml
<arc:DnsResolution Domain="status.paper-kite.io" Address="198.51.100.7" TimeToLive="60" IsRepeatLookupShown="False" />
```

### 追蹤章節

<Demo name="StepLog" />

```csharp
card.StepChanged += (_, e) => log.Add(e.Step.ToString());
```

`Labels` 包含卡片顯示或朗讀的所有文字；替換它即可翻譯或改寫。播放按鈕的名稱來自 `PlaybackLabels`。

### 減弱動效

在減弱動效下，卡片開啟時直接顯示結尾。播放與 Next step 仍可使用，每個章節會在原處直接呈現，沒有封包移動。

## 無障礙

- 卡片是以 `Title` 命名的群組（"DNS resolution"）。狀態列以圖示與文字說明 Ready、Resolving、Paused 或 Resolved。
- 圖表的協助工具名稱會跟著故事變化：最後一則訊息（"Root server to Resolver: Ask the .dev servers"）以及兩個讀數。
- 只有讀者主動推進故事（單步、暫停、重新開始）時，即時區域才會朗讀：它會讀出該章節的說明文字。故事自行播放時它保持安靜。
- 播放、Next step 與重新開始都是帶有名稱與工具提示的按鈕；速度控制項是名為 "Speed" 的分段控制項。Tab 鍵會在它們之間移動。
- 色彩不是唯一的訊號：記錄寫出了每則訊息的傳送者、接收者與內容。

## 動效

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 封包 | 一個帶短尾跡的圓點在 0.9 s 內沿每條曲線移動 | 不顯示 | 不顯示 |
| 故事目前所在的部分 | 強調色光環淡入 | 立即顯示 | 立即顯示 |
| 記錄行 | 上移 6 px 並在 240 ms 內淡入 | 直接出現 | 直接出現 |
| 查詢時間 | 在 0.5 s 內往上計數 | 立即改變 | 立即改變 |
| 快取檢查 | 方框邊框閃一下後淡出 | 立即顯示 | 立即顯示 |
| 說明文字 | 交叉淡入淡出 | 原處更換 | 原處更換 |

所有動畫都依循故事時鐘，因此會跟著暫停、單步，並依 `Speed` 縮放。卡片不在螢幕上時，時鐘會停止。

## 響應式

- 寬度達到 520 px 時，各伺服器在解析器右側排成一欄；更窄時，它們在解析器下方排成一列，名稱會縮小以符合寬度。
- 卡片最寬 760 px；窄於 560 px 時內距收緊，窄於 420 px 時會隱藏 "Speed" 文字（控制項保留其名稱）。
- 每個控制項都是按鈕，因此觸控與滑鼠操作的效果相同。
