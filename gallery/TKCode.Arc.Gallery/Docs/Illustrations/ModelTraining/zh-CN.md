## 何时使用

`ModelTraining` 说明模型如何学习，每次讲训练循环中的一步。从数据中取出一批样本，向前流过一个小网络，得到预测。预测与正确答案对比：条形显示模型给
每个类别的概率，损失是正确类别概率的负对数，因此很有把握地答对代价很小，很有把握地答错代价很大。接着损失向后流过各层，为每个权重算出梯度，
每个权重朝梯度的反方向迈出一小步，步长由学习率决定。连线随权重的变化改变粗细和颜色，损失落在一条逐步下降的曲线上。第一步在每个阶段都会停下并显示
说明文字；之后的步骤以更快的速度重复循环。其中的网络和数字都是示意性的。

- **课程与新人引导**：在讲数学之前，先上一堂梯度下降课。
- **训练平台的产品页面**：放在介绍微调或训练任务的文字旁边的示意图。
- **演讲**：不需要旁白，在约二十秒内讲完整个循环。

## 何时不用

- **真实的训练任务**：卡片播放的是它自己的小故事。实时任务请使用 `TrainingRun`，或用 `LineChart` 绘制实测的损失。
- **讲解某一种架构**：网络只是一个通用的三层草图，不是 transformer，也不是卷积网络。
- **同一页面上有多张卡片**：每张卡片在播放时都会做动画。每个页面只保留一张，或用 `IsPlaying` 暂停其他卡片。

## 用法

卡片无需数据：它播放六个步骤，使用一条示例损失曲线，从 2.30 开始下降，最后在 0.4 附近趋于平稳。

```xml
<arc:ModelTraining />
```

`ModelTraining` 派生自 `Explainer`，基类提供故事时钟（`IsPlaying`、`Speed`、`IsLooping`、`Play()`、`Pause()`、`StepForward()`、`Restart()`）、
进入可视区域即开始播放的行为、播放按钮以及礼貌的实时区域；本控件添加速度控件和舞台。

### 一个步骤

| 阶段 | 发生了什么 |
|---|---|
| `Batch` | 一张批次卡片从数据滑入输入层 |
| `Forward` | 一波激活从输入流向输出 |
| `Loss` | 预测条形填满；正确类别被点亮；损失是它概率的 −ln |
| `Backward` | 一波梯度从输出流回输入 |
| `Update` | 每条连线移向新的权重并发光一次；损失被画到曲线上 |

`Phase`、`Iteration` 和 `CurrentLoss` 报告故事进行到哪里；每个步骤结束时会引发 `IterationCompleted`，并带上步骤序号和它的损失。

### 你自己的训练

`StepCount`（2 到 20）设置步骤数，`BatchSize` 和 `LearningRate` 会出现在说明文字和读数中，`LossValues` 替换示例曲线。下面的例子展示了过大的学习率：
损失来回跳动，而不是逐渐稳定。

<Demo name="OwnLosses" />

```csharp
card.StepCount = 8;
card.LossValues = [2.31, 1.12, 1.64, 0.98, 1.41, 0.92, 1.27, 0.95];
card.IterationCompleted += (_, e) => log.Add($"{e.Iteration}: {e.Loss:0.00}");
```

`Labels` 包含卡片显示或朗读的所有文字，包括阶段名称；替换它即可翻译或改写。

### 减弱动效

在减弱动效下，卡片打开时直接显示结尾和完整的曲线。播放和 Next step 仍然可用，每个阶段在原位直接呈现，没有波动动画。

## 无障碍

- 卡片是一个以 `Title` 命名的分组（"Model training"）。状态行说明 Ready、Training、Paused 或 Trained。
- 舞台的无障碍名称跟随故事（"Step 2 / 6, Backward, loss 1.48"）。
- 只有读者主动推进故事时，实时区域才会播报：第一步期间读出各阶段的说明文字，之后每一步读出 "Step 3 / 6: loss 1.05"。故事自动播放时它保持安静。
- 播放、Next step 和重新开始都是带名称和工具提示的按钮；速度控件的名称为 "Speed"。
- 阶段条用文字写出每个阶段的名称，正确类别除了颜色之外，还标有 "target"。

## 动效

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 批次 | 卡片滑入输入层 | 直接出现 | 直接出现 |
| 前向和反向传播 | 圆点沿连线移动，波经过时节点亮起 | 不显示 | 不显示 |
| 预测条形 | 在 0.5 s 内填满 | 立即填满 | 立即填满 |
| 权重更新 | 连线平滑过渡到新的粗细并发光一次 | 立即改变 | 立即改变 |
| 损失点 | 新的点放大出现 | 直接出现 | 直接出现 |
| 说明文字 | 交叉淡入淡出 | 原位更换 | 原位更换 |

在速度 1 下，第一步大约需要六秒；之后的步骤不到它的一半。所有动画都跟随故事时钟，因此会随之暂停、单步，并按 `Speed` 缩放。

## 响应式

- 宽度达到 600 px 时，预测条形和损失曲线在右侧排成一列；更窄时，它们在网络下方并排显示。
- 卡片最宽 780 px；窄于 560 px 时内边距收紧，窄于 420 px 时隐藏 "Speed" 文字。
- 每个控件都是按钮，因此触摸与指针操作效果相同。
