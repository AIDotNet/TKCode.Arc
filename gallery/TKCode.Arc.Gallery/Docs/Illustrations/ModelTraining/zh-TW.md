## 何時使用

`ModelTraining` 說明模型如何學習，每次講解訓練迴圈中的一步。從資料中取出一批範例，向前流過一個小型網路，得到預測。預測會與正確答案比較：長條顯示模型給
每個類別的機率，損失是正確類別機率的負對數，因此很有把握地答對代價很小，很有把握地答錯代價很大。接著損失向後流過各層，為每個權重算出梯度，
每個權重朝梯度的反方向跨出一小步，步幅由學習率決定。連線會隨權重的變化改變粗細與顏色，損失則落在一條逐步下降的曲線上。第一步會在每個階段停下並顯示
說明文字；之後的步驟會以更快的速度重複迴圈。其中的網路與數字都是示意用的。

- **課程與新人引導**：在講數學之前，先上一堂梯度下降課。
- **訓練平台的產品頁面**：放在介紹微調或訓練工作的文字旁的視覺圖。
- **演講**：不需旁白，在約二十秒內講完整個迴圈。

## 何時不用

- **真實的訓練工作**：卡片播放的是它自己的小故事。即時工作請使用 `TrainingRun`，或用 `LineChart` 繪製實際測得的損失。
- **說明某一種架構**：網路只是通用的三層草圖，不是 transformer，也不是摺積網路。
- **同一個頁面上有多張卡片**：每張卡片在播放時都會產生動畫。每頁只放一張，或使用 `IsPlaying` 暫停其他卡片。

## 用法

卡片不需要資料：它播放六個步驟，使用一條範例損失曲線，從 2.30 開始下降，最後在 0.4 附近趨於平穩。

```xml
<arc:ModelTraining />
```

`ModelTraining` 衍生自 `Explainer`，此基底提供故事時鐘（`IsPlaying`、`Speed`、`IsLooping`、`Play()`、`Pause()`、`StepForward()`、`Restart()`）、
進入畫面時開始播放的行為、播放按鈕與禮貌的即時區域；此控制項則加上速度控制項與舞台。

### 一個步驟

| 階段 | 發生什麼事 |
|---|---|
| `Batch` | 一張批次卡片從資料滑入輸入層 |
| `Forward` | 一波激活從輸入流向輸出 |
| `Loss` | 預測長條填滿；正確類別亮起；損失是它機率的 −ln |
| `Backward` | 一波梯度從輸出流回輸入 |
| `Update` | 每條連線移向新的權重並發光一次；損失被畫到曲線上 |

`Phase`、`Iteration` 與 `CurrentLoss` 回報故事進行到哪裡；每個步驟結束時會引發 `IterationCompleted`，並附上步驟與它的損失。

### 你自己的訓練

`StepCount`（2 到 20）設定步驟數，`BatchSize` 與 `LearningRate` 會出現在說明文字與讀數中，`LossValues` 會取代範例曲線。下面的範例呈現過大的學習率：
損失來回跳動，而不是逐漸穩定。

<Demo name="OwnLosses" />

```csharp
card.StepCount = 8;
card.LossValues = [2.31, 1.12, 1.64, 0.98, 1.41, 0.92, 1.27, 0.95];
card.IterationCompleted += (_, e) => log.Add($"{e.Iteration}: {e.Loss:0.00}");
```

`Labels` 包含卡片顯示或朗讀的所有文字，包括階段名稱；替換它即可翻譯或改寫。

### 減弱動效

在減弱動效下，卡片開啟時直接顯示結尾與完整的曲線。播放與 Next step 仍可使用，每個階段會在原處直接呈現，沒有波動動畫。

## 無障礙

- 卡片是以 `Title` 命名的群組（"Model training"）。狀態列說明 Ready、Training、Paused 或 Trained。
- 舞台的協助工具名稱會跟著故事變化（"Step 2 / 6, Backward, loss 1.48"）。
- 只有讀者主動推進故事時，即時區域才會朗讀：第一步期間讀出各階段的說明文字，之後每一步讀出 "Step 3 / 6: loss 1.05"。故事自行播放時它保持安靜。
- 播放、Next step 與重新開始都是帶有名稱與工具提示的按鈕；速度控制項的名稱為 "Speed"。
- 階段列以文字寫出每個階段的名稱，正確類別除了顏色之外，也標有 "target"。

## 動效

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 批次 | 卡片滑入輸入層 | 直接出現 | 直接出現 |
| 前向與反向傳播 | 圓點沿連線移動，波經過時節點亮起 | 不顯示 | 不顯示 |
| 預測長條 | 在 0.5 s 內填滿 | 立即填滿 | 立即填滿 |
| 權重更新 | 連線平順過渡到新的粗細並發光一次 | 立即改變 | 立即改變 |
| 損失點 | 新的點放大出現 | 直接出現 | 直接出現 |
| 說明文字 | 交叉淡入淡出 | 原處更換 | 原處更換 |

在速度 1 下，第一步大約需要六秒；之後的步驟不到它的一半。所有動畫都依循故事時鐘，因此會跟著暫停、單步，並依 `Speed` 縮放。

## 響應式

- 寬度達到 600 px 時，預測長條與損失曲線在右側排成一欄；更窄時，它們在網路下方並排顯示。
- 卡片最寬 780 px；窄於 560 px 時內距收緊，窄於 420 px 時會隱藏 "Speed" 文字。
- 每個控制項都是按鈕，因此觸控與滑鼠操作的效果相同。
