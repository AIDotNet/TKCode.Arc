## 何时使用

`BlackHole` 包裹一个列表、网格或看板，让一次删除显得有分量。把即将删除的行交给它，它们就会落进一个只有几像素宽的洞里，每个点沿着各自的对数螺线下落；同时，包裹层里的其他内容像光线绕过质量那样围绕这个洞弯曲。随后洞坍缩，放出一圈柔和的冲击波，真实内容立即回来，被吞掉的行保持隐藏，以便你的列表合上空隙。撤销时同一路径倒放。

- **删除或归档几个选中的行、卡片或文件**，随后提供撤销。
- **清空回收站、清除通知或批量忽略**，希望这次移除显得彻底。
- **演示或新手引导中的一个时刻**，希望某一次删除令人难忘。

## 何时不用

- **频繁的小型移除**，例如清除一个标签块或标签。普通的高度收拢读起来更快。
- **没有撤销的不可逆操作。** 这个效果不是确认；请先询问，或提供撤销。
- **整体包裹一个很长的滚动列表。** 效果绘制的是包裹层，所以请包裹可见视口（滚动容器的内容区域），而不是一个几千像素高的列表。
- **每隔几秒移除一项**，例如实时动态流。1.3 s 的过渡会一个接一个地排队。

## 用法

`BlackHole` 是 Special 包中的一个 `ContentControl`：请在 `UseArcControls()` 旁调用 `UseArcSpecial()` 进行注册。把列表放进去并保留各项控件的引用，然后用要移除的项调用 `SwallowAsync`。任务完成后，再把它们从数据中移除；在此之前它们一直保持隐藏。

```xml
<arc:BlackHole x:Name="Hole">
    <StackPanel x:Name="Rows" />
</arc:BlackHole>
```

```csharp
await Hole.SwallowAsync(selectedRows);
foreach (var row in selectedRows)
{
    Rows.Children.Remove(row);
}
```

撤销时，先把这些项放回原处，并在 UI 线程的同一轮中立即调用 `ReleaseAsync`。它们会立刻被隐藏；黑洞等到它们不再移动（你的列表重新打开它们的位置）后，再把它们旋转着放回原处。

```csharp
Rows.Children.Insert(index, row);
await Hole.ReleaseAsync([row]);
```

调用会排队：在吞噬过程中请求的释放，会在吞噬结束后开始。过渡运行期间 `IsRunning` 为 true；在此期间请禁用或忽略你的删除与撤销触发器，避免连按两次删除两次。

预览是一个邮箱。用单击、Space 或 Enter 选择会话，然后按页眉里的删除按钮，或在某一行上按 Delete 或 Backspace。选中的行落进在它们中心打开的洞；接着它们的位置以平滑弹簧收拢，卡片下方的胶囊说明移除了几条消息，并带有 Undo。Undo 只恢复最近一批，放回原来的位置，恢复的行不再是选中状态。发件人、主题和头像都是虚构的；头像是用代码绘制的渐变。

### 洞在哪里打开

默认情况下，洞在目标合并边界的中心打开，所以删除一行时它就开在那一行上，删除两行相隔较远的行时它开在两者之间。`BlackHoleOptions.Origin` 把它放在黑洞自身坐标中的某一点，`OriginElement` 则放在某个控件的中心，例如删除这些项的那个按钮。`BlackHoleOptions.Duration` 改变一次调用的时长；控件上的 `Duration` 设置默认值（1.3 s），释放的时长是它的 `ReleaseSpeed`（0.92）倍。

<Demo name="Origin" />

```csharp
await Hole.SwallowAsync(rows, new BlackHoleOptions
{
    OriginElement = deleteButton,
    Duration = TimeSpan.FromSeconds(2)
});
```

### 窄容器

黑洞在每次运行开始时测量其内容，所以在任何宽度下都能工作。洞、透镜和冲击波的尺寸以设备无关像素计，保持不变；在 320 px 宽时，邮箱会隐藏时间列。

<Demo name="Narrow" />

### 减少动效

在减少动效下，项目不再下落，而是在 200 ms 内淡出，释放时再淡入。关闭动效时，它们直接消失和出现。无论哪种情况任务都会完成，所以你的代码不需要改变。

### 结构

1. **包裹层**：黑洞本身。你的内容照常布局并接收输入。
2. **舞台**：盖在内容上的一层，只在过渡运行时存在。它显示内容快照被弯曲和吞噬的过程，不接收输入。
3. **透镜后的内容**：除目标之外的一切，被位于洞处的点质量弯曲。在爱因斯坦环（核半径的四倍）之外，内容被向外推；在环内，你会看到洞另一侧内容的一个小小的镜像。
4. **下落的项目**：目标被切成 5 px 的网格。每个点沿各自的螺线下落，所以行会被拉成弯曲的旋臂。
5. **洞**：半径 5.5 px 的黑色核心、紧贴其外的一圈细灰色光子环，以及一圈柔和的暗色光晕。
6. **冲击波**：坍缩后向外扩到 90 px 的一圈环，在浅色表面上是暗的，在深色表面上是亮的。

### 状态

| 状态 | 屏幕上显示什么 |
|---|---|
| 静止 | 只有内容。舞台隐藏，不产生任何开销 |
| 吞噬中 | 内容上方的舞台：透镜、下落的项目、洞；然后是坍缩和冲击波 |
| 已吞噬 | 内容恢复，目标保持隐藏（不透明度 0），直到你移除它们 |
| 等待释放 | 恢复的目标保持隐藏，同时它们的位置逐渐打开 |
| 释放中 | 舞台再次出现，把吞噬过程倒放 |
| 排队 | 一次调用等待正在运行的那一次；`IsRunning` 保持为 true |

### 内容指南

- 传入代表完整项目的控件（一行、一张卡片、一个方块），而不是其中的文本块：控件绘制的一切都会落进去，包括它的选中背景。
- 把包裹层限制在会变化的区域。页眉、工具栏和撤销消息放在包裹层之外，这样在效果运行时它们仍然清晰、可点击。
- 在列表旁用文字说明发生了什么（"2 messages removed"），并提供 Undo。这个效果只是视觉上的。

### 最佳实践

**建议**

- 只在 `SwallowAsync` 完成后再从数据中移除这些项。
- 给列表配上高度动画，让删除后的空隙收拢、释放前的位置打开。
- 在放回这些项的同一轮中调用 `ReleaseAsync`，让它们不会先在原处闪现。
- 当 `IsRunning` 为 true 时忽略删除与撤销。

**避免**

- 在吞噬结束前移除这些项：它们会从快照的位置消失，没有任何东西可以下落。
- 包裹整个页面。快照和逐像素透镜的开销随包裹层面积增长。
- 依赖这个效果作为反馈。请在实时区域中播报结果。

### 常见问题

**隐藏的项目仍然占据空间吗？** 是的。被吞噬的项目保持自身尺寸、不透明度为 0，直到你移除它，因此效果下方不会发生跳动。任务完成后移除它（或把它的高度动画到零）。

**如果黑洞在过渡期间离开窗口会怎样？** 过渡直接跳到结尾，任务完成，你的代码继续执行。

**它需要 GPU 吗？** 不需要。内容在开始时用 `RenderTargetBitmap` 快照一次（按屏幕缩放，最多 2x），每一帧在 CPU 上按行带并行绘制，然后作为一张位图画出。

**为什么在效果期间目标自身的动画停住了？** 效果显示的是开始时拍下的快照。效果一结束，真实内容就回来了。

## 无障碍

- 舞台对辅助技术隐藏，并且只在过渡运行时存在；效果一结束，真实控件就回来了。
- 这个效果本身不会播报任何内容。请在礼貌的实时区域中播报结果（"2 messages removed"），就像预览里的撤销胶囊那样，并让 Undo 可通过键盘访问。
- 过渡期间不会阻止输入。当 `IsRunning` 为 true 时忽略你的触发器，但不要把它们变灰。
- 在预览中，每一行都是一个复选框，以发件人、主题和时间命名。键盘焦点在行外显示 2 px 的环；指针获得焦点时不显示。当获得焦点的行被删除时，焦点随该行一同离开。

### 键盘

黑洞本身没有按键。像预览那样，把 Delete 或 Backspace 连接到你自己的选择上：

| 按键 | 操作（预览） |
|---|---|
| `Tab` / `Shift+Tab` | 在删除按钮、各行与 Undo 之间移动 |
| 行上的 `Space` / `Enter` | 选中或取消选中该行 |
| 行上的 `Delete` / `Backspace` | 删除所选内容 |
| 删除按钮或 Undo 上的 `Enter` / `Space` | 按下它 |

## 动效

以下时间对应默认的 1.3 s；其他 `Duration` 会按比例缩放所有时间。

- 洞在 190 ms 内打开，有 10 % 的过冲，吞噬时增大 40 %，保持一会儿，然后以缓入在 95 ms 内坍缩。
- 项目的每个点在开始后 110 ms 再加上与洞的距离每像素 1.84 ms 时开始下落（如果最远的点会在时长的 90 % 之后才落到，则更少），然后下落 610 ms，其半径按缓入正弦缩小。它的角度遵循 θ = θ₀ + 0.88 · ln(r₀ / r)，在屏幕上顺时针：距离每缩小为原来的 1/2.7，约转 50°。
- 透镜强度跟随核心：任何时刻爱因斯坦半径都是核半径的四倍，所以弯曲随洞一起打开、增大和坍缩。
- 冲击波在坍缩开始 30 ms 后出现，在 160 ms 内扩到 90 px（三次缓出），宽 6 px，不透明度从 0.6 开始按剩余时间的平方下降。
- 释放是吞噬在时长的 0.92 内倒放，在恢复的项目停止移动之后开始。

| 变化 | 完整 | 减少 | 关闭 |
|---|---|---|---|
| 吞噬 | 螺旋、透镜、洞、冲击波 | 项目在 200 ms 内淡出 | 项目消失 |
| 释放 | 同上，倒放 | 项目在 200 ms 内淡入 | 项目出现 |
| 任务完成 | 效果结束时 | 淡化结束时 | 立即 |

## 响应式

- 每次运行开始时都会测量包裹层，所以效果在任何宽度下都能工作，包括 320 px。
- 洞、透镜和冲击波以设备无关像素确定尺寸；快照跟随屏幕缩放，最多 2x。
- 每一帧都在 CPU 上绘制：开销随包裹层面积增长。预览中的列表（478 × 313）是效果调校时所用的尺寸。
