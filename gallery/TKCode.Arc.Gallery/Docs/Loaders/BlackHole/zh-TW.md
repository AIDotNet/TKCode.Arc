## 何時使用

`BlackHole` 包住一個清單、格線或看板，讓一次刪除顯得有份量。把即將刪除的列交給它，它們就會落進一個只有幾像素寬的洞裡，每個點沿著各自的對數螺線落下；同時，外層裡的其他內容像光線繞過質量那樣圍著這個洞彎曲。接著洞塌縮，送出一圈柔和的震波，真實內容立刻回來，被吞掉的列維持隱藏，讓你的清單把空隙合起來。復原時同一條路徑倒著播放。

- **刪除或封存幾個選取的列、卡片或檔案**，接著提供復原。
- **清空垃圾桶、清除通知或批次略過**，希望這次移除感覺徹底。
- **示範或新手導覽中的一個時刻**，希望某一次刪除讓人印象深刻。

## 何時不用

- **頻繁的小型移除**，例如清除一個標籤塊或標籤。單純的高度收合看起來更快。
- **沒有復原的不可逆動作。** 這個效果不是確認；請先詢問，或提供復原。
- **整個包住一個很長的捲動清單。** 效果繪製的是外層，所以請包住可見的檢視區（捲動容器的內容區域），而不是一個幾千像素高的清單。
- **每隔幾秒移除一項**，例如即時動態。1.3 s 的轉場會一個接一個排隊。

## 用法

`BlackHole` 是 Special 套件中的一個 `ContentControl`：請在 `UseArcControls()` 旁呼叫 `UseArcSpecial()` 註冊。把清單放進去並保留各項控制項的參考，然後用要移除的項目呼叫 `SwallowAsync`。工作完成後，再把它們從資料中移除；在那之前它們一直維持隱藏。

```xml
<arc:BlackHole x:Name="Hole">
    <StackPanel x:Name="Rows" />
</arc:BlackHole>
```

```csharp
await Hole.SwallowAsync(selectedRows);
foreach (var row in selectedRows)
{
    Rows.Children.Remove(row);
}
```

復原時，先把這些項目放回原處，並在 UI 執行緒的同一輪中立刻呼叫 `ReleaseAsync`。它們會立刻被隱藏；黑洞等到它們不再移動（你的清單重新打開它們的位置）之後，再把它們旋轉著放回原處。

```csharp
Rows.Children.Insert(index, row);
await Hole.ReleaseAsync([row]);
```

呼叫會排隊：在吞噬過程中要求的釋放，會在吞噬結束後開始。轉場執行期間 `IsRunning` 為 true；這段時間請停用或忽略你的刪除與復原觸發器，避免連按兩次刪掉兩次。

預覽是一個信箱。用點按、Space 或 Enter 選取對話，然後按頁首的刪除按鈕，或在某一列上按 Delete 或 Backspace。選取的列落進在它們中心打開的洞；接著它們的位置以平滑彈簧收合，卡片下方的膠囊說明移除了幾則訊息，並附上 Undo。Undo 只還原最近一批，放回原本的位置，還原的列不再是選取狀態。寄件者、主旨和大頭貼都是虛構的；大頭貼是用程式碼繪製的漸層。

### 洞在哪裡打開

預設情況下，洞在目標合併邊界的中心打開，所以刪除一列時它就開在那一列上，刪除兩列相隔較遠的列時它開在兩者之間。`BlackHoleOptions.Origin` 把它放在黑洞自身座標中的某一點，`OriginElement` 則放在某個控制項的中心，例如刪除這些項目的那個按鈕。`BlackHoleOptions.Duration` 改變單次呼叫的長度；控制項上的 `Duration` 設定預設值（1.3 s），釋放的長度是它的 `ReleaseSpeed`（0.92）倍。

<Demo name="Origin" />

```csharp
await Hole.SwallowAsync(rows, new BlackHoleOptions
{
    OriginElement = deleteButton,
    Duration = TimeSpan.FromSeconds(2)
});
```

### 窄容器

黑洞在每次執行開始時測量它的內容，所以在任何寬度下都能運作。洞、透鏡和震波的尺寸以裝置無關像素計算，維持不變；寬度為 320 px 時，信箱會隱藏時間欄。

### 減少動態效果

在減少動態效果下，項目不再落下，而是在 200 ms 內淡出，釋放時再淡入。關閉動態效果時，它們直接消失和出現。不論哪一種情況工作都會完成，所以你的程式碼不必改變。

### 結構

1. **外層**：黑洞本身。你的內容照常排版並接收輸入。
2. **舞台**：蓋在內容上的一層，只在轉場執行時存在。它顯示內容快照被彎曲和吞噬的過程，不接收輸入。
3. **透鏡後的內容**：目標以外的一切，被位於洞上的點質量彎曲。在愛因斯坦環（核心半徑的四倍）之外，內容被往外推；在環內，你會看到洞另一側內容的一個小小鏡像。
4. **落下的項目**：目標被切成 5 px 的網格。每個點沿各自的螺線落下，所以列會被拉成彎曲的旋臂。
5. **洞**：半徑 5.5 px 的黑色核心、緊貼在外的一圈細灰色光子環，以及一圈柔和的暗色光暈。
6. **震波**：塌縮後往外擴到 90 px 的一圈環，在淺色表面上是暗的，在深色表面上是亮的。

### 狀態

| 狀態 | 畫面上顯示什麼 |
|---|---|
| 靜止 | 只有內容。舞台隱藏，不產生任何負擔 |
| 吞噬中 | 內容上方的舞台：透鏡、落下的項目、洞；然後是塌縮和震波 |
| 已吞噬 | 內容回來，目標維持隱藏（不透明度 0），直到你移除它們 |
| 等待釋放 | 還原的目標維持隱藏，同時它們的位置逐漸打開 |
| 釋放中 | 舞台再次出現，把吞噬過程倒著播放 |
| 排隊 | 一次呼叫等待正在執行的那一次；`IsRunning` 維持為 true |

### 內容指引

- 傳入代表完整項目的控制項（一列、一張卡片、一個方塊），而不是其中的文字區塊：控制項繪製的一切都會落進去，包括它的選取背景。
- 把外層限制在會變動的區域。頁首、工具列和復原訊息放在外層之外，這樣效果執行時它們仍然清楚、可以點按。
- 在清單旁用文字說明發生了什麼（"2 messages removed"），並提供 Undo。這個效果只是視覺上的。

### 最佳做法

**建議**

- 只在 `SwallowAsync` 完成後再從資料中移除這些項目。
- 為清單搭配高度動畫，讓刪除後的空隙收合、釋放前的位置打開。
- 在放回這些項目的同一輪中呼叫 `ReleaseAsync`，讓它們不會先在原處閃現。
- 當 `IsRunning` 為 true 時忽略刪除與復原。

**避免**

- 在吞噬結束前移除這些項目：它們會從快照的位置消失，沒有任何東西可以落下。
- 包住整個頁面。快照和逐像素透鏡的負擔隨外層面積增加。
- 依賴這個效果當作回饋。請在即時區域中播報結果。

### 常見問題

**隱藏的項目還會佔空間嗎？** 會。被吞噬的項目維持自身尺寸、不透明度為 0，直到你移除它，所以效果下方不會跳動。工作完成後移除它（或把它的高度動畫到零）。

**如果黑洞在轉場期間離開視窗會怎樣？** 轉場直接跳到結尾，工作完成，你的程式碼繼續執行。

**它需要 GPU 嗎？** 不需要。內容在開始時用 `RenderTargetBitmap` 快照一次（依螢幕縮放，最多 2x），每一個影格在 CPU 上依列帶平行繪製，然後當作一張點陣圖畫出。

**為什麼效果期間目標自己的動畫停住了？** 效果顯示的是開始時拍下的快照。效果一結束，真實內容就回來了。

## 無障礙

- 舞台對輔助技術隱藏，而且只在轉場執行時存在；效果一結束，真實控制項就回來了。
- 這個效果本身不會播報任何內容。請在禮貌的即時區域中播報結果（"2 messages removed"），就像預覽裡的復原膠囊那樣，並讓 Undo 可以用鍵盤操作。
- 轉場期間不會阻擋輸入。當 `IsRunning` 為 true 時忽略你的觸發器，但不要把它們變灰。
- 在預覽中，每一列都是一個核取方塊，以寄件者、主旨和時間命名。鍵盤焦點在列外顯示 2 px 的環；用指標取得焦點時不顯示。當取得焦點的列被刪除時，焦點會隨著那一列一起離開。

### 鍵盤

黑洞本身沒有按鍵。像預覽那樣，把 Delete 或 Backspace 接到你自己的選取上：

| 按鍵 | 動作（預覽） |
|---|---|
| `Tab` / `Shift+Tab` | 在刪除按鈕、各列與 Undo 之間移動 |
| 列上的 `Space` / `Enter` | 選取或取消選取該列 |
| 列上的 `Delete` / `Backspace` | 刪除選取的內容 |
| 刪除按鈕或 Undo 上的 `Enter` / `Space` | 按下它 |

## 動態效果

以下時間對應預設的 1.3 s；其他 `Duration` 會依比例縮放所有時間。

- 洞在 190 ms 內打開，有 10 % 的過衝，吞噬時變大 40 %，停留一下，然後以漸入在 95 ms 內塌縮。
- 項目的每個點在開始後 110 ms 再加上與洞的距離每像素 1.84 ms 時開始落下（如果最遠的點會在長度的 90 % 之後才落到，則更少），然後落下 610 ms，半徑依漸入正弦縮小。它的角度遵循 θ = θ₀ + 0.88 · ln(r₀ / r)，在螢幕上順時針：距離每縮小為原本的 1/2.7，大約轉 50°。
- 透鏡強度跟隨核心：任何時刻愛因斯坦半徑都是核心半徑的四倍，所以彎曲會隨著洞一起打開、變大和塌縮。
- 震波在塌縮開始 30 ms 後出現，在 160 ms 內擴到 90 px（三次漸出），寬 6 px，不透明度從 0.6 開始依剩餘時間的平方下降。
- 釋放是吞噬在長度的 0.92 內倒著播放，在還原的項目停止移動之後開始。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 吞噬 | 螺旋、透鏡、洞、震波 | 項目在 200 ms 內淡出 | 項目消失 |
| 釋放 | 同上，倒著播放 | 項目在 200 ms 內淡入 | 項目出現 |
| 工作完成 | 效果結束時 | 淡化結束時 | 立刻 |

## 響應式

- 每次執行開始時都會測量外層，所以效果在任何寬度下都能運作，包括 320 px。
- 洞、透鏡和震波以裝置無關像素決定尺寸；快照跟隨螢幕縮放，最多 2x。
- 每一個影格都在 CPU 上繪製：負擔隨外層面積增加。預覽中的清單（478 × 313）是效果調校時使用的尺寸。
