## 何时使用

`ChargeSession` 实时展示一次充电会话的进展。一台拉丝金属质感的充电桩通过线缆连接到侧卧放置的电池包。小股能量包从充电桩发出，沿线缆穿过电池包，落在填充前沿上，每落下一次前沿便微微变亮。电池包的电量朝向充电上限增长，你可以沿电池包或其下方的充电曲线拖动这个上限。充电曲线在接近满电时趋于平缓，实时点沿曲线移动。功率、已补充的能量、距离上限所需的时间以及费用，每一帧都会更新。

- **需要展示实时会话、并允许驾驶者修改充电上限的电动车与车队应用**
- **运营控制台**：员工借此监视某个充电车位或某辆车的功率、能量与费用
- **展示充电网络如何报告充满所需时间与费用的产品页和落地页**
- **任何可充电设备**：笔记本扩展坞、滑板车车位或储能电池组，只要一次会话具有起点、上限和价格

## 何时不用

- **静态的配额或单一百分比**：使用 `Progress` 或用量仪表。
- **没有会话的单次实时读数**：使用仪表或数据格。
- **同时存在的大量会话**：表格或图表更适合比较它们。每张卡片都运行自己的动画循环。
- **测得功率的实时数据流**：卡片会根据你给出的数值运行自己的模拟（参见[你自己的会话](#your-own-session)）。

## 用法

未设置任何内容时，卡片会显示一台虚构的快速充电桩（"Bay 6 rapid point"，82 kWh 的电池包，峰值 180 kW）。它一出现就从 28% 开始朝 80% 的上限充电。上方的预览正是使用这些默认值。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:ChargeSession />
</UserControl>
```

`ChargeSession` 派生自 Avalonia 的 `TemplatedControl`，位于 Special 包中：请在 `UseArcControls()` 旁调用 `UseArcSpecial()` 进行注册。它的宽度最多为 880 px，并会拉伸到所获得的宽度。

用普通属性描述电池、充电桩和价格：

```xml
<arc:ChargeSession Title="Bay 12, depot charger"
                   Location="North yard, 350 kW"
                   Capacity="98"
                   MaxPower="350"
                   StartCharge="22"
                   Limit="85"
                   Rate="0.38"
                   Currency="EUR"
                   Locale="de-DE" />
```

`Limit` 是双向的：拖动和方向键都会改变它，而设置它则会移动标记。`StateChanged` 会在每次停止、恢复、完成和新建会话时报告当时的电量、能量、费用和上限；`LimitChanged` 则在一次拖动或按键操作结束后报告上限（最后一次变化之后 350 ms）。

```csharp
card.LimitChanged += (_, e) => api.SetChargeLimit("bay-12", e.Limit);
card.StateChanged += (_, e) =>
{
    if (e.State == ChargeSessionState.Stopped)
    {
        api.StopSession("bay-12", e.Detail.EnergyAdded, e.Detail.Cost);
    }
};
```

### 事件与其他货币

这辆面包车以欧元计价、采用德国的数字格式，充电速度为四倍。它下方的日志显示了后端会收到的内容。

<Demo name="FleetEvents" />

`Currency` 接受 ISO 4217 代码，`Locale` 接受区域设置名称。当货币与区域设置的货币一致时，费用使用该区域设置自己的符号（`de-DE` 配合 `EUR` 显示为 "9,57 €"）；否则使用简短的国际符号（`en-US` 配合 `EUR` 显示为 "€9.57"）。能量与功率使用同样的数字格式。日元和韩元没有小数位。

### 结构

1. **页眉**：左侧是标题与位置；右侧是以大号等宽数字显示的电量，其下方是状态（强调色的闪电图标配 "Charging"，方块配 "Stopped"，满电电池配 "Limit reached"）。
2. **场景**：充电桩及其屏幕，以及随功率变暗的指示灯；线缆及其发光的线芯；插头凸起与电池包。电池包内部包括直至当前电量的填充、十个电芯格、前沿线、超出上限的着色区域以及虚线上限线。能量包在最上层移动。
3. **上限标记**：一个药丸形的标签，显示上限值，并通过一根细杆向下延伸到电池包。它的触控区域为 64 × 44。
4. **充电曲线**：功率与电量的关系，并带有满功率和半功率的参考线。本次会话已充入的部分以强调色绘制在渐隐的面积之上，实时点沿曲线移动，虚线标示上限。标题显示读数，例如 "180 kW at 43%"。
5. **数据格**：以 2 × 2 网格排列的功率、已补充能量、距上限时间和费用。
6. **页脚**：提示文字以及操作按钮（Stop charging、Resume charging 或 Start new session）。

### 状态

| 状态 | 页眉 | 时间数据格 | 按钮 | 能量流 |
|---|---|---|---|---|
| `Charging` | 强调色闪电，"Charging" | 以满功率计算的分钟数（"23 min"、"1 h 05 min"、"Under 1 min"） | 描边按钮，Stop charging | 能量包持续流动，指示灯与线芯发光 |
| `Stopped` | 方块，"Stopped" | "Paused" | 实心按钮，Resume charging | 约一秒内功率回落，已在途中的能量包落下，实时点降至基线 |
| `Complete` | 满电电池，"Limit reached" | "Done" | 实心按钮，Start new session | 与已停止相同；电量恰好保持在上限处 |

按钮保留其最长标签的宽度，因此状态变化时页脚不会移动。

### 移动上限

在电池包或充电曲线上的任意位置按下，上限会直接跳到指针处。之后它会一对一地跟随指针移动，没有阈值、没有惯性，也没有回弹；它会停在 `MinLimit` 与 100% 处。按住期间，标签会略微放大并反转颜色，上限线也会加深。在触控设备上，水平拖动会移动上限，而垂直滑动仍然滚动页面。

- 充电时，若将上限降到当前电量或其以下，会话会立即完成。
- 会话完成后，若将上限提高到当前电量之上，充电会恢复。
- 停止状态下，上限可以移动，但会话保持停止。

### 你自己的会话

卡片运行的是会话的模拟，它并不读取充电桩。屏幕上的一秒相当于 `Speed` 为 1 时的四十秒充电，因此从 28% 充到 80% 的会话大约需要 25 秒。功率为 `MaxPower` 乘以充电曲线，再乘以可用度水平。开始或恢复充电时可用度会逐渐升高，停止时则逐渐回落，因此数字、指示灯、线芯、能量包的节奏和实时点会一同下降。

- `Speed` 用于放大模拟时间；为 0 时会话保持不动，而能量包仍在流动。
- `IsPaused` 会在当前帧冻结会话与能量流；上限和按钮仍然可用。
- `TaperAt` 移动收窄的起点；`PowerCurve` 可以用你自己的函数替换曲线，它以电量（0 到 1）为输入，输出峰值功率的比例（0 到 1）。
- `Stop()`、`Resume()` 和 `StartNewSession()` 执行与按钮相同的操作。
- `Charge`、`Power`、`EnergyAdded`、`Cost`、`MinutesToLimit` 和 `State` 是只读属性，可以用于绑定。

### 窄容器

<Demo name="Narrow" />

卡片跟随其自身的宽度，而不是窗口的宽度。宽度从 640 px 起，曲线与数据格并排显示，电量高 72 px。宽度低于 640 px 时，数据格移到曲线之下，内边距变为 24，电量高 52 px。宽度为 420 px 及以下时，内边距变为 16，电量高 36 px，数据格缩小一档，按钮横跨整张卡片。场景在任何宽度下都保持其比例，而药丸、标签和触控区域则保持其真实尺寸。

### 减弱动效

<Demo name="ReducedMotion" />

在减少动效下，会话停留在起点不动：能量包沿路径均匀排列，以显示能量流的方向，充电时它们会一起以透明度呼吸（每 1.8 s 一次），表明仍在充电；数字显示满功率；停止、恢复以及上限的变化都会立即生效。关闭动效时，能量包静止且不呼吸。

### 内容准则

- **标题**：人们熟悉的充电桩或设备名称，短到能放在一行内："Bay 6 rapid point"、"Fleet van 14"。
- **位置**：所在地点及其峰值功率，每张卡片的顺序保持一致："Lantern Quay depot, 180 kW"。留空则隐藏这一行。
- **提示文字**：一句话说明拖动会做什么。保持在约 60 个字符以内，以便在宽卡片上与按钮并排放下。
- **标签**：每个文字都位于 `ChargeSessionLabels` 中。带数字的句子是函数，因此翻译时可以调整词序；数字已按 `Locale` 格式化后传入。

### 最佳实践

- 填写真实可用的容量与峰值功率。到上限的时间由它们和曲线计算得出，因此容量错误会让其他所有数字也一同出错。
- 将 `MinLimit` 设为你的后端接受的最低上限，并从 `LimitChanged` 将上限发送给后端，而不是在拖动时的每次属性变化中发送。
- 仅在需要让能量颜色与品牌色一致时使用 `AccentBrush`。它会重新着色填充、能量包、指示灯、线芯、曲线的已充部分以及实时点；其余部分保持主题的样式。
- 每个用户正在关注的会话只显示一张卡片。若有十几个会话，请将它们列在表格中，并为选中的那个打开一张卡片。

### 常见问题

**为什么按下 Stop 后电量还会短暂上升？** 功率会在约一秒内回落，而不是直接降到零，会话会累计仍在流入的能量。这种上升约为十分之一个百分点，且永远不会超过上限。

**为什么时间数据格显示的不是屏幕上的时间？** 它是以满功率计算的充电时间：23 分钟的充电在 `Speed` 为 1 时大约需要屏幕上的 35 秒。

**我能提供实测值吗？** 不能直接提供：卡片运行的是它自己的会话。当你的数据变化时，请调用 `Stop()`、`Resume()` 和 `StartNewSession()`，并设置 `Limit`，使它与你的后端保持同步。

## 无障碍

- 卡片是一个分组，其名称由 `AccessibleLabel`（或标题）提供，标题为三级标题。
- 上限标记是一个名为 "Charge limit" 的滑块，范围从 `MinLimit` 到 100，其值文本如 "Charge limit 80%, about 23 minutes to go"。充电时，值文本会随剩余分钟数更新。
- 停止、恢复、达到上限、开始新会话以及上限变更稳定后，都会以礼貌方式播报，并附上当时的电量、能量与费用。
- 操作按钮在任一时刻只有一个无障碍名称：即当前显示的标签。
- 场景和曲线图不向辅助技术开放。它们显示的每个数值，也都出现在页眉、数据格或滑块中。
- 状态从不只依赖颜色：页眉将图标与文字配对，时间数据格则显示 "Paused" 或 "Done"。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 移动到上限标记，然后移动到操作按钮 |
| 标记上的 `←` `↓` / `→` `↑` | 将上限降低或提高 1% |
| `Shift` + 方向键、`Page Down` / `Page Up` | 将上限降低或提高 10% |
| `Home` / `End` | 将上限设为 `MinLimit` 或 100% |
| 按钮上的 `Enter` / `Space` | 停止、恢复或开始新会话 |

按键会立即移动上限，没有动画。卡片本身不可获得焦点，按下电池包或曲线时，焦点停留在原处。键盘焦点环是一个围绕上限标记触控区域的 2 px 方框；药丸也会变为柔和的表面色并带上深色边框。

## 动效

- 一个帧循环负责推进会话与能量包，并绘制场景与曲线。当卡片移出屏幕、设置了 `IsPaused`，或停止后能量流已排空、或达到上限时，它就会停止。
- 能量包按沿线缆的距离移动，因此在曲线上保持均匀的节奏。它们从充电桩缓出，以稳定的速度巡航，接近填充前沿时减速，并在两端淡入淡出。满功率时约每 0.22 s 发出一个；功率回落期间，它们减速至 40%，并停止发出。
- 可用度以 0.38 s 的时间常数上升，以 0.24 s 的时间常数回落。每次落下都会使前沿线变亮，辉光在约半秒内消退。
- 按住上限期间，药丸会以 CSS 弹簧（0.58 s）放大到 1.08 倍，其颜色在 160 ms 内反转。按钮按下时缩小到 0.97 倍，其标签在 160 ms 内交叉淡入淡出。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 会话与能量包 | 运行 | 保持静止；充电时能量包沿路径均匀排列并以透明度呼吸 | 保持静止；能量包均匀排列，不呼吸 |
| 停止、恢复、新会话 | 功率回落或爬升 | 立即 | 立即 |
| 药丸按住、按钮按下 | 弹簧缩放，颜色渐变 | 颜色立即变化 | 颜色立即变化 |
| 数字 | 每帧更新 | 当前值 | 当前值 |

## 响应式

- 断点以卡片自身的宽度为准：640 px 起并排显示，低于此宽度则上下堆叠，420 px 及以下为紧凑模式。
- 无论大小，场景都以卡片内容宽度的 0.24 绘制。细线（轮廓、电芯分隔线、前沿线与上限线）保持其像素宽度；线缆与能量包则随场景缩放。
- 曲线拉伸至其所在列的宽度。与数据格并排时，其高度为宽度的 0.40；堆叠时为 0.50。
- 在提示文字宽度至少为 220 px 时，它会占据按钮旁的空间；否则按钮会移到自己的一行。
