## 何時使用

`ChargeSession` 即時呈現一次充電工作階段。一台拉絲金屬質感的充電樁透過纜線連接到橫躺的電池組。小小的能量封包從充電樁發出，沿著纜線穿過電池組，抵達填充前緣，每抵達一次就亮一點。電池組朝著充電上限填充，而這個上限可以沿著電池組或下方的曲線拖曳。充電曲線在接近滿電時趨於平緩，即時點會沿著曲線移動。功率、已增加的能量、距離上限的時間與費用都會逐影格更新。

- **電動車與車隊應用程式**：顯示即時的充電工作階段，駕駛可以變更充電上限。
- **營運主控台**：工作人員監看單一充電位或單一車輛的功率、能量與費用。
- **產品頁與行銷頁**：展示充電網路如何回報充滿所需時間與費用。
- **任何可充電裝置**：筆電基座、電動機車充電位或電池櫃，只要一次工作階段有起點、上限與價格即可。

## 何時不用

- **靜態配額或單一百分比**：請使用 `Progress` 或用量計量表。
- **沒有工作階段的單一即時讀數**：請使用儀表或數據統計。
- **同時有許多工作階段**：表格或圖表比較容易比較它們。每張卡片都會執行自己的動畫迴圈。
- **即時的實測功率資料流**：卡片會根據你提供的數字執行自己的模擬（見[你自己的工作階段](#你自己的工作階段)）。

## 用法

未設定任何內容時，卡片會顯示一台虛構的快速充電樁（"Bay 6 rapid point"，82 kWh 電池組與 180 kW 峰值功率），一出現就從 28% 開始朝 80% 的上限充電。上方的預覽使用的正是這些預設值。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:ChargeSession />
</UserControl>
```

`ChargeSession` 衍生自 Avalonia 的 `TemplatedControl`，位於 Special 套件中：請在 `UseArcControls()` 旁呼叫 `UseArcSpecial()` 來註冊。它的寬度最多為 880 px，並會依所獲得的寬度伸展。

以一般屬性描述電池、充電樁與價格：

```xml
<arc:ChargeSession Title="Bay 12, depot charger"
                   Location="North yard, 350 kW"
                   Capacity="98"
                   MaxPower="350"
                   StartCharge="22"
                   Limit="85"
                   Rate="0.38"
                   Currency="EUR"
                   Locale="de-DE" />
```

`Limit` 是雙向的：拖曳與方向鍵都會變更它，而設定它會移動標記。`StateChanged` 會在每次停止、繼續、完成與開始新工作階段時回報當下的電量、能量、費用與上限；`LimitChanged` 則會在拖曳或按鍵結束後回報上限（最後一次變更後 350 ms）。

```csharp
card.LimitChanged += (_, e) => api.SetChargeLimit("bay-12", e.Limit);
card.StateChanged += (_, e) =>
{
    if (e.State == ChargeSessionState.Stopped)
    {
        api.StopSession("bay-12", e.Detail.EnergyAdded, e.Detail.Cost);
    }
};
```

`Currency` 接受 ISO 4217 代碼，`Locale` 接受地區設定名稱。當貨幣是該地區設定的貨幣時，費用會使用該地區設定自己的符號（`de-DE` 搭配 `EUR` 顯示為 "9,57 €"）；否則使用簡短的國際符號（`en-US` 搭配 `EUR` 顯示為 "€9.57"）。能量與功率使用相同的數字格式。日圓與韓元沒有小數位。

### 結構

1. **標頭**：左側是標題與地點；右側是以大型等寬數字顯示的電量，上方是狀態（強調色的閃電圖示搭配 "Charging"，方塊搭配 "Stopped"，滿格電池搭配 "Limit reached"）。
2. **場景**：充電樁與其螢幕，螢幕的 LED 會隨功率變暗；纜線與其發光的核心；插頭的小凸起與電池組。電池組內部有：到達電量為止的填充、十格電池格、填充前緣、超過上限的色調，以及虛線的上限線。能量封包會在最上層移動。
3. **上限標記**：一個膠囊，內含上限數值，並由一條細柱向下延伸到電池組。它的觸控區域為 64 × 44。
4. **充電曲線**：功率對電量的圖形，帶有滿功率與半功率的線。本次工作階段已充入的部分以強調色繪製，下方是淡出的區域；即時點沿著曲線移動；虛線標示上限。標題會顯示讀數，例如 "180 kW at 43%"。
5. **資料格**：以 2 × 2 格線排列的功率、已增加的能量、距離上限的時間與費用。
6. **頁尾**：提示文字與操作按鈕（Stop charging、Resume charging 或 Start new session）。

### 狀態

| 狀態 | 標頭 | 時間資料格 | 按鈕 | 能量流 |
|---|---|---|---|---|
| `Charging` | 強調色閃電，"Charging" | 以滿功率計算的分鐘數（"23 min"、"1 h 05 min"、"Under 1 min"） | 外框樣式，Stop charging | 能量封包流動，LED 與纜線核心發光 |
| `Stopped` | 方塊，"Stopped" | "Paused" | 實心樣式，Resume charging | 功率在約一秒內消退，已在途中的封包仍會抵達，即時點降到基準線 |
| `Complete` | 滿格電池，"Limit reached" | "Done" | 實心樣式，Start new session | 與停止相同；電量恰好保持在上限 |

按鈕會保留其最長標籤的寬度，因此狀態改變時頁尾不會移動。

### 移動上限

按住電池組或曲線上的任一處，上限就會跳到指標位置。之後上限會與指標一對一跟隨，沒有門檻、沒有慣性，也沒有回彈，並會停在 `MinLimit` 與 100%。在拖曳期間，膠囊會稍微放大並反轉顏色，上限線也會變深。在觸控裝置上，水平拖曳會移動上限，垂直滑動仍會捲動頁面。

- 充電中把上限降到或低於目前電量，會立即完成工作階段。
- 工作階段完成後把上限調高到超過目前電量，會恢復充電。
- 停止時上限仍可移動，但工作階段維持停止。

### 你自己的工作階段

卡片會執行工作階段的模擬，它不會讀取充電樁。螢幕上的一秒等於 `Speed` 為 1 時的四十秒充電，因此從 28% 充到 80% 大約需要 25 秒。功率為 `MaxPower` 乘以充電曲線，再乘以可用度。充電開始或繼續時可用度會逐步上升，停止時則會消退，因此數字、LED、纜線核心、封包節奏與即時點會一起減弱。

- `Speed` 會乘上模擬時間；設為 0 時工作階段保持不動，而封包仍會持續流動。
- `IsPaused` 會凍結目前影格上的工作階段與能量流；上限與按鈕仍可運作。
- `TaperAt` 移動收斂的起點；`PowerCurve` 可以用你自己的函式取代曲線，輸入為電量（0 到 1），輸出為峰值功率的比例（0 到 1）。
- `Stop()`、`Resume()` 與 `StartNewSession()` 的作用與按鈕相同。
- `Charge`、`Power`、`EnergyAdded`、`Cost`、`MinutesToLimit` 與 `State` 是唯讀屬性，可供繫結。

### 窄容器

卡片依循它自己的寬度，而不是視窗的寬度。寬度 640 px 以上時，曲線與資料格並排，電量高 72 px。640 px 以下時，資料格移到曲線下方，內距變為 24，電量高 52 px。420 px 以下時，內距變為 16，電量高 36 px，資料格縮小一級，按鈕橫跨整張卡片。場景在任何寬度下都保持比例，而膠囊、標籤與觸控區域則保持其實際尺寸。

在減少動態效果下，工作階段停留在起點不動：封包沿路徑等距靜止排列，以顯示能量流的方向，充電時它們會一起以透明度呼吸（每 1.8 s 一次），表示仍在充電；數字顯示滿功率；停止、繼續與變更上限則一次全部生效。關閉動態效果時，封包靜止且不呼吸。

### 內容指引

- **標題**：人們熟悉的充電樁或裝置，短到能放在一行："Bay 6 rapid point"、"Fleet van 14"。
- **地點**：所在位置與其峰值功率，每張卡片的順序都相同："Lantern Quay depot, 180 kW"。留空即可隱藏此行。
- **提示**：一句話說明拖曳會做什麼。請把它控制在約 60 個字元以內，讓它能在寬卡片上與按鈕並排。
- **標籤**：每個字都在 `ChargeSessionLabels` 中。含有數字的句子是函式，因此翻譯時可以改變語序；數字會依 `Locale` 預先格式化後傳入。

### 最佳做法

- 提供實際可用的容量與峰值功率。距離上限的時間是依據它們與曲線計算的，因此錯誤的容量會使其他所有數字也跟著錯誤。
- 把 `MinLimit` 設為你的後端接受的最低上限，並從 `LimitChanged` 把上限送到後端，而不是在拖曳時每次屬性變更都送。
- 只有在需要與品牌色相符的能量色時才使用 `AccentBrush`。它會重新著色填充、封包、LED、纜線核心、曲線的已充電部分與即時點；其餘部分保持主題的樣式。
- 每個使用者正在監看的工作階段顯示一張卡片。若有十幾個工作階段，請以表格列出，並為選取的那一個開啟卡片。

### 常見問題

**為什麼按下 Stop 後電量還會再微幅上升一下？** 功率會在約一秒內消退，而不是直接降到零，工作階段會累計仍在流入的能量。這個微幅上升約為十分之一個百分點，而且永遠不會超過上限。

**為什麼時間資料格不是螢幕上顯示的時間？** 它是以滿功率充電計算的時間：23 分鐘的充電在 `Speed` 為 1 時，螢幕上大約需要 35 秒。

**可以餵入實測值嗎？** 不能直接餵入：卡片會執行自己的工作階段。若要與後端保持同步，請呼叫 `Stop()`、`Resume()` 與 `StartNewSession()`，並在資料變更時設定 `Limit`。

## 無障礙

- 卡片是一個群組，名稱由 `AccessibleLabel` 提供（或標題）；標題為第 3 級標題。
- 上限標記是一個名為 "Charge limit" 的滑桿，範圍從 `MinLimit` 到 100，其值文字例如 "Charge limit 80%, about 23 minutes to go"。充電中，值文字會隨剩餘分鐘數更新。
- 停止、繼續、達到上限、開始新工作階段，以及上限變更完成時，都會以禮貌方式播報當下的電量、能量與費用。
- 操作按鈕在任一時刻只有一個無障礙名稱：即目前顯示的標籤。
- 場景與曲線圖不會暴露給輔助技術。它們顯示的每個數值也都出現在標頭、資料格或滑桿中。
- 狀態從不只靠顏色區分：標頭以圖示搭配文字，時間資料格則顯示 "Paused" 或 "Done"。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 移到上限標記，再移到操作按鈕 |
| 標記上的 `←` `↓` / `→` `↑` | 將上限降低或提高 1% |
| `Shift` + 方向鍵、`Page Down` / `Page Up` | 將上限降低或提高 10% |
| `Home` / `End` | 將上限設為 `MinLimit` 或 100% |
| 按鈕上的 `Enter` / `Space` | 停止、繼續或開始新工作階段 |

按鍵會立即移動上限，沒有動畫。卡片本身不可聚焦；按下電池組或曲線時，焦點會留在原處。鍵盤焦點環是一個圍繞標記觸控區域的 2 px 方形外框；膠囊也會轉為柔和的表面色並帶有深色邊框。

## 動態效果

- 一個影格迴圈會推進工作階段與封包，並繪製場景與曲線。卡片移出畫面、設定 `IsPaused`，以及停止或到達上限後能量流排空時，迴圈都會停止。
- 封包依沿纜線的距離移動，因此在曲線上的速度保持均勻。它們從充電樁緩出，以穩定速度巡航，接近填充前緣時減速，並在兩端淡入淡出。滿功率時大約每 0.22 秒送出一個；功率消退時，它們會減速到 40%，並停止送出。
- 可用度以 0.38 秒的時間常數上升，以 0.24 秒的時間常數消退。每次落點都會使前緣變亮，光暈在約半秒內淡去。
- 上限被按住時，膠囊會以 CSS 彈簧（0.58 秒）放大到 1.08，顏色則在 160 ms 內反轉。按鈕按下時縮小到 0.97，其標籤在 160 ms 內交叉淡化。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 工作階段與封包 | 執行 | 保持不動；充電中封包沿路徑均勻排列並以透明度呼吸 | 保持不動；封包均勻排列，不呼吸 |
| 停止、繼續、新工作階段 | 功率消退或回升 | 立即 | 立即 |
| 按住膠囊、按下按鈕 | 彈簧縮放，顏色淡化 | 立即變色 | 立即變色 |
| 數字 | 每影格更新 | 目前的值 | 目前的值 |

## 響應式

- 斷點使用卡片自身的寬度：640 px 以上並排，以下則堆疊；420 px 及以下進入緊湊模式。
- 無論尺寸多大，場景都以卡片內容寬度的 0.24 繪製。細線（外框、格線分隔、前緣與上限線）保持其像素寬度；纜線與封包則隨場景縮放。
- 曲線會伸展以填滿其欄位。並排於資料格旁時，其高度為寬度的 0.40；堆疊時為 0.50。
- 提示文字在獲得至少 220 px 時會占用按鈕旁的空間；否則按鈕會移到自己的一行。
