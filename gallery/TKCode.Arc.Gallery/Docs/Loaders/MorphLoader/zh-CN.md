## 何时使用

`MorphLoader` 是一个只由四根笔画组成的加载标记。工作进行时，它以四种形状之一循环；工作结束后，同样的笔画会在原处折成一个对勾或一个叉号，并弹一下。再次开始加载时，笔画会重新收拢成加载形状，因此同一个加载器可以服务一个又一个请求。

- **结果应出现在原处的行内进度**：放在按钮、表格行、输入框或工具栏中，紧挨着正在保存的内容。
- **结果明确的短时操作**：保存、发布、上传、发送、同步。
- **需要小巧清晰的旋转指示**：它以矢量绘制，可以任意尺寸显示，并继承文字颜色，因此与周围的图标相称。

## 何时不用

- **工作量已知**：改用带百分比的 `Progress` 进度条。
- **内容加载进布局**：用 `Skeleton` 预留空间，或让 `SkeletonMorph` 长成内容。
- **整个按钮的文字也要随之变化**：使用带有自身加载状态的按钮，或如下所示，在按钮内放一个装饰性的加载器。
- **工作耗时数分钟，且需要步骤或取消操作**：在状态胶囊或面板中显示其进度。

## 用法

根据请求状态设置 `Status`，并在整个产品中保持 `Variant` 不变。未设置任何内容时，加载器是一排 24 px 高、依次跳动的三个点。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:MorphLoader Variant="Ring" Size="20" Status="{Binding SaveState}" />
</UserControl>
```

`MorphLoader` 派生自 Avalonia 的 `Control` 并自行绘制，没有模板。它位于 Special 包中：请在 `UseArcControls()` 旁调用 `UseArcSpecial()` 进行注册。

上方的预览搭建了一个小型测试台：一个带滑动胶囊的形状选择器，以及把 `Status` 设为 `Success` 或 `Error` 的 Resolve 与 Reject 按钮。1.7 秒后，测试台会把 `Status` 设回 `Loading`，并且在显示结果期间两个按钮处于禁用状态。形状可以随时更改，包括在形变进行中或结果显示时。测试台、它的计时器以及其中的文字（"Saving"、"Saved"、"Couldn't save"）属于演示，而不属于加载器。

```csharp
loader.Status = MorphLoaderStatus.Loading;
try
{
    await api.SaveAsync(draft);
    loader.Status = MorphLoaderStatus.Success;
}
catch (HttpRequestException)
{
    loader.Status = MorphLoaderStatus.Error;
}
```

### 形状与结果

以 32 px 显示的每种形状与两种结果。第二行关闭了 `Tone`，因此对勾与叉号保持文字颜色。

<Demo name="States" />

| 形状 | 加载时 |
|---|---|
| `Dots`（默认） | 三个点按顺序以波浪方式跳动 3.2 个网格单位，并在跳跃顶端略微变大 |
| `Bars` | 四条竖条从左到右依次伸长、缩短，高度在 4.5 与 12 个网格单位之间变化 |
| `Ring` | 环的四段圆弧以每秒 330 度顺时针转动，同时圆弧随之变短、变长地"呼吸" |
| `Square` | 方块先静止，然后翻转四分之一圈，同时其角点张开又收拢 |

| 状态 | 结果 |
|---|---|
| `Loading` | 该形状的循环 |
| `Success` | 成功色的对勾 |
| `Error` | 危险色的叉号 |

### 尺寸

绘图基于 24 个单位的网格并缩放到 `Size`，加载器始终占据恰好 `Size` × `Size` 的空间，因此结果出现时布局不会移位。16 至 32 px 适合行内使用；48 px 及以上适合空状态。16 px 时请将 `StrokeWidth` 设为 3，使笔画的粗细与周围的图标相称。

<Demo name="Sizes" />

`StrokeWidth` 以网格单位计算，作用于环、方块、对勾和叉号；点和条保持各自的宽度（分别为 4 和 3 个单位）。

### 按钮内使用

在自身会宣布状态的控件内，加载器应设为 `IsDecorative`，使屏幕阅读器不会把状态重复播报两次。这里按钮会更改其标签和无障碍名称；加载器只负责绘制。`Settled` 在结果完成折叠、弹动并变为对应颜色后引发一次，是重置按钮的好时机。

<Demo name="InButton" />

```csharp
loader.Settled += (_, e) =>
{
    // e.Status is Success or Error
    ScheduleReset();
};
```

### 颜色

加载器像文字一样继承 `Foreground`，因此它采用所在按钮或行的颜色。开启 `Tone`（默认值）后，对勾会在 240 ms 内变为主题的成功色，叉号变为危险色；重新回到加载状态时则恢复为前景色。设置 `Foreground` 可以为加载器指定自己的颜色，例如空状态中的强调色。

### 减少动效

在减少动效下，每种状态都是单一的静态形状（三个点、四条竖条、环的四段圆弧、闭合的方块、对勾、叉号），每次变化都会立即切换，包括颜色。加载时，静止的形状会以透明度缓慢呼吸（每 1.8 s 从完全不透明到 45% 再回来），因此仍能看出工作正在进行；关闭动效时则保持静止。播报内容不变，结果也从不只靠颜色来表示。

### 结构

1. **笔画**：四根带圆头端点的笔画。每根笔画由中心、长度、方向、弯曲度、宽度和不透明度定义。点形状会在中心隐藏第四根笔画；当其他形状需要它时，它会从中间生长出来。
2. **绘制**：四根笔画围绕中心一起旋转和缩放：环与方块在加载时转动，结果则向前转到正立位置并弹一下。
3. **占位尺寸**：一个边长为 `Size` 的正方形，在分配到的空间中居中。

### 内容准则

加载器没有可见文字；它的标签供屏幕阅读器使用。请用现在时为工作命名，并用结果来描述发生了什么。

| 避免 | 改为 |
|---|---|
| Loading | Saving |
| Success | Saved |
| Error | Couldn't save |
| Please wait while we upload your file | Uploading |

### 最佳实践

**建议**

- 为产品选定一种形状风格，并在各处保持一致。
- 下一次请求时把 `Status` 设回 `Loading`，而不是新建一个加载器：笔画会收拢回该形状。
- 在会宣布自身进度的按钮和行中设置 `IsDecorative`。
- 提供能说明工作内容的 `Labels`（"Publishing"、"Published"、"Couldn't publish"）。

**避免**

- 让错误结果停留在屏幕上，却没有重试的途径。
- 用于耗时超过几秒、却不说明正在发生什么的工作。
- 同一屏幕上为同一个请求放置多个加载器。

### 常见问题

**结果会改变加载器的尺寸吗？** 不会。弹一下只是渲染缩放；占位尺寸始终为 `Size`。

**形变进行到一半时状态改变会怎样？** 每个笔画参数都有自己的弹簧，获得新目标时会保持其速度，因此笔画会平滑地弯向新的形状。

**结果显示时能更改形状吗？** 可以。在 `Status` 回到 `Loading` 之前，屏幕上不会有任何变化；然后笔画会收拢成新的形状。

**无人可见时它还会运行吗？** 不会。帧循环只在加载或结算时运行，在隐藏或滚出可视区域时暂停。

## 无障碍

- 加载器是礼貌级别的实时区域。它的无障碍名称是当前状态的标签（`Labels.Loading`、`Labels.Success` 或 `Labels.Error`；默认分别为 "Loading"、"Done" 和 "Failed"），因此每次变化只被播报一次。
- 结果从不只靠颜色表示：笔画会变成对勾或叉号。
- `IsDecorative` 会对辅助技术隐藏加载器并使其静音，适用于会自行宣布状态的控件内的加载器。
- 加载器无法获得焦点，也不接受指针输入。

### 键盘

加载器没有键盘交互。在预览测试台中，每个形状选项和两个按钮都是 Tab 停靠点；按下 `Enter` 或 `Space` 即可触发，结果按钮在禁用期间会离开 Tab 顺序。

## 动效

- 每个笔画参数都有自己的临界阻尼弹簧。形状之间的形变约半秒内稳定（视觉时长 0.46 s），所有笔画一起运动。离开点形状时，笔画先移动，稍后再伸展成线条。
- 结果出现时，循环先在其静止形状中冻结一帧，然后笔画每隔 35 ms 依次折成对勾或叉号（视觉时长 0.52 s）。对勾沿笔尖的路径绘制：先是短边，然后是从拐角向上的长边。
- 同时，绘制内容会转向下一个正立位置，并保持其原有速度（视觉时长 0.6 s），然后弹一下：1、1.14、1，耗时 420 ms。
- 回到加载状态时，笔画收拢在一起，循环在约 100 ms 内淡入；环同时加速。
- 颜色在 240 ms 内过渡到成功色或危险色，再返回。
- 运动中途的变化会保持速度。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 加载循环 | 有动画 | 静止形状，以透明度呼吸（1.8 s） | 静态形状 |
| 形状变化 | 形变 | 立即 | 立即 |
| 结果 | 折成、转正并弹一下 | 立即 | 立即 |
| 颜色 | 240 ms | 立即 | 立即 |

## 响应式

- 加载器以矢量绘制，可以任意尺寸显示，且占位尺寸永不改变。
- 它在分配到的空间中居中，从不被拉伸。
- 帧循环只在加载或结算时运行，在可视区域之外或隐藏时暂停。

## 相关组件

- `Progress`：用于工作量已知的情况。
- `Skeleton` 与 `SkeletonMorph`：用于正在加载进布局的内容。
- 带有自身加载状态的 `Button`：当按钮本身显示进度时使用。

| 组件 | 何时选用 |
|---|---|
| `MorphLoader` | 一次短时操作应在原处以对勾或叉号结束 |
| `Progress` | 你知道工作完成了多少 |
| `Skeleton` | 内容即将填充进布局 |
| `SkeletonMorph` | 占位符应长成内容 |
