## 何時使用

`MorphLoader` 是一個只由四道筆畫組成的載入標記。工作進行時，它會循環播放四種形狀之一；工作結束時，同樣的四道筆畫會在原位折成勾號或叉號，並彈一下。重新回到載入時，它們會再度收攏成形狀，因此同一個載入器可以服務一個又一個的請求。

- **結果應出現在同一位置的行內進度**：放在按鈕、表格列、欄位或工具列中，就在正在儲存的東西旁邊。
- **結果明確的短暫作業**：儲存、發布、上傳、傳送、同步。
- **任何需要小巧俐落的旋轉指示**：它以向量繪製，任何尺寸都清晰，並繼承文字顏色，因此會與周圍的圖示相配。

## 何時不用

- **工作量是已知的**：請改用附百分比的 `Progress` 進度條。
- **內容正載入到版面中**：請用 `Skeleton` 保留空間，或讓 `SkeletonMorph` 長成內容。
- **整個按鈕都應同時改變標籤**：請使用具有自己載入狀態的按鈕，或如下所示，在按鈕中放一個裝飾性載入器。
- **工作需要數分鐘，並需要步驟或取消動作**：請在狀態膠囊或面板中顯示其進度。

## 用法

依你的請求狀態設定 `Status`，並讓整個產品的 `Variant` 保持一致。什麼都不設定時，載入器是一排 24 px 高、三個跳動的點。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:MorphLoader Variant="Ring" Size="20" Status="{Binding SaveState}" />
</UserControl>
```

`MorphLoader` 衍生自 Avalonia 的 `Control`，自行繪製；它沒有範本。它位於 Special 套件中：請在 `UseArcControls()` 旁呼叫 `UseArcSpecial()` 來註冊。

上方的預覽重建了一個小型測試台：一個帶有滑動膠囊的形狀選擇器，以及把 `Status` 設為 `Success` 或 `Error` 的 Resolve 與 Reject 按鈕。1.7 秒後，測試台會把 `Status` 設回 `Loading`；結果顯示期間，兩個按鈕會停用。形狀隨時都可以改變，即使在變形途中或結果顯示期間也一樣。測試台、它的計時器與它的標籤（"Saving"、"Saved"、"Couldn't save"）都屬於示範，而不屬於載入器。

```csharp
loader.Status = MorphLoaderStatus.Loading;
try
{
    await api.SaveAsync(draft);
    loader.Status = MorphLoaderStatus.Success;
}
catch (HttpRequestException)
{
    loader.Status = MorphLoaderStatus.Error;
}
```

### 形狀與結果

| 形狀 | 載入時 |
|---|---|
| `Dots`（預設） | 三個點依序以波浪方式跳動 3.2 個格線單位，並在跳起的頂端稍微放大 |
| `Bars` | 四條條依序由左至右伸長與縮短，長度介於 4.5 與 12 個單位之間 |
| `Ring` | 環上的四段弧以每秒 330 度順時針旋轉，同時弧線時而變短、時而變長，如同呼吸 |
| `Square` | 方塊先靜止，接著翻轉四分之一圈，同時四個角展開又收合 |

| 狀態 | 結果 |
|---|---|
| `Loading` | 該變體的循環 |
| `Success` | 以成功色調顯示的勾號 |
| `Error` | 以危險色調顯示的叉號 |

### 尺寸

繪圖是以 `Size` 縮放的 24 格線單位，而載入器永遠恰好佔用 `Size` × `Size`，因此結果出現時不會改變版面。16 至 32 px 適合行內使用；48 px 以上適合空白狀態。在 16 px 時請把 `StrokeWidth` 設為 3，讓筆畫與周圍圖示的粗細一致。

<Demo name="Sizes" />

`StrokeWidth` 以格線單位計算，套用於環、方塊、勾號與叉號；點與條則保有各自的寬度（4 與 3 個單位）。

### 按鈕內

若控制項自己會播報狀態，其內部的載入器應設為 `IsDecorative`，讓螢幕閱讀器不會把狀態念兩次。這裡按鈕會改變其標籤與無障礙名稱；載入器只負責繪製。結果完成折疊、彈跳並套用顏色後會引發 `Settled`，這正是重設按鈕的好時機。

<Demo name="InButton" />

```csharp
loader.Settled += (_, e) =>
{
    // e.Status is Success or Error
    ScheduleReset();
};
```

### 顏色

載入器與文字一樣繼承 `Foreground`，因此會採用它所在的按鈕或列的顏色。開啟 `Tone`（預設值）時，勾號會在 240 ms 內套用主題的成功色，叉號則套用危險色；回到載入時會回到前景色。若要讓載入器有自己的顏色，請設定 `Foreground`，例如在空白狀態中使用強調色。

### 減少動態效果

在減少動態效果下，每一種狀態都是單一靜態形狀（三個點、四條條、環的四段弧、一個閉合的方塊、一個勾號、一個叉號），而且每次變化都會立即替換，顏色也一樣。載入時，靜止的形狀會以透明度緩慢呼吸（每 1.8 s 從完全不透明到 45% 再回來），因此仍看得出工作正在進行；關閉動態效果時則保持靜止。播報內容不變，結果也永遠不會只靠顏色呈現。

### 結構

1. **筆畫**：四道帶圓端的筆畫。每一道都由中心、長度、方向、彎曲度、寬度與不透明度組成。點的狀態會把第四道筆畫隱藏在中心；當其他形狀需要時，它會從中間長出來。
2. **繪製**：四道筆畫會一起圍繞中心旋轉與縮放：載入時環與方塊會旋轉；結果則會向前轉到正立位置並彈一下。
3. **佔位尺寸**：一個 `Size` 大小的正方形，在分得的空間中置中。

### 內容指引

載入器本身沒有可見文字；它的標籤是給螢幕閱讀器用的。請以現在式描述工作，並以已發生的事描述結果。

| 不要寫 | 改為寫 |
|---|---|
| 載入中 | 儲存中 |
| 成功 | 已儲存 |
| 錯誤 | 無法儲存 |
| 請稍候，我們正在上傳您的檔案 | 上傳中 |

### 最佳做法

**建議**

- 在你的產品中選定一種變體，並在各處保持一致。
- 下一個請求時把 `Status` 改回 `Loading`，而不是建立新的載入器：筆畫會收攏回形狀。
- 在會播報自己進度的按鈕與列中設定 `IsDecorative`。
- 為 `Labels` 設定能說明工作內容的文字（"Publishing"、"Published"、"Couldn't publish"）。

**避免**

- 讓結果一直留在畫面上，卻沒有方式重試錯誤。
- 用於超過幾秒、卻沒有說明正在發生什麼的工作。
- 同一個畫面上為同一個請求放置多個載入器。

### 常見問題

**結果會改變載入器的大小嗎？** 不會。彈跳只是繪製時的縮放；佔位尺寸永遠是 `Size`。

**如果在變形途中狀態改變，會怎樣？** 每個筆畫參數都有自己的彈簧，當它得到新目標時會保持原有速度，因此筆畫會平滑地朝新形狀彎曲。

**結果顯示期間能改變變體嗎？** 可以。在 `Status` 回到 `Loading` 之前，畫面上不會有任何變化；之後筆畫會收攏成新的形狀。

**沒有人看得見時還會執行嗎？** 不會。影格迴圈只在載入或定型時執行，並在隱藏或捲出可視範圍時暫停。

## 無障礙

- 載入器是一個禮貌的即時區域。其無障礙名稱是目前狀態的標籤（`Labels.Loading`、`Labels.Success` 或 `Labels.Error`；預設為 "Loading"、"Done" 與 "Failed"），因此變化只會被朗讀一次。
- 結果永遠不會只靠顏色呈現：筆畫會變成勾號或叉號。
- `IsDecorative` 會把載入器從輔助技術中隱藏並使其靜音，適用於位在會自行播報狀態的控制項中的載入器。
- 載入器無法取得焦點，也不接受指標輸入。

### 鍵盤

載入器沒有鍵盤互動。在預覽測試台中，每個形狀選項與兩個按鈕都是 Tab 停駐點；`Enter` 或 `Space` 可以按下它們，而結果按鈕在停用期間會離開 Tab 順序。

## 動態效果

- 每個筆畫參數都有自己的臨界阻尼彈簧。形狀與形狀之間的變形約在半秒內穩定（視覺時長 0.46 s），所有筆畫一起進行。離開點的狀態時，筆畫會先移動，稍後再拉伸成線條。
- 結果出現時，迴圈會在其靜止形狀中凍結一個影格，接著四道筆畫會依序每隔 35 ms 折成勾號或叉號（視覺時長 0.52 s）。勾號是沿著筆尖的路徑繪製的：先畫短邊，再從轉角向上畫長邊。
- 同時，繪圖會以原有速度轉向下一個正立位置（視覺時長 0.6 s），並彈一次：在 420 ms 內由 1 變化到 1.14 再回到 1。
- 回到載入時，筆畫會收攏在一起，循環會在約 100 ms 內淡入；環也會隨之加速。
- 顏色會在 240 ms 內緩和地變為成功或危險色調，再緩和地回去。
- 動態進行途中的變化會保留其速度。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 載入循環 | 有動畫 | 靜止形狀，以透明度呼吸（1.8 s） | 靜態形狀 |
| 形狀變化 | 變形 | 立即 | 立即 |
| 結果 | 折疊、轉正並彈一下 | 立即 | 立即 |
| 顏色 | 240 ms | 立即 | 立即 |

## 響應式

- 載入器在任何尺寸下都以向量繪製，且永遠不會改變其佔位尺寸。
- 它在分得的空間中置中，且永遠不會被拉伸。
- 影格迴圈只在載入或定型時執行，並在螢幕外或隱藏時暫停。

## 相關元件

- `Progress`：用於已知數量的工作。
- `Skeleton` 與 `SkeletonMorph`：用於載入到版面中的內容。
- 具有自己載入狀態的 `Button`：當按鈕本身顯示進度時使用。

| 元件 | 適用時機 |
|---|---|
| `MorphLoader` | 短暫作業應在同一位置以勾號或叉號結束 |
| `Progress` | 你知道工作完成了多少 |
| `Skeleton` | 內容即將填入版面 |
| `SkeletonMorph` | 佔位內容應長成真正的內容 |
