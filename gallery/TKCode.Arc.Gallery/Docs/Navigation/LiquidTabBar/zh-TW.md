## 何時使用

`LiquidTabBar` 是圓角軌道上的一排分頁，被選取的分頁坐落在一滴強調色的液滴上。選取移動時，液滴的表現像液體而不是滑動的方塊：前端先伸向新的分頁，液滴在兩者之間被拉長，變長時中間變細並收緊，然後後端追上來，在新的分頁下方變圓。

- **切換同一個畫面的檢視**：動態消息的各個區段、儀表板的各個時段、個人檔案的各個分頁。
- **手機的底部列**，每個分頁配一個圖示。
- **活潑的產品**，讓控制項帶一點個性，符合品牌調性。

## 何時不用

- **很多分頁或很長的標籤**：這個列不會捲動；請用 `Tabs`，它會捲動並讓邊緣淡出。
- **各自有面板的分頁**：這個列只負責選取；請搭配你自己的內容，或改用 `Tabs`。
- **嚴肅、資訊密集的工具**：動效會分散注意力，普通的分段控制項更沉穩。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:LiquidTabBar SelectedIndex="0">
        <arc:LiquidTabBarItem Content="Overview" />
        <arc:LiquidTabBarItem Content="Activity" />
        <arc:LiquidTabBarItem Content="Settings" />
    </arc:LiquidTabBar>
</UserControl>
```

`LiquidTabBar` 位於 Special 套件：在 `UseArcControls()` 旁邊用 `UseArcSpecial()` 註冊。可以直接寫 `LiquidTabBarItem` 元素，或把 `ItemsSource` 繫結到你的資料（每個項目顯示它的字串，或使用 `ItemTemplate`）。項目可以在標籤前面放一個 `Glyph`。只要有分頁，就一定有一個被選取；用 `SelectedIndex` 或 `SelectedItem` 讀取和設定，並監聽 `SelectionChanged`。停用的項目會被略過。

分頁預設排在水平堆疊中。若要讓分頁等寬，請把 `ItemsPanel` 設為單列的 `UniformGrid`，並讓這個列拉伸。

### 有多像液體

`Viscosity` 的範圍是 0 到 1，決定液滴後端落後前端多遠：為 0 時液滴幾乎不拉長，為 1 時液滴會拉得很長才收攏。預設值是 0.5。

### 最佳實務

**建議**

- 標籤保持在一兩個短詞，分頁最多五個。
- 手機底部列使用圖示，並仍然為輔助技術設定標籤。

**避免**

- 用計時器改變 `SelectedIndex`：液滴每次移動都會吸引視線。
- 在同一個列中混用有圖示和沒有圖示的分頁。

## 無障礙

- 這個列會被朗讀為分頁清單，每個項目被朗讀為分頁，以文字標籤命名，並帶有選取狀態。
- 只有被選取的分頁在 Tab 順序中；方向鍵在分頁之間移動，並隨著移動而選取。
- 鍵盤焦點會在分頁周圍顯示統一的焦點環；使用指標時則不顯示。

### 鍵盤互動

| 按鍵 | 動作 |
|---|---|
| Tab | 把焦點移到被選取的分頁。 |
| 右或下 | 選取下一個可用的分頁，到最後一個之後繞回第一個。 |
| 左或上 | 選取上一個可用的分頁，到第一個之前繞到最後一個。 |
| Home / End | 選取第一個或最後一個可用的分頁。 |
| Enter 或 Space | 選取有焦點的分頁。 |

## 動效

- 液滴的兩端以兩個彈簧移動。朝向新分頁的一端快速且帶一點彈性；另一端依 `Viscosity` 變慢。兩端之間的距離決定液滴變細的程度（最多為其高度的 22%）以及腰部收緊的深度。
- 液滴還在移動時做出的選取，會從它目前的位置和速度接著繼續。
- 分頁標籤在 240ms 內變色。
- 液滴是一個形狀，它的各個點原地移動，所以每一影格不配置記憶體，也不觸發版面配置。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 液滴 | 拉長並安定 | 直接跳到新的分頁 | 直接跳到新的分頁 |
| 標籤顏色 | 240ms | 120ms | 立即變化 |

## 響應式行為

- 這個列的寬度與它的分頁一樣寬。它不會捲動或換行，所以在窄螢幕上請減少分頁數量。
- 把單列的 `UniformGrid` 當作 `ItemsPanel` 並拉伸這個列，就能在手機上得到滿寬的底部列。
- 調整這個列的大小時，液滴會立即跟上它的分頁，沒有動效。

## 相關元件

- `Tabs` 會捲動、讓邊緣淡出，並顯示每個分頁的面板。
- `MorphNav` 把網站的導覽收在一個膠囊裡。

| 元件 | 何時選擇 |
|---|---|
| `LiquidTabBar` | 幾個檢視，用一點個性來選取 |
| `Tabs` | 很多分頁，或各自有面板的分頁 |
| `MorphNav` | 網站導覽應當不佔空間 |
