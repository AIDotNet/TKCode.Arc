## 何時使用

`MorphNav` 是一個不佔空間的網站或應用程式選單。平時它只是一個小膠囊：你的標誌、名稱、目前所在的頁面和一個選單圖示。按下它不會開啟另一個選單；膠囊本身會以彈簧動畫展開成一個面板，裡面有帶標題的區段，每列一個連結，選定連結後面板會縮回膠囊，膠囊上顯示新的頁面名稱。因為始終是同一個表面在改變大小、圓角和陰影，視線不會跟丟。

- **行銷網站與文件**：只有少數區段，完整的頁首列會擠壓主視覺。
- **專注型應用程式**（編輯器、閱讀器、播放器）：希望導覽一按就到，但不必一直顯示在螢幕上。
- **手機版面**：面板佔滿螢幕寬度，並把各區段上下堆疊。

## 何時不用

- **很深的階層**：有許多層級的樹狀結構需要側邊欄或導覽路徑，而不是一個面板。
- **任務的每一步都要用的導覽**：可見的分頁列或側邊欄每次都能少按一下。
- **動作**，例如刪除或匯出：面板是用來前往某處的；做事請用選單或工具列。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:MorphNav Title="Lantern">
        <arc:MorphNavSection Header="Notebook">
            <arc:MorphNavLink Text="Today" Description="What you saw this morning" />
            <arc:MorphNavLink Text="Archive" />
        </arc:MorphNavSection>
        <arc:MorphNavSection Header="Help">
            <arc:MorphNavLink Text="Contact" />
        </arc:MorphNavSection>
    </arc:MorphNav>
</UserControl>
```

`MorphNav` 位於 Special 套件：在 `UseArcControls()` 旁邊用 `UseArcSpecial()` 註冊。它的內容是一串 `MorphNavSection` 元素，每個都有 `Header` 和它的 `MorphNavLink` 元素。連結有 `Text`、選用的 `Description` 說明行，以及選用的 `Glyph`（畫在小方塊裡）；`Tag` 可以放你自己的值，例如路由。

導覽在版面中只佔膠囊的空間。面板會浮在頁面上方展開：導覽靠左對齊時向右展開，靠右對齊時向左展開，置中時向兩側展開，並與視窗兩側保持 16 px 的距離。它位於同層元素之上（`ZIndex` 為 10），所以請把它放在與它所浮於其上的頁面相同的面板中。

### 得知選了什麼

選擇連結時會觸發 `LinkInvoked`，連結在 `e.Link` 中。該連結會成為 `CurrentLink`，它是雙向的：把它繫結到你的路由器來標示目前所在的頁面，頁面以其他方式改變時也要設定它。它的文字顯示在膠囊上，它所在的列會在面板中被標記。`Open()`、`Close()`、`Toggle()` 和雙向的 `IsOpen` 可以在程式碼中控制面板。

`Footer` 顯示在各區段下方，可放登入或行動呼籲。`PanelWidth` 設定面板寬度（預設 600 px），最大不會超過視窗寬度減去兩側間距。

### 最佳實務

**建議**

- 保持在兩到四個區段，每個區段幾個連結，讓面板一眼就能看懂。
- 當連結名稱本身比較含糊時，給它一段簡短的 `Description`。
- 讓 `CurrentLink` 與頁面同步，膠囊就能一直說明你在哪裡。

**避免**

- 過長的連結文字：列會以刪節號截斷，而不是換行。
- 把導覽放在會裁切的父層裡：面板是畫在膠囊的框之外的。

## 無障礙

- 膠囊是一個由 `MenuLabel` 和目前頁面命名的按鈕（「Open menu, Archive」），並回報面板是否已展開。
- 連結會被朗讀為以文字命名的連結，說明則作為輔助說明文字。輔助技術可以呼叫每一個連結。
- 從鍵盤開啟面板時，焦點會移入面板（移到目前頁面，沒有的話移到第一個連結），關閉時移回膠囊。使用指標時不顯示焦點環；使用鍵盤時顯示統一的焦點環。

### 鍵盤互動

| 按鍵 | 動作 |
|---|---|
| 膠囊上的 Enter 或 Space | 開啟面板。 |
| 下 / 上 | 移到下一個或上一個連結。 |
| 右 / 左 | 當各區段並排時，移到旁邊區段中同樣高度的連結。 |
| Home / End | 移到第一個或最後一個連結。 |
| 連結上的 Enter 或 Space | 選擇該連結並關閉面板。 |
| Escape | 關閉面板並把焦點移回膠囊。 |

在導覽之外按一下也會關閉面板。

## 動效

- 開啟與關閉是同一個表面在以變形彈簧改變大小，圓角從膠囊的圓角變成面板的圓角，陰影從靜止狀態升為浮起狀態。
- 面板淡入時膠囊淡出；收回時面板先保留它的空間直到淡出，然後表面縮回膠囊。
- 表面只在移動時才裁切內容。移動期間，導覽以外的任何內容都不會重新配置。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 大小 | 變形彈簧 | 直接跳轉 | 直接跳轉 |
| 圓角與陰影 | 彈簧與 240ms | 直接跳轉 | 直接跳轉 |
| 膠囊與面板 | 交叉淡化 | 交叉淡化 | 直接切換 |

## 響應式行為

- 面板寬 `PanelWidth`，最寬不超過視窗寬度減去兩側各 16 px。在手機預覽中，它會跟隨預覽的寬度。
- 只要每一欄至少能有 176 px 寬，各區段就並排，更窄的螢幕上則上下堆疊。
- 膠囊的寬度跟隨它的內容；在手機上請讓標題保持簡短。

## 相關元件

- `Tabs` 和 `LiquidTabBar` 讓導覽一直顯示在螢幕上。
- `ActionMorph` 使用同樣會長大的表面，但用於動作而不是導覽。

| 元件 | 何時選擇 |
|---|---|
| `MorphNav` | 導覽在需要之前應當保持為一個小膠囊 |
| `Tabs` | 同一頁的幾個檢視應當始終可見 |
| `ActionMorph` | 單一動作需要一點空間來輸入內容 |
