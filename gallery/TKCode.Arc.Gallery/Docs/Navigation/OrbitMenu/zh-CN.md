## 何时使用

`OrbitMenu` 把一个对象的三到六个一步完成的操作放在圆形按钮后面。按下时，操作从按钮中扫出，落到按钮上方的圆弧上，而同一次按压就能完成整件事：朝某个操作的方向拖动，松手，它就被触发。轻点一下则让圆弧留在外面，之后可以像普通菜单一样悬停和点击操作。只要圆弧在显示，按钮与圆弧之间的胶囊就会说出正被对准的操作；操作触发后，按钮显示对勾，胶囊显示一句简短的确认。

- **照片、便签或消息**，需要几个快捷动词：喜欢、保存、发送、删除。
- **手机和平板**：一次按住-拖动-松手，比先打开菜单再在里面点选更快。
- **悬浮的新建按钮**：提供几种新建项目。

## 何时不用

- **操作很多，或名称需要先读一读**：`DropdownMenu` 或 `ContextMenu` 一次显示所有名称。
- **选中后保持开启的模式或工具**：应放在 `ToolDock` 或工具栏里。
- **只有一个操作**：普通按钮更清楚。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:OrbitMenu Label="Note actions">
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Pin}" Label="Pin" DoneText="Pinned" />
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Send}" Label="Send" DoneText="Sent" />
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Trash2}" Label="Delete" DoneText="Deleted" Tone="Danger" />
    </arc:OrbitMenu>
</UserControl>
```

`OrbitMenu` 在 Special 包中：除了 `UseArcControls()`，还要用 `UseArcSpecial()` 注册。它的项是 `OrbitMenuAction` 元素，也可以通过 `ItemsSource` 绑定数据（每项的文字成为操作的标签）。每个操作都有 `Glyph` 和 `Label`：标签是操作被对准时胶囊显示的名称，也是辅助技术读出的名称。触发后胶囊显示 `DoneText`，为空时显示标签；`Tone="Danger"` 用危险色绘制破坏性操作。

操作触发时，它先引发自己的 `Click`、执行 `Command`，菜单再引发带有该操作及其数据项的 `ActionInvoked`；随后圆弧收起，按钮显示对勾，胶囊显示确认约 1.4 秒。`IsOpen`（双向）、`Open()`、`Close()` 和 `Toggle()` 可以从代码控制圆弧。`Label` 为按钮和菜单命名；圆弧展开但没有对准任何操作时，胶囊也显示它。`CancelText` 是拖动离开所有操作时胶囊上的文字。`Announces` 开启时（默认），确认文字也会由屏幕阅读器读出。

### 对准、轻点与取消

对准取决于方向，而不是碰到操作本身。指针离按钮中心超过 34 px 后，目标就是绕按钮的角度与指针最接近的那个操作，即使指针还没到达它。透镜滑到该操作下方，靠近指针的操作会被轻轻吸向指针。松手即触发目标。持续不到约三分之一秒的轻点会让圆弧保持展开；在中心附近、远超圆弧处松手，或按住不动后松手，圆弧会收起，什么也不触发。点击操作之间的空白处或外部任意位置，圆弧同样收起。

### 位置

菜单在布局中只占按钮的位置，圆弧画在周围内容之上。`Direction` 是圆弧朝向的角度，单位为度，从右侧顺时针计：默认 -90 朝上，90 朝下，180 朝左。`Spread` 决定圆弧张开的角度（默认 150；360 时操作均匀分布成一整圈），`Radius` 决定操作离中心的距离（104 px）。

### 最佳实践

**推荐**

- 保持三到六个操作，每个都有简短的 `Label` 和 `DoneText`。
- 删除或移除类的操作使用 `Tone="Danger"`。
- 让圆弧朝向没有重要内容的地方，并留出 `Radius` 再加约 30 px 的空白。

**避免**

- 把完成某件重要事情的唯一途径藏在按钮后面。
- 把按钮放在圆弧会超出窗口的位置：圆弧不会被挪回窗口内。

## 无障碍

- 按钮以 `Label` 命名，报告菜单是否展开，以及它会打开一个菜单。
- 每个操作都是以 `Label` 命名的菜单项，可由辅助技术调用。收起的操作对辅助技术隐藏，也不在 Tab 顺序中；所有操作在 Tab 顺序中只占一个位置。
- 获得键盘焦点的操作就是目标：透镜位于其下，胶囊显示其名称，所以焦点总是可见。
- 开启 `Announces` 时，礼貌型实时区域会读出每条确认。

### 键盘交互

| 按键 | 操作 |
|---|---|
| 按钮上的 Enter 或 Space | 切换圆弧；展开时焦点在第一个操作上。 |
| 按钮上的方向键 | 显示圆弧，焦点在第一个操作上；按 Up 时在最后一个上。 |
| Right 或 Down | 下一个操作；最后一个之后回到第一个。 |
| Left 或 Up | 上一个操作；第一个之前是最后一个。 |
| Home / End | 第一个或最后一个操作。 |
| 操作上的 Enter 或 Space | 触发该操作；焦点回到按钮。 |
| Escape | 收起圆弧；焦点回到按钮。 |
| Tab | 收起圆弧，焦点移到下一个控件。 |

## 动效

- 展开时，操作按项目顺序逐个离开按钮，间隔 35 ms：每个沿弧线绕到圆弧上的位置，同时从 40% 大小长大，柔和的模糊逐渐散去。收起时顺序相反，而且更快。
- 一条细轨迹在操作后方从圆弧中间画向两端。
- 在目标之间，透镜沿圆弧滑动，移动时较小，到达后恢复完整大小。靠近指针的操作会被轻轻拉向指针并略微变大（只对鼠标和笔）。
- 按钮上的省略号在圆弧展开时变形为关闭标记，操作触发后变形为对勾。胶囊上升出现，以弹簧调整大小贴合文字，并通过柔和的模糊切换文字。

| 变化 | Full | Reduced | Off |
|---|---|---|---|
| 操作展开与收起 | 错峰旋转，缩放与模糊由弹簧驱动 | 原地淡入淡出 | 直接出现与消失 |
| 透镜 | 弹簧滑动 | 跳到位置，淡入淡出 | 跳到位置 |
| 附近的操作 | 倾斜并变大 | 只变大 | 只变大 |
| 按钮标记 | 弹簧形变 | 立即切换 | 立即切换 |
| 胶囊 | 上升放大出现，文字模糊切换 | 淡入淡出，文字交叉淡化 | 直接出现 |

## 响应式

- 按钮（56 px）和操作（46 px）在任何宽度下都保持尺寸，都是舒适的触摸目标。
- 触摸时按住、拖动、松手同样有效；向指针倾斜只对鼠标和笔生效。
- 没有任何机制把圆弧限制在窗口内：在手机上，让它朝向屏幕中部，并留出它需要的空间。

## 相关组件

- `DropdownMenu` 带名称地列出操作。
- `ContextMenu` 把次要操作放在所选对象旁边。
- `ActionMorph` 把一个操作展开成一个小面板。

| 组件 | 何时选用 |
|---|---|
| `OrbitMenu` | 针对一个对象的三到六个熟悉的操作，一个手势即可完成 |
| `DropdownMenu` | 操作需要显示名称，或者数量较多 |
| `ActionMorph` | 一个操作需要输入框或几个选项 |
