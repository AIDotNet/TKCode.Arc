## 何時使用

`OrbitMenu` 把一個物件的三到六個一步完成的動作放在圓形按鈕後面。按下時，動作從按鈕中掃出，落到按鈕上方的圓弧上，而同一次按壓就能完成整件事：朝某個動作的方向拖曳，放開，它就會觸發。輕點一下則讓圓弧留在外面，之後可以像一般選單一樣懸停並點選動作。只要圓弧在顯示，按鈕與圓弧之間的膠囊就會說出正被對準的動作；動作觸發後，按鈕顯示勾號，膠囊顯示一句簡短的確認。

- **相片、便條或訊息**，需要幾個快捷動詞：喜歡、儲存、傳送、刪除。
- **手機與平板**：一次按住-拖曳-放開，比先打開選單再在裡面點選更快。
- **浮動的新增按鈕**：提供幾種新增項目。

## 何時不用

- **動作很多，或名稱需要先讀一讀**：`DropdownMenu` 或 `ContextMenu` 一次顯示所有名稱。
- **選取後保持開啟的模式或工具**：應放在 `ToolDock` 或工具列裡。
- **只有一個動作**：一般按鈕更清楚。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:OrbitMenu Label="Note actions">
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Pin}" Label="Pin" DoneText="Pinned" />
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Send}" Label="Send" DoneText="Sent" />
        <arc:OrbitMenuAction Glyph="{x:Static arc:ArcIcons.Trash2}" Label="Delete" DoneText="Deleted" Tone="Danger" />
    </arc:OrbitMenu>
</UserControl>
```

`OrbitMenu` 位於 Special 套件：除了 `UseArcControls()`，還要用 `UseArcSpecial()` 註冊。它的項目是 `OrbitMenuAction` 元素，也可以透過 `ItemsSource` 繫結資料（每個項目的文字會成為動作的標籤）。每個動作都有 `Glyph` 與 `Label`：標籤是動作被對準時膠囊顯示的名稱，也是輔助技術讀出的名稱。觸發後膠囊顯示 `DoneText`，為空時顯示標籤；`Tone="Danger"` 以危險色繪製破壞性動作。

動作觸發時，它先引發自己的 `Click`、執行 `Command`，選單再引發帶有該動作與其資料項目的 `ActionInvoked`；接著圓弧收起，按鈕顯示勾號，膠囊顯示確認約 1.4 秒。`IsOpen`（雙向）、`Open()`、`Close()` 與 `Toggle()` 可以從程式碼控制圓弧。`Label` 為按鈕與選單命名；圓弧展開但沒有對準任何動作時，膠囊也顯示它。`CancelText` 是拖曳離開所有動作時膠囊上的文字。`Announces` 開啟時（預設），確認文字也會由螢幕閱讀器讀出。

### 對準、輕點與取消

對準取決於方向，而不是碰到動作本身。指標離按鈕中心超過 34 px 後，目標就是繞按鈕的角度與指標最接近的那個動作，即使指標還沒到達它。透鏡滑到該動作下方，靠近指標的動作會被輕輕吸向指標。放開即觸發目標。持續不到約三分之一秒的輕點會讓圓弧保持展開；在中心附近、遠超過圓弧處放開，或按住不動後放開，圓弧會收起，什麼也不觸發。點選動作之間的空白處或外部任何位置，圓弧同樣收起。

### 位置

選單在版面中只佔按鈕的位置，圓弧畫在周圍內容之上。`Direction` 是圓弧朝向的角度，單位為度，從右側順時針計：預設 -90 朝上，90 朝下，180 朝左。`Spread` 決定圓弧張開的角度（預設 150；360 時動作平均分布成一整圈），`Radius` 決定動作離中心的距離（104 px）。

### 最佳實務

**建議**

- 維持三到六個動作，每個都有簡短的 `Label` 與 `DoneText`。
- 刪除或移除類的動作使用 `Tone="Danger"`。
- 讓圓弧朝向沒有重要內容的地方，並留出 `Radius` 再加約 30 px 的空白。

**避免**

- 把完成某件重要事情的唯一途徑藏在按鈕後面。
- 把按鈕放在圓弧會超出視窗的位置：圓弧不會被移回視窗內。

## 無障礙

- 按鈕以 `Label` 命名，回報選單是否展開，以及它會開啟一個選單。
- 每個動作都是以 `Label` 命名的選單項目，可由輔助技術叫用。收起的動作對輔助技術隱藏，也不在 Tab 順序中；所有動作在 Tab 順序中只佔一個位置。
- 取得鍵盤焦點的動作就是目標：透鏡位於其下，膠囊顯示其名稱，所以焦點一定看得見。
- 開啟 `Announces` 時，禮貌型即時區域會讀出每則確認。

### 鍵盤互動

| 按鍵 | 動作 |
|---|---|
| 按鈕上的 Enter 或 Space | 切換圓弧；展開時焦點在第一個動作上。 |
| 按鈕上的方向鍵 | 顯示圓弧，焦點在第一個動作上；按 Up 時在最後一個上。 |
| Right 或 Down | 下一個動作；最後一個之後回到第一個。 |
| Left 或 Up | 上一個動作；第一個之前是最後一個。 |
| Home / End | 第一個或最後一個動作。 |
| 動作上的 Enter 或 Space | 觸發該動作；焦點回到按鈕。 |
| Escape | 收起圓弧；焦點回到按鈕。 |
| Tab | 收起圓弧，焦點移到下一個控制項。 |

## 動效

- 展開時，動作依項目順序逐一離開按鈕，間隔 35 ms：每個沿弧線繞到圓弧上的位置，同時從 40% 大小長大，柔和的模糊逐漸散去。收起時順序相反，而且更快。
- 一條細軌跡在動作後方從圓弧中間畫向兩端。
- 在目標之間，透鏡沿圓弧滑動，移動時較小，到達後恢復完整大小。靠近指標的動作會被輕輕拉向指標並略微變大（僅限滑鼠與筆）。
- 按鈕上的刪節號在圓弧展開時變形為關閉標記，動作觸發後變形為勾號。膠囊上升出現，以彈簧調整大小貼合文字，並透過柔和的模糊切換文字。

| 變化 | Full | Reduced | Off |
|---|---|---|---|
| 動作展開與收起 | 錯開旋轉，縮放與模糊由彈簧驅動 | 原地淡入淡出 | 直接出現與消失 |
| 透鏡 | 彈簧滑動 | 跳到位置，淡入淡出 | 跳到位置 |
| 附近的動作 | 傾斜並變大 | 只變大 | 只變大 |
| 按鈕標記 | 彈簧變形 | 立即切換 | 立即切換 |
| 膠囊 | 上升放大出現，文字模糊切換 | 淡入淡出，文字交叉淡化 | 直接出現 |

## 響應式行為

- 按鈕（56 px）與動作（46 px）在任何寬度下都維持尺寸，都是舒適的觸控目標。
- 觸控時按住、拖曳、放開同樣有效；朝指標傾斜僅限滑鼠與筆。
- 沒有任何機制把圓弧限制在視窗內：在手機上，讓它朝向螢幕中央，並留出它需要的空間。

## 相關元件

- `DropdownMenu` 帶名稱地列出動作。
- `ContextMenu` 把次要動作放在所選物件旁邊。
- `ActionMorph` 把一個動作展開成一個小面板。

| 元件 | 何時選用 |
|---|---|
| `OrbitMenu` | 針對一個物件的三到六個熟悉動作，一個手勢即可完成 |
| `DropdownMenu` | 動作需要顯示名稱，或數量較多 |
| `ActionMorph` | 一個動作需要輸入框或幾個選項 |
