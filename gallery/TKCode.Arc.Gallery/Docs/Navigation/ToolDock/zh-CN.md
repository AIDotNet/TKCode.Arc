## 何时使用

`ToolDock` 是一条浮动的工具条，放的是编辑器里工作时反复切换的工具：选择、平移、绘制、输入文字、评论。正在使用的工具衬着一块柔和的强调色底，换成另一个工具时，这块底随之移过去。鼠标或键盘焦点所在的工具上方会出现一枚小标签，写着它的名称和按键，并随着你的移动一路跟过去。同一工具的几个变体（矩形、椭圆、直线）可以共用一个槽位，它会在工具栏上方打开一块同材质的托盘；在托盘里选中的那个就成为槽位的图标。

- **可视化编辑器的指针工具**：选择、平移、形状、文字、便签、评论。
- **编辑器的模式**：一个模式保持生效，直到被另一个取代。
- **用户自己定制的工具栏**：开启重新排序后，可以拖动槽位，或用 Alt 加方向键移动它。

## 何时不用

- **在表单或工具栏里从两到四个选项中选一个**：`SegmentedControl` 更合适。
- **执行完就结束的命令**，例如撤销或导出，不会留下任何选中状态：用普通按钮就对了。
- **在应用的各个部分之间导航**：用 `Tabs` 或 `LiquidTabBar`。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:ToolDock SelectedValue="select">
        <arc:ToolDockItem Value="select" Label="Select" Shortcut="V" Glyph="{x:Static arc:ArcIcons.Move}" />
        <arc:ToolDockItem Value="shapes" Label="Shapes">
            <arc:ToolDockItem Value="square" Label="Square" Shortcut="R" Glyph="{x:Static arc:ArcIcons.Square}" />
            <arc:ToolDockItem Value="circle" Label="Circle" Shortcut="O" Glyph="{x:Static arc:ArcIcons.Circle}" />
        </arc:ToolDockItem>
        <arc:ToolDockItem Value="text" Label="Text" Shortcut="T" Glyph="{x:Static arc:ArcIcons.Type}" />
    </arc:ToolDock>
</UserControl>
```

`ToolDock` 在 Special 包里：在 `UseArcControls()` 旁边用 `UseArcSpecial()` 注册。每一项是一个 `ToolDockItem`，带 `Value`、`Label`、24 × 24 的 `Glyph`，还可以加 `Shortcut` 和 `Badge`。`SelectedValue`（双向）是选中项的 `Value`；`ItemChosen` 报告通过指针、键盘或辅助技术做出的每一次选择。快捷键提示只是显示出来：请在页面上处理按键并设置 `SelectedValue`，就像上面的预览那样。项也可以来自 `ItemsSource`，用 `ItemContainerTheme` 绑定容器的属性。

每个槽位 40 px，工具栏的宽度就是所有槽位加起来的宽度，不会为了放下而挤压任何东西。工具栏上方要留出空位，因为托盘和浮动标签都出现在那里。

### 组与托盘

在一项里嵌套成员，它就成为一个组。按下组会让它当前可见的成员成为当前工具，并在槽位上方升起一个装着所有成员的托盘；从托盘里选一个，会让该成员成为当前工具并把托盘收起。从此槽位换上所选成员的图标（旧图标模糊淡出，新图标淡入），即使在使用其他工具时也不变。组的一角带着一个小标记，很容易和单个工具区分开。在工具栏以外的任何地方按下都会收起托盘；在代码里调用 `CloseTray()`。

### 重新排序

设置 `CanReorder` 后，用户可以重新排列工具栏：横向拖动一个槽位时它会被抬起，邻居滑开让位；用 Alt 加左、右方向键可以移动有焦点的槽位。内联的项，或者可修改的列表形式的 `ItemsSource`，会被原地重新排序，`Reordered` 报告每一次移动，包括该项以及它原来和新的索引。只有横向拖动才会重新排序；在工具栏上竖向滑动照样可以滚动页面。

<Demo name="Reorder" />

### 徽标

`Badge` 在槽位的角上显示一个计数，例如未处理的评论。计数变化时数字会滚动，计数归零时徽标退场。计数也是槽位无障碍名称的一部分。

### 最佳实践

**建议**

- 给每一项一个简短的 `Label`：它既是浮动标签，也是无障碍名称。
- 挑选不看名称也一目了然的图标，因为触摸时永远不会出现浮动标签。
- 让工具栏保持简短，大约四到八个槽位，把同一工具的变体放进一个组。

**避免**

- 往工具栏里塞满不会留下选中状态的命令。
- 把工具栏放在上方没有空间容纳托盘和标签的位置。

## 无障碍

- 工具栏是一个以 `Label`（默认 "Tools"）命名的工具栏，只有一个 Tab 停靠点：按 Tab 进入时落在上次获得焦点的槽位（或选中的槽位），方向键沿着工具栏移动。
- 单个工具是一个按钮，报告它是否被按下（选中）。组是一个按钮，报告它的托盘是否展开；托盘是以组名命名的分组，收起时对辅助技术隐藏。
- 每个槽位的无障碍名称以快捷键提示结尾，有徽标时再加上计数："Text, T"、"Comment, C, 2"。组的名称由组标签和当前可见的成员组成，例如 "Shapes: Circle, O"；当前工具是它的成员之一时，还会加上 "selected"。
- 浮动标签只是重复无障碍名称，所以对屏幕阅读器隐藏。鼠标悬停和键盘焦点会让它出现，触摸则永远不会。只有键盘操作时才显示焦点环。

### 键盘交互

| 按键 | 操作 |
|---|---|
| Left / Right | 从一个槽位走到下一个，到两端时循环；在打开的托盘里，在成员之间逐个移动。 |
| Home / End | 移到第一个或最后一个槽位（或成员）。 |
| Enter 或 Space | 让有焦点的工具成为当前工具。在组上，可见的成员成为当前工具，托盘随之显示或隐藏。在托盘里，该成员成为当前工具，托盘隐藏，焦点回到组上。 |
| Up | 在组上：显示托盘，焦点放在槽位持有的成员上。 |
| Down | 在托盘里：隐藏托盘并聚焦它的组。 |
| Tab | 在托盘里：隐藏托盘，焦点继续移出工具栏。 |
| Alt + Left / Right | `CanReorder` 为 true 时移动有焦点的槽位。 |
| Escape | 隐藏打开的托盘并聚焦它的组。 |

## 动效

- 标签第一次出现前会稍等片刻（鼠标 400 ms，键盘约 200 ms），然后带着轻微的缩放升到位置上。标签可见时，或指针刚离开不久，它会直接移向下一个工具：在弹簧上滑行，同时文字以短暂的模糊切换。
- 选中工具的底色在带一点回弹的弹簧上滑到新工具，全程保持形状不变。
- 按下槽位时，它在 90 ms 内下沉到 92%，随后弹回。
- 托盘从组的槽位长到完整大小，成员依次淡入、放大并上升，彼此相隔 35 ms。收起时托盘沉回工具栏。
- 被拖动的槽位抬起到 112%，邻居在平滑的弹簧上滑开。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 标签 | 上升、滑行、模糊切换文字 | 原地淡入，在工具之间直接跳 | 直接出现 |
| 选中底色 | 在弹簧上滑动 | 直接跳到位 | 直接跳到位 |
| 托盘 | 长出与沉回，成员依次进场 | 立即打开和收起 | 立即打开和收起 |
| 组图标 | 缩小、模糊并交叉淡化 | 交叉淡化 | 直接替换 |
| 按下与拖动 | 下沉、抬起、邻居滑开 | 无；邻居直接到位 | 无 |
| 徽标 | 数字滚动，徽标弹入弹出 | 数字直接变化，徽标淡入淡出 | 立即变化 |

## 响应式

- 槽位在任何宽度下都保持 40 px，便于触摸；在手机上请让工具栏保持简短。
- 工具栏不会缩到比槽位更窄；请把它放在放得下完整宽度的地方。
- 触摸没有悬停，用户永远看不到浮动标签，所以每个图标都必须单独就能认出来。
- 从工具栏上开始的上下滑动照常滚动页面；重新排序需要横向拖动。

## 相关组件

- `MagnifyDock` 是一个应用启动栏，图标会在指针下放大。
- `LiquidTabBar` 在应用的主要区域之间移动。
- `SegmentedControl` 在几个行内选项中选一个。

| 组件 | 适用场景 |
|---|---|
| `ToolDock` | 浮动栏里会保持选中的工具或模式 |
| `LiquidTabBar` | 应用里要前往的地方 |
| `SegmentedControl` | 表单或工具栏里的两到四个选项 |
