## 何時使用

`ToolDock` 是一條浮動的工具條，放的是編輯器裡工作時反覆切換的工具：選取、平移、繪製、輸入文字、留言。正在使用的工具襯著一塊柔和的強調色底，換成另一個工具時，這塊底隨之移過去。滑鼠或鍵盤焦點所在的工具上方會出現一枚小標籤，寫著它的名稱與按鍵，並隨著你的移動一路跟過去。同一工具的幾個變體（矩形、橢圓、直線）可以共用一個槽位，它會在工具列上方開啟一塊同材質的托盤；在托盤裡選取的那個就成為槽位的圖示。

- **視覺化編輯器的指標工具**：選取、平移、形狀、文字、便利貼、留言。
- **編輯器的模式**：一個模式保持生效，直到被另一個取代。
- **使用者自行訂製的工具列**：開啟重新排序後，可以拖曳槽位，或用 Alt 加方向鍵移動它。

## 何時不用

- **在表單或工具列裡從兩到四個選項中選一個**：`SegmentedControl` 更合適。
- **執行完就結束的指令**，例如復原或匯出，不會留下任何選取狀態：用一般按鈕就對了。
- **在應用程式的各個部分之間導覽**：請用 `Tabs` 或 `LiquidTabBar`。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:ToolDock SelectedValue="select">
        <arc:ToolDockItem Value="select" Label="Select" Shortcut="V" Glyph="{x:Static arc:ArcIcons.Move}" />
        <arc:ToolDockItem Value="shapes" Label="Shapes">
            <arc:ToolDockItem Value="square" Label="Square" Shortcut="R" Glyph="{x:Static arc:ArcIcons.Square}" />
            <arc:ToolDockItem Value="circle" Label="Circle" Shortcut="O" Glyph="{x:Static arc:ArcIcons.Circle}" />
        </arc:ToolDockItem>
        <arc:ToolDockItem Value="text" Label="Text" Shortcut="T" Glyph="{x:Static arc:ArcIcons.Type}" />
    </arc:ToolDock>
</UserControl>
```

`ToolDock` 位於 Special 套件：在 `UseArcControls()` 旁邊用 `UseArcSpecial()` 註冊。每個項目是一個 `ToolDockItem`，帶有 `Value`、`Label`、24 × 24 的 `Glyph`，也可以加上 `Shortcut` 與 `Badge`。`SelectedValue`（雙向）是選取項目的 `Value`；`ItemChosen` 回報透過指標、鍵盤或輔助技術做出的每一次選擇。快速鍵提示只是顯示出來：請在頁面上處理按鍵並設定 `SelectedValue`，就像上面的預覽那樣。項目也可以來自 `ItemsSource`，以 `ItemContainerTheme` 繫結容器的屬性。

每個槽位 40 px，工具列的寬度就是所有槽位加起來的寬度，不會為了放下而擠壓任何東西。工具列上方要預留空位，因為托盤與浮動標籤都出現在那裡。

### 群組與托盤

在項目裡巢狀放入成員，它就成為一個群組。按下群組會讓它目前可見的成員成為目前的工具，並在槽位上方升起一個裝著所有成員的托盤；從托盤裡選一個，會讓該成員成為目前的工具並把托盤收起。從此槽位換上所選成員的圖示（舊圖示模糊淡出，新圖示淡入），即使在使用其他工具時也不變。群組的一角帶著一個小標記，很容易和單一工具區分開來。在工具列以外的任何地方按下都會收起托盤；在程式碼中呼叫 `CloseTray()`。

### 重新排序

設定 `CanReorder` 後，使用者可以重新排列工具列：橫向拖曳一個槽位時它會被抬起，鄰居滑開讓位；用 Alt 加左、右方向鍵可以移動有焦點的槽位。行內的項目，或可修改的清單形式的 `ItemsSource`，會被就地重新排序，`Reordered` 回報每一次移動，包含該項目以及它原本與新的索引。只有橫向拖曳才會重新排序；在工具列上直向滑動照樣可以捲動頁面。

### 徽章

`Badge` 在槽位的角落顯示一個計數，例如尚未處理的留言。計數變化時數字會捲動，計數歸零時徽章退場。計數也是槽位無障礙名稱的一部分。

### 最佳實務

**建議**

- 給每個項目一個簡短的 `Label`：它既是浮動標籤，也是無障礙名稱。
- 挑選不看名稱也一目了然的圖示，因為觸控時永遠不會出現浮動標籤。
- 讓工具列保持精簡，大約四到八個槽位，把同一工具的變體放進一個群組。

**避免**

- 往工具列裡塞滿不會留下選取狀態的指令。
- 把工具列放在上方沒有空間容納托盤與標籤的位置。

## 無障礙

- 工具列是以 `Label`（預設 "Tools"）命名的工具列，只有一個 Tab 停駐點：按 Tab 進入時落在上次取得焦點的槽位（或選取的槽位），方向鍵沿著工具列移動。
- 單一工具是一個按鈕，回報它是否被按下（選取）。群組是一個按鈕，回報它的托盤是否展開；托盤是以群組名稱命名的群組，收起時對輔助技術隱藏。
- 每個槽位的無障礙名稱以快速鍵提示結尾，有徽章時再加上計數："Text, T"、"Comment, C, 2"。群組的名稱由群組標籤與目前可見的成員組成，例如 "Shapes: Circle, O"；目前的工具是它的成員之一時，還會加上 "selected"。
- 浮動標籤只是重複無障礙名稱，所以對螢幕閱讀器隱藏。滑鼠停留與鍵盤焦點會讓它出現，觸控則永遠不會。只有鍵盤操作時才顯示焦點環。

### 鍵盤互動

| 按鍵 | 動作 |
|---|---|
| Left / Right | 從一個槽位走到下一個，到兩端時循環；在開啟的托盤裡，在成員之間逐一移動。 |
| Home / End | 移到第一個或最後一個槽位（或成員）。 |
| Enter 或 Space | 讓有焦點的工具成為目前的工具。在群組上，可見的成員成為目前的工具，托盤隨之顯示或隱藏。在托盤裡，該成員成為目前的工具，托盤隱藏，焦點回到群組上。 |
| Up | 在群組上：顯示托盤，焦點放在槽位持有的成員上。 |
| Down | 在托盤裡：隱藏托盤並聚焦它的群組。 |
| Tab | 在托盤裡：隱藏托盤，焦點繼續移出工具列。 |
| Alt + Left / Right | `CanReorder` 為 true 時移動有焦點的槽位。 |
| Escape | 隱藏開啟中的托盤並聚焦它的群組。 |

## 動效

- 標籤第一次出現前會稍等片刻（滑鼠 400 ms，鍵盤約 200 ms），然後帶著輕微的縮放升到定位。標籤可見時，或指標剛離開不久，它會直接移向下一個工具：在彈簧上滑行，同時文字以短暫的模糊切換。
- 選取工具的底色在帶一點回彈的彈簧上滑到新工具，全程保持形狀不變。
- 按下槽位時，它在 90 ms 內下沉到 92%，隨後彈回。
- 托盤從群組的槽位長到完整大小，成員依序淡入、放大並上升，彼此相隔 35 ms。收起時托盤沉回工具列。
- 被拖曳的槽位抬起到 112%，鄰居在平順的彈簧上滑開。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 標籤 | 上升、滑行、模糊切換文字 | 原地淡入，在工具之間直接跳動 | 直接出現 |
| 選取底色 | 在彈簧上滑動 | 直接跳到定位 | 直接跳到定位 |
| 托盤 | 長出與沉回，成員依序進場 | 立即開啟與收起 | 立即開啟與收起 |
| 群組圖示 | 縮小、模糊並交叉淡化 | 交叉淡化 | 直接替換 |
| 按下與拖曳 | 下沉、抬起、鄰居滑開 | 無；鄰居直接到位 | 無 |
| 徽章 | 數字捲動，徽章彈入彈出 | 數字直接變化，徽章淡入淡出 | 立即變化 |

## 響應式行為

- 槽位在任何寬度下都維持 40 px，方便觸控；在手機上請讓工具列保持精簡。
- 工具列不會縮得比槽位更窄；請把它放在容得下完整寬度的地方。
- 觸控沒有停留，使用者永遠看不到浮動標籤，所以每個圖示都必須單獨就能認出來。
- 從工具列上開始的上下滑動照常捲動頁面；重新排序需要橫向拖曳。

## 相關元件

- `MagnifyDock` 是應用程式啟動列，圖示會在指標下放大。
- `LiquidTabBar` 在應用程式的主要區域之間移動。
- `SegmentedControl` 從幾個行內選項中選一個。

| 元件 | 適用情境 |
|---|---|
| `ToolDock` | 浮動列中會保持選取的工具或模式 |
| `LiquidTabBar` | 應用程式中要前往的地方 |
| `SegmentedControl` | 表單或工具列中的兩到四個選項 |
