## 何时使用

`Tooltip` 为无法在屏幕上自我说明的控件提供一句简短的标签。它通过 `arc:Tooltip.Tip` 附加到控件上，因此触发器保留自己的布局，页面上不会增加额外元素。悬停或键盘聚焦时显示标签；读者按下控件或移开指针后，它立即消失。

- **工具栏中的纯图标按钮。** 带有打印机、链接或归档图标的文档或订单工具栏，需要“打印装箱单”这样的标签，让读者在按下之前就知道每个图标的作用。
- **表格或卡片中被截断的文字。** 被省略号截断的订单备注或商品名称，可以在悬停时显示完整文字，读者无需打开记录即可阅读。
- **设置旁的简短提示。** 字段或开关旁的一句提示，例如“付款结算后开放退款”，在不占用表单空间的前提下解释规则。
- **需要说明原因的禁用控件。** 禁用的退款按钮可以在读者指向它时说明为何暂时不可用。

## 何时不用

- **链接、带操作的按钮或读者必须使用的输入框：** 用 `Popover`。提示内容无法交互，因此其中的链接或按钮无法被触达。
- **人员或链接的丰富预览：** 用 `HoverCard`，它可以用多项信息的布局展示个人资料或摘要。
- **触摸用户必须看到的信息：** 应显示在页面上，而不是放在提示中。提示在指针悬停和键盘聚焦时打开，因此触摸用户可能永远看不到这些文字。
- **错误与验证消息：** 使用字段自身的错误行，例如 `Input` 的 `ErrorMessage`。提示会在下一次按下时消失，而且没有指向字段的读者无法找到它。
- **超过一两句话的说明：** 使用行内辅助文字，或带标题的 `Popover`。气泡宽度限制为 240 px，适合标签，不适合段落。

## 用法

提示是一个附加属性。在任意控件上设置 `arc:Tooltip.Tip`；悬停或键盘聚焦时显示文字。提示不是该控件的子元素，因此可以安全地添加到按钮、文本块、复选框或模板中的图标上。

### 结构

1. **触发器**：带有 `arc:Tooltip.Tip` 的控件。它保留自己的尺寸与布局，提示从不改变它。
2. **气泡**：圆角方框，使用页面文字颜色的反色，因此在浅色页面上是深色标签，在深色页面上是浅色标签。它有一条 1 px 的细边框，由 14% 的背景色与前景色混合而成，使边缘在两种主题下都清晰可见。
3. **文字**：提示内容，使用小号字体、常规字重。字符串与数字在气泡内换行，气泡最大宽度为 240 px，文字两侧各留 16 px 内边距，上下各留 12 px。
4. **间距**：气泡位于触发器 8 px 外，位于 `Side` 设定的一侧；打开时它向上移动 3 px 就位。

### 基础

```xml
<arc:Button Content="复制" arc:Tooltip.Tip="复制链接" />
```

纯图标按钮使用简短的动词短语，因为提示是唯一可见的标签。已经说明自身用途的文字按钮无需提示；重复按钮文字的提示只会增加延迟和干扰。

### 方向

`arc:Tooltip.Side` 设置气泡在触发器的哪一侧打开：`Top`（默认）、`Bottom`、`Left` 或 `Right`。选择能让气泡不遮挡读者正在看的内容的一侧。

```xml
<arc:Button Variant="Secondary" Content="分享" arc:Tooltip.Tip="与你的团队分享"
            arc:Tooltip.Side="Bottom" />
```

页面中部的控件使用 `Top`；贴着窗口顶部边缘的页头控件使用 `Bottom`；垂直工具栏边缘的控件使用 `Left` 或 `Right`，因为顶部提示会遮住上方的工具栏。

### 绑定文字

`Tip` 接受任意对象。当文字来自视图模型时进行绑定，这样标签会随应用状态而变化。

```xml
<arc:Button Content="保存" arc:Tooltip.Tip="{Binding SaveHint}" />
```

### 修改文字与延迟

提示打开时可以在代码中修改文字。文字会交叉淡化，气泡会调整大小以适应新内容。设置 `ShowDelay` 可以改变第一个提示打开前的等待时间；默认为 250 ms，当另一个提示已经打开时立即出现的提示会忽略它。

<Demo name="LiveText" />

```csharp
Tooltip.SetTip(save, "刚刚已保存");
Tooltip.SetShowDelay(save, TimeSpan.FromMilliseconds(400));
```

仅在读者正在看的状态改变时修改文字，例如保存后按钮从“保存草稿”变为“刚刚已保存”。不要每秒修改一次；不断改写自己的提示很难阅读。

### 从代码显示

`Tooltip.SetIsOpen` 立即显示或隐藏某个元素上的提示，不经过 `ShowDelay`。用它说明读者刚刚改变的控件，例如付款结算后变为可用的退款按钮。以 `false` 调用可再次隐藏提示。指针离开、按下控件或焦点移开时，提示仍会自行关闭，因此读者离开之后不要通过代码让它保持打开。

```csharp
Tooltip.SetIsOpen(refund, true);
```

### 绑定到视图模型

当说明取决于数据时，把提示绑定到视图模型属性。禁用的控件是常见情形：提示解释为何无法执行该操作，并在指针悬停于控件上时显示。

```csharp
using CommunityToolkit.Mvvm.ComponentModel;

public partial class OrderRowViewModel : ObservableObject
{
    [ObservableProperty]
    private bool _canRefund;

    [ObservableProperty]
    private string _refundHint = "付款结算后开放退款。";
}
```

```xml
<arc:Button Content="退款"
            IsEnabled="{Binding CanRefund}"
            arc:Tooltip.Tip="{Binding RefundHint}" />
```

禁用的控件不会因悬停或聚焦而自行打开提示；禁用控件上的提示只有在指针悬停其上时才会打开。把原因写在提示中，让读者知道什么条件能使控件可用。原因改变时（例如“付款结算后开放退款”变为“退款已于 2026-10-18 申请”），更新绑定的属性，提示会随之更新。

### 排队与时机

第一个提示在指针进入控件或 Tab 焦点落在控件上之后，等待 `ShowDelay`（默认 250 ms）。任何提示打开期间，以及上一个提示关闭后的 300 ms 内，下一个提示会立即打开，仅以淡入呈现。共享的时间让读者沿工具栏移动时，无需在每个按钮前等待即可读到各个标签；而首次等待则避免指针仅仅穿过窗口时屏幕上出现提示。

鼠标聚焦不会打开提示；点击控件只会关闭提示。按下触发器会立即关闭提示，因此它不会遮住该次按下所打开的菜单。

### 示例：履约控制台中的订单行操作

履约控制台中的一行，包含被截断的客户备注和三个操作。由于该行宽度固定，备注无法完整显示，因此它在提示中显示完整文字。按钮本身带有文字标签，只有在标签不足以说明时才使用提示：退款按钮已禁用，其提示解释了阻止它的规则。

```xml
<StackPanel Width="560" Spacing="12">
    <Grid ColumnDefinitions="*,Auto,Auto,Auto" ColumnSpacing="8">
        <StackPanel Spacing="2" VerticalAlignment="Center">
            <TextBlock Text="ord_2026_0412 · Acme Analytics"
                       FontWeight="Medium"
                       Foreground="{arc:ArcDesignTokenResource Foreground}" />
            <TextBlock Text="请把包裹交给后门的礼宾员，按两次门铃。"
                       MaxWidth="320"
                       TextTrimming="CharacterEllipsis"
                       Foreground="{arc:ArcDesignTokenResource TextSecondary}"
                       arc:Tooltip.Tip="请把包裹交给后门的礼宾员，按两次门铃。" />
        </StackPanel>
        <arc:Button Grid.Column="1" Variant="Ghost" Content="打印标签"
                    VerticalAlignment="Center"
                    arc:Tooltip.Tip="打印运单标签" />
        <arc:Button Grid.Column="2" Variant="Ghost" Content="复制单号"
                    VerticalAlignment="Center"
                    arc:Tooltip.Tip="复制物流单号" />
        <arc:Button Grid.Column="3" Variant="Secondary" Content="退款"
                    VerticalAlignment="Center"
                    IsEnabled="False"
                    arc:Tooltip.Tip="付款结算后开放退款。" />
    </Grid>
</StackPanel>
```

备注被截断，是因为该行宽度固定，完整文字会把操作按钮挤出该行。提示重复的是完整文字而非摘要，因为读者来此是为了看完整的备注。禁用的退款按钮保留了它的提示，因为禁用的控件不会提供其他线索说明它为何无法使用。

### 文案规范

- **长度**：一个简短的短语或一句话。气泡最宽 240 px，因此超过约 60 个字符的提示会换成多行，更难扫读。
- **形式**：动作用动词短语（“复制链接”“打印运单标签”），状态用名词短语（“草稿已于 2 分钟前保存”）。使用句子式大小写，不使用感叹号。
- **句号**：单句可以以句号结尾，短语则不需要。每个应用选定一种风格并保持一致。
- **快捷键**：只有应用定义了快捷键时才包含它。不要为提示虚构快捷键。
- **禁用的控件**：说明什么条件能使控件可用，而不只是说它不可用。

| 不要写 | 改为 |
|---|---|
| 点击此按钮可将链接复制到剪贴板。 | 复制链接 |
| 删除 | 删除草稿 |
| 重要！！！请先阅读。 | 24 小时后过期 |
| 不可用 | 付款结算后开放退款。 |
| 保存 | 保存草稿 |

### 最佳实践

**推荐**

- 为每个纯图标控件提供可见的提示和 `AutomationProperties.Name`。提示面向指向控件的明眼读者；名称是屏幕阅读器播报的内容，不会被提示取代。
- 提示只保留读者做决定所需的那一件事。说明动作的标签比整个屏幕的描述更有用。
- 同一工具栏中的提示使用同一方向，让读者的视线习惯标签出现的位置。
- 被截断标签的完整文字放在提示中，让读者无需打开记录即可阅读。
- 页头中使用 `Bottom`，垂直工具栏中使用 `Left` 或 `Right`，使气泡不遮挡读者正指向的控件。

**避免**

- 在提示中放置交互内容，例如链接或按钮。提示内容无法通过键盘到达，因此不使用指针的人会失去该操作。
- 把提示作为必填字段或错误的唯一说明。它会在下一次按下时消失，读者可能从未看到；应使用字段自身的辅助或错误行。
- 在页面的每个控件上都加提示。满屏提示会显得嘈杂；只在图标或被截断的文字需要时添加。
- 依赖触摸设备上的提示。触摸用户可能看不到它，因此必须阅读的内容应放在页面上。
- 在提示中重复按钮文字。按钮“复制”配上提示“复制”只增加延迟，没有提供任何信息。

### 常见问题

**为什么禁用的按钮不显示提示？** 禁用的控件不会因悬停或聚焦而打开提示。只有指针悬停在禁用控件上时才会打开，因此它可以在控件无需获得焦点的情况下说明原因。

**为什么点击按钮后提示消失？** 按下触发器会立即关闭提示，因此它不会遮住该次按下所打开的菜单、对话框或面板。

**能用 Escape 关闭提示吗？** 提示本身不处理 Escape。焦点移开或指针离开时它会关闭。

**提示能在触摸屏上使用吗？** 提示在悬停和键盘聚焦时打开，而触摸屏不能可靠地提供这些操作。触摸用户需要的信息应保留在页面上。

**能否在不可聚焦的控件上显示提示？** 它会在指针悬停时打开，`Tooltip.SetIsOpen` 也可以从代码打开它。无法获得焦点的控件仍需为屏幕阅读器提供名称，因此请设置 `AutomationProperties.Name`。

## API 参考

<!-- api: Tooltip -->

提示的方向由 `TooltipSide` 设置，它有四个成员。

| 成员 | 含义 |
|---|---|
| `Top` | 气泡在触发器上方打开（默认） |
| `Bottom` | 气泡在触发器下方打开 |
| `Left` | 气泡在触发器左侧打开 |
| `Right` | 气泡在触发器右侧打开 |

## 无障碍

- 提示打开时，其文字会写入触发器的帮助文本。
- 提示不能替代名称。仅含图标的触发器仍需设置自己的 `AutomationProperties.Name`。
- 提示在指针悬停和键盘聚焦时打开。Tab 聚焦会在延迟后打开它，焦点移开则关闭它。
- 气泡不可聚焦，也不接收指针输入，因此它永远不会从所描述的控件处夺走焦点。
- 气泡中没有可交互元素，因此键盘用户无需失去焦点即可阅读内容。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` 移到触发器上 | 经过 `ShowDelay` 后打开提示；若另一个提示已经打开则立即打开 |
| `Tab` 移离触发器 | 关闭提示 |

## 动效

- 第一个提示等待 250ms，然后从触发器向上升起 3px，同时从缩放 0.97 开始出现。
- 指针移到相邻触发器，或上一个提示在 300ms 之前刚关闭时，下一个提示立即打开，仅以淡入呈现。
- 提示打开期间文字变化时，新词带着柔和的模糊升起，气泡以弹簧调整为新尺寸。
- 关闭为瞬间淡出，气泡同时缩小到 0.98。
- 减弱动效时移除移动，保留短暂淡入。关闭动效时提示立即显示或移除。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 第一个提示打开 | 等待 `ShowDelay`，然后上升 3px 并从 0.97 缩放出现 | 仅短暂淡入 | 立即显示 |
| 提示已打开时的下一个提示 | 立即打开，仅以淡入呈现 | 仅短暂淡入 | 立即显示 |
| 打开时文字变化 | 新词带着柔和模糊升起；气泡以弹簧调整为新尺寸 | 仅短暂淡入 | 立即显示 |
| 提示关闭 | 瞬间淡出，气泡缩小到 0.98 | 短暂淡入 | 立即移除 |

## 相关组件

- `Popover` 用于锚定在控件上的互动内容。
- `HoverCard` 用于人员或链接的丰富只读预览。

| 组件 | 适用场景 |
|---|---|
| `Popover` | 内容含有链接、按钮或表单，且点击后打开 |
| `HoverCard` | 悬停时需要人员或链接的只读预览 |
| `Input` | 关于字段的消息必须保留在页面上，直到字段被修正 |
| `Dialog` | 读者必须阅读或确认某事后才能继续 |
