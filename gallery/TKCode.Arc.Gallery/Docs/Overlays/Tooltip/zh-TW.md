## 何時使用

`Tooltip` 為無法在畫面上自我說明的控制項提供一句簡短的標籤。它透過 `arc:Tooltip.Tip` 附加到控制項上，因此觸發器保留自己的版面配置，頁面上不會增加額外元素。懸停或鍵盤聚焦時顯示標籤；使用者按下控制項或移開指標後，它立即消失。

- **工具列中的純圖示按鈕。** 帶有印表機、連結或封存圖示的文件或訂單工具列，需要「列印裝箱單」這樣的標籤，讓使用者在按下之前就知道每個圖示的作用。
- **表格或卡片中被截斷的文字。** 被省略號截斷的訂單備註或商品名稱，可以在懸停時顯示完整文字，使用者無需開啟紀錄即可閱讀。
- **設定旁的簡短說明。** 欄位或開關旁的一句提示，例如「付款結算後開放退款」，在不佔用表單空間的前提下說明規則。
- **需要說明原因的停用控制項。** 停用的退款按鈕可以在使用者指向它時說明為何暫時無法使用。

## 何時不用

- **連結、帶操作的按鈕或使用者必須操作的輸入框：** 用 `Popover`。工具提示內容無法互動，因此其中的連結或按鈕無法被觸達。
- **人員或連結的豐富預覽：** 用 `HoverCard`，它可以用多項資訊的版面展示個人資料或摘要。
- **觸控使用者必須看到的資訊：** 應顯示在頁面上，而不是放在工具提示中。工具提示在指標懸停和鍵盤聚焦時開啟，因此觸控使用者可能永遠看不到這些文字。
- **錯誤與驗證訊息：** 使用欄位自身的錯誤列，例如 `Input` 的 `ErrorMessage`。工具提示會在下一次按下時消失，而且沒有指向欄位的使用者無法找到它。
- **超過一兩句話的說明：** 使用列內輔助文字，或帶標題的 `Popover`。氣泡寬度限制為 240 px，適合標籤，不適合段落。

## 用法

工具提示是一個附加屬性。在任意控制項上設定 `arc:Tooltip.Tip`；懸停或鍵盤聚焦時顯示文字。工具提示不是該控制項的子元素，因此可以安全地加到按鈕、文字區塊、核取方塊或範本中的圖示上。

### 結構

1. **觸發器**：帶有 `arc:Tooltip.Tip` 的控制項。它保留自己的尺寸與版面配置，工具提示從不改變它。
2. **氣泡**：圓角方框，使用頁面文字顏色的反色，因此在淺色頁面上是深色標籤，在深色頁面上是淺色標籤。它有一條 1 px 的細邊框，由 14% 的背景色與前景色混合而成，使邊緣在兩種主題下都清晰可見。
3. **文字**：工具提示內容，使用小號字體、一般字重。字串與數字在氣泡內換行，氣泡最大寬度為 240 px，文字兩側各留 16 px 內距，上下各留 12 px。
4. **間距**：氣泡位於觸發器 8 px 外，位於 `Side` 設定的一側；開啟時它向上移動 3 px 就位。

### 基本

```xml
<arc:Button Content="複製" arc:Tooltip.Tip="複製連結" />
```

純圖示按鈕使用簡短的動詞片語，因為工具提示是唯一可見的標籤。已經說明自身用途的文字按鈕無需工具提示；重複按鈕文字的工具提示只會增加延遲和干擾。

### 方向

`arc:Tooltip.Side` 設定氣泡在觸發器的哪一側開啟：`Top`（預設）、`Bottom`、`Left` 或 `Right`。選擇能讓氣泡不遮住使用者正在看的內容的一側。

```xml
<arc:Button Variant="Secondary" Content="分享" arc:Tooltip.Tip="與你的團隊分享"
            arc:Tooltip.Side="Bottom" />
```

頁面中間的控制項使用 `Top`；貼著視窗頂端邊緣的頁首控制項使用 `Bottom`；垂直工具列邊緣的控制項使用 `Left` 或 `Right`，因為頂部工具提示會遮住上方的工具列。

### 繫結文字

`Tip` 接受任意物件。當文字來自檢視模型時進行繫結，這樣標籤會隨應用程式狀態而變化。

```xml
<arc:Button Content="儲存" arc:Tooltip.Tip="{Binding SaveHint}" />
```

### 修改文字與延遲

工具提示開啟時可以在程式碼中修改文字。文字會交叉淡化，氣泡會調整大小以符合新內容。設定 `ShowDelay` 可以改變第一個工具提示開啟前的等待時間；預設為 250 ms，當另一個工具提示已經開啟時立即出現的工具提示會忽略它。

<Demo name="LiveText" />

```csharp
Tooltip.SetTip(save, "剛剛已儲存");
Tooltip.SetShowDelay(save, TimeSpan.FromMilliseconds(400));
```

僅在使用者正在看的狀態改變時修改文字，例如儲存後按鈕從「儲存草稿」變為「剛剛已儲存」。不要每秒修改一次；不斷改寫自己的工具提示很難閱讀。

### 從程式碼顯示

`Tooltip.SetIsOpen` 立即顯示或隱藏某個元素上的工具提示，不經過 `ShowDelay`。用它說明使用者剛剛改變的控制項，例如付款結算後變為可用的退款按鈕。以 `false` 呼叫可再次隱藏工具提示。指標離開、按下控制項或焦點移開時，工具提示仍會自行關閉，因此使用者離開之後不要透過程式碼讓它保持開啟。

```csharp
Tooltip.SetIsOpen(refund, true);
```

### 繫結到檢視模型

當說明取決於資料時，把工具提示繫結到檢視模型屬性。停用的控制項是常見情形：工具提示解釋為何無法執行該操作，並在指標懸停於控制項上時顯示。

```csharp
using CommunityToolkit.Mvvm.ComponentModel;

public partial class OrderRowViewModel : ObservableObject
{
    [ObservableProperty]
    private bool _canRefund;

    [ObservableProperty]
    private string _refundHint = "付款結算後開放退款。";
}
```

```xml
<arc:Button Content="退款"
            IsEnabled="{Binding CanRefund}"
            arc:Tooltip.Tip="{Binding RefundHint}" />
```

停用的控制項不會因懸停或聚焦而自行開啟工具提示；停用控制項上的工具提示只有在指標懸停其上時才會開啟。把原因寫在工具提示中，讓使用者知道什麼條件能使控制項可用。原因改變時（例如「付款結算後開放退款」變為「退款已於 2026-10-18 申請」），更新繫結的屬性，工具提示會隨之更新。

### 排隊與時機

第一個工具提示在指標進入控制項或 Tab 焦點落在控制項上之後，等待 `ShowDelay`（預設 250 ms）。任何工具提示開啟期間，以及上一個工具提示關閉後的 300 ms 內，下一個工具提示會立即開啟，僅以淡入呈現。共用的時間讓使用者沿工具列移動時，無需在每個按鈕前等待即可讀到各個標籤；而首次等待則避免指標只是穿過視窗時畫面上出現工具提示。

滑鼠聚焦不會開啟工具提示；點擊控制項只會關閉工具提示。按下觸發器會立即關閉工具提示，因此它不會遮住該次按下所開啟的選單。

### 範例：履約主控台中的訂單列操作

履約主控台中的一列，包含被截斷的客戶備註和三個操作。由於該列寬度固定，備註無法完整顯示，因此它在工具提示中顯示完整文字。按鈕本身帶有文字標籤，只有在標籤不足以說明時才使用工具提示：退款按鈕已停用，其工具提示說明了阻擋它的規則。

```xml
<StackPanel Width="560" Spacing="12">
    <Grid ColumnDefinitions="*,Auto,Auto,Auto" ColumnSpacing="8">
        <StackPanel Spacing="2" VerticalAlignment="Center">
            <TextBlock Text="ord_2026_0412 · Acme Analytics"
                       FontWeight="Medium"
                       Foreground="{arc:ArcDesignTokenResource Foreground}" />
            <TextBlock Text="請把包裹交給後門的禮賓員，按兩次門鈴。"
                       MaxWidth="320"
                       TextTrimming="CharacterEllipsis"
                       Foreground="{arc:ArcDesignTokenResource TextSecondary}"
                       arc:Tooltip.Tip="請把包裹交給後門的禮賓員，按兩次門鈴。" />
        </StackPanel>
        <arc:Button Grid.Column="1" Variant="Ghost" Content="列印標籤"
                    VerticalAlignment="Center"
                    arc:Tooltip.Tip="列印運送標籤" />
        <arc:Button Grid.Column="2" Variant="Ghost" Content="複製單號"
                    VerticalAlignment="Center"
                    arc:Tooltip.Tip="複製物流單號" />
        <arc:Button Grid.Column="3" Variant="Secondary" Content="退款"
                    VerticalAlignment="Center"
                    IsEnabled="False"
                    arc:Tooltip.Tip="付款結算後開放退款。" />
    </Grid>
</StackPanel>
```

備註被截斷，是因為該列寬度固定，完整文字會把操作按鈕擠出該列。工具提示重複的是完整文字而非摘要，因為使用者來此是為了看完整的備註。停用的退款按鈕保留了它的工具提示，因為停用的控制項不會提供其他線索說明它為何無法使用。

### 文案規範

- **長度**：一個簡短的片語或一句話。氣泡最寬 240 px，因此超過約 60 個字元的工具提示會換成多行，更難掃讀。
- **形式**：動作用動詞片語（「複製連結」「列印運送標籤」），狀態用名詞片語（「草稿已於 2 分鐘前儲存」）。使用句子式大小寫，不使用驚嘆號。
- **句號**：單句可以以句號結尾，片語則不需要。每個應用程式選定一種風格並保持一致。
- **快速鍵**：只有應用程式定義了快速鍵時才包含它。不要為工具提示虛構快速鍵。
- **停用的控制項**：說明什麼條件能使控制項可用，而不只是說它無法使用。

| 不要寫 | 改為 |
|---|---|
| 點擊此按鈕可將連結複製到剪貼簿。 | 複製連結 |
| 刪除 | 刪除草稿 |
| 重要！！！請先閱讀。 | 24 小時後過期 |
| 無法使用 | 付款結算後開放退款。 |
| 儲存 | 儲存草稿 |

### 最佳做法

**建議**

- 為每個純圖示控制項提供可見的工具提示和 `AutomationProperties.Name`。工具提示面向指向控制項的明眼使用者；名稱是螢幕閱讀器播報的內容，不會被工具提示取代。
- 工具提示只保留使用者做決定所需的那一件事。說明動作的標籤比整個畫面的描述更有用。
- 同一工具列中的工具提示使用同一方向，讓使用者的視線習慣標籤出現的位置。
- 被截斷標籤的完整文字放在工具提示中，讓使用者無需開啟紀錄即可閱讀。
- 頁首中使用 `Bottom`，垂直工具列中使用 `Left` 或 `Right`，使氣泡不遮住使用者正指向的控制項。

**避免**

- 在工具提示中放置互動內容，例如連結或按鈕。工具提示內容無法透過鍵盤到達，因此不使用指標的人會失去該操作。
- 把工具提示作為必填欄位或錯誤的唯一說明。它會在下一次按下時消失，使用者可能從未看到；應使用欄位自身的輔助或錯誤列。
- 在頁面的每個控制項上都加工具提示。滿版工具提示會顯得嘈雜；只在圖示或被截斷的文字需要時添加。
- 依賴觸控裝置上的工具提示。觸控使用者可能看不到它，因此必須閱讀的內容應放在頁面上。
- 在工具提示中重複按鈕文字。按鈕「複製」配上工具提示「複製」只增加延遲，沒有提供任何資訊。

### 常見問題

**為什麼停用的按鈕不顯示工具提示？** 停用的控制項不會因懸停或聚焦而開啟工具提示。只有指標懸停在停用的控制項上時才會開啟，因此它可以在控制項無需取得焦點的情況下說明原因。

**為什麼點擊按鈕後工具提示消失？** 按下觸發器會立即關閉工具提示，因此它不會遮住該次按下所開啟的選單、對話方塊或面板。

**能用 Escape 關閉工具提示嗎？** 工具提示本身不處理 Escape。焦點移開或指標離開時它會關閉。

**工具提示能在觸控螢幕上使用嗎？** 工具提示在懸停和鍵盤聚焦時開啟，而觸控螢幕無法可靠地提供這些操作。觸控使用者需要的資訊應保留在頁面上。

**能否在不可聚焦的控制項上顯示工具提示？** 它會在指標懸停時開啟，`Tooltip.SetIsOpen` 也可以從程式碼開啟它。無法取得焦點的控制項仍需為螢幕閱讀器提供名稱，因此請設定 `AutomationProperties.Name`。

## API 參考

<!-- api: Tooltip -->

工具提示的方向由 `TooltipSide` 設定，它有四個成員。

| 成員 | 含義 |
|---|---|
| `Top` | 氣泡在觸發器上方開啟（預設） |
| `Bottom` | 氣泡在觸發器下方開啟 |
| `Left` | 氣泡在觸發器左側開啟 |
| `Right` | 氣泡在觸發器右側開啟 |

## 無障礙

- 工具提示開啟時，其文字會寫入觸發器的說明文字。
- 工具提示不能取代名稱。僅含圖示的觸發器仍需設定自己的 `AutomationProperties.Name`。
- 工具提示在指標懸停和鍵盤聚焦時開啟。Tab 聚焦會在延遲後開啟它，焦點移開則關閉它。
- 氣泡不可聚焦，也不接收指標輸入，因此它永遠不會從所描述的控制項處搶走焦點。
- 氣泡中沒有可互動元素，因此鍵盤使用者無需失去焦點即可閱讀內容。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` 移到觸發器上 | 經過 `ShowDelay` 後開啟工具提示；若另一個工具提示已經開啟則立即開啟 |
| `Tab` 移離觸發器 | 關閉工具提示 |

## 動態效果

- 第一個工具提示等待 250ms，然後從觸發器向上升起 3px，同時從縮放 0.97 開始出現。
- 指標移到相鄰的觸發器，或上一個工具提示在 300ms 之前剛關閉時，下一個工具提示立即開啟，僅以淡入呈現。
- 工具提示開啟期間文字變化時，新詞帶著柔和的模糊升起，氣泡以彈簧調整為新尺寸。
- 關閉為瞬間淡出，氣泡同時縮小到 0.98。
- 減少動態效果時移除移動，保留短暫淡入。關閉動態效果時工具提示立即顯示或移除。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 第一個工具提示開啟 | 等待 `ShowDelay`，然後上升 3px 並從 0.97 縮放出現 | 僅短暫淡入 | 立即顯示 |
| 工具提示已開啟時的下一個工具提示 | 立即開啟，僅以淡入呈現 | 僅短暫淡入 | 立即顯示 |
| 開啟時文字變化 | 新詞帶著柔和模糊升起；氣泡以彈簧調整為新尺寸 | 僅短暫淡入 | 立即顯示 |
| 工具提示關閉 | 瞬間淡出，氣泡縮小到 0.98 | 短暫淡入 | 立即移除 |

## 相關元件

- `Popover` 用於錨定在控制項上的互動內容。
- `HoverCard` 用於人員或連結的豐富唯讀預覽。

| 元件 | 適用情境 |
|---|---|
| `Popover` | 內容含有連結、按鈕或表單，且點擊後開啟 |
| `HoverCard` | 懸停時需要人員或連結的唯讀預覽 |
| `Input` | 關於欄位的訊息必須保留在頁面上，直到欄位被修正 |
| `Dialog` | 使用者必須閱讀或確認某事後才能繼續 |
