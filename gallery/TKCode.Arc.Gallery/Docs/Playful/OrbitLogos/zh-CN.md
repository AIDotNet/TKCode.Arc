## 何时使用

`OrbitLogos` 把产品能接入的一切以标志的形式排在两条环上，环绕着你自己的标志。环缓慢转动，指针或键盘焦点进入时就停下。选中一个标志会让它滑到固定位置，从中央向它画一条线，并打开一张卡片，说明这个集成做什么、当前状态，以及连接操作。

- **集成页面或首屏**：生动呈现生态，又允许人们仔细查看。
- **应用内的集成页面**：在同一处按类别浏览、了解工具并连接。
- **发布页**：一眼看到产品能配合的所有工具。

## 何时不用

- **只用来背书的标志**：如果没人会打开它们，一排安静的标志就够了，动得更少。
- **很大的目录**：两条环放到二三十个标志就会拥挤，而且大列表需要搜索；请用带搜索框的网格或表格。
- **顺序或搜索很重要时**：环在转动，没有东西停留在固定位置。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:OrbitLogos>
        <arc:OrbitLogo Name="Vercel"
                       Category="Dev"
                       Icon="m12 1.608 12 20.784H0Z"
                       Description="Comments preview links on builds."
                       IsConnected="True" />
        <arc:OrbitLogo Name="Slack"
                       Category="Comms"
                       Icon="avares://MyApp/Assets/slack-color.png"
                       Description="Posts deploy alerts to your channels."
                       Href="https://example.com/docs/slack" />
    </arc:OrbitLogos>
</UserControl>
```

`OrbitLogos` 是 Special 包中的模板化控件。在 `UseArcControls()` 旁边调用 `UseArcSpecial()` 注册该包。标志就是它的内容：每个 `OrbitLogo` 有 `Name`、可选的 `Id`（选择以 `Id` 为准，没有时用名称）、`Icon`、`Category`、一行 `Description`、起始的 `IsConnected`，以及用于 Docs 链接的 `Href`。轨道占满宽度，最宽 460px；宽度达到 760px 时与详情面板并排，更窄时卡片位于轨道下方。

### 标志图形

`Icon` 可以是 24 × 24 网格上的 SVG 路径数据（Simple Icons 格式）、图片地址（`.png`、`.jpg`、`.webp` 文件，或 http(s)、`avares`、file、data URL）、`ImageSource` 或任意控件。路径数据跟随文本颜色，所以黑白品牌无需设置颜色；在标志上设置 `Color` 则用品牌色绘制。图片保留自己的颜色。把控件作为 `Icon` 时只显示在环上，卡片里改为显示名称的首字母。

品牌标志只是示例内容。请只展示确实存在的集成，并遵守各品牌的商标规则。

### 类别

给每个标志设置 `Category`，轨道上方就会出现类别胶囊；`AllLabel` 用于改名第一个胶囊。选中一个胶囊会把匹配的标志转向详情一侧并让其余标志变暗，此后方向键只在该类别内移动。如果打开的卡片不属于所选类别，卡片会关闭。

### 打开、连接与中央

`DefaultSelected` 在首次显示时打开一个标志；`SelectedId` 是打开的标志的 id 或名称，双向绑定，`null` 会关闭卡片。当用户打开、切换或关闭时，`SelectionChanged` 报告 `Logo` 与 `Index`，卡片关闭时没有标志且索引为 -1。

```csharp
orbit.ConnectHandler = async logo => await api.ConnectAsync(logo.Id ?? logo.Name);
```

连接按钮调用 `ConnectHandler`（或设置了 `Completion` 的 `ConnectRequested` 处理程序）。任务运行期间卡片显示 Connecting，完成后把标志标为已连接，失败则显示 Try again。没有处理程序时，卡片会模拟一次短暂的连接。

<Demo name="Connect" />

`Center` 是中央圆盘的内容，例如你的产品标志；默认是强调色的简单图形。`Speed` 用于缩放转速（为 1 时内环每 64 秒转一圈，外环反向每 88 秒转一圈；0 让轨道静止），`IsPaused` 则用于页面级的动效控制。`Label` 是标志列表的无障碍名称，也是空闲面板的标题。

### 最佳实践

**建议**

- 把产品标志放在中央，给每个标志设置类别和一行说明。
- 把 `ConnectHandler` 接到真实流程并返回它的任务。
- 保持在十二个左右，让环保持清晰易读。

**避免**

- 没有名称的标志：名称既是无障碍名称，也是人们看到的标签。
- 把轨道作为到达集成的唯一入口；请保留它所属的设置页面。

### 常见问题

**为什么我移到轨道上它就停了？** 指针或焦点在其中、选中了类别或打开了卡片时，轨道会缓动到静止，这样你瞄准时没有东西在动。

**触屏上会显示名称标签吗？** 不会。标签只在悬停和键盘焦点时出现。

## 无障碍

- 标志是带标签的开关按钮列表；每个名称都包含类别以及是否已连接。
- 只有一个标志在 Tab 顺序中，所以轨道在类别胶囊与卡片之间只占一个停靠点。
- 卡片是带标签的分组，包含真正的按钮和 Docs 链接。
- 连接状态在卡片中以文字和图标显示，而不只依靠标志上的圆点。
- 打开、切换、筛选和连接都会以礼貌的方式播报。
- 指针聚焦不绘制焦点环；键盘聚焦显示共用的焦点环、抬起的标志及其名称标签。

### 键盘

| 按键 | 操作 |
|---|---|
| Tab | 先进入类别胶囊，再到轨道中的一个标志，然后进入卡片。焦点在内时轨道保持静止。 |
| 方向键 | 移到当前类别中的上一个或下一个标志。卡片打开时，卡片和环随之移动。 |
| Home、End | 跳到当前类别的第一个或最后一个标志。 |
| Enter、Space | 打开获得焦点的标志；若已打开则关闭。 |
| Escape | 关闭卡片，并把焦点还给它的标志。 |

## 动效

- 一个循环用渲染变换移动标志，所有东西静止、轨道不在视野内或窗口隐藏时就休眠。
- 指针或焦点进入、选中类别或打开卡片时，转动在临界阻尼弹簧上缓动到静止。
- 打开一个标志时，它所在的环沿近路弹到位，带一点点过冲，直到标志停在固定位置：与详情面板并排时在轨道右侧，否则在底部。外环标志停靠时，内环会转开一个间隙，让连线保持畅通。
- 强调色连线从中央长到所选标志。
- 卡片从标志中长出：先是标志所在位置的一个圆，再弹簧般展开成自己的区域，然后内容淡入。上一个和下一个按行进方向滑入内容。
- 类别高亮是一块在胶囊之间沿形变弹簧滑动的药丸。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 旋转 | 缓慢转动，缓动到静止 | 无 | 无 |
| 环与连线 | 弹簧到位 | 立即到位 | 立即到位 |
| 卡片 | 从标志中长出 | 直接出现 | 直接出现 |
| 上一个和下一个 | 滑动 | 直接切换 | 直接切换 |
