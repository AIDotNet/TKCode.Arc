## 何時使用

`OrbitLogos` 把產品能接入的一切以標誌的形式排在兩條環上，環繞著你自己的標誌。環緩慢轉動，指標或鍵盤焦點進入時就停下。選中一個標誌會讓它滑到固定位置，從中央向它畫一條線，並開啟一張卡片，說明這個整合做什麼、目前狀態，以及連線操作。

- **整合頁面或首屏**：生動呈現生態，又允許人們仔細查看。
- **應用程式內的整合頁面**：在同一處依類別瀏覽、了解工具並連線。
- **發佈頁**：一眼看到產品能配合的所有工具。

## 何時不用

- **只用來背書的標誌**：如果沒人會開啟它們，一排安靜的標誌就夠了，動得更少。
- **很大的目錄**：兩條環放到二三十個標誌就會擁擠，而且大清單需要搜尋；請用帶搜尋框的格狀或表格。
- **順序或搜尋很重要時**：環在轉動，沒有東西停留在固定位置。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:OrbitLogos>
        <arc:OrbitLogo Name="Vercel"
                       Category="Dev"
                       Icon="m12 1.608 12 20.784H0Z"
                       Description="Comments preview links on builds."
                       IsConnected="True" />
        <arc:OrbitLogo Name="Slack"
                       Category="Comms"
                       Icon="avares://MyApp/Assets/slack-color.png"
                       Description="Posts deploy alerts to your channels."
                       Href="https://example.com/docs/slack" />
    </arc:OrbitLogos>
</UserControl>
```

`OrbitLogos` 是 Special 套件中的範本化控制項。在 `UseArcControls()` 旁邊呼叫 `UseArcSpecial()` 註冊該套件。標誌就是它的內容：每個 `OrbitLogo` 有 `Name`、可選的 `Id`（選擇以 `Id` 為準，沒有時用名稱）、`Icon`、`Category`、一行 `Description`、起始的 `IsConnected`，以及用於 Docs 連結的 `Href`。軌道佔滿寬度，最寬 460px；寬度達到 760px 時與詳情面板並排，更窄時卡片位於軌道下方。

### 標誌圖形

`Icon` 可以是 24 × 24 網格上的 SVG 路徑資料（Simple Icons 格式）、圖片位址（`.png`、`.jpg`、`.webp` 檔案，或 http(s)、`avares`、file、data URL）、`ImageSource` 或任意控制項。路徑資料跟隨文字顏色，所以黑白品牌無需設定顏色；在標誌上設定 `Color` 則用品牌色繪製。圖片保留自己的顏色。把控制項作為 `Icon` 時只顯示在環上，卡片裡改為顯示名稱的首字母。

品牌標誌只是範例內容。請只展示確實存在的整合，並遵守各品牌的商標規則。

### 類別

給每個標誌設定 `Category`，軌道上方就會出現類別膠囊；`AllLabel` 用於改名第一個膠囊。選中一個膠囊會把相符的標誌轉向詳情一側並讓其餘標誌變暗，此後方向鍵只在該類別內移動。如果開啟的卡片不屬於所選類別，卡片會關閉。

### 開啟、連線與中央

`DefaultSelected` 在首次顯示時開啟一個標誌；`SelectedId` 是開啟的標誌的 id 或名稱，雙向繫結，`null` 會關閉卡片。當使用者開啟、切換或關閉時，`SelectionChanged` 回報 `Logo` 與 `Index`，卡片關閉時沒有標誌且索引為 -1。

```csharp
orbit.ConnectHandler = async logo => await api.ConnectAsync(logo.Id ?? logo.Name);
```

連線按鈕呼叫 `ConnectHandler`（或設定了 `Completion` 的 `ConnectRequested` 處理常式）。工作執行期間卡片顯示 Connecting，完成後把標誌標為已連線，失敗則顯示 Try again。沒有處理常式時，卡片會模擬一次短暫的連線。

<Demo name="Connect" />

`Center` 是中央圓盤的內容，例如你的產品標誌；預設是強調色的簡單圖形。`Speed` 用於縮放轉速（為 1 時內環每 64 秒轉一圈，外環反向每 88 秒轉一圈；0 讓軌道靜止），`IsPaused` 則用於頁面層級的動態控制。`Label` 是標誌清單的無障礙名稱，也是閒置面板的標題。

### 最佳實務

**建議**

- 把產品標誌放在中央，給每個標誌設定類別和一行說明。
- 把 `ConnectHandler` 接到真實流程並傳回它的工作。
- 保持在十二個左右，讓環保持清晰易讀。

**避免**

- 沒有名稱的標誌：名稱既是無障礙名稱，也是人們看到的標籤。
- 把軌道作為到達整合的唯一入口；請保留它所屬的設定頁面。

### 常見問題

**為什麼我移到軌道上它就停了？** 指標或焦點在其中、選中了類別或開啟了卡片時，軌道會緩動到靜止，這樣你瞄準時沒有東西在動。

**觸控螢幕上會顯示名稱標籤嗎？** 不會。標籤只在懸停和鍵盤焦點時出現。

## 無障礙

- 標誌是帶標籤的切換按鈕清單；每個名稱都包含類別以及是否已連線。
- 只有一個標誌在 Tab 順序中，所以軌道在類別膠囊與卡片之間只佔一個停靠點。
- 卡片是帶標籤的群組，包含真正的按鈕和 Docs 連結。
- 連線狀態在卡片中以文字和圖示顯示，而不只依靠標誌上的圓點。
- 開啟、切換、篩選和連線都會以禮貌的方式播報。
- 指標聚焦不繪製焦點環；鍵盤聚焦顯示共用的焦點環、抬起的標誌及其名稱標籤。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| Tab | 先進入類別膠囊，再到軌道中的一個標誌，然後進入卡片。焦點在內時軌道保持靜止。 |
| 方向鍵 | 移到目前類別中的上一個或下一個標誌。卡片開啟時，卡片和環隨之移動。 |
| Home、End | 跳到目前類別的第一個或最後一個標誌。 |
| Enter、Space | 開啟取得焦點的標誌；若已開啟則關閉。 |
| Escape | 關閉卡片，並把焦點還給它的標誌。 |

## 動態

- 一個迴圈用轉換矩陣移動標誌，所有東西靜止、軌道不在視野內或視窗隱藏時就休眠。
- 指標或焦點進入、選中類別或開啟卡片時，轉動在臨界阻尼彈簧上緩動到靜止。
- 開啟一個標誌時，它所在的環沿近路彈到位，帶一點點過衝，直到標誌停在固定位置：與詳情面板並排時在軌道右側，否則在底部。外環標誌停靠時，內環會轉開一個間隙，讓連線保持暢通。
- 強調色連線從中央長到所選標誌。
- 卡片從標誌中長出：先是標誌所在位置的一個圓，再彈簧般展開成自己的區域，然後內容淡入。上一個和下一個依行進方向滑入內容。
- 類別高亮是一塊在膠囊之間沿形變彈簧滑動的藥丸。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 旋轉 | 緩慢轉動，緩動到靜止 | 無 | 無 |
| 環與連線 | 彈簧到位 | 立即到位 | 立即到位 |
| 卡片 | 從標誌中長出 | 直接出現 | 直接出現 |
| 上一個和下一個 | 滑動 | 直接切換 | 直接切換 |
