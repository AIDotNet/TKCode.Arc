## 何时使用

`StickerPeel` 是一面可以随手装饰的表面。每张贴纸都带一圈白色模切边；悬停会翘起离指针最近的一角，拉动会沿真实的折线把它折回，拉得足够远就会整张揭下，可以拿到别处。它支持键盘和触摸，并会告诉你当前的布局，方便保存。

- **个人资料与团队墙**：产品里一块由用户自己装饰的角落，贴上赢得或挑选的徽章。
- **发布或活动页面**：一个好玩的物件，奖励每一个伸手去碰它的人。
- **收藏**：随时间慢慢填满的成就架或贴纸册。

## 何时不用

- **排名或排序**：这里的位置只是装饰，不是数据；请用可重排列表。
- **需要阅读的文字**：贴纸上放一个图形或一个词，不放一段话。
- **繁忙的工具与表单**：它邀人玩耍，而人们想完成任务时这种情绪不合适。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:StickerPeel Height="320" Label="Laptop lid">
        <arc:StickerPeel.Stickers>
            <arc:StickerPeelItem Id="ship" Label="Ship it sticker" Shape="Pill" X="0.3" Y="0.35" Rotate="-6">
                <Border Width="112" Height="40" Background="#ffd84d">
                    <TextBlock Text="Ship it" HorizontalAlignment="Center" VerticalAlignment="Center" />
                </Border>
            </arc:StickerPeelItem>
        </arc:StickerPeel.Stickers>
    </arc:StickerPeel>
</UserControl>
```

`StickerPeel` 是 Special 包里的 `ContentControl`。请在 `UseArcControls()` 旁边用 `UseArcSpecial()` 注册该包。给它设一个高度；它至少 280px 高。它的 `Content` 画在表面上、贴纸之下，贴纸会被裁剪到表面的圆角框内。

### 贴纸

每个 `StickerPeelItem` 有稳定的 `Id`、供辅助技术使用的 `Label`、印在上面的 `Content`、起始中心（`X` 和 `Y`，在表面上各取 0 到 1）、可选的 `Rotate`（角度）和 `Shape`。请给内容一个固定尺寸：白色模切边和轮廓由控件添加。贴纸最好不超过十来张，这样表面才不会显得杂乱。

| 形状 | 轮廓 | 从哪里揭起 |
|---|---|---|
| `Circle` | 较短的边是直径 | 圆边上离指针最近的点 |
| `Rounded` | 圆角矩形 | 最近的角，沿对角线 |
| `Pill` | 两端完全圆润的矩形 | 最近的角，沿对角线 |

### 保存布局

位置是表面的比例，所以布局会随容器缩放，并且在改变大小后依然成立。贴纸在新位置落定后会触发一次 `PositionsChanged`，带上每张贴纸的位置。保存下来，再通过 `Positions` 传回即可。从外部改变 `Positions`（比如重置）时，每张贴纸会滑向新的位置。`Reset()` 会让每张贴纸回到它的项所设的起始位置。

<Demo name="Saved" />

```xml
<arc:StickerPeel Positions="{Binding Positions, Mode=TwoWay}" />
```

### 使用键盘

Tab 在贴纸之间移动。Enter 或 Space 拿起当前贴纸，再按一次就把它贴在原地。拿着贴纸时，方向键每次移动 10px，按住 Shift 为 40px；Escape 把它放回拿起时的位置。用 Tab 离开正拿着的贴纸会把它贴下。

### 最佳实践

**建议**

- 把它用在一个好玩、有触感的时刻：个人主页、发布页、团队墙或徽章架。
- 给每张贴纸一个固定尺寸的画面和有意义的 `Label`。
- 保存 `PositionsChanged` 给出的结果，以持久化布局。

**避免**

- 用在需要精确摆放或顺序重要的地方。
- 把人们必须阅读的文字放在贴纸背面：翘起的角只会显示素白的纸。

### 常见问题

**触摸屏上能揭贴纸吗？** 可以：在贴纸上拖动，同样会揭起。从贴纸之外开始的滑动仍会滚动页面。

**为什么贴纸只是跟着指针走？** 减弱动效会跳过揭起和悬停翘角：按下就直接拿起贴纸，它与指针一比一同步。

## 无障碍

- 表面是一个以 `Label` 命名的分组；每张贴纸是一个按钮，角色描述为“sticker”，带有自己的标签，拿着时处于已切换状态。
- 每张贴纸的帮助文本说明了键盘操作方式，一个礼貌（polite）的状态区域会播报揭下、拿起、贴下和放回。
- 贴纸的图案本身不承载含义，含义由标签承担。
- 指针聚焦不绘制焦点环；键盘聚焦显示共用的焦点环。拿着的贴纸的抬升和阴影表明哪一张处于活动状态。

### 键盘交互

| 按键 | 作用 |
|---|---|
| Tab | 在贴纸之间移动。离开正拿着的贴纸会把它贴下。 |
| Enter 或 Space | 拿起当前贴纸，或把它贴在原地。 |
| 方向键 | 把拿着的贴纸移动 10px，按住 Shift 为 40px。 |
| Escape | 把拿着的贴纸放回拿起时的位置。 |

## 动效

- 揭起是真实的折叠：被拉起的部分沿折线镜像，露出素色纸背，折痕处有一片柔和的阴影，另有一层始终向下落的轻阴影。折线最多偏斜 35 度，所以它始终是一个短而干净的折角。
- 圆形从圆边上离指针最近的点揭起；圆角矩形和胶囊形从一个角沿对角线揭起。
- 鼠标悬停会把最近的一角翘起几个像素。移到另一个角时，先让第一个角平放，再翘起下一个。
- 所有弹簧都是临界阻尼的：纸张略微落后于手指，落定时没有过冲、回弹或摆动。
- 折线越过中点、快速一拽，或手明显把它带走时，贴纸就会揭下。随后它抬升 3%，带着柔和的阴影，按自己的角度跟着手移动。
- 放下时，它正好落在屏幕上当前的位置，阴影在 200ms 内淡入。在它落定的过程中再次抓住它，它会就地被接住。
- 被拿着的贴纸碰到表面边缘时会带着越来越大的阻力被拉伸，放下时按其角度夹回表面内。
- 只有贴纸在动时才会产生帧，表面滚出视野时暂停。每一帧只写贴纸的姿态（一个变换）和折叠的几何，不触发布局。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 悬停翘角 | 翘起最近的一角 | 无 | 无 |
| 揭起 | 把角折回 | 无；按下就拿起贴纸 | 无；按下就拿起贴纸 |
| 拿着 | 抬升并投下阴影，略落后于手 | 与指针一比一同步 | 与指针一比一同步 |
