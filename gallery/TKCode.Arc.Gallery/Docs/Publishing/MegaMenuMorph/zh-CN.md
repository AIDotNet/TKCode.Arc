## 何时使用

`MegaMenuMorph` 用作营销网站或拥有很多入口的产品的顶部导航。每个顶层项目都可以在导航栏下方打开一个放满链接的大面板。它不会关掉一个下拉菜单再打开下一个，而是始终只有一个面板：指针从“Product”移到“Teams”时，面板以弹簧变到新项目的宽度、高度和位置，旧链接朝指针来的方向滑出，新链接从指针去的方向滑入。这个动作告诉用户，他们在浏览同一个菜单，而不是打开一叠互不相干的菜单。

- **入口分组的网站页头**：产品、方案、资源，每一项都带一句简短说明。
- **大小不同的面板**：两栏网格、单列列表和一张推荐卡片并存，变形动画吸收了它们之间的差别。
- **面板和普通链接混合的导航栏**：没有面板的项目（Pricing）就是一个链接，会关闭面板。

## 何时不用

- **产品内部的应用导航**：使用侧边导航或 `Tabs`；悬停面板会拖慢重复的操作。
- **只有几个操作**：使用 `DropdownMenu`。
- **只面向小屏幕**：把同样的入口放进 `Drawer` 或 `BottomSheet`；触摸屏上没有悬停。
- **层级很深**：大型菜单每一项只显示一层链接；更多层级请用 `TreeView` 或网站地图页面。

## 用法

`MegaMenuMorph` 位于 Special 包中：在 `UseArc()` 旁边用 `UseArcSpecial()` 注册它。把项目写成子元素。项目的内容就是它的面板：任何控件都可以，通常是放着 `MegaMenuMorphLink` 的 `Grid` 或 `StackPanel`。没有内容的项目是普通链接。

```xml
<arc:MegaMenuMorph Label="Main">
    <arc:MegaMenuMorphItem Header="Product">
        <StackPanel Width="280" Spacing="4">
            <arc:MegaMenuMorphLink Title="Boards" Description="Plan work in columns" />
            <arc:MegaMenuMorphLink Title="Docs" Description="Write specs next to the work" />
        </StackPanel>
    </arc:MegaMenuMorphItem>
    <arc:MegaMenuMorphItem Header="Pricing" />
</arc:MegaMenuMorph>
```

选中面板里的链接，或选中没有面板的项目时，会触发 `LinkInvoked`；它的参数带有 `Item`、`Link`（普通项目时为 null）和 `Title`。在这里跳转即可，面板此时已经开始关闭。

面板按最多 `MaxPanelWidth` 宽（默认 760）来测量内容，与视口边缘至少保持 12px，并居中放在触发项下方。给面板里的各栏设置固定宽度，变形动画就有清楚的尺寸可以在其间移动。

### 只在点击时打开

关闭 `OpensOnHover` 后，面板只在点击、轻点或使用键盘时打开。打开一个面板之后，移到相邻项目时面板仍会变形过去。

<Demo name="ClickToOpen" />

### 时间

`OpenDelay`（80 毫秒）是指针在触发项上停留多久后才打开关闭中的菜单，这样指针只是经过导航栏时不会让它闪开。`CloseDelay`（220 毫秒）是指针可以同时离开导航栏和面板多久，它覆盖两者之间的空隙和短暂滑出边缘的情况。打开时在项目之间移动不需要等待。

### 减少动态效果

在减少动态效果下，面板直接跳到下一项的位置和大小，内容在 120 毫秒内交叉淡入淡出而不滑动；打开和关闭都只有淡入淡出。

<Demo name="ReducedMotion" />

### 结构

1. **导航栏**：一行触发项，每个是 36px 高的胶囊，间距 2px，标签使用次要文字颜色和中等字重。
2. **高亮**：一块柔和的胶囊，滑到悬停、获得焦点或已打开的触发项下方。
3. **箭头**：只在有面板的项目上出现，面板打开时翻转过来。
4. **面板**：凸起的表面，带细边线、面板圆角和浮层阴影，位于导航栏下方 10px，内边距 12px。
5. **链接**：一行，左边是图标块（36px，柔和底色，悬停时带强调色），右边是标题和可选的说明。

## 无障碍

- 控件是一个导航区域，名称来自 `Label`。有面板的触发项是按钮，会报告展开或折叠；没有面板的触发项和每个 `MegaMenuMorphLink` 都是链接。链接的说明是它的帮助文字。
- 打开的面板是一个以项目命名的区域。
- 键盘焦点会在触发项和链接上显示 2px 的焦点环，并移动高亮；指针焦点不显示。

### 键盘

| 按键 | 作用 |
|---|---|
| Tab | 在触发项之间移动；在面板内时，越过最后一个链接后移到下一个触发项（面板关闭） |
| Left / Right | 移到上一个 / 下一个触发项；已打开的面板跟着移动 |
| Home / End | 移到第一个 / 最后一个触发项 |
| Enter / Space | 打开或关闭触发项的面板，或打开普通链接 |
| Down | 打开面板并移到第一个链接；在面板内时移到下一个链接 |
| Up | 在面板内移到上一个链接 |
| Escape | 关闭面板并回到它的触发项 |

## 动效

- **变形**：面板的矩形（位置、宽度和高度一起）跟随一个没有回弹的弹簧，大约 0.4 秒停稳，并且从当前所在的位置出发，所以沿导航栏快速划过时依然连贯。
- **内容**：在 300 毫秒内按标准曲线，旧内容朝指针来的方向滑动 36px，在 55% 时消失；新内容从另一侧滑入同样的距离，在前 15% 之后开始淡入。两者都裁剪在面板当前的形状里。
- **打开 / 关闭**：面板在 200 毫秒内按进入曲线淡入，同时下移 6px 停稳，并从 98.5% 放大；关闭时在 150 毫秒内淡出。箭头按 snappy 弹簧旋转。
- 减少动态效果时只保留淡入淡出（内容在 120 毫秒内交叉淡化）；关闭动效时一切立即完成。

## 响应式

- 面板最宽不超过视口减去两侧各 12px；内容更宽时按可用宽度测量并换行。
- 面板居中放在触发项下方，靠近边缘时会沿导航栏滑动，保持在屏幕内。
- 导航栏不换行：在窄屏上请把同样的项目放进 `Drawer`，从某个断点起再显示 `MegaMenuMorph`。触摸时轻点即可打开面板，没有任何功能依赖悬停。

## 相关组件

- `DropdownMenu`：按钮下方的操作菜单。
- `SiteHeader`：完整的网站页头区块，包含标志、导航和操作。
- `Tabs`：在同一页面的不同视图之间切换。
- `Drawer`：在小屏幕上放置同样的入口。
