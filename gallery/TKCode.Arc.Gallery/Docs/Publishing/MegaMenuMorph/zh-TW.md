## 何時使用

`MegaMenuMorph` 用作行銷網站或擁有很多入口的產品的頂部導覽。每個頂層項目都可以在導覽列下方開啟一個放滿連結的大面板。它不會關掉一個下拉選單再開啟下一個，而是始終只有一個面板：指標從「Product」移到「Teams」時，面板以彈簧變到新項目的寬度、高度和位置，舊連結朝指標來的方向滑出，新連結從指標去的方向滑入。這個動作告訴使用者，他們在瀏覽同一個選單，而不是開啟一疊互不相干的選單。

- **入口分組的網站頁首**：產品、方案、資源，每一項都帶一句簡短說明。
- **大小不同的面板**：兩欄網格、單欄清單和一張推薦卡片並存，變形動畫吸收了它們之間的差別。
- **面板和一般連結混合的導覽列**：沒有面板的項目（Pricing）就是一個連結，會關閉面板。

## 何時不用

- **產品內部的應用程式導覽**：使用側邊導覽或 `Tabs`；懸停面板會拖慢重複的操作。
- **只有幾個操作**：使用 `DropdownMenu`。
- **只面向小螢幕**：把同樣的入口放進 `Drawer` 或 `BottomSheet`；觸控螢幕上沒有懸停。
- **層級很深**：大型選單每一項只顯示一層連結；更多層級請用 `TreeView` 或網站地圖頁面。

## 用法

`MegaMenuMorph` 位於 Special 套件中：在 `UseArc()` 旁邊用 `UseArcSpecial()` 註冊它。把項目寫成子元素。項目的內容就是它的面板：任何控制項都可以，通常是放著 `MegaMenuMorphLink` 的 `Grid` 或 `StackPanel`。沒有內容的項目是一般連結。

```xml
<arc:MegaMenuMorph Label="Main">
    <arc:MegaMenuMorphItem Header="Product">
        <StackPanel Width="280" Spacing="4">
            <arc:MegaMenuMorphLink Title="Boards" Description="Plan work in columns" />
            <arc:MegaMenuMorphLink Title="Docs" Description="Write specs next to the work" />
        </StackPanel>
    </arc:MegaMenuMorphItem>
    <arc:MegaMenuMorphItem Header="Pricing" />
</arc:MegaMenuMorph>
```

選取面板裡的連結，或選取沒有面板的項目時，會觸發 `LinkInvoked`；它的參數帶有 `Item`、`Link`（一般項目時為 null）和 `Title`。在這裡跳轉即可，面板此時已經開始關閉。

面板按最多 `MaxPanelWidth` 寬（預設 760）來測量內容，與視口邊緣至少保持 12px，並置中放在觸發項下方。給面板裡的各欄設定固定寬度，變形動畫就有清楚的尺寸可以在其間移動。

### 只在點擊時開啟

關閉 `OpensOnHover` 後，面板只在點擊、輕觸或使用鍵盤時開啟。開啟一個面板之後，移到相鄰項目時面板仍會變形過去。

### 時間

`OpenDelay`（80 毫秒）是指標在觸發項上停留多久後才開啟關閉中的選單，這樣指標只是經過導覽列時不會讓它閃開。`CloseDelay`（220 毫秒）是指標可以同時離開導覽列和面板多久，它涵蓋兩者之間的空隙和短暫滑出邊緣的情況。開啟時在項目之間移動不需要等待。

### 減少動態效果

在減少動態效果下，面板直接跳到下一項的位置和大小，內容在 120 毫秒內交叉淡入淡出而不滑動；開啟和關閉都只有淡入淡出。

### 結構

1. **導覽列**：一行觸發項，每個是 36px 高的膠囊，間距 2px，標籤使用次要文字顏色和中等字重。
2. **醒目標示**：一塊柔和的膠囊，滑到懸停、取得焦點或已開啟的觸發項下方。
3. **箭頭**：只在有面板的項目上出現，面板開啟時翻轉過來。
4. **面板**：凸起的表面，帶細邊線、面板圓角和浮層陰影，位於導覽列下方 10px，內距 12px。
5. **連結**：一行，左邊是圖示塊（36px，柔和底色，懸停時帶強調色），右邊是標題和選用的說明。

## 無障礙

- 控制項是一個導覽區域，名稱來自 `Label`。有面板的觸發項是按鈕，會回報展開或摺疊；沒有面板的觸發項和每個 `MegaMenuMorphLink` 都是連結。連結的說明是它的說明文字。
- 開啟的面板是一個以項目命名的區域。
- 鍵盤焦點會在觸發項和連結上顯示 2px 的焦點環，並移動醒目標示；指標焦點不顯示。

### 鍵盤

| 按鍵 | 作用 |
|---|---|
| Tab | 在觸發項之間移動；在面板內時，越過最後一個連結後移到下一個觸發項（面板關閉） |
| Left / Right | 移到上一個 / 下一個觸發項；已開啟的面板跟著移動 |
| Home / End | 移到第一個 / 最後一個觸發項 |
| Enter / Space | 開啟或關閉觸發項的面板，或開啟一般連結 |
| Down | 開啟面板並移到第一個連結；在面板內時移到下一個連結 |
| Up | 在面板內移到上一個連結 |
| Escape | 關閉面板並回到它的觸發項 |

## 動效

- **變形**：面板的矩形（位置、寬度和高度一起）跟隨一個沒有回彈的彈簧，大約 0.4 秒停穩，並且從目前所在的位置出發，所以沿導覽列快速劃過時依然連貫。
- **內容**：在 300 毫秒內按標準曲線，舊內容朝指標來的方向滑動 36px，在 55% 時消失；新內容從另一側滑入同樣的距離，在前 15% 之後開始淡入。兩者都裁切在面板目前的形狀裡。
- **開啟 / 關閉**：面板在 200 毫秒內按進入曲線淡入，同時下移 6px 停穩，並從 98.5% 放大；關閉時在 150 毫秒內淡出。箭頭按 snappy 彈簧旋轉。
- 減少動態效果時只保留淡入淡出（內容在 120 毫秒內交叉淡化）；關閉動效時一切立即完成。

## 響應式

- 面板最寬不超過視口減去兩側各 12px；內容更寬時按可用寬度測量並換行。
- 面板置中放在觸發項下方，靠近邊緣時會沿導覽列滑動，保持在螢幕內。
- 導覽列不換行：在窄螢幕上請把同樣的項目放進 `Drawer`，從某個斷點起再顯示 `MegaMenuMorph`。觸控時輕觸即可開啟面板，沒有任何功能依賴懸停。

## 相關元件

- `DropdownMenu`：按鈕下方的操作選單。
- `SiteHeader`：完整的網站頁首區塊，包含標誌、導覽和操作。
- `Tabs`：在同一頁面的不同檢視之間切換。
- `Drawer`：在小螢幕上放置同樣的入口。
