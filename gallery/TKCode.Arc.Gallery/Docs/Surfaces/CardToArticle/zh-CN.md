## 何时使用

`CardToArticle` 是一个编辑风格的网格，其中的卡片会展开成它们所预告的故事。每张卡片是一幅图片，上面叠加着一个标签、一个标题和一行简短的元信息。按下卡片不会打开新页面或单独的对话框：卡片本身会长成一张居中的文章面板。它的外框和圆角在同一根弹簧上拉伸，图片整体放大成文章的头图（标题随之放大，从不重新排版），正文从下方升起，关闭按钮最后弹出。关闭时沿相同的路径反向进行，并让面板准确落回卡片的位置。

- **杂志、博客与新闻简报**：只展示少量故事，并希望阅读感觉像是浏览的延续，而不是一次页面加载。
- **应用内的指南与专题故事**：读者瞥一眼卡片、阅读，然后回到网格中的同一位置。
- **以触控为先的布局**：文章通过下拉来关闭，就像人们在手机上关闭面板那样。
- **中短篇文本**：署名行、几个段落和一段引文，都能放进文章的单列滚动区域。

## 何时不用

- **包含几十个条目的长列表或信息流**：网格没有分页或虚拟化。请使用列表加常规的详情页。
- **不以图片为主的卡片**：形变依赖于图片以相同的宽高比铺满卡片和头图。对于只需快速查看的文字卡片，请使用带详情的 `Card`。
- **需要整页的文档**：表格、代码和较长的导航应放在独立的路由中。
- **表单或编辑**：文章用于阅读；输入请放在 `Dialog` 或 `BottomSheet` 中。

```csharp
Stories.Items = CardToArticleSamples.Stories();
```

`CardToArticle` 派生自 Avalonia 的 `TemplatedControl`，位于 Special 包中：请在 `UseArc()` 旁调用 `UseArcSpecial()` 进行注册。

### 通过代码打开与关闭

`OpenItemId` 保存当前打开文章的 id，并支持双向绑定：按下卡片会写入该卡片的 id，关闭会写入 null，设置它则会以同样的形变打开或关闭文章。`Open(id)` 与 `Close()` 可在代码中完成相同的操作。`OpenItemChanged` 会报告每一次变化，附带旧 id、新 id 以及它的 `Reason`（`Click`、`Keyboard`、`CloseButton`、`Escape`、`Drag`、`Wheel` 或 `Programmatic`）。下面的演示通过两个按钮打开和关闭，并记录每个事件。

<Demo name="EventLog" />

在控件首次显示之前就已打开的文章会直接出现，而不会从一张无人见过的卡片中长出来。当某篇文章打开时把 `OpenItemId` 设为另一个 id，会就地换成另一个故事；没有任何条目拥有的 id 则什么也不会打开。

### 结构

- **网格**：控件宽度超过 `ColumnBreakpoint`（默认 520）时为两列，间距 16 px；低于该值时为一列，间距 12 px。每张卡片占一列宽，宽高比为 `AspectRatio`（默认 4:3）。控件最宽 680 px，并自行居中。
- **卡片**：一个以图片为主体的按钮，圆角 26 px。标签胶囊位于左上角；标题和元信息行位于左下角，叠在一层渐变遮罩上，该遮罩会压暗图片底部 60% 的区域。图片内部的所有尺寸都是其宽度的一个比例（标签文字 3.2%，标题 7.4%，元信息 3.4% 且上限为 20 px），因此卡片和头图是同一幅画在两种缩放下的呈现。
- **文章面板**：位于窗口的覆盖层上，最宽 680 px，距两侧 16 px，距窗口顶部和底部 24 px（在宽度不超过 520 px 的窗口中分别为 8 和 12 px）。无论文本多长，它始终填满这一高度。
- **头图**：卡片的图片，宽度与面板相同；它随文本一起滚动消失。
- **文本**：署名行（头像、作者、日期）、段落和引文，两侧内边距为窗口宽度的 6%，范围在 20 到 48 px 之间。
- **阅读进度**：沿顶部边缘的一条 3 px 强调色条，随滚动位置增长。
- **关闭按钮**：一个 36 px 的磨砂圆形按钮，位于右上角内侧 14 px 处；它不随内容滚动。
- **背景遮罩**：页面背景色以 55% 的不透明度覆盖在页面之上，并带有模糊。

### 撰写文章

`CardToArticleItem.Body` 在常见情况下接受纯文本。空行表示新的段落，以 "> " 开头的段落会变成带强调色竖线的引文。请设置 `Author`、`Published`，以及可选的 `Avatar` 来生成署名行；没有头像时，作者的首字母会显示在彩色圆圈上。若 `Body` 本身是一个控件，则按原样显示，其他任何对象则通过 `BodyTemplate` 呈现。

### 下拉关闭

打开的文章会跟随向下的下拉：它向下移动下拉距离的 0.3，并且每像素缩小 1/1500，缩放的中心点位于窗口水平居中、纵向 30% 处，下拉距离最多计到 480 px。在超过 120 px 时松手，或以快于 600 px/s 的速度快速甩动，就会关闭文章；不足这些则弹回。

- **鼠标和触控笔**：拖动图片。在文本上按下则是选择文字。
- **触摸**：文章滚动到顶部后，可在任意位置拖动。从较低位置开始的拖动会先滚动文本，到达顶部时在同一次动作中转为下拉。
- **滚轮和触控板**：在顶部向上滚动时，按滚动距离的 0.6 进行下拉，下拉超过 120 px 时立即关闭；滚动停止 150 ms 后，文章弹回。

### 窄容器

网格跟随控件自身的宽度，而不是窗口的宽度：在 360 px 的列中，每行只显示一张卡片。文章则始终按窗口来确定自身的大小。

### 减弱动效

<Demo name="ReducedMotion" />

在减弱动效下，卡片悬停时不会抬起，文章立即就位，其文本、关闭按钮和背景遮罩只做淡入；关闭时文章立即移除。下拉仍会跟随指针，因为这个动作是读者自己的操作。

### 内容准则

- 标签保持一两个词（"Recipe"、"Field guide"），标题要短到在卡片上只占两行；标题以均衡的方式换行，因此两行的标题看起来是一个整体。
- 元信息行只写一个读者据以决定的事实，例如阅读时长。
- 选择底部 40% 比较平静的图片：标题就叠在那里的渐变遮罩上。
- 为文章的头图编写 `ImageAlt`；卡片本身由其标题和元信息行命名。
- 正文保持在几个段落以内，引文最多一两处。

### 最佳实践

- 为每个条目提供唯一且稳定的 `Id`：`OpenItemId` 保存的就是它，路由或深层链接也可以据此恢复。
- 当页面打开期间有故事到来或离开时，请为 `Items` 使用可观察列表（`AvaloniaList` 或 `ObservableCollection`）；移除正在打开的故事会关闭其文章。
- 让控件自己决定宽度，最宽 680 px；更宽的页面可以并排显示多个实例。
- 文章打开期间，请保持其下方的页面静止：模糊的背景遮罩取自页面当时的样子。

### 常见问题

**文章可以比 680 px 更宽吗？** 不可以；文本的行宽是设计的一部分。请把控件放进更宽的布局中。

**窗口调整大小后形变还有效吗？** 有效。关闭时会在那一刻重新测量卡片的槽位，因此面板会落在卡片现在所处的位置，即使网格已经切换为单列。

**在另一篇文章正在关闭时按下卡片会怎样？** 正在关闭的文章会立即交还它的卡片，新的文章从被按下的卡片长出来。在同一张卡片正在关闭时再次按下它，会以当前的速度让形变掉头。

## 无障碍

- 每张卡片都是一个按钮，由其标题和元信息行命名（`Labels.CardName`）。它会报告其文章是否已展开，其图片不会被单独播报。
- 打开的文章是一个模态对话框，由故事的标题命名（`Labels.ArticleName`）。头图的文字替代是 `ImageAlt`。
- 文章打开时，焦点移到关闭按钮，并在文章打开期间保持在文章之内。关闭时焦点返回到打开它的卡片；如果使用的是键盘，则显示键盘焦点环。
- 关闭按钮默认命名为 "Close article"（`Labels.Close`）。
- 阅读进度条和渐变遮罩只是装饰，不会被播报。
- 键盘焦点环为 2 px，仅在键盘焦点时显示。

### 键盘

| 按键 | 位置 | 操作 |
|---|---|---|
| `Tab` / `Shift+Tab` | 网格 | 在卡片之间移动。 |
| `Enter` / `Space` | 卡片 | 打开其文章。 |
| `Tab` / `Shift+Tab` | 文章 | 停留在关闭按钮上。 |
| `Up` / `Down` | 文章 | 将文本滚动 40 px。 |
| `PageUp` / `PageDown` | 文章 | 将文本滚动接近一屏。 |
| `Home` / `End` | 文章 | 滚动到顶部或末尾。 |
| `Enter` / `Space` | 关闭按钮 | 关闭文章。 |
| `Escape` | 文章 | 关闭文章。 |

## 动效

| 时刻 | 什么在动 | 方式 |
|---|---|---|
| 悬停卡片 | 卡片放大到 1.012，阴影抬高 | 240 ms，标准曲线 |
| 按下卡片 | 卡片收缩到 0.985 | 240 ms，标准曲线 |
| 打开 | 面板和图片从卡片长出 | 临界阻尼弹簧，0.52 s |
| 打开 | 背景遮罩淡入 | 350 ms，进入曲线 |
| 打开 | 文本上升 16 px 并淡入 | 360 ms，标准曲线，延迟 135 ms |
| 打开 | 关闭按钮从 0.8 放大并淡入 | 临界阻尼弹簧，0.30 s，延迟 175 ms |
| 下拉 | 文章下移并缩小 | 精确跟随指针 |
| 短距离下拉后松手 | 文章弹回 | 临界阻尼弹簧，0.38 s |
| 关闭 | 面板和图片飞回卡片上 | 临界阻尼弹簧，0.44 s |
| 关闭 | 文本和关闭按钮淡出 | 120 ms |
| 关闭 | 背景遮罩淡出 | 290 ms，进入曲线 |

在打开过程中关闭，会以当前速度让同一根弹簧掉头，因此面板会再多走一小段才回到原位。面板拉伸时，圆角保持圆润，文本和关闭按钮保持原有大小：只有面板的边缘会裁剪它们。

## 响应式

- 故事网格按控件自身宽度变化：大于 `ColumnBreakpoint`（520 px）时为两列，不超过 520 px 时为一列，最宽 680 px。
- 打开的文章按视口（最近的视口宿主，否则为窗口）变化：居中的面板最宽 680 px；视口不超过 520 px 时铺满整个屏幕，左右边距也变小。
- 长文章在面板内滚动；滚动条浮在正文上方，停止滚动后隐藏。
- 触控时，从文章顶部向下拉即可把它送回卡片；关闭按钮和 Escape 也能做到，没有功能依赖手势。

- `Dialog`：用于决策和表单的模态对话框。
