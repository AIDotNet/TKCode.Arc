## 何時使用

`CardToArticle` 是一個編輯風格的網格，其中的卡片會展開成它們所預告的故事。每張卡片是一張圖片，上面疊著標籤、標題與一行簡短的資訊列。按下卡片不會開啟新頁面或獨立的對話方塊：卡片本身會長成置中的文章面板。它的外框與圓角以同一個彈簧伸展，圖片整體縮放成文章的主圖（標題隨之放大，且不會重新換行），文字從下方升起，關閉按鈕最後才彈出。關閉時則反向走同一條路徑，讓面板精準落在卡片的位置上。

- **雜誌、部落格與電子報**：只呈現少數幾則故事，並希望閱讀感覺像是瀏覽的延續，而不是載入新頁面。
- **應用程式中的指南與專題故事**：讀者瞄一眼卡片、閱讀，然後回到網格中的同一個位置。
- **以觸控為主的版面**：以下拉來關閉文章，就像在手機上關閉面板一樣。
- **短到中等長度的文字**：署名列、幾段文字與一則引文，剛好放得進文章的單欄捲動區。

## 何時不用

- **有數十筆項目的長清單或動態消息**：網格沒有分頁或虛擬化。請使用清單搭配一般的詳細頁面。
- **不是圖片的卡片**：形變仰賴圖片以相同的長寬比填滿卡片與主圖。若是文字卡片並要快速查看，請使用 `Card` 搭配其詳細內容。
- **需要完整頁面的文件**：表格、程式碼與較長的導覽應放在獨立的路由。
- **表單或編輯**：文章是用來閱讀的；輸入請放在 `Dialog` 或 `BottomSheet` 中。

## 用法

預覽顯示四則來自 `CardToArticleSamples.Stories()` 的虛構故事。設定 `Items`，其餘交給控制項處理：網格、形變、文章、焦點、Escape 與下拉手勢。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:CardToArticle x:Name="Stories" />
</UserControl>
```

```csharp
Stories.Items = CardToArticleSamples.Stories();
```

`CardToArticle` 衍生自 Avalonia 的 `TemplatedControl`，位於 Special 套件中：請在 `UseArc()` 旁呼叫 `UseArcSpecial()` 來註冊。

### 從程式碼開啟與關閉

`OpenItemId` 保存目前開啟之文章的 id，並且是雙向繫結：按下卡片會寫入該卡片的 id，關閉則寫入 null，設定它會以相同的形變開啟或關閉。`Open(id)` 與 `Close()` 可從程式碼執行相同的操作。`OpenItemChanged` 會回報每一次變更，包含舊 id、新 id 與其 `Reason`（`Click`、`Keyboard`、`CloseButton`、`Escape`、`Drag`、`Wheel` 或 `Programmatic`）。下面的示範以兩個按鈕開啟與關閉，並記錄每個事件。

<Demo name="EventLog" />

在控制項第一次顯示之前就已開啟的文章會直接出現，不會從沒人看過的卡片長出來。在文章已開啟時把 `OpenItemId` 設為另一個 id，會原地換成那則故事；沒有任何項目擁有的 id 則不會開啟任何東西。

### 結構

- **網格**：控制項寬於 `ColumnBreakpoint`（預設 520）時為兩欄，間距 16 px；低於時為一欄，間距 12 px。每張卡片占一欄寬，長寬比為 `AspectRatio`（預設 4:3）。控制項最寬 680 px，並自行置中。
- **卡片**：整張圖片就是一個按鈕，圓角 26 px。標籤膠囊位於左上角；標題與資訊列位於左下角，下方有一層漸層遮罩，把圖片底部 60% 壓暗。圖片內的每個尺寸都是其寬度的一個比例（標籤文字 3.2%、標題 7.4%、資訊列 3.4% 且上限 20 px），因此卡片與主圖其實是同一幅畫面的兩種縮放。
- **文章面板**：位於視窗的覆蓋層上，最寬 680 px，距左右兩側 16 px，距視窗上下各 24 px（寬度不超過 520 px 的視窗則為 8 與 12 px）。無論文字多長，它一律填滿這個高度。
- **主圖**：卡片的圖片，寬度與面板相同；它會隨文字一起捲走。
- **文字**：署名列（頭像、作者、日期）、段落與引文，左右內距為視窗寬度的 6%，限制在 20 到 48 px 之間。
- **閱讀進度**：沿上緣的 3 px 強調色橫條，隨捲動位置增長。
- **關閉按鈕**：36 px 的霧面圓形，位於右上角內縮 14 px 處；它不會隨內容捲動。
- **背景遮罩**：以 55% 的頁面背景色疊在頁面上，並加以模糊。

### 撰寫文章

`CardToArticleItem.Body` 在一般情況下接受純文字。空白行會開始新的段落，以 "> " 開頭的段落會變成帶有強調色線條的引文。請設定 `Author`、`Published`，以及可選的 `Avatar` 作為署名列；沒有頭像時，作者的姓名縮寫會顯示在有顏色的圓形上。若 `Body` 是控制項，就原樣顯示，其他任何物件則透過 `BodyTemplate` 呈現。

### 下拉關閉

開啟的文章會跟隨向下的下拉：它向下移動下拉距離的 0.3，並且每下拉一個像素就縮小 1/1500，以視窗橫向正中、由上往下 30% 處為中心，下拉最多計算到 480 px。放開時若超過 120 px，或快速甩動的速度超過 600 px/s，就會關閉；較短的下拉則會彈回。

- **滑鼠與手寫筆**：拖曳圖片。在文字上按下則是選取文字。
- **觸控**：文章捲動到頂端後，可在任何位置拖曳。從較下方開始的拖曳會先捲動文字，並在到達頂端時於同一個動作中轉為下拉。
- **滾輪與觸控板**：在頂端向上捲動時，下拉量為捲動距離的 0.6，下拉超過 120 px 就立即關閉；捲動停止 150 ms 後，文章會彈回。

### 窄容器

網格依循控制項自己的寬度，而不是視窗的寬度：在 360 px 寬的欄中，每列只顯示一張卡片。文章則一律依視窗調整大小。

在減少動態效果下，卡片在滑鼠移上時不會抬起，文章立即就位，它的文字、關閉按鈕與背景遮罩只做淡入；關閉時則立即移除。下拉仍會跟隨指標，因為這個動作是讀者自己的操作。

### 內容指引

- 標籤保持一到兩個字（"Recipe"、"Field guide"），標題短到在卡片上最多兩行；標題會以平衡的行數換行，所以兩行的標題看起來像一個整體。
- 資訊列只放讀者據以做決定的一項事實，例如閱讀時間。
- 選擇底部 40% 較為平靜的圖片：標題就位於那裡的漸層遮罩上。
- 請為文章的主圖撰寫 `ImageAlt`；卡片本身則由其標題與資訊列來命名。
- 內文保持在幾個段落，引文最多一到兩則。

### 最佳做法

- 為每個項目提供唯一且穩定的 `Id`：它是 `OpenItemId` 所儲存的值，也是路由或深層連結可以還原的依據。
- 當頁面開啟期間會有故事加入或移除時，請為 `Items` 使用可觀察的清單（`AvaloniaList` 或 `ObservableCollection`）；移除目前開啟的故事會關閉它的文章。
- 讓控制項自行決定寬度，最寬 680 px；較寬的頁面可以並排顯示多個執行個體。
- 文章開啟時，讓其下方的頁面保持不變：模糊的背景遮罩取自頁面當時的樣子。

### 常見問題

**文章可以比 680 px 更寬嗎？** 不行；文字的行寬是設計的一部分。請改把控制項放在較寬的版面中。

**視窗調整大小後，形變還能運作嗎？** 可以。關閉時會在那一刻重新量測卡片的位置，因此即使網格已切換成一欄，面板仍會落在卡片現在所在之處。

**在另一篇文章關閉時按下卡片會怎樣？** 正在關閉的文章會立即把它的卡片交還，新的文章則從被按下的卡片長出來。在同一張卡片關閉期間再次按下它，會以目前的速度把形變反轉。

## 無障礙

- 每張卡片都是一個按鈕，由其標題與資訊列命名（`Labels.CardName`）。它會回報其文章是否已展開，圖片不會被另外朗讀。
- 開啟的文章是一個強制回應對話方塊，由故事的標題命名（`Labels.ArticleName`）。主圖的替代文字是 `ImageAlt`。
- 文章開啟時，焦點會移到關閉按鈕，並在文章開啟期間停留在文章內。關閉時焦點會回到開啟它的卡片；若使用的是鍵盤，則會顯示鍵盤焦點環。
- 關閉按鈕預設命名為 "Close article"（`Labels.Close`）。
- 閱讀進度橫條與漸層遮罩屬於裝飾，不會被朗讀。
- 鍵盤焦點環為 2 px，且只在鍵盤焦點時顯示。

### 鍵盤

| 按鍵 | 位置 | 操作 |
|---|---|---|
| `Tab` / `Shift+Tab` | 網格 | 在卡片之間移動。 |
| `Enter` / `Space` | 卡片 | 開啟其文章。 |
| `Tab` / `Shift+Tab` | 文章 | 停留在關閉按鈕上。 |
| `Up` / `Down` | 文章 | 將文字捲動 40 px。 |
| `PageUp` / `PageDown` | 文章 | 將文字捲動接近一個螢幕的高度。 |
| `Home` / `End` | 文章 | 捲動到頂端或結尾。 |
| `Enter` / `Space` | 關閉按鈕 | 關閉文章。 |
| `Escape` | 文章 | 關閉文章。 |

## 動態效果

| 時機 | 什麼在動 | 方式 |
|---|---|---|
| 滑鼠移到卡片上 | 卡片放大到 1.012，陰影抬高 | 240 ms，標準曲線 |
| 按下卡片 | 卡片縮到 0.985 | 240 ms，標準曲線 |
| 開啟 | 面板與圖片從卡片長出 | 臨界阻尼彈簧，0.52 s |
| 開啟 | 背景遮罩淡入 | 350 ms，進入曲線 |
| 開啟 | 文字上升 16 px 並淡入 | 360 ms，標準曲線，延遲 135 ms |
| 開啟 | 關閉按鈕從 0.8 放大並淡入 | 臨界阻尼彈簧，0.30 s，延遲 175 ms |
| 下拉 | 文章向下移動並縮小 | 完全跟隨指標 |
| 放開較短的下拉 | 文章彈回 | 臨界阻尼彈簧，0.38 s |
| 關閉 | 面板與圖片飛回卡片上 | 臨界阻尼彈簧，0.44 s |
| 關閉 | 文字與關閉按鈕淡出 | 120 ms |
| 關閉 | 背景遮罩淡出 | 290 ms，進入曲線 |

在開啟途中關閉，會以目前的速度把同一個彈簧反轉，因此面板在返回之前還會再往前移動一點。面板伸展時，圓角保持圓弧，文字與關閉按鈕維持原本的大小：只有面板的邊緣會裁切它們。

## 響應式

- 故事網格依控制項自身寬度變化：大於 `ColumnBreakpoint`（520 px）時為兩欄，不超過 520 px 時為一欄，最寬 680 px。
- 開啟的文章依視口（最近的視口宿主，否則為視窗）變化：置中的面板最寬 680 px；視口不超過 520 px 時鋪滿整個螢幕，左右邊距也變小。
- 長文章在面板內捲動；捲軸浮在內文上方，停止捲動後隱藏。
- 觸控時，從文章頂部向下拉即可把它送回卡片；關閉按鈕和 Escape 也能做到，沒有功能依賴手勢。

## 相關元件

- `Card`：內容卡片，其詳細內容會在從它長出的快速查看中開啟。
- `BottomSheet`：從底部滑上來、向下拖曳即可關閉的面板。
- `Dialog`：用於決定與表單的強制回應對話方塊。
