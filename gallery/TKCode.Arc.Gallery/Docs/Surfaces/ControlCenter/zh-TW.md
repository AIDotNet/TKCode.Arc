## 何時使用

`ControlCenter` 是一個精簡的面板，收納工作區中日常使用的開關：一個寬的專注磚塊、通知與簡報磚塊，以及兩條分別用於提醒音量與文字大小的分段條。每個磚塊按一下即可切換，並說明它此刻的意義（"Until 12:13 PM"、"2 of 3 channels"、"Off"）。帶有箭頭按鈕的磚塊會展開成填滿面板的詳細面板，較細的設定都在其中，完成後再縮回原位。它的大小為 360 × 396 像素，適合放在彈出框、側邊面板或設定頁面的角落。

- **快速設定彈出框**，放在狀態列或頭像按鈕後方：人們一天會多次使用的少數幾個開關，每一個都只需按一下。
- **專注時段**：選擇一個模式，在轉盤上設定時長（轉一圈為兩小時，以 5 分鐘為一級），然後開始。之後磚塊會顯示該模式以及時段結束的時間。
- **兩個層級的通知控制**：磚塊可一次暫停所有通知；詳細面板則為每個頻道提供一個開關，並顯示哪些人的訊息一律放行。
- **應該有實體手感的音量或大小**：分段條會一比一跟隨拖曳，按一下即跳到該位置，按住時會膨脹，並在兩端稍微伸展，而不是突然停住。

## 何時不用

- **完整的設定頁面**：多個群組、搜尋與說明需要由 `Switch`、`Slider` 與表單列組成的頁面，而不是固定大小的面板。
- **單一的開／關選項**：請在說明該選項的位置使用 `Switch`。
- **精確的數值輸入**：需要輸入或讀到小數位的值，需要附欄位的 `Slider` 或數字輸入框。
- **超過兩個向下展開的區域或更深的瀏覽層級**：面板只有兩個詳細面板與一個層級；需要堆疊的面板時，請使用底部面板或頁面導覽。
- **排程**：這裡的時段都是立即開始，最長執行兩小時。更晚開始或更長的安排，適合使用行事曆或時間選擇器。

## 用法

為面板提供專注模式、頻道以及（可選的）人員。按一下專注磚塊時，會以第一個模式及其預設時長開始。

```xml
<arc:ControlCenter Volume="{Binding AlertVolume}"
                   TextSize="{Binding TextSize}"
                   AreNotificationsOn="{Binding NotificationsOn}"
                   IsPresenting="{Binding Presenting}"
                   FocusSession="{Binding Session}" />
```

```csharp
center.FocusModes.Add(new ControlCenterFocusMode
{
    Id = "drafting", Label = "Drafting", Icon = ControlCenterSamples.HeadphonesIcon,
    Description = "Long stretches for writing and sketching", DefaultMinutes = 50
});
center.Channels.Add(new ControlCenterChannel { Id = "comments", Label = "Comments", IsOn = true });
center.People.Add(new ControlCenterPerson { Id = "mara", Name = "Mara Lind" });
```

`ControlCenter` 衍生自 Avalonia 的 `TemplatedControl`。它位於 Special 套件中：請在 `UseArc()` 旁呼叫 `UseArcSpecial()` 來註冊。`ControlCenterSamples.Apply(center)` 會以預覽中的虛構內容填滿面板。

使用者能變更的每個值都是雙向屬性，而 `StateChanged` 會在每次變更後回報完整狀態與變更原因。拖曳分段條時，每經過一個完整級距才回報一次，而不是每移動一個像素就回報。文字大小只會縮放面板中的 "Aa" 範例：請自行將它套用到你的應用程式。

### 結構

1. **面板**：寬 360（若容器較窄則為容器寬度），高度固定為 396；凸起的表面、1px 邊框、圓角 30、浮動陰影、10px 內距。
2. **專注磚塊**：全寬，高 84。包含圖示圓、標題與狀態列；右側的箭頭按鈕會開啟專注詳細面板。
3. **通知與簡報磚塊**：半寬，高 104，圖示在上、文字在下。通知磚塊的角落有一個箭頭按鈕。
4. **分段條**：一列標籤（圖示、標籤、值，文字大小還有 "Aa" 範例），下方是一條 30px、由 28 段組成的軌道。
5. **詳細面板**：從面板邊框內縮 8，圓角 22，位於一層 55% 凸起表面的遮罩之上。其標頭包含圖示、標題與關閉按鈕。

「開啟」狀態的磚塊會在表面中混入 9% 的強調色，並以強調色填滿其圖示圓。磚塊在滑鼠懸停時沒有變化；只有箭頭按鈕與關閉按鈕會回應指標。

### 專注詳細面板

- **模式切換**：每個模式一段，並有一個凸起的膠囊滑向所選的模式。選擇模式會把轉盤設為該模式的預設時長，並滾入其說明。
- **轉盤**：轉一整圈為 120 分鐘。在任何位置抓住並轉動：它依你轉動的角度移動，而不是跳到你按下的位置，因此按一下不會改變任何東西。它跨過 12 點鐘位置時會繼續計算，在超過 5 與 120 分鐘時產生阻力（弧線與數字會停在極限值），放開時會對齊到最接近的 5 分鐘。數字下方會顯示若現在開始時段將於何時結束。
- **按鈕**：沒有時段時為「開始時段」；有時段時為「結束時段」與「更新時段」。

詳細面板編輯的是一份草稿。開始與更新會套用草稿（時段會在現在加上其分鐘數時結束）；關閉、Escape 或按下遮罩則會捨棄草稿，再次開啟時會顯示執行中時段的模式與時長。時段不會自行結束：時間到時，若有需要，請從你的程式碼以 `EndFocus()` 結束時段。

### 通知詳細面板

頂端的主開關與磚塊是同一個設定。主開關關閉時，頻道開關會變淡但仍可操作，磚塊也仍會記住每個頻道。頻道列來自 `Channels`；清單過長時會在詳細面板內捲動。設定 `People` 後，詳細面板底部會顯示他們的頭像（圖片，或在產生的漸層上顯示姓名縮寫），以及一句列出他們名字的句子。

### 你自己的標籤與內容

面板顯示的所有文字都來自 `ControlCenterLabels`：磚塊標題、狀態、按鈕文字、無障礙名稱、時間格式以及含有數字的句子（委派）。這個示範完全以 XAML 撰寫，包含一個專注模式、五個頻道，沒有人員。

### 窄容器

面板會採用較窄容器的寬度。當容器寬度為 312 以下，或視窗寬度為 360 以下時，它會縮小間距（6px 的內距與間隔、較小的磚塊內距），並使用 150px 的轉盤。在寬度 455 以下的視窗中，它還會移除邊框、圓角、陰影與填色，讓自己貼齊頁面，而開啟的詳細面板則保留自己的表面。

### 內容指引

- 模式名稱保持一到兩個字（"Drafting"、"Reviewing"）；它們共用模式切換的寬度。
- 模式說明寫成一句簡短的句子，說明仍有哪些內容能傳達進來。過長的文字會在面板寬度處被截斷。
- 以頻道傳遞的內容為其命名（"Comments"、"Shared folders"），並用第二行說明何時傳遞。
- 簡報的狀態列應以兩三個字說明簡報會做什麼。
- 傳入人員的全名；句子會使用名字，頭像則使用姓名縮寫。

### 最佳做法

- 保存來自 `StateChanged`（或繫結屬性）的狀態，並透過設定相同的屬性來還原它。
- 為轉盤的模式設定合理的預設值：最常用的時長應該只需按一下。
- 使用 `TimeProvider` 為面板提供你的應用程式時鐘（也可用來測試時段結束時間）。
- 使用 `Labels.FormatTime` 為你的使用者格式化時間；預設為美式簡短時間格式（"12:13 PM"）。
- 從程式碼以 `OpenDetail` 開啟詳細面板（例如來自深層連結），而不是模擬點擊。

### 常見問題

**為什麼時段不會自行結束？** 面板會顯示時段何時結束，但不會據此採取動作，因此主機可以依自己的需要延長、通知或結束時段。請呼叫 `EndFocus()` 或將 `FocusSession` 設為 null。

**可以新增第三個詳細面板或更多磚塊嗎？** 不行：版面是固定的。請使用多個面板，或以 `Switch` 與元件庫中的其他控制項自行建立。

**為什麼按一下轉盤會被忽略？** 轉盤依你轉動的角度移動，因此不小心的點按永遠不會改變時長。相較之下，分段條會在你放開時跳到點按的位置。

## 無障礙

- 面板是一個以 `Labels.PanelName` 命名的群組。每個磚塊都是切換按鈕，其名稱會朗讀標題與狀態（"Notifications, 2 of 3 channels"）；箭頭按鈕分別命名為 "Focus session settings" 與 "Notification channels"。
- 開啟的詳細面板以其標題命名。它後方的磚塊與分段條會離開 Tab 順序、點擊測試與自動化樹，焦點會留在詳細面板內直到它關閉。
- 模式切換是一個名為 "Mode" 的選項按鈕群組。轉盤是一個名為 "Session length"、範圍 5 到 120 的滑桿，其說明文字會朗讀分鐘數與結束時間（"50 minutes, until 12:13 PM"）。分段條是以其標籤命名的滑桿，值的格式如 "64%"。
- 開關以其所在列的標籤命名。頭像僅供裝飾：名字都寫在旁邊的句子中。
- 鍵盤焦點會在磚塊、按鈕、區段、轉盤或軌道外側 2px 處顯示 2px 的焦點環；滑鼠焦點則不顯示。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 專注磚塊、其箭頭按鈕、通知磚塊、其箭頭按鈕、簡報磚塊、音量、文字大小。在詳細面板內：關閉、所選模式、轉盤、按鈕，然後回到關閉 |
| `Enter` / `Space` 於磚塊 | 切換它（專注磚塊會開始第一個模式或結束時段） |
| `Enter` / `Space` 於箭頭按鈕 | 開啟其詳細面板；焦點移到關閉 |
| `←` `→` `↑` `↓` / `Home` / `End` 於模式切換 | 選擇上一個、下一個、第一個或最後一個模式 |
| `←` `↓` / `→` `↑` 於轉盤 | 縮短或延長 5 分鐘 |
| `Page Down` / `Page Up` 於轉盤 | 縮短或延長 15 分鐘 |
| `Home` / `End` 於轉盤 | 5 或 120 分鐘 |
| `←` `↓` / `→` `↑` 於分段條 | 一級（音量 1%、文字大小 5%） |
| `Page Down` / `Page Up` 於分段條 | 四級 |
| `Home` / `End` 於分段條 | 最小值或最大值 |
| `Escape` | 關閉詳細面板；焦點回到其箭頭按鈕 |

每個磚塊是一個 Tab 停駐點，模式切換則是單一 Tab 停駐點並以方向鍵操作，符合選項按鈕群組應有的行為。

## 動態效果

- 開啟詳細面板時，磚塊的方框會以無回彈的彈簧效果長成詳細面板的方框（約 0.75 s 穩定）。圓角全程保持 22，內容則以最終大小配置，因此長大的方框是逐步顯露內容，而不是拉伸內容；圖示與標題會從磚塊滑入標頭。遮罩在 230ms 內淡入，內容在 60ms 後以 240ms 淡入。
- 關閉時以相同的彈簧反向執行。內容在 110ms 內淡出；磚塊在前半段淡回，詳細面板則在一半到 95% 之間淡出。
- 按下磚塊時，它會以相同的彈簧縮小到 0.975。磚塊顏色在 240ms 內變化。
- 模式膠囊以相同的彈簧滑動；轉盤切換到新模式、按鍵或對齊時會快速彈動，從超出兩端的位置彈回時則較慢。分段條的值在點按或按鍵時以彈簧效果移動，數字隨之計數；按住時軌道會膨脹到其高度的 1.18 倍，伸展後再彈回。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 詳細面板開啟與關閉 | 形變、交叉淡化、遮罩與內容淡入淡出 | 原地出現；遮罩與內容淡入淡出 | 立即 |
| 圖示與狀態交換 | 模糊、位移（圖示另有縮放） | 淡入淡出與模糊，無位移 | 立即 |
| 轉盤與分段條的值 | 彈簧效果，數字計數 | 直接跳到 | 直接跳到 |
| 分段條膨脹 | 按住時 1.18 | 無 | 無 |
| 磚塊按下 | 縮放到 0.975 | 無 | 無 |

## 響應式

- 面板與所在位置同寬，最寬 360 px，高度固定 396 px；磁貼在這個寬度內重新排列。
- 視口（最近的視口宿主，否則為視窗）不超過 360 px，或面板本身不超過 312 px 時，間距收緊，專注轉盤縮小到 150 px。
- 視口不超過 455 px 時，面板去掉邊框、圓角、陰影和底色，平鋪在手機螢幕上；開啟的詳情保留自己的底面，確保可讀。
- 觸控時，磁貼、轉盤和音量條都支援輕觸與拖曳；每個數值也能用鍵盤修改（音量條和轉盤上用方向鍵），沒有功能依賴懸停。

## 相關元件

- `Switch`：附標籤的單一開／關選項。
- `Slider`：附刻度或欄位的精確值。
- `SegmentedControl`：在頁面中從少數幾個選項中挑選一個。
- `Popover`：從按鈕顯示此面板。

| 元件 | 適用時機 |
|---|---|
| `ControlCenter` | 幾個日常設定應該只需按一下，並可按需深入 |
| `Switch` | 單一選項，在原位說明 |
| `Slider` | 精確的數值 |
| `SegmentedControl` | 在頁面或工具列中從少數幾個選項中選擇一個 |
