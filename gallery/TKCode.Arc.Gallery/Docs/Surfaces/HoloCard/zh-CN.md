## 何时使用

`HoloCard` 让一张卡片成为页面上的主角：会员卡、大会胸卡、成就徽章，或一张等待揭晓的礼品卡。指针移到卡上时，它以透视朝指针倾斜，指针下方的那一角向后沉；彩虹箔、细碎的闪粉与柔和的高光随光点在卡面上流动，一块漂浮的阴影则朝相反方向偏移。有背面时，点按一下卡片就翻转半圈，于是这张卡有两面可读。

- **俱乐部通行证或积分等级**，在用户加入或升级的那一刻交到他手上。
- **活动胸卡或门票**，正面是持有人，背面是会场与时间。
- **成就或奖励**，值得一点惊喜的时刻，比如获得一枚徽章或升到新的等级。
- **礼品卡揭晓**：正面邀请用户翻面，背面显示面额或兑换码。

## 何时不用

- **列表或网格中的多张卡片**：每张卡在移动的每一帧都要混合三层光效。同屏保持一到两张；一组内容请用 `Card`。
- **卡片上需要放控件**：卡面是投影之下的图像，不接收输入。按钮和链接放在卡片旁边，不要放在卡上。
- **一叠可以翻看的支付卡**：使用 `WalletStack`。
- **只需悬停时轻轻抬起的普通内容**：使用 `Card`；倾斜与光效是装饰，会吸引注意力。

## 用法

给卡片设置 `Front`，需要翻面时再设置 `Back`。两者都接受任意内容，内容铺满整张卡并按圆角裁剪。卡片始终是 5:7。不设宽度时，它与所在位置一样宽，最多 300，所以窄容器里卡片会变小；设置 `Width` 可固定宽度。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:HoloCard Width="290" Label="Mira Okafor, Lumen Society patron pass">
        <arc:HoloCard.Front>
            <Grid Background="#0D0D0D"><!-- art, name, stats --></Grid>
        </arc:HoloCard.Front>
        <arc:HoloCard.Back>
            <Grid Background="#0D0D0D"><!-- mark, title, note --></Grid>
        </arc:HoloCard.Back>
    </arc:HoloCard>
</UserControl>
```

`HoloCard` 派生自 Avalonia 的 `TemplatedControl`。它位于 Special 包中：在 `UseArc()` 旁边用 `UseArcSpecial()` 注册。

### 结构

1. **漂浮阴影**：从卡片向内收进的一块柔和深色区域，与倾斜方向相反地偏移；它不随卡片翻转，所以卡片转动时两侧边缘之间会露出页面。
2. **卡片**：正面与背面，每一面先是内容，然后是混合进内容的三层光效：
   - **箔层**，粉、桃、薄荷、天蓝、淡紫交替的斜向彩虹带，提亮下方内容（颜色减淡），跟随光点移动，并随光点位置改变色相；
   - **闪粉**，光点周围细碎的白色亮点，与指针反向漂移（仅正面）；
   - **高光**，光点处柔和的白色亮斑，到远处角落渐变为轻微的阴影。
3. **边缘光**：卡片边缘内侧一条 1px、14% 白色的细线。
4. **焦点环**：2px，位于卡片外 2px，随卡片一起倾斜；只在键盘焦点时显示。

### 翻面

点按或轻点卡片右半边，卡片再向右转半圈；点在左半边，则向左转回。Enter 与 Space 向右转。转动会累计：右、右、左依次为 0°、180°、360°、180°。转动途中再按一次会改写同一个弹簧的目标，卡片带着已有的速度继续，而不是重新起步。

`IsFlipped` 表示哪一面朝向观众，且为双向绑定：把它绑定到你自己的状态来记住朝向，或在代码中设置它来翻转卡片。`FlippedChanged` 报告每一次由点按、轻点、键盘或 `Flip` 引起的翻面，并附带引起它的一侧；你自己设置 `IsFlipped` 不会触发它。

<Demo name="Controlled" />

```csharp
card.FlippedChanged += (_, e) => log.Add($"{(e.IsFlipped ? "Back" : "Front")} ({e.Side})");
card.Flip();                         // to the right
card.Flip(HoloCardFlipSide.Left);    // back to the left
```

### 只倾斜的徽章

没有 `Back` 时，卡片是一幅会倾斜的图像：不翻面、不可聚焦，也不是按钮。`MaxTilt` 设置最大倾斜角度（默认 14，设为 0 则关闭倾斜），`Intensity` 在 0 到 1 之间统一缩放箔层、闪粉与高光。浅色卡纸上光效显得更强，强度减半看起来更平衡。

### 减少动效

当应用或系统要求减少动效时，卡片保持平整、静止：不倾斜、不抬起、光点不移动，也没有闪粉。翻面改为两面在 240ms 内交叉淡入淡出，而不是旋转。动效关闭时两面立即切换。

### 手势

| 输入 | 效果 |
|---|---|
| 鼠标或触控笔在卡片上 | 朝指针倾斜（最多 `MaxTilt`），放大到 1.035，光效全开 |
| 鼠标或触控笔离开 | 倾斜、抬起与光效一起回到静止 |
| 点按 | 翻面：右半边向右，左半边向左转回 |
| 手指按下并拖动 | 在手指下方倾斜，不抬起 |
| 轻点（移动不超过 10px） | 按落点所在的半边翻面 |

### 内容准则

- 每一面都按 5:7 的整张卡来设计：内容铺满卡片，并按 22px 圆角裁剪。
- 每一面都给出自己的不透明背景。光效会提亮下方内容，所以深色或饱和的卡纸最能显出箔层；浅色卡纸上把 `Intensity` 降到 0.5 左右。
- 文字要大而短：卡面是投影出来的，一个名字、一个职位和两个数字在倾斜时依然清晰。
- 使用你自己的标识和生成的图像；这里的示例用的是虚构的观星社、虚构的观测者和绘制的日落。
- 把 `Label` 设为一句说明卡片的话，例如 "Mira Okafor, Lumen Society patron pass"。不设置时，卡片读出朝向观众那一面的文字。

### 最佳实践

- 同时只显示一张卡片，最多两张。每张移动中的卡片都会重新烘焙光效层并把它们混合进内容。
- 在卡片周围给倾斜、抬起和阴影留出空间：下方约 40px，两侧约 16px。
- 卡片的操作（加入钱包、分享）放在卡片外、靠近卡片的位置。
- 让背面和正面一样有用：胸卡背面写会场与时间，礼品卡背面写兑换码。

### 常见问题

**手机上卡片能跟随设备倾斜吗？** 暂时不能：Avalonia 没有提供设备姿态，所以在触屏上，卡片在手指按下时随手指倾斜。

**为什么卡片里按钮的点击不起作用？** 卡面在投影之下绘制，不接收输入。请把控件放在卡片外。

**可以一开始就显示背面吗？** 可以：设置 `IsFlipped="True"`。卡片从第一帧起就显示背面，不会旋转。

**被隐藏的一面有开销吗？** 转到背后的那一面是隐藏的，既不绘制，也不会被朗读。

## 无障碍

- 有背面时，卡片是一个切换按钮，角色描述为 "flip card"（`RoleDescription`）；它的按下状态跟随 `IsFlipped`，在按下时立即改变，而不是等旋转结束。
- 它的名称是 `Label`，或朝向观众那一面的文字。转到背后的那一面、阴影与光效层都不在无障碍树中。
- 没有背面时，卡片是一个有名称的组，不可聚焦。
- 键盘焦点显示一个位于卡片外 2px、宽 2px 的环，随卡片倾斜；指针聚焦时不显示。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` / `Shift+Tab` | 移到卡片（仅当它有背面时） |
| `Enter` / `Space` | 把卡片向右翻面 |

## 动效

- 倾斜以一个没有过冲的弹簧跟随指针（约 0.48 s 落定）；光点、抬起与阴影用稍软的弹簧跟随，所以光点会略微落后于倾斜。
- 每倾斜一度，阴影反向移动 0.9px；悬停时阴影从 28% 加深到 40%。
- 翻面是一个约 0.6 s、带一点过冲的弹簧。转到一半时，箔层横扫过卡面，色相最多转过 90°，光效升到最强，随后在另一面转到眼前时回落。

| 变化 | 完整 | 减少 | 关闭 |
|---|---|---|---|
| 指针在卡片上 | 倾斜、抬起、光点移动 | 无 | 无 |
| 翻面 | 旋转半圈 | 两面交叉淡入淡出（240ms） | 两面直接切换 |
| 闪粉 | 显示并漂移 | 隐藏 | 隐藏 |

## 响应式

- `HoloCard` 没有断点：它占用所在位置的宽度，最宽 300 px，并保持卡片比例，所以会随窄栏缩小。放在宽布局中时请设置 `Width`（Gallery 用 290）。
- 触控时，手指按住期间卡片随手指倾斜，抬起后回正；轻点（移动不超过 10 px）会把卡片翻面。设备姿态不会驱动倾斜。
- 翻面也是按钮操作（Enter 或空格，或 `IsFlipped`），不用指针也能看到背面。

## 相关组件

- `Card`：带轻微悬停抬起的内容卡片。
- `WalletStack`：采用真实材质的一叠支付卡。
- `CardStack`：可以滑动翻看的一叠卡片。

| 组件 | 适用场景 |
|---|---|
| `HoloCard` | 一张卡片要像有两面的实物 |
| `Card` | 列表或网格中的内容卡片 |
| `WalletStack` | 浏览并打开多张支付卡 |
