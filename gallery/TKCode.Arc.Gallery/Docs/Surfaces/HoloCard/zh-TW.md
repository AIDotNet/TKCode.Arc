## 何時使用

`HoloCard` 讓一張卡片成為頁面上的主角：會員卡、大會識別證、成就徽章，或一張等著揭曉的禮物卡。指標移到卡上時，它以透視朝指標傾斜，指標下方的那一角往後沉；彩虹箔、細碎的亮粉與柔和的高光隨光點在卡面上流動，一塊浮起的陰影則朝反方向偏移。有背面時，按一下卡片就翻轉半圈，這張卡因此有兩面可讀。

- **俱樂部通行證或集點等級**，在使用者加入或升級的那一刻交到他手上。
- **活動識別證或票券**，正面是持有人，背面是會場與時間。
- **成就或獎勵**，值得一點驚喜的時刻，例如拿到一枚徽章或升上新的等級。
- **禮物卡揭曉**：正面邀請使用者翻面，背面顯示面額或兌換碼。

## 何時不用

- **清單或格線中的多張卡片**：每張卡在移動的每一個影格都要混合三層光效。同一畫面保持一到兩張；一組內容請用 `Card`。
- **卡片上需要放控制項**：卡面是投影之下的影像，不接收輸入。按鈕和連結放在卡片旁邊，不要放在卡上。
- **一疊可以翻看的付款卡**：使用 `WalletStack`。
- **只需要懸停時輕輕浮起的一般內容**：使用 `Card`；傾斜與光效是裝飾，會吸引目光。

## 用法

替卡片設定 `Front`，需要翻面時再設定 `Back`。兩者都接受任意內容，內容會鋪滿整張卡並依圓角裁切。卡片永遠是 5:7。不設定寬度時，它和所在位置一樣寬，最多 300，所以窄容器裡的卡片會變小；設定 `Width` 可以固定寬度。

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:HoloCard Width="290" Label="Mira Okafor, Lumen Society patron pass">
        <arc:HoloCard.Front>
            <Grid Background="#0D0D0D"><!-- art, name, stats --></Grid>
        </arc:HoloCard.Front>
        <arc:HoloCard.Back>
            <Grid Background="#0D0D0D"><!-- mark, title, note --></Grid>
        </arc:HoloCard.Back>
    </arc:HoloCard>
</UserControl>
```

`HoloCard` 衍生自 Avalonia 的 `TemplatedControl`。它位於 Special 套件中：在 `UseArc()` 旁邊用 `UseArcSpecial()` 註冊。

### 結構

1. **浮起的陰影**：從卡片往內縮的一塊柔和深色區域，往傾斜的反方向偏移；它不隨卡片翻轉，所以卡片轉動時兩側邊緣之間會露出頁面。
2. **卡片**：正面與背面，每一面先是內容，接著是混合進內容的三層光效：
   - **箔層**，粉、桃、薄荷、天藍、淡紫交替的斜向彩虹帶，讓下方內容變亮（加亮顏色），跟著光點移動，並隨光點位置改變色相；
   - **亮粉**，光點周圍細碎的白色亮點，和指標反向漂移（僅正面）；
   - **高光**，光點處柔和的白色亮斑，到遠處角落漸變為淡淡的陰影。
3. **邊緣光**：卡片邊緣內側一條 1px、14% 白色的細線。
4. **焦點環**：2px，位於卡片外 2px，隨卡片一起傾斜；只在鍵盤焦點時顯示。

### 翻面

在卡片右半邊按一下或輕觸，卡片再往右轉半圈；按在左半邊，則往左轉回。Enter 與 Space 往右轉。轉動會累計：右、右、左依序為 0°、180°、360°、180°。轉動途中再按一次會改寫同一個彈簧的目標，卡片帶著原有的速度繼續，而不是重新起步。

`IsFlipped` 表示哪一面朝向觀看者，而且是雙向繫結：把它繫結到你自己的狀態來記住朝向，或在程式碼中設定它來翻轉卡片。`FlippedChanged` 會回報每一次由按一下、輕觸、鍵盤或 `Flip` 造成的翻面，並附上造成它的一側；你自己設定 `IsFlipped` 不會觸發它。

<Demo name="Controlled" />

```csharp
card.FlippedChanged += (_, e) => log.Add($"{(e.IsFlipped ? "Back" : "Front")} ({e.Side})");
card.Flip();                         // to the right
card.Flip(HoloCardFlipSide.Left);    // back to the left
```

### 只會傾斜的徽章

沒有 `Back` 時，卡片是一幅會傾斜的影像：不翻面、無法取得焦點，也不是按鈕。`MaxTilt` 設定最大傾斜角度（預設 14，設為 0 則關閉傾斜），`Intensity` 在 0 到 1 之間一併縮放箔層、亮粉與高光。淺色卡紙上的光效看起來更強，強度減半會比較平衡。

### 減少動態效果

當應用程式或系統要求減少動態效果時，卡片維持平整、靜止：不傾斜、不浮起、光點不移動，也沒有亮粉。翻面改成兩面在 240ms 內交叉淡入淡出，而不是旋轉。動態效果關閉時兩面立即切換。

### 手勢

| 輸入 | 效果 |
|---|---|
| 滑鼠或觸控筆在卡片上 | 朝指標傾斜（最多 `MaxTilt`），放大到 1.035，光效全開 |
| 滑鼠或觸控筆離開 | 傾斜、浮起與光效一起回到靜止 |
| 按一下 | 翻面：右半邊往右，左半邊往左轉回 |
| 手指按下並拖曳 | 在手指下方傾斜，不浮起 |
| 輕觸（移動不超過 10px） | 依落點所在的半邊翻面 |

### 內容指引

- 每一面都以 5:7 的整張卡來設計：內容鋪滿卡片，並依 22px 圓角裁切。
- 每一面都要有自己的不透明背景。光效會讓下方內容變亮，所以深色或飽和的卡紙最能顯出箔層；淺色卡紙上把 `Intensity` 降到 0.5 左右。
- 文字要大而短：卡面是投影出來的，一個名字、一個職稱和兩個數字在傾斜時仍然清楚。
- 使用你自己的標誌和產生的影像；這裡的範例用的是虛構的觀星社、虛構的觀測者和繪製的夕陽。
- 把 `Label` 設為一句說明卡片的話，例如 "Mira Okafor, Lumen Society patron pass"。沒有設定時，卡片會讀出朝向觀看者那一面的文字。

### 最佳做法

- 同時只顯示一張卡片，最多兩張。每張移動中的卡片都會重新烘焙光效層，再把它們混合進內容。
- 在卡片周圍替傾斜、浮起和陰影留出空間：下方約 40px，兩側約 16px。
- 卡片的動作（加入錢包、分享）放在卡片外、靠近卡片的位置。
- 讓背面和正面一樣有用：識別證背面寫會場與時間，禮物卡背面寫兌換碼。

### 常見問題

**手機上卡片能跟著裝置傾斜嗎？** 目前還不行：Avalonia 沒有提供裝置的方向資訊，所以在觸控螢幕上，卡片會在手指按下時跟著手指傾斜。

**為什麼卡片裡的按鈕按了沒反應？** 卡面在投影之下繪製，不接收輸入。請把控制項放在卡片外。

**可以一開始就顯示背面嗎？** 可以：設定 `IsFlipped="True"`。卡片從第一個影格起就顯示背面，不會旋轉。

**被隱藏的那一面有成本嗎？** 轉到背後的那一面是隱藏的，既不繪製，也不會被朗讀。

## 無障礙

- 有背面時，卡片是一個切換按鈕，角色描述為 "flip card"（`RoleDescription`）；它的按下狀態跟著 `IsFlipped`，按下時立即改變，而不是等旋轉結束。
- 它的名稱是 `Label`，或朝向觀看者那一面的文字。轉到背後的那一面、陰影與光效層都不在無障礙樹中。
- 沒有背面時，卡片是一個有名稱的群組，無法取得焦點。
- 鍵盤焦點會顯示一個位於卡片外 2px、寬 2px 的環，隨卡片傾斜；以指標取得焦點時不顯示。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| `Tab` / `Shift+Tab` | 移到卡片（僅當它有背面時） |
| `Enter` / `Space` | 把卡片往右翻面 |

## 動態效果

- 傾斜以一個沒有過衝的彈簧跟著指標（約 0.48 s 停穩）；光點、浮起與陰影用稍軟的彈簧跟隨，所以光點會稍微落後於傾斜。
- 每傾斜一度，陰影反向移動 0.9px；懸停時陰影從 28% 加深到 40%。
- 翻面是一個約 0.6 s、帶一點過衝的彈簧。轉到一半時，箔層橫掃過卡面，色相最多轉過 90°，光效升到最強，接著在另一面轉到眼前時回落。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 指標在卡片上 | 傾斜、浮起、光點移動 | 無 | 無 |
| 翻面 | 旋轉半圈 | 兩面交叉淡入淡出（240ms） | 兩面直接切換 |
| 亮粉 | 顯示並漂移 | 隱藏 | 隱藏 |

## 響應式

- `HoloCard` 沒有斷點：它佔用所在位置的寬度，最寬 300 px，並保持卡片比例，所以會隨窄欄縮小。放在寬版面中時請設定 `Width`（Gallery 用 290）。
- 觸控時，手指按住期間卡片隨手指傾斜，抬起後回正；輕點（移動不超過 10 px）會把卡片翻面。裝置姿態不會驅動傾斜。
- 翻面也是按鈕操作（Enter 或空白鍵，或 `IsFlipped`），不用指標也能看到背面。

## 相關元件

- `Card`：帶輕微懸停浮起的內容卡片。
- `WalletStack`：採用真實材質的一疊付款卡。
- `CardStack`：可以滑動翻看的一疊卡片。

| 元件 | 適用情境 |
|---|---|
| `HoloCard` | 一張卡片要像有兩面的實物 |
| `Card` | 清單或格線中的內容卡片 |
| `WalletStack` | 瀏覽並開啟多張付款卡 |
