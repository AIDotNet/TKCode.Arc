## 何時使用

`LinkUnfurl` 是一個訊息欄位，適用於大家分享連結的地方：聊天頻道、留言框、筆記收件匣。貼上的網址，或輸入後接著按下空白鍵的網址，會變成一個行內連結。抓取預覽期間，連結會在柔和的掃光下顯示網址；預覽送達時，網站圖示與頁面標題會滾入連結，連結本身則在訊息下方展開成一張卡片，上面有網站、標題、簡短描述與分享圖片。卡片隨時都能收合回連結，也可以連同連結一起移除。

- **聊天與留言的訊息輸入框**：使用者在傳送前就能看到連結指向什麼，也能拿掉只會增加雜訊的預覽。
- **筆記與收件匣的快速擷取**：貼上的網址會立刻變成易讀的內容。
- **展示你的應用程式如何處理連結的產品頁面**：搭配內建範例與自動播放，訊息輸入框會自行播放整個演示過程。

## 何時不用

- **顯示別人寫的連結**：請使用 `HoverCard`，在滑鼠停留或取得焦點時預覽它；這個控制項是用來撰寫的。
- **代表人員、頻道或紀錄的 token**：請使用 `MentionInput`，它會在你輸入時提供建議。
- **有格式的長篇文件**：請使用 `RichTextEditor`。
- **單一的網址欄位**：附有驗證的一般 `TextField` 會比訊息輸入框更清楚。

## 用法

`LinkUnfurl` 衍生自 Avalonia 的 `TemplatedControl`，位於 Special 套件中：請在 `UseArc()` 旁呼叫 `UseArcSpecial()` 來註冊。未設定任何內容時，它是一個空白的訊息輸入框，會把任何網址展開成一張由網址本身建立的簡單卡片。上方的預覽另外加入了三個虛構的範例、一則起始訊息與自動播放；自動播放會在訊息輸入框第一次進入可視範圍 1.1 秒後貼上第一個範例，除非已經有人使用過它。

```xml
<arc:LinkUnfurl Label="Message #trail-club"
                Placeholder="Message #trail-club"
                Samples="{x:Static arc:LinkUnfurlSamples.Previews}" />
```

### 你自己的解析器與傳送處理常式

在應用程式中，請在你的伺服器上展開連結（Open Graph、oEmbed），並從 `Resolver` 傳回 `LinkUnfurlPreview`。沒有東西可顯示時請傳回 null：連結會留在文字中而不顯示卡片，按一下時會再抓取一次。連結被移除或訊息傳送時，取消權杖會觸發，請務必遵循它。

```csharp
composer.Resolver = FetchPreview;
composer.SendHandler = message => http.PostAsync("/api/messages", new StringContent(message.Text));

async Task<LinkUnfurlPreview?> FetchPreview(string url, CancellationToken cancellationToken)
{
    var response = await http.GetAsync($"/api/unfurl?url={Uri.EscapeDataString(url)}", cancellationToken);
    if (!response.IsSuccessStatusCode)
    {
        return null;
    }
    // Read site, title, description and image from your own response format here.
    return new LinkUnfurlPreview(url, "Site name", "Page title") { Description = "One or two sentences." };
}
```

按下 Enter 或傳送按鈕會引發 `SendRequested`，接著呼叫 `SendHandler`。訊息包含文字（其中每個連結都寫成當初貼上的網址），以及已解析完成的預覽。傳回的工作執行期間，訊息輸入框會保持等待：訊息為唯讀，傳送按鈕顯示旋轉圖示。工作完成時，內容會向上移開，訊息輸入框縮回原本大小，按鈕顯示勾號 1.6 秒；工作失敗時，其訊息會以警示的形式出現在訊息輸入框下方，文字則保留。下方的示範會記錄每一個事件；含有 "missing" 的網址不會得到預覽，含有 "fail" 的訊息則會被拒絕。

### 依需求開啟卡片

### 結構

1. **訊息輸入框**：寬度最多 576px，1px 的外框在焦點位於其中時會變深，圓角半徑 26。
2. **訊息**：Inter 16/26，高度至少兩行。連結在文字中以單一單位呈現。
3. **連結**：高 26px，寬度最多 224px。載入中：一個地球圖示與去掉通訊協定的網址，位於掃光之下。已解析：網站圖示與標題，過長時以省略號截斷。已展開：強調色色調與外環。
4. **卡片欄**：卡片依連結的順序排列，每個連結一張，間距 10px。
5. **卡片**：寬度最多 440px，有一個標頭（網站圖示、網站、一個收合按鈕與一個移除按鈕）、以真正連結呈現的標題、最多兩行的描述，以及採用 Open Graph 比例 1.91 : 1 的圖片。沒有圖片的預覽會得到純文字卡片；沒有網站圖示的預覽則在一個小方塊上顯示網站的首字母。
6. **工具列**：左側為 "Try" 與範例按鈕，右側為圓形的傳送按鈕。

### 狀態

| 部分 | 狀態 | 外觀 |
|---|---|---|
| 連結 | 載入中 | 淡色填滿、細外環、次要文字、呼吸效果的地球圖示，以及每 1.15 s 一次的掃光 |
| 連結 | 已解析、已收合 | 淡色填滿，網站圖示與標題以文字顏色顯示 |
| 連結 | 已展開 | 11%（深色模式為 20%）的強調色，以及 34%（48%）的強調色外環 |
| 連結 | 沒有預覽 | 網址加上靜止的地球圖示；按一下會再抓取一次 |
| 卡片 | 開啟 / 收合 | 收合的卡片會隱藏，且不在 Tab 鍵順序中 |
| 範例按鈕 | 不在訊息中 / 在訊息中 | 細外環 / 淡色填滿 |
| 傳送按鈕 | 閒置 / 等待中 / 已傳送 | 文字顏色 / 旋轉圖示 / 成功顏色加上勾號 |

### 手勢

- **按一下連結**即可收合或開啟其卡片；沒有預覽的連結會再抓取一次。
- **向上拖曳卡片**即可收合它。卡片會跟隨指標（拖曳到卡片高度的 80% 就會完全收合）；放開時若超過 40%，或以向上快速滑動放開，卡片就會收合，否則會以放開時的速度彈回開啟狀態。使用滑鼠或觸控筆時，整張卡片都可拖曳；使用觸控時只有標頭可以拖曳，因此在卡片內文上仍可捲動頁面。
- **範例按鈕**會貼上其連結，接著收合或開啟其卡片。

### 窄容器

訊息輸入框依其自身寬度調整大小：低於 560px 時內距會縮小，低於 360px 時 "Try" 會隱藏，讓範例按鈕與傳送按鈕維持在同一列（若仍放不下，範例會橫向捲動）。卡片會填滿較窄的卡片欄，圖片則維持 1.91 : 1 的比例。

### 內容指引

- 網站圖示請維持正方形；它們位於 16px 的欄位中，在連結與其卡片之間對齊。
- 標題請依頁面原本的寫法傳回；連結會在 224px 處截斷過長的標題，卡片則顯示完整標題。
- 描述請保持在一兩句話以內；卡片只顯示兩行。
- 當圖片具有意義時，請提供 `ImageAlt`；若未提供，輔助技術會把圖片視為裝飾。
- 請依訊息的去處為欄位命名（`Label`，"Message #trail-club"），並把它沿用為預留位置文字。

### 最佳做法

- 在你的伺服器上抓取預覽，設定較短的逾時，並傳回 null 而不是空白的預覽。
- 在傳回預覽之前先解碼圖片，讓卡片永遠不會在空白的畫面上開啟。
- 讓使用者移除不想要的預覽；移除按鈕也會把連結從訊息中拿掉。
- `AutoPlay` 請保留給行銷頁面與示範使用；在真正的訊息輸入框中請將它關閉（它只有在有範例時才會作用）。

### 常見問題

**文字會保留網址嗎？** 會。`Text` 與已傳送的訊息會完全依照貼上或輸入時的樣子保留網址；連結只是它的繪製方式。

**什麼算是網址？** 以 `http://`、`https://` 或 `www.` 開頭，且主機名稱含有一個點、頂層網域至少有兩個字母的文字。`https://x` 與 `localhost:3000` 會維持為文字。

**可以從程式碼開啟卡片嗎？** 請使用 `ExpandPreview`、`CollapsePreview`、`TogglePreview`、`RemoveLink` 與 `Retry`，並傳入取自 `Links` 的連結 `Id`；`Paste` 會在插入點加入連結，`Send` 則會傳送訊息。

## 無障礙

- 訊息是一個多行文字欄位，以 `Label` 命名，並以列出其按鍵的 `LinkUnfurlLabels.KeyHint` 描述。其狀態會依名稱列出連結：載入中時為網址加上 "preview on its way"，解析完成後為 "Link to site: title"。
- 連結是一個單位：插入點會跳過它，在它旁邊按一次 Backspace 或 Delete 就會整個移除。
- 每張卡片都有一個具名稱的收合按鈕與一個具名稱的移除按鈕，其標題是會開啟該網址的真正連結。收合的卡片會隱藏，且不在 Tab 鍵順序中；鍵盤焦點若位於正在收合的卡片內，會回到訊息。
- 禮貌即時區域會播報連結的加入、卡片的開啟、收合與移除、缺少預覽，以及已傳送的訊息。傳送錯誤會以果斷的警示出現在訊息輸入框下方。
- 載入狀態以掃光、淡色文字，以及取代網站圖示的地球圖示呈現，並且會被播報：從不只靠顏色。
- 鍵盤焦點會顯示 2px 的焦點環，並在按鈕上顯示淡色填滿；滑鼠焦點則不顯示。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| Enter | 傳送訊息 |
| Shift+Enter | 開始新的一行 |
| Alt+Enter | 開啟或收合插入點之前最近一個連結的卡片 |
| Backspace / Delete | 在連結旁邊時，移除整個連結 |
| 網址之後的 Space | 把網址轉成連結 |
| Tab | 從訊息移到每張開啟卡片的收合按鈕、移除按鈕與標題，然後移到範例與傳送按鈕 |

## 動態效果

- 一個彈簧進度驅動一張卡片：卡片被裁切成其連結的精確矩形，兩個網站圖示對齊，並移到連結上；隨著彈簧運行，裁切範圍會先變寬、再變深（寬度依循 1 − (1 − p)^1.6，高度依循 p^1.35），圓角半徑從 13 增加到 18，卡片下方的底板只在途中才會浮起並帶有陰影。內文在標頭之後淡入，圖片則從些微放大的狀態安定下來。開啟使用略為過阻尼的彈簧，約一秒穩定；收合則以較快的彈簧沿相同路徑反向運行。
- 卡片欄依相同的進度隨卡片一起變高，因此工具列會平滑移動而不是跳動。
- 預覽送達時，連結的寬度會在 340 ms 內緩動以符合標題，同時標題向上滾入，網站圖示彈出。
- 被移除的連結會在其卡片收合進去之後淡出並縮小消失。
- 傳送時，內容會向上移開（180 ms），訊息輸入框緩動到新的高度（480 ms），空白的欄位再淡入回來。
- `Speed` 會縮放形變動畫與模擬的抓取。減少動態效果與 `IsPaused` 會立即開啟與收合，並讓載入色調保持靜止。訊息輸入框離開視覺樹時，卡片會立即就定位。

## 響應式

- `LinkUnfurl` 依自身寬度變化，最寬 576 px：低於 560 px（`:compact`）時，編輯區、預覽區和工具列的內距變小；低於 360 px（`:tight`）時隱藏範例連結前的提示文字。
- 預覽卡最寬 440 px，隨輸入框一起縮小；過長的標題和描述以省略號結尾。
- 卡片上的按鈕是 30 px 的圓形，但點擊區域為 44 px，觸控時也容易點中。拖曳卡片即可把它折回，也可以用卡片的摺疊和移除按鈕；沒有功能依賴懸停。

## 相關元件

- `MentionInput`：一個文字欄位，支援 @人員與 #頻道 token，並在插入點提供建議。
- `RichTextEditor`：一個輕量、具格式功能的編輯器，適用於長篇文字。
- `HoverCard`：在滑鼠停留或取得焦點時預覽人員或連結，不必離開頁面。
- `TokenTextEditor`：此訊息輸入框所依據的編輯器，可用於你自己的行內 token 類型。
