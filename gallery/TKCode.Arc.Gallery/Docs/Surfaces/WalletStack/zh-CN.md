## 何时使用

`WalletStack` 像手机钱包那样展示几张卡：一小叠卡，最前面的卡在最上层，每张卡都用自己的材质绘制，带有芯片、非接触标记、压印卡号，以及一束跟随指针的光。选中一张卡，它会升到顶部，其余的卡收到下方，它的余额与最新交易随之出现在下面。放回去只需按一下、按一个键或向下拉一下。

- **几张支付卡、通行卡或会员卡**，用户每次打开一张查看上面的内容。
- **钱包与银行界面**，希望用实体卡的隐喻：真实的表面质感、层次，以及可以一张张翻看的卡叠。
- **有个性的账户选择器**：打开的卡就是选中的账户，`SelectedCard` 告诉你是哪一张。

## 何时不使用

- **账户很多**：超过五六张卡，卡叠会遮住太多内容。请使用列表或 `DataGrid`。
- **不是卡包的可滑动内容**：请使用 `CardStack`。
- **只需原地展开的一张卡**：请使用可展开卡片。
- **并排比较余额**：卡叠一次只显示一张卡；请使用表格或一组磁贴。

## 用法

按顺序给卡叠提供卡片（第一张在最前）和一个标签。其余都有默认值：en-US 区域的美元、内置的虚构卡组织标记和英文文案。

```xml
<arc:WalletStack Label="Mira’s wallet" Cards="{Binding Cards}" SelectedCard="{Binding OpenCard}" />
```

```csharp
var cards = new List<WalletStackCard>
{
    new()
    {
        Id = "current", Issuer = "Larkspur", Product = "Current account", LastFour = "5306", Holder = "Mira Castell",
        Expires = "08/29", Material = WalletStackMaterial.Metal, Balance = 2914.35m, BalanceLabel = "Available",
        Transactions =
        {
            new() { Id = "t1", Merchant = "Pinecrest Power", Detail = "Electricity · This morning", Amount = -96.40m, Icon = WalletStackIcons.Zap },
        },
    },
};
```

### 结构

- **标题行**：左侧是标签；右侧是计数（"1 of 4"），有卡打开时它让位给 "All cards" 按钮。
- **舞台**：放卡片的区域，比卡包左右各宽 12px，比一张卡高 220px。最前面的卡位置偏低，后面每张卡缩小 5% 并略微上移；翻过去的卡停在底边的口袋里，只露出顶边。
- **卡面**：发卡方与产品名、EMV 芯片、非接触标记、带后四位的掩码卡号、持卡人、"Valid thru" 与有效期，以及卡组织标记。每个细节都是卡宽的固定比例，因此较窄的卡包会整体缩放卡面。
- **交易明细**：位于打开的卡下方，先是余额及其标签和一条分隔线，然后是最新的三笔交易，每笔有圆形图标或姓名缩写、商户、明细和带符号的金额。

### 材质

`Material` 选择表面：`Metal`（默认，拉丝质感，带车削纹理和柔和的反光）、`Black`（细颗粒和雕刻的玫瑰纹）、`Glass`（磨砂玻璃：后面的卡透出来，模糊并略微提高饱和度）和 `Color`（任意 `Tint`，从左上较浅过渡到右下较深）。`Artwork` 把你自己的图片放在表面之下；`NetworkMark` 替换虚构标记，`ShowNetwork="False"` 则隐藏它。

### 手势

- 用鼠标**悬停**会让卡叠向上展开；被悬停的卡上升 8px、阴影加深，并朝指针倾斜最多 5 度，同时有一块高光跟随指针。触摸永远不会展开或倾斜。
- 在任意卡片上**上下拖动**即可翻卡。最前面的卡 1:1 跟随指针进入口袋，下一张卡随之前移；拖动在 8px 之后才开始，所以更小的晃动仍算作按下。松手时按当时的速度向前预估 0.2 秒，落到最近的那张卡，但与拖动开始处最多相差一张。越过第一张或最后一张时，卡叠会带阻力地拉伸并弹回。
- **点击**任意可见的卡即可打开它，即使是最前面那张后面的卡。有卡打开时，点击收起的卡可切换，点击打开的卡则把它放回。
- **向下拉打开的卡**即可放回：它以大约一半的指针速度跟随，预估位置越过一半时关闭；向下一甩则在更高处就能关闭。

### 你自己的数据与事件

`PositionChanged` 报告来到最前面的卡，`SelectedCardChanged` 报告打开的卡（放回时为 `null`）。这两个属性都是双向的，`Next`、`Previous`、`GoTo`、`Open` 和 `Close` 可以从代码驱动卡叠。

### 货币、区域与文案

`Currency`（ISO 4217 代码）和 `Culture` 决定所有金额的格式：余额使用货币样式，交易金额入账带 "+"，支出使用真正的减号。`Labels` 保存卡叠显示或朗读的全部文案；带数值的句子是委托，因此译文可以调整语序。

### 内容指南

- 发卡方名称保持简短（一两个词），产品名控制在几个词以内；过长的文字在卡上会以省略号截断。
- `BalanceLabel` 写成说明金额含义的短语："Available"、"Statement balance"、"Stored value"。在卡的朗读名称中它会转为小写。
- 交易明细用 "类别或地点 · 时间" 的形式，姓名缩写或照片只用于人。
- 有效期使用真实的 "MM/YY" 日期，或者让 `Expires` 留空。

### 最佳实践

- 按使用频率排列卡片：第一张卡是用户首先看到的。
- 保持在四五张卡以内；更深的卡会隐藏在第四张后面等待。
- 选择明暗差别明显的材质，让卡叠中的边缘清晰可辨。
- 当界面上其他部分依赖所选的卡时，绑定 `SelectedCard`，而不是在需要时再去读取。

### 常见问题

**卡片显示后还能修改吗？** 卡叠在卡片到来时读取它。要显示新数据，请在列表中替换这张卡（`ObservableCollection` 会被监听）；只要 `Id` 不变，打开的卡就保持打开。

**为什么余额会计数？** 打开一张卡时，余额从零开始向上计数；切换时从上一张卡的金额开始，使用与移动卡片相同的弹簧。在减少动效下，金额会立即显示。

**磨砂玻璃会模糊页面吗？** 它模糊的是卡叠中其他卡片和主题背景。舞台背后的其他内容不属于磨砂背景。

## 无障碍

- 舞台是一个以 `Label` 命名的分组，并带有键盘提示作为描述。只有最前面的卡（或打开的卡）在 Tab 顺序中。
- 每张卡都是带展开状态的按钮。它的名称依次读出发卡方、产品、后四位、位置和余额（"Larkspur Current account ending in 5306, 1 of 4, available $2,914.35"）；掩码数字、芯片和标记不会被读出。
- 礼貌级实时区域在另一张卡来到前面时播报 "… in front, 2 of 4"，在卡片打开时播报 "… open"。
- 交易明细是名为 "{issuer} activity" 的区域，其中的列表名为 "Recent activity on {issuer}"；没有卡打开时，它对辅助技术和输入都是隐藏的。
- 键盘焦点在卡外 2px 处绘制 2px 的焦点环，并随卡一起倾斜；指针焦点不绘制焦点环。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` | 移到最前面的卡；有卡打开时，先到 All cards 按钮，再到打开的卡 |
| `Down` / `Right` | 让下一张卡来到前面；有卡打开时，打开下一张卡 |
| `Up` / `Left` | 让上一张卡来到前面；有卡打开时，打开上一张卡 |
| `Home` / `End` | 第一张或最后一张卡 |
| `Enter` / `Space` | 打开最前面的卡，或把打开的卡放回 |
| `Escape` | 把打开的卡放回，焦点留在它上面 |

方向键不会循环。焦点跟随来到前面的卡。

## 动效

- 展开、悬停上升、倾斜与高光、翻卡、打开与关闭，全部使用同一条无过冲的弹簧（视觉时长约 0.4 秒）。打断时保留速度：可以在半空中抓住一张卡，再按一次键会让同一个运动改换目标。
- 打开时，卡以 88% 的大小升到顶部，其余的卡收成底部的一行；交易明细上升 16px，并在打开过程的后段淡入。各行在明细主体出现后的 80、136 和 192ms 淡入。
- 计数中的数字变化时向上滚动 6px；计数淡出后 40ms，All cards 按钮淡入并放大。
- 按下的卡在 160ms 内缩小到 98.5%。

| 变化 | 完整 | 减少 | 关闭 |
|---|---|---|---|
| 展开、上升、翻卡、打开 | 弹簧 | 立即 | 立即 |
| 倾斜与高光 | 跟随指针 | 保持平整，高光静止 | 保持平整，高光静止 |
| 交易行 | 错峰淡入并上升 | 错峰淡入 | 直接显示 |
| 余额 | 向上计数 | 最终金额 | 最终金额 |
| 计数与 All cards | 滚动并淡入淡出 | 淡入淡出 | 直接替换 |

## 响应式

- `WalletStack` 没有断点：它与所在位置同宽，最宽 296 px，卡片上的一切（卡号、芯片、标记、间距）都按这个宽度缩放，所以 260 px 宽的卡包就是完整卡包的缩小版。
- 卡堆下方的舞台高度是卡片高度加上展开与口袋所需的空间，请让卡包保持自然高度，不要压缩它。
- 触控时没有展开和倾斜（它们跟随鼠标）：上下拖动轮换卡片，点按一张卡打开它，把打开的卡向下拖即可放回。方向键、卡片按钮和 "All cards" 不需要手势也能完成同样的操作。
