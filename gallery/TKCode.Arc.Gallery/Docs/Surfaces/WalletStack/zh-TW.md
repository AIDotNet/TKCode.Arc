## 何時使用

`WalletStack` 像手機錢包那樣展示幾張卡：一小疊卡，最前面的卡在最上層，每張卡都以自己的材質繪製，帶有晶片、感應標記、壓印卡號，以及一道跟著指標移動的光。選取一張卡，它會升到頂端，其餘的卡收到下方，它的餘額與最新交易隨之出現在下面。放回去只需按一下、按一個鍵或往下拉一下。

- **幾張支付卡、通行卡或會員卡**，使用者每次打開一張查看上面的內容。
- **錢包與銀行畫面**，希望用實體卡的隱喻：真實的表面質感、層次，以及可以一張張翻看的卡疊。
- **有個性的帳戶選擇器**：打開的卡就是選取的帳戶，`SelectedCard` 會告訴你是哪一張。

## 何時不使用

- **帳戶很多**：超過五、六張卡，卡疊會遮住太多內容。請改用清單或 `DataGrid`。
- **不是卡夾的可滑動內容**：請使用 `CardStack`。
- **只需原地展開的一張卡**：請使用可展開卡片。
- **並排比較餘額**：卡疊一次只顯示一張卡；請使用表格或一組磚塊。

## 用法

依序提供卡疊的卡片（第一張在最前）和一個標籤。其餘都有預設值：en-US 地區的美元、內建的虛構發卡組織標記和英文文字。

```xml
<arc:WalletStack Label="Mira’s wallet" Cards="{Binding Cards}" SelectedCard="{Binding OpenCard}" />
```

```csharp
var cards = new List<WalletStackCard>
{
    new()
    {
        Id = "current", Issuer = "Larkspur", Product = "Current account", LastFour = "5306", Holder = "Mira Castell",
        Expires = "08/29", Material = WalletStackMaterial.Metal, Balance = 2914.35m, BalanceLabel = "Available",
        Transactions =
        {
            new() { Id = "t1", Merchant = "Pinecrest Power", Detail = "Electricity · This morning", Amount = -96.40m, Icon = WalletStackIcons.Zap },
        },
    },
};
```

### 結構

- **標題列**：左側是標籤；右側是計數（"1 of 4"），有卡打開時它讓位給 "All cards" 按鈕。
- **舞台**：放卡片的區域，比卡夾左右各寬 12px，比一張卡高 220px。最前面的卡位置偏低，後面每張卡縮小 5% 並略微上移；翻過去的卡停在底邊的口袋裡，只露出頂邊。
- **卡面**：發卡機構與產品名稱、EMV 晶片、感應標記、帶末四碼的遮罩卡號、持卡人、"Valid thru" 與有效期限，以及發卡組織標記。每個細節都是卡寬的固定比例，因此較窄的卡夾會整體縮放卡面。
- **交易明細**：位於打開的卡下方，先是餘額及其標籤和一條分隔線，接著是最新的三筆交易，每筆有圓形圖示或姓名縮寫、商家、明細和帶正負號的金額。

### 材質

`Material` 選擇表面：`Metal`（預設，髮絲紋質感，帶車削紋理和柔和的反光）、`Black`（細顆粒和雕刻的玫瑰紋）、`Glass`（霧面玻璃：後面的卡透出來，模糊並略微提高飽和度）和 `Color`（任意 `Tint`，從左上較淺過渡到右下較深）。`Artwork` 把你自己的圖片放在表面之下；`NetworkMark` 取代虛構標記，`ShowNetwork="False"` 則隱藏它。

### 手勢

- 用滑鼠**懸停**會讓卡疊向上展開；被懸停的卡上升 8px、陰影加深，並朝指標傾斜最多 5 度，同時有一塊高光跟著指標移動。觸控永遠不會展開或傾斜。
- 在任何卡片上**上下拖曳**即可翻卡。最前面的卡 1:1 跟著指標進入口袋，下一張卡隨之前移；拖曳在 8px 之後才開始，所以更小的晃動仍算是按下。放開時依當下的速度往前預估 0.2 秒，落到最近的那張卡，但與拖曳開始處最多相差一張。越過第一張或最後一張時，卡疊會帶阻力地拉伸並彈回。
- **點按**任何可見的卡即可打開它，即使是最前面那張後面的卡。有卡打開時，點按收起的卡可切換，點按打開的卡則把它放回。
- **往下拉打開的卡**即可放回：它以大約一半的指標速度跟隨，預估位置越過一半時關閉；往下一甩則在更高處就能關閉。

### 你自己的資料與事件

`PositionChanged` 回報來到最前面的卡，`SelectedCardChanged` 回報打開的卡（放回時為 `null`）。這兩個屬性都是雙向的，`Next`、`Previous`、`GoTo`、`Open` 和 `Close` 可以從程式碼驅動卡疊。

### 貨幣、地區與文字

`Currency`（ISO 4217 代碼）和 `Culture` 決定所有金額的格式：餘額使用貨幣樣式，交易金額入帳帶 "+"，支出使用真正的減號。`Labels` 保存卡疊顯示或朗讀的全部文字；帶數值的句子是委派，因此譯文可以調整語序。

### 內容指引

- 發卡機構名稱保持簡短（一兩個詞），產品名稱控制在幾個詞以內；過長的文字在卡上會以刪節號截斷。
- `BalanceLabel` 寫成說明金額意義的短語："Available"、"Statement balance"、"Stored value"。在卡的朗讀名稱中它會轉為小寫。
- 交易明細用 "類別或地點 · 時間" 的形式，姓名縮寫或照片只用於人。
- 有效期限使用真實的 "MM/YY" 日期，或者讓 `Expires` 留空。

### 最佳做法

- 依使用頻率排列卡片：第一張卡是使用者最先看到的。
- 保持在四、五張卡以內；更深的卡會隱藏在第四張後面等待。
- 選擇明暗差異明顯的材質，讓卡疊中的邊緣清楚可辨。
- 當畫面上其他部分依賴所選的卡時，繫結 `SelectedCard`，而不是在需要時再去讀取。

### 常見問題

**卡片顯示後還能修改嗎？** 卡疊在卡片到來時讀取它。要顯示新資料，請在清單中替換這張卡（`ObservableCollection` 會被監聽）；只要 `Id` 不變，打開的卡就保持打開。

**為什麼餘額會計數？** 打開一張卡時，餘額從零開始往上計數；切換時從上一張卡的金額開始，使用與移動卡片相同的彈簧。在減少動態效果下，金額會立即顯示。

**霧面玻璃會模糊頁面嗎？** 它模糊的是卡疊中其他卡片和主題背景。舞台背後的其他內容不屬於霧面背景。

## 無障礙

- 舞台是一個以 `Label` 命名的群組，並以鍵盤提示作為描述。只有最前面的卡（或打開的卡）在 Tab 順序中。
- 每張卡都是帶展開狀態的按鈕。它的名稱依序讀出發卡機構、產品、末四碼、位置和餘額（"Larkspur Current account ending in 5306, 1 of 4, available $2,914.35"）；遮罩數字、晶片和標記不會被讀出。
- 禮貌層級的即時區域在另一張卡來到前面時播報 "… in front, 2 of 4"，在卡片打開時播報 "… open"。
- 交易明細是名為 "{issuer} activity" 的區域，其中的清單名為 "Recent activity on {issuer}"；沒有卡打開時，它對輔助技術和輸入都是隱藏的。
- 鍵盤焦點在卡外 2px 處繪製 2px 的焦點環，並隨卡一起傾斜；指標焦點不繪製焦點環。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| `Tab` | 移到最前面的卡；有卡打開時，先到 All cards 按鈕，再到打開的卡 |
| `Down` / `Right` | 讓下一張卡來到前面；有卡打開時，打開下一張卡 |
| `Up` / `Left` | 讓上一張卡來到前面；有卡打開時，打開上一張卡 |
| `Home` / `End` | 第一張或最後一張卡 |
| `Enter` / `Space` | 打開最前面的卡，或把打開的卡放回 |
| `Escape` | 把打開的卡放回，焦點留在它上面 |

方向鍵不會循環。焦點跟著來到前面的卡。

## 動態效果

- 展開、懸停上升、傾斜與高光、翻卡、打開與關閉，全部使用同一條無過衝的彈簧（視覺時長約 0.4 秒）。中斷時保留速度：可以在半空中抓住一張卡，再按一次鍵會讓同一個運動改換目標。
- 打開時，卡以 88% 的大小升到頂端，其餘的卡收成底部的一列；交易明細上升 16px，並在打開過程的後段淡入。各列在明細主體出現後的 80、136 和 192ms 淡入。
- 計數中的數字變化時往上捲動 6px；計數淡出後 40ms，All cards 按鈕淡入並放大。
- 按下的卡在 160ms 內縮小到 98.5%。

| 變化 | 完整 | 減少 | 關閉 |
|---|---|---|---|
| 展開、上升、翻卡、打開 | 彈簧 | 立即 | 立即 |
| 傾斜與高光 | 跟著指標 | 保持平整，高光靜止 | 保持平整，高光靜止 |
| 交易列 | 錯開淡入並上升 | 錯開淡入 | 直接顯示 |
| 餘額 | 往上計數 | 最終金額 | 最終金額 |
| 計數與 All cards | 捲動並淡入淡出 | 淡入淡出 | 直接替換 |

## 響應式

- `WalletStack` 沒有斷點：它與所在位置同寬，最寬 296 px，卡片上的一切（卡號、晶片、標記、間距）都依這個寬度縮放，所以 260 px 寬的卡包就是完整卡包的縮小版。
- 卡堆下方的舞台高度是卡片高度加上展開與口袋所需的空間，請讓卡包保持自然高度，不要壓縮它。
- 觸控時沒有展開和傾斜（它們跟隨滑鼠）：上下拖曳輪換卡片，輕觸一張卡開啟它，把開啟的卡向下拖即可放回。方向鍵、卡片按鈕和 "All cards" 不需要手勢也能完成同樣的操作。

## 相關

- `CardStack` 用於可滑動的內容卡片。
- `HoloCard` 用於一張帶全像箔、可以翻轉的卡。

| 元件 | 何時選擇 |
|---|---|
| `WalletStack` | 幾張卡，每次打開一張查看餘額與交易 |
| `CardStack` | 使用者滑動瀏覽的內容卡片 |
| `HoloCard` | 一張會傾斜和翻轉的收藏風格卡片 |
| `DataGrid` | 在欄中比較許多帳戶 |
